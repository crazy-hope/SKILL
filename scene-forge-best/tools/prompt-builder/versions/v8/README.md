## 多选如何生成

02“想画什么”多选默认作为候选范围，07“数量”决定最终方案数。例如选 21 项、数量 5，模型按必须项和创作自由度选配 5 个不同方案，不要求用户先选 5 个编号或逐条分组。

“建筑环境”“人物肖像”等画面类型可与具体场景结合，不机械计为独立场景。候选多时选择合适方向；候选少时围绕已选内容设计动作、视角、结构或关系变化；只有一个场景时围绕它展开。相容内容可以组合，但不为凑齐所有候选而把无关场景硬拼成一张图。

03“必须包含”继续是硬性要求。明确写“全部必须体现”“逐项独立成图”或固定组合时优先遵循，不以候选规则省略。只有明确硬性要求无法兼容时才澄清。未填写人数不等于冲突，普通细节按创作自由度补齐，保留明确人数及“另一名”等关系。

结果的方案说明需说明所用候选与关键设计假设，首条概括本批次选配情况；未采用候选保留在原始输入，不代表已画或自动安排后续任务。可复制的中英文正文只描述对应画面。
