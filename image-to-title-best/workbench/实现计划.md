# 图片文案工作台 v1

目标：读取项目已确认的 skill，使用 React 与 Ant Design 构建本地双语短视频文案工作台。

## 实现决策

- 原 skill 版本不变；工作台代码保存在 `workbench/v1`，独立 `CURRENT` 选择启动版本。
- React、Ant Design、Vite 前端；Node 本地 HTTP 服务；Zod 校验模型结果；仅监听 127.0.0.1。
- 单图上传与预览、可选描述、模型设置、看图测试、生成／取消、画面分析、五组中英文、推荐、标签复制及结果下载。
- OpenAI 与 DeepSeek 使用官方视觉模型预设；另支持用户配置 OpenAI 兼容接口。API Key 只在当前页面内存或本地已忽略的环境文件中，不写浏览器存储或日志。
- 每次生成从根目录 `CURRENT` 加载完整 skill 并校验对应版本，发送真实图片内容。失败明确显示，无模拟结果回退；测试用模型服务仅在测试目录。
- 根目录 `.command` 定位启用版本、检查 Node、按锁文件安装依赖、构建并启动，成功后打开浏览器。端口占用不终止其他进程。

## 实施与验证

1. 先建立后端行为测试：skill 读取、请求中图片及规范、双语结构、错误与版本校验、密钥隔离、请求取消。
2. 实现服务与前端，补齐启动和版本脚本、使用说明。
3. 运行测试与生产构建；用本地测试上游验收完整请求链和浏览器上传、设置、结果、取消、复制、移动布局。
4. 核查 `.command` 可执行及重复启动行为，记录真实 API 未配置时的验证边界。

范围：本地应用，不发布站点、不改动旧 skill、不提交父仓库中其他项目的变更。
