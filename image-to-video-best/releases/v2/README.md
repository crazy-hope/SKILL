# 图生视频提示词 Skill

根据画面氛围、动作、材质、时序和目标模型，选择**简短 / 中等 / 细致**三档。默认中文、5秒；用户指定优先。

项目维护入口：[Agent.md](Agent.md) → [AGENTS.md](AGENTS.md)。所有修改记录在 [CHANGELOG.md](CHANGELOG.md)，保存与回退见 [VERSIONING.md](VERSIONING.md)。

当前完整项目快照：`releases/v2/`；网页版本：0.3.0；Skill推荐版本：v2。三者独立管理，后续完整项目依次保存到releases/v3、v4，不覆盖旧版。

## 页面工作台

已提供本地网页 **成镜**：上传图片、填写简短需求，按三档规则生成提示词，支持复制与Markdown导出。启动命令为 `npm start --prefix web`，默认地址为 [http://127.0.0.1:3210](http://127.0.0.1:3210)。

真实生成请点击页面右上角「配置模型接口」，填写兼容OpenAI的多模态服务地址、模型与密钥，保存后立即生效。详见[配置与使用](web/README.md)、[页面验证记录](web/VALIDATION.md)。应用默认只读使用v2资料快照，不改变已发布技能；尚未接入在线检索或视频生成。

v2的细致档充分展开材质外观、分层运动、动作牵引、持续状态与光影氛围，同时保留用户指定的动作、运镜方向、速度、先后顺序和收尾；不会因为进入特写就自行加速。规则和测试不等于真实视频效果保证。

## 使用

选择一个版本中的整个 `image-to-video-best` 文件夹作为技能包，保留其中的相对目录。不要同时安装多个同名版本。本项目没有自动安装、替换已有技能或调用视频生成服务。

可直接让支持本地技能的助手读取 [SKILL.md](v2/image-to-video-best/SKILL.md)，提供图片、目标模型及期望动作。例如：

> 使用 image-to-video-best。目标 Runway Gen-4.5 官方网页，时长5秒。根据这张图片自动选择等级，给中文提示词、简短设计原因与必要设置。

> 使用细致档，目标 Seedance 2.5，7秒。图片中的人物单手施剑诀，流体持续回旋；请先确认我使用的平台，再给适配提示词。

可查看[分级规则](v2/image-to-video-best/references/levels.md)、[原始参考案例分析](v2/image-to-video-best/references/cases/liquid-goddess.md)和[本次流光衣服反馈分析](v2/image-to-video-best/references/cases/flowing-clothes.md)。

## 更新与回退

1. 已发布版本保持完整快照；日常在线查证不会自动修改它。
2. 用户要求更新时，将上一版完整复制到下一个尚不存在的版本目录，例如v3。不要提前创建空版本，也不共享可变资料。
3. 在新版本中修改规则与资料，记录官方来源、核查日期、行为变化及原因。旧验证结果作为历史证据标明，重新执行新版本测试。
4. 验证技能格式、资料链接、独立复制使用、行为案例及旧版校验和；更新新版本发布说明与校验清单后，才更新这里的推荐版本。
5. 回退时选择历史技能包，并修改推荐版本索引；不覆盖历史目录。文件夹版本保存与父仓库Git可以并用，本次未操作其他项目的暂存内容或提交历史。

每版的 `SHA256SUMS` 记录该版全部文件（不含清单自身）的校验值。可在版本目录运行 `shasum -a 256 -c SHA256SUMS` 检查历史内容是否改变；这是完整性检查，不是防篡改签名。根索引不属于冻结快照。

## 验证边界

[验证记录](v2/validation/REPORT.md)区分格式/行为测试和真实视频效果。用户原案例被报告为准确稳定；本项目未获得成片、模型和实际设置，未进行视频生成对照。模型资料会变化，使用时按技能要求核查当前官方入口。
