# 尺度与空间规则

## 必须具备的五层空间

每幅场景都要包含以下五层，并按所选画幅调整：

1. **近景巨型框景**：被裁切的屋檐、龙柱、松干、悬崖、门边或平台底部。
2. **人物承载阈境**：宽阔开放的露台、台阶、廊道、桥头、镜面地坪或云崖边缘。
3. **主导事件**：一个连续的宫殿、柱廊、墙体、门洞、宫基、屋顶系统或浮雕体量。
4. **从属天域**：克制后退的墙体、屋顶带、次级宫殿体量、云岛或桥线。
5. **终端远景**：云海、更高天界、遥远主宫、山峦、天光或无边天空。

绝不能把场景压缩成前景墙加空天空、一座漂在雾中的宫殿，或没有垂直分层的连续屋顶海。

## 内容承载空气

画面约40–60%应为有信息的空气：云隙、天空、开敞庭地、门洞空间、宫基下方虚空、体量间距、水面或极远处光域。

前景阈境必须在视觉和物理上连接这片外部空间。被连续中景墙困在后面的云景不算开放空气。

除非用户明确要求人物浸入云中，主云海应位于人物承载面之下。仅在宫基、瀑布和云边局部使用雾气；绝不使用均匀灰色薄幕。

## 主体占比

- 常规巨构：主导连续体量约占画面50–70%。
- 最大压迫感：若仍能通过开口和裁切周围清楚读到至少35%的外部云、天空或虚空，主体可占65–80%。
- 不要为了展示完整城市而缩小主巨构。
- 不要用额外的同等地标填满开放天域。

### 结构性天环例外

- 天环外轮廓必须100%收入画面，圆周与画框四边之间保留清楚的呼吸空间；任何一侧都不能被画框截断。
- 天环应位于中远景或远景，不作为贴近镜头的前景框景。完整环体连同支撑体系通常占画面约35–60%，同时保留人物承载面、从属宫阙、云层和终端远景。
- 纤细桥线、支撑柱或薄云带可以局部越过环体，但不得遮成只剩半环、四分之一弧或无法闭合的弧段。缩略图下必须一眼读出完整圆形。
- 天环直径至少以数百个成年人宽度来描述；再用微小人物、跨云层支撑、环内宫阙和大气层级证明它的宏伟，不能用近景放大冒充尺度。

## 可量化的尺度证据

至少加入四项可见证据：

- 成年人尺度标记采用已经确认的四档之一：`0.5–2%`极远尺度标记、`2–4%`强巨构尺度、`4–8%`标准巨构（默认）、`8–12%`人物叙事增强；最终必须在所选档内锁定一个具体画面高度占比；
- 主柱直径约为6–10个成年人高度，柱高约为50–100个成年人高度；
- 主开口高约25–50个成年人高度；
- 屋檐、墙、桥、露台或屋顶横跨数百个身体宽度；
- 至少一个形体延伸出画框；
- 重复的柱、屋顶或墙段朝远处消失点逐步缩小；
- 宫基、瀑布或悬崖穿过两层或更多云层；
- 主人物周围保留15–30个身体长度的开放表面；
- 极远处宫殿即使距离遥远仍保持宏伟。

仅有裁切不算证据。仅有密度也不算证据。

## 人物尺度档与镜头距离

在最终提示词或生图前提供以下选项供选择和确认：

1. `0.5–2%｜极远尺度标记`：最强巨构断层，人物接近剪影但仍能辨认完整人体，适合天环、悬空宫基和超远跨度。
2. `2–4%｜强巨构尺度`：人物清楚可辨但极小，优先强调震感、压迫感和超远建筑跨度。
3. `4–8%｜标准巨构（默认）`：人物动作可读但明显从属，兼顾空间真实性、尺度参照和巨构压迫感。
4. `8–12%｜人物叙事增强`：人物动作和服装更可读，建筑仍须占绝对主导；不用于需要极端渺小感的画面。

确认档位后，在该闭区间内随机锁定一个具体百分比并写入参数锁定。用户不选择、明确要求直接执行或不再提问时，使用默认档，在`4–8%`内随机锁定具体值。不同变体可以分别随机，但每张图必须报告自己的确定值。

镜头必须离人物足够远，使人物以完整全身出现。人物必须真实站立或行走在平台、桥面、台阶、柱础旁或其他明确承载面上，脚底接触、接触阴影和遮挡关系必须成立。人物的作用是把建筑比例显出来；禁止通过靠近人物、肖像景别、半身构图或浅景深把人物提升为主角。建筑与人物之间至少同时展示两项可量化关系，例如柱径为`6–10`个人高、主开口为`25–50`个人高或跨度达数百个身体宽。

## 同一空间与连续尺度链

固定尺度链为：`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`。“当前主导巨构”必须替换为本图实际抽中或指定的屋檐、柱廊、宫基、云崖露台、巨型开口、瀑布、浮雕墙、巨柱、天环、天障或长廊，不得写成候选列表。人物一级不可省略；每幅至少从人物起连续显示其中四级，优先完整显示五级。尺度证据必须沿同一个连续三维空间传递，不能从互不相干的画面区域拼凑。

- 人物、承载面、建筑与巨构共享同一地平面、地平线、主导消失系统和镜头焦距；同一深度的人物大小一致，距离越远则按透视连续缩小。
- 人物脚底与承载面真实接触；投影方向、软硬和长度服从场景主光，人物与建筑之间存在正确遮挡和接触阴影。
- 近处结构更清晰、反差更高，远处宫阙、天环、天障与云层按距离逐级降低反差、纯度和细节；人物不得拥有与所在空间层冲突的锐度、色温或雾化程度。
- 每个相邻层级至少给出一个直接可读的大小或距离关系。画面百分比只决定人物在成图中的可读大小，不能替代场景内以成年人身高为基准的真实比例。
- 禁止后贴人物、拼贴人物、悬浮脚、错位投影、人物与建筑透视不一致、不同焦距拼接，以及只靠近景裁切或广角畸变伪造巨构。

## 机位纪律

- 默认使用人眼高度或更低、水平到轻微仰视的机位。
- 远距离使用70–100mm，压缩无尽屋脊、墙体和逼近的巨型体量。
- 外部阈境、门洞、露台和可信建筑局部使用35–50mm。
- 只有接近宫殿、宫基下构和柱阵才使用24–35mm直线广角；保持足够拍摄距离，避免前景畸变。
- 不要把超广角畸变与长焦压缩同时使用。
- 只有明确要求展示城市布局时才使用高位或鸟瞰视角。
- 结构性天环使用远景或超远景、人眼高度或略低机位，优先70–135mm；拍摄距离必须足以容纳完整圆周、支撑体系和至少三层远近空间。禁止24–35mm贴近环体的局部特写。
- 所有人物尺度档都采用远离人物的观察距离。即使选择`8–12%`档，也通过焦距和构图保持人物全身与建筑环境同框，不切换为人物近景或肖像镜头。

## 透视与距离

选择一个主导消失系统。控制垂直线。人物、台阶、柱列、平台、宫阙、天环或天障必须服从同一地平线和消失点；重复构件的尺寸和间距随距离一致缩小。近景平面更暗、更锐利、纹理更多；远景更亮、更冷、反差更低，但不能变成灰色。

## 无栏杆规则

所有露台、平台、台阶、桥梁、廊道、崖边和建筑边缘默认保持开放、无栏杆。用铺地、层级变化、柱列、光线、种植、水体或结构节奏界定通行路线。
