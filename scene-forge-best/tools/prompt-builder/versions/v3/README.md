# 提示词工作台 V3

基于 [工作台 V2](../v2/README.md)，使用 [规范 V5](../../../../versions/v5/输出/规范框架v5.md)。保留八张条件卡片，新增可编辑“负面提示词”输入框，共九项输入。

## 使用

1. 如旧服务仍运行，先在对应终端按 Control+C；双击根目录 [启动提示词工作台.command](../../../../启动提示词工作台.command)。需要 Python 3.9+，无第三方依赖。
2. 在同一浏览器地址 `http://127.0.0.1:8787` 使用，右上配置 OpenAI / DeepSeek 文本模型。
3. 负面提示词已预填“不要有水印，不要有logo，不要有变形，不要有空白黑边”，可编辑、清空或写“无”。修改自动保存；重置恢复默认。其他八项仍按原方式填写。
4. 点击底部生成，结果按方案展示中文和英文；支持互斥展开、一键复制、汇总 Markdown 下载，以及每个方案一个 Markdown 的 ZIP 下载。

## 兼容与数据

草稿、预设和历史继续使用原本地存储，不因升级丢失。旧草稿/预设作为新任务补入默认；旧历史原样保留，查看和下载不追补该字段。把旧历史恢复为新的输入时会显示当前默认，可以在生成前修改。

负面提示词为空时表示不添加该字段的默认约束，其他字段的明确约束仍有效。中英文由文本模型按规范适配，不保证实际图片绝无缺陷。

密钥仍单独保存在当前浏览器地址的本地存储，可在配置中清除，不进入备份、历史、源码或日志。更换浏览器、端口或清理站点数据不会共享原存储。
