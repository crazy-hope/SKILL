## 本次真实会话证据

旧版提示词为四位仙女逐一指定发型、衣色、左右手、托肘、扶叶、持盘与拨花，并要求玉盘、悬滴、面部和全部手势清楚。原文例如：“右手掌托住她左肘下方，左手扶住她的左前臂”“焦点覆盖四人的互动与盘上方的露滴”。

用户提供两张 Midjourney 结果，明确图2对应上述采露提示词，图1对应另一段花瓣下躲雨提示词：

- 图1：四张可辨人脸，人物占幅大，紧凑近景，湿发与局部衣料反光明显；虽然原提示词要求三人、中大全景，结果并未遵守这些要求。
- 图2：三张可辨人脸，中间后方人物明显失焦，前景两人的五官轮廓可辨但皮肤较平滑；人物占幅更小，玉盘及协作采露动作没有清楚成立。
- 可据此描述成图的景别、焦点、材质和指令执行差异；不能证明长提示词、人数、某个词或某年代风格导致卡通化。不同结果的随机条件未被控制。

这不是新增生图实验，也不是对全部输出有效性的证明。验证对象是 skill 的写作与分析行为。

## 本轮验收清单

- [x] 根据特写／中景／远景选择细节尺度；按用户补充要求，所有景别的人物与可见面部都清晰，不把后排或远处人物自动虚化，柔光不等于人物失焦。
- [x] 多人都要清楚时处理距离与遮挡；方式1不能为实现共面而移动人物或改变动作。
