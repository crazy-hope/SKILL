## 需求与验收条件

| 编号 | 要求 | 验收条件 |
|---|---|---|
| R-01 | 创作意图可独立驱动生成 | 只填写感觉或模糊想法即可生成；不要求补选题材、主体或元素 |
| R-02 | 元素默认为灵感，明确必需才锁定出现 | 点击候选或添加自定义元素默认为参考；可逐项标记必须出现；参考可不采用，必需对象逐方案保留 |
| R-03 | 模型可设计库外主体与关系 | 不发送完整候选库作为生成边界；不再限定只能补辅助对象；人物由创作意图决定，明确无人及其他禁止条件仍约束生成 |
| R-04 | 属性与出现要求分别表达 | 参考对象的属性只在采用时适用，不自动升级为必须出现；必需关系不允许因省略目标而失效 |
| R-05 | 多方案形成实质差异 | 在硬约束内允许不同主体、概念、结构及关系，不能只换光色；实际设计和双语一致 |
| R-06 | 规范与应用一致，保护旧版数据语义 | 新完整规范V11与工作台V15独立保存；旧规范、旧应用和旧创作存储不重写；新数据完整保存参考/必需语义 |
| R-07 | 完整功能验证与记录 | 前后端、双服务请求、草稿/预设/历史/备份/下载、生产构建与桌面手机验证；真实模型及出图状态如实记录 |
