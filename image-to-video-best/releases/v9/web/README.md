# 成镜 · 图生视频提示词工作台

当前产品 **0.7.1**，React 19 + Ant Design 6 + Vite，默认加载独立规范 **v6**。左侧镜头任务，中间图片与创作设置，右侧提示词预览；窄屏切换编辑 / 结果。生成提示词与设置建议，不生成视频。

目标模型有四个独立选项：**Seedance 2.0、Seedance 2.5、Kling O3、Kling 4.0**。可灵两项均为快手平台，具体网页/API入口与账号能力仍按资料及用户输入判断。

## 启动

需要 Node.js 22.13 或更新版本。交付包包含 `dist/` 构建产物，运行本机后端无需安装依赖。

macOS可双击根目录 [启动工作台.command](../启动工作台.command)，也可以运行：

```sh
npm start --prefix web
```

默认打开 [http://127.0.0.1:3210](http://127.0.0.1:3210)。脚本从自身位置定位目录，读取现有配置，服务就绪后才打开浏览器。保持启动终端运行；Control+C停止本次启动的服务。重复启动可复用可识别的实例，不终止其他端口占用者。升级后若旧实例占用端口，请在原终端停止它再启动新版，或在运行副本设置不同PORT。不要将启动文件单独移出项目。

## 创作流程

1. 默认4个镜头；点击左侧切换，用加号新增，编辑区右上角复制当前图片与要求为新镜头。各任务独立保存当前页面状态。
2. 点击、拖入或在图片区域粘贴首帧。支持PNG/JPEG/WebP；上传后可替换或移除。需求可留空，根据图片自动构思；有需求则优先保留动作、速度、主体和收尾。
3. 选择目标视频模型、详细程度、时长、画幅。默认自动等级、5秒、保持原图。细化动作、运镜、环境、手部、声音等要求可展开填写；平台入口可选填。
4. 点击「生成提示词」，右侧直接阅读。也可「全部生成」并发处理已上传、未完成或待更新任务；已完成、运行中和失败任务会跳过。失败镜头单独「重试生成」。
5. 右侧在完整提示词、设计与设置、资料来源之间切换；复制正文、提交版或全部，导出Markdown。正文保持用户指定的六段结构，明确要求单行时由规则按同一逻辑合并。
6. 取消或编辑正在运行的镜头会停止等待旧请求；迟到响应不能覆盖新要求，其他镜头继续。旧结果保留并标记待更新。保存或清除连接配置会使当前页面全部旧结果失效。

并发速度、限额和费用由看图服务决定；工作台不自动重试。取消会中断本机等待并尝试取消连接，不能保证上游尚未处理或计费。图片、需求与结果仅在当前页面内存中，刷新前请导出；有内容时注册离开提醒，浏览器是否弹出取决于其规则。

时长与比例是用户目标，不擅自改写为某平台限制；不支持或未确认的组合由结果说明。细节单项上限2000字符，主需求6000字符；页面限制与后端一致。

## 连接看图写词服务

右上角「配置服务 / 连接设置」打开抽屉：

1. 选择OpenAI、DeepSeek或自定义预设，填写API根地址。
2. 填写API Key，填写支持图片输入的看图模型ID，或「测试并读取模型」后选择。
3. 「保存配置」立即生效，无需重启。测试与保存期间表单锁定，避免旧接口响应混入新配置。

预设只填API地址，模型ID由用户确认。此模型负责理解图片、写提示词；编辑区的Seedance和可灵是目标视频模型，二者职责不同。

接口需支持Chat Completions的 `image_url` data URL、多模态输入、system消息和中文JSON输出。仅名称上“OpenAI兼容”不保证这些能力。模型列表只请求 `/models`，不发送图片；列表成功不等于模型具备视觉能力，不支持列表的服务可手动填ID。

地址会追加 `/chat/completions`；远程必须HTTPS，本机可HTTP，不填查询参数、嵌入凭据或完整completions端点。已保存Key不回显，同一地址留空沿用，更换地址需要重新填写。关闭抽屉清空未保存密钥；清除后不会恢复.env旧值。

配置在 `web/.local-connection.json` 以0600权限原子写入，已忽略且不进入版本包；它是本地明文文件，不是加密密钥库。浏览器不存localStorage，GET配置和创作结果不回传密钥。

`.env`可提供初始配置；保存/清除后持久配置优先。端口与限制仍通过.env配置，修改后重启：

```dotenv
PORT=3210
LLM_TIMEOUT_MS=120000
MAX_IMAGE_MB=10
```

生成超时范围1000—600000毫秒，模型列表最多15秒。图片上限0.01—10MiB且不超过8000万像素；浏览器检查解码和格式，服务端检查大小、编码、签名及尺寸。接口配置齐全不代表真实生成已验证。

## 规范与资料

当前版本统一在 `lib/catalog.mjs` 声明；前端通过配置API取得版本与模型选项。请求完整包含v6 Skill、图像分析、六段结构、场景动态、创作保真、等级、连续性、资料核查规则，画面效果与约束取舍规则，以及**仅所选模型卡**。用户原始需求、全部细节和图片一起进入请求；空需求保留为空并允许模型自主设计。

v6保持六段规则：全局基础硬性设定、场景基底、主体动态细节、运镜规则、同期环境音效、硬性约束。三档调整展开粒度，不改变用户意图；只有图片时给建议设计。两张水下图仍为一组学习参考，不当独立对照实验。

API显式指定v1/v2可读取当时四模型，v5可读取Seedance 2.0/2.5和可灵O3/4.0，当前界面只显示本次四型号。规范可独立使用，发布新目录不会自动切换应用。

每次生成使用**资料快照，本次未在线复核**。日期取所选卡：Seedance保留2026-10-17资料，可灵卡为2026-10-25。Kling4卡只核对官方索引摘录，正文抓取未成功；8,000 tokens不等同字符上限，未确认API字段保留未知。源链接由后端补充，不让模型伪造在线访问。未进行真实看图模型或视频效果验证。

## 效果核对

“设计与设置”新增**效果核对（模型自检）**：逐项显示用户要求或自主设计、用户原文、完整正文及提交版的对应摘录。模型需在交付前修正强度降低、对象范围遗漏、强制收尾或过度姿态锁；运动强度与三档详细程度独立，固定/轻柔/指定停住仍遵从用户。

程序只检查记录结构和引文是否逐字存在，不能判断所有语义是否相符、是否漏掉其他关键要求或视频是否实现。模型未提供记录、引文无出处、提交版缺对应句或模型主动标注问题时，显示待复核提示并保留正文。不会自动再次调用服务或丢弃可用输出。复制全部与Markdown导出包含记录，单独复制提示词仅含正文。

一次生成仍只有一次上游请求；核对记录会增加少量输出内容。旧版结果没有该字段仍可显示，不把历史结果标成已核验。当前程序没有独立视觉/语义评分器，不把关键词命中或正则检查冒充创作质量验证。

## 开发与验证

```sh
npm ci --prefix web
npm run build --prefix web
npm test --prefix web
```

源码在 `src/`，通用任务/图片/导出函数保留在 `public/`；Vite关闭public自动复制，只将构建产物放入dist。已移除旧版原生界面文件，历史源码保存在完整项目快照中。修改源码后必须重新构建再使用双击入口。

开发热更新：另开终端启动默认3210后端，再运行 `npm run dev --prefix web`。Vite仅监听回环；代理仅改写来自自身同源回环页面的Origin，生产后端Origin校验保持不变。更改后端端口时相应修改开发代理target。

```sh
node web/test/dev-qa.mjs
# 安装开发依赖后运行，临时端口验证真实Vite代理，无外部请求。
```

浏览器验收使用已安装Playwright与Chrome，未捆绑浏览器、不自动下载：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs BROWSER_EXECUTABLE=/absolute/path/to/chrome npm run test:browser --prefix web
node web/test/preview.mjs
```

手动模拟预览为 `http://127.0.0.1:3211/?mock=1`，明确标记本地模拟，不加载保存的密钥，不是真实模型验收。自动测试需要本机回环监听权限。详见[验证记录](VALIDATION.md)与[执行记录](PROGRESS.md)。

## 数据与边界

只有点击生成才将图片和需求发给配置的服务；本地不写创作历史或完整请求日志。上游数据保留规则由服务商决定。应用仅监听127.0.0.1，Host/Origin限制与静态构建资源白名单保护配置；Ant Design动态样式需要style-src允许内联，脚本仍限同源。未提供公开部署、多用户认证、在线检索或视频生成。

## 刷新样式兼容（0.7.1）

工作台使用独立的组件主题缓存标识，避免浏览器扩展中的另一套React/Ant Design主题覆盖工作台样式。此次修复无需关闭扩展或清空浏览器数据；重新加载即可读取新前端。已有Node服务的页头产品版本来自启动时加载的配置，服务正常重启后显示0.7.1，不为更新标签强制终止已有服务。

可用 `npm run test:refresh --prefix web` 运行刷新回归，需要Playwright及浏览器；支持PLAYWRIGHT_MODULE和BROWSER_EXECUTABLE环境变量。使用独立本机服务、模拟外来主题覆盖，测试桌面/窄屏加载、刷新、主题变量、控件尺寸和下拉框，不读取真实配置或调用生成服务。
