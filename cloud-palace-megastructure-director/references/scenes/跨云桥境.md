# 跨云桥境

## 场景说明

围绕“跨越空隙”组织巨构：桥面连接明确承载端，下方云峡揭示跨度与下构。宏大天庭桥境以桥串联庞大建筑体系；用户明确要求独立单桥、纯结构研究或排除宫廷时，采用桥与两端平台/山体构成的独立空间。可选物件按空间作用取舍，“非必需”不等于禁止出现。

## 空间细类

- 横跨云峡：两端平台或山体明确，桥腹与深云隙共同可读。
- 桥上行进：桥面延向另一端，但仍留侧向证据说明宽度与厚度。
- 桥外侧台：人物站在宽阔、纵深很长的侧台或廊台上，经可见节点真正接入桥头或桥侧，不把人物另放在孤立的小观景石板上。
- 桥下仰望：下构主导，人物如有应在另一个真实下层平台而非半空。
- 弯桥/折桥：路径转向，桥头与墩台承接折转。
- 断桥端点：仅明确点名断桥时选用，其余部分维持完整受力归属。

## 物件调用

核心为[桥](../objects/桥.md)、[云雾](../objects/云雾.md)；侧台、承台或宫基读[平台与宫基](../objects/平台与宫基.md)，山体承载端读[山体与浮山](../objects/山体与浮山.md)。桥型从物件库选，不因场景名锁死为梁桥或拱桥。选用横向巨殿时读[宫殿](../objects/宫殿.md)，巨门开口读[门窗与巨型开口](../objects/门窗与巨型开口.md)，有顶廊台读[长廊](../objects/长廊.md)；人物、松树或瀑布按实际选用再读取，不整表加载。

## 尺度与连接

可用踏步/栏板→桥头承台→桥面与桥腹→主跨/云峡→远端支承与云海。桥下机位沿下层步道→宫基或山根→深梁/拱脚→主跨起链。悬挂假桥墩不能替代连接，桥面纵深不能替代宽度。

## 桥外人物与天庭连通

空间卡先明确“人物承载面 → 接桥节点 → 跨云主线 → 远端建筑或承载体”，再选择观看关系。

- 人物在桥外时，侧台或廊台要同时有宽度和长纵深，能从人物近旁追踪到中景接桥处；相接地坪、厚台体及转折连续可读，有高差则展示阶道或坡道。人物与侧台、桥共享相机透视、光照及真实接触关系，不靠将人物推到远处制造小点。
- 宏大天庭桥境中，桥由近景进入中景，再延向远处的厚宫基、巨门或横向巨殿。选与通行主线相符的连接对象，展示桥头嵌接、入口或地坪衔接，让桥属于同一庞大天庭体系，不以无数小亭阁说明规模。
- 为压迫感安排近旁高耸支承、上方有承重归属的悬置体量与深处云峡：例如从侧台向下延入云峡的墩/柱，以及向上承托深檐、廊盖或高位桥腹的结构。各层由同一空间关系串起，不把装饰块无支撑地吊在人物头顶。
- 桥外人物场景中，主桥纵深与侧台纵深同时成立；云域解释高差和远度，不代替建筑跨度与厚度。即使人物不缩小，也应从她近旁可用踏步、台体、主支承、桥系及宫基读出尺度跃迁。桥上行进仍由桥面承载人物，不为套用此细类把人物移出桥面。

## 可选观看关系

宏大纵深桥境优先选择能同时看见桥面横向宽度、向深处延伸和桥腹的机位，如侧台偏轴看桥头至远端、较低机位看桥侧并沿通行方向入深景。严格侧向适合横跨关系或结构研究；需要长纵深时，不用“不是沿桥看远处”锁死观看方向。桥下、高位、折转等变体仍可选，按实际可见面验证差异；人物侧面/背影不意味着桥只能严格侧拍。焦距、人物朝向与距离沿用共用尺度规则。

## 组合与检查

组合宫门、水庭、巨壁或山台时，先解开标高与连接。保持桥的通行主线清楚，宫基、巨门或横向巨殿可以成为它的承载端与延续，而不是孤立的第二个小焦点。松树可作近旁尺度参照，瀑布可说明落差；根据需要选用，不强制添加，也不因“可选”将整个类别写进负面提示。

检查：人物若在桥外，脚下空间是否宽、深且真实接桥？桥是否同时呈现宽度、厚度与远伸，而非短小全桥？天庭桥境是否能追踪到厚宫基、巨门或巨殿？近旁高耸支承、上方重量与深云峡是否共同建立压迫感？独立单桥按用户范围检查，不为补清单增添宫廷。

宏大天庭桥境可选片段：『成年仙女侧身站在宽阔而纵深悠长的廊台上，可用踏步从她近旁接入厚重桥头；桥面宽若空场，从近景跨入中景并延向远处横向巨殿的厚宫基，侧下方深桥腹与墩台承接清楚。廊台高柱托起上方深檐，桥墩向下穿入翻涌云峡，近处使用层、巨大承台、桥系与远宫连续递进，建筑大面安静。』只借用实际选择的关系，不把此例变成全部桥境的固定构图。

## 命名示例

只有明确选择以下断桥方案时才锁定其断口与右下至左上的方向；普通随机桥境不继承断口、单瀑或固定左右。

### T4. 断桥对角巨瀑

- 适用：用户要求极简的桥头人物、唯一巨瀑和强烈对角线关系，不需要宫殿城市作为第三焦点。
- 空间关系：一座厚重、受力可信的断桥从画面右下伸入开放云域，成年仙女完整站在断桥最前端，向左上方仰望唯一一条巨瀑；瀑布从上方画外落下并贯穿至少三层云带。默认保持“右下桥头 → 左上瀑布”的方向，只有用户明确要求镜像时才反转。
- 机位与尺度：35–50mm的桥基平视、桥下低机位、轻俯或严格侧向机位；人物大小由桥面、下构厚度与瀑布空间层次决定，不指定画高。断口是用户指定的单一结构事件，桥体其余部分保持洁净完整并显示梁、托臂或桥腹厚度。
- 连续尺度链：`成年仙女 → 桥面与断口 → 桥身和下构 → 跨越多层云域的唯一巨瀑 → 云海终景`。
- 避免失败：不要第二条瀑布、宫殿天际线、桥从左侧进入、瀑布居中或居右、人物离开桥头、断桥变成漂浮薄板、过曝白瀑或整幅废墟化。
