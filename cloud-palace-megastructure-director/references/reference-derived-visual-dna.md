# 参考图视觉基因

本参考文件从提供的云宫图像中提炼可迁移特征。它不授权复制任何完整源构图、艺术家身份、文字、Logo或水印。

实际参考图和截图的角色标注见[参考图巨构标准](reference-image-megastructure-standard.md)；物件构造按[物件总览](objects/物件总览.md)选读。无参考图时不为了单个物件或多图任务加载参考图处理文件。

## 核心视觉承诺

1. **一个主导巨构关系**：最有力量的画面让单体建筑或由屋顶、柱廊、墙体、桥梁、山体与水系组成的复合系统具有清楚主次。小建筑可以丰富世界，只要不平均争夺注意力。
2. **空间释放或有意围合**：外部路线可直接开放到云海、天空、深渊或极远处；内殿、巨门、桥下和仪式空间也可以通过框景、光线和尺度形成有意围合，不必全部改成露台。
3. **有意不完整**：屋顶、柱阵、宫基或墙体延伸出画框。结构性天环是明确例外：必须用远景完整展示圆周，并依靠支撑跨度、人物与相邻参照和多层天域建立尺度，不能把圆环裁成局部弧段。
4. **纵深重复**：重复构件按实际深度缩小，平行方向保持一致消失关系，转折与曲线允许方向变化。远景通常降低细节与反差；不强制更亮或更冷。
5. **断层式尺度**：真实体型的成年人、巨柱、充满画框的结构和遥远天界锚点分别占据明显不同的尺度层级；人物的渺小感来自相对巨构的空间关系，不要求缩成画面中的小点。
6. **可控的装饰密度**：安静巨面是默认策略；高度装饰、仪式高潮或繁复彩画场景也可扩大细节覆盖，只要结构和主次仍清楚。
7. **可读的氛围**：采用建筑与材质参考的统一光照池；用户指定其他天气时按扩展处理，保留方向和材质层次，避免色罩与过曝。
8. **有主次的自然对形**：巨松、瀑布、悬崖、云河、雪线、雨幕或风暴云可以单独或少量组合，并通过尺度、位置和反差服从主构。

## 可迁移场景家族

以下只展示视觉可能性，不是封闭场景池。实际空间组织从[场景总览](scenes/场景总览.md)按需选择或组合，镜头与随机变化见[构图路线](composition-routes.md)；不要把列举物件全部加入一幅图。

- 云海上方的无尽曲檐与柱阵。
- 被裁切的宫殿下构，下方悬着城市或云隙。
- 面向云海彼端遥远主宫的外部露台。
- 揭示更高天界的巨大门洞或建筑开口。
- 瀑布或光柱切开一体化宫殿巨构。
- 巨型雕刻墙或龙纹浮雕与无尽空明相平衡。
- 云崖宫殿一角连接后退墙体与一棵古松。
- 隔着云峡正面遥望对岸巨构与完整支撑体系。
- 从桥腹、宫基或下层平台仰看悬空体量。
- 从深殿内部穿过柱阵直接看向开放天域，或从外部反向看入巨门。
- 人物位于巨型屋顶台原、跨云桥面、垂直阶崖、柱海前场或云河水庭。
- 隔着辽阔正面轴线前场，以长焦正视巨墙、巨门、长阶或柱群。

## 不得继承的内容

- 手机外框、黑边、灵动岛形状、播放器控件或音量浮层。
- 字幕、倒计时文字、Logo、印章、签名或水印。
- 参考图中抢占画面、横贯开放空间或遮挡尺度关系的栏杆；结构合理、局部从属的栏杆可以重新设计后使用。
- 受版权保护的精确人物、服饰、坐骑或可识别的专有设计。
- 参考图生成瑕疵：不可能的重复人物、扭曲柱体、克隆屋顶、不连贯桥梁或形似UI的开口。

## 层级测试

默认外部云宫在缩略图下按以下主次阅读；内殿或桥下路线可由开口、明暗与云隙表达空间，用户指定无人时使用替代参照，不强迫出现仙女或露台：

1. 一个巨型建筑轮廓；
2. 一片开放天界虚空或云域；
3. 一个从属于建筑的尺度标记或自然锚点。

如果缩略图读作许多大小相近的屋顶、塔楼或浮岛，应先简化再继续。
