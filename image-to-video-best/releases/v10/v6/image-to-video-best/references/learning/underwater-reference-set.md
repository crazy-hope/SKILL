## 可迁移的结构和关系

两组正文均依次使用：全局基础硬性设定、场景基底、主体动态细节、运镜规则、同期环境音效、硬性约束。用户要求以此作为规范的默认结构，详细职责见[六段结构](../prompt-structure.md)。

| 参考中的表达 | 学习价值 | 不能据此推出 |
|---|---|---|
| 前景、远景、所有、全程、持续 | 运动有对象范围和时间范围 | 所有场景必须全员运动 |
| 环境动态优先，人物为视觉核心 | 动态重点与构图重点可以不同 | 环境可以吞没人脸或取消人物动作 |
| 被水流带动、平台起伏、鱼群穿梭 | 不同对象有驱动与不同节奏 | 所有材质统一成水浪或同步摆动 |
| 部分坐下、部分跑动、有人眺望 | 群体共同状态与个体任务分开 | 每个人依次执行全部动作 |
| 触手卷糕点、递到唇边、轻咬 | 执行者、物体、接收者存在连续接触关系 | 吃东西只能用手，或者允许凭空新增触手 |
| 光线提亮、光束移动、面部光影偏移 | 整体变化与局部响应相连 | 自动布光或自动景深是已核实接口参数 |
| 无配乐，保留环境声和偶尔笑声 | 音乐、对白、非语言人声、环境声分开 | 无对白等于禁止笑声，或无配乐等于静音 |
| 开头重点、中部实施、末尾持续约束 | 同一意图可在不同层次落实 | 机械重复越多越有效 |

图1的主要启发是环境与群像共同构成镜头；图2的主要启发是前景交互与背景持续活动并行。材质、光影、群体规模与镜头距离影响控制的展开程度，而非仅靠字数分档。

## 原文歧义与迁移边界

图1的巨大叶状承载面有薄膜般透光和褶皱，不能仅凭图片确定真实植物种类或运动机制。人物有不同姿态与发式，增强散发和裙摆运动不等于拆掉发髻。相机后退会改变景别；保持人物与场景身份不等于构图像素固定。群像远景不承诺每张脸达到特写级细节。

图2可见立体吸盘触手状结构，原文开头的“触手纹样”与后续独立取食需要区分；连接点和总数量不能凭遮挡区域猜测。“单手抵桌、手掌托腮”需明确同一手臂的支撑部位或双手分工；首帧未托腮就要交代过渡。“身体右侧”与“画面右侧”不能默默互换。原图无法证明背景人物是侍女，也不能证明小鱼一定清楚可见；用户指定的小鱼可作为新增设计。

“剧烈”应保留其强度意图，分别确定幅度与速度，不擅自改为轻摆；强动态不要求所有对象同频抖动。“全程不停”针对冻结，不排斥摆动自然换向。“缓慢光影”和“快速影子”若作用于同一现象同一时段，需说明冲突；若解释成整体缓变与局部光斑较快，应明示这项设计解释，不冒充原文已规定。

水下亭台、悬浮承载面、取食等属于幻想世界观，可保留并设计局部可信的受力、支撑和接触。发丝声、沙沙声和远处笑声可以是幻想拟音；不能从图片确认其自然录音效果。胶片、摄影感、无配乐和强水流均是本组选择，不自动成为其他任务默认。

本组只用于学习与解释规则来源。验证采用另外明确构造的跨题材请求，并保留新旧实际输出；不将本组原文当标准答案，也不宣称效果已经复现。
