# 本轮需求

- 日期：2026-10-16；事前记录。
- 用户要求：每次根据目标图像模型生成匹配提示词；补充其他模型的官方文档链接到规范，让工作台使用对应规则，解决结果偏向 Midjourney 的问题。
- 基线：规范 V5、工作台 V4。

## 要求与验收

- R-01：完整规范 V6 增加五类目标模型的官方链接、查阅日期、规则适用范围；不添加题材元素库。
- R-02：目标图像模型与编写提示词的 OpenAI / DeepSeek 文本接口独立；工作台从规范直接提取对应适配规则，连同完整规范发送。
- R-03：分别处理描述组织、负面要求、画幅及参数位置；未知或未指定目标不回退 Midjourney，不冒充已核实具体版本。
- R-04：拒绝非 Midjourney 提示词中的 Midjourney 参数；结果、历史、备份及 Markdown 下载记录目标、规则、官方来源和查阅日期。旧历史不补造来源。
- R-05：保持九项输入、双语、默认负面与清空、密钥隔离、内容库、旧版本；更新索引启动入口并记录实际验证边界。

## 范围与假设

官方规则为本轮查阅的本地快照；普通文本接口没有自动打开文档链接的能力，本轮不添加联网代理或实时爬取。未指定目标输出通用自然语言；自定义模型仅在明确识别家族时采用保守规则，具体版本/平台能力待核实。来源链接不等于已验证出图效果。实际付费调用和图片生成不在本轮范围。
