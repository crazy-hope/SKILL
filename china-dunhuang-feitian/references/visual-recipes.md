# 视觉配方：分类后的可控融合

## 主模式选择

用户明确指定优先；只说“中国敦煌飞天”或“随机来一张”采用“融合重彩”。这些是本 skill 的设计模式，不是历史时期名称。

| 模式 | 人物与画面 | 材质及光照 | 适用口令 |
|---|---|---|---|
| 融合重彩（默认） | 清晰全身、屈伸凌空，红青披帛，适度卷云与冠饰 | 细描、平涂轻层染，少量壁面颗粒和边缘磨蚀，柔和漫射光 | 敦煌飞天、来一张、国风重彩 |
| 青绿古壁 | 小到中等人物，大面积青绿／暖白长带组织画面 | 哑光平面、黑褐轮廓、低对比露底，不出现真实投影 | 古朴、青绿、壁画感、飘带主导 |
| 深褐金线 | 修长舞姿或旋升，深底亮人，细密装饰集中在冠颈腰 | 深褐平面底，少量旧金描线和稀疏金点，不整体金属化 | 暗底、华丽、金线、赭金 |
| 洞窟斜光 | 中等立体人物，古壁／圆拱局部框景 | 暖色定向斜光、相应阴影，旧墙颗粒，人物适度立体 | 洞窟、斜光、壁画走出来、现代光影 |
| 真人摄影 | 真人皮肤、真实布料厚度、大裙摆与细带对照 | 可信光源、景深与衣料高光，可少量金尘 | 真人、摄影、商业大片 |
| 静态造像（题材分支） | 静立或安静半身，垂带、冠饰、可选头光／莲台 | 与用户选择的绘画模式一致，默认为低饱和细描 | 菩萨式、造像、静立莲台、庄严肖像 |

摄影模式仅在需要商业主视觉时加入产品，依照用户给定产品设计互动关系。没有产品任务时，不自动放置化妆品、圆形包装或品牌标志。

## 配色系统

以下 HEX 是从可见色彩关系归纳的创作用近似值，不是像素取色、颜料鉴定或文物原色。色名“石青／石绿”描述观感。

| 色族 | 建议色值 | 角色 |
|---|---|---|
| 暖砂、纸土 | `#B59A70`、`#D4C39E` | 默认底色、安静留白 |
| 赭褐、烟褐 | `#72513D`、`#493A30` | 深底模式、局部边缘 |
| 青绿、灰石绿 | `#398D83`、`#80AB99` | 主要披帛、腰布、卷云 |
| 朱赭、赭红 | `#AB4E32`、`#843F31` | 裤裙、第二主带 |
| 暖白 | `#E9DCB8` | 肌肤、浅色带、少量云纹 |
| 旧金 | `#BA985B` | 冠饰、项链、细小纹样 |
| 墨褐 | `#302C29` | 发髻、勾线、少量最深对比 |

默认面积可从“暖土背景约一半，红青衣带合计约三成，暖白肌肤及浅带约两成，金饰仅零星点缀”开始调整；这只是组织色块的建议，不按像素硬算。脸部靠明度与周围暗发区分，不靠整张打白。青绿古壁减少红色，深褐金线降低背景明度；同系列保持同一套关系。

## 身体与披帛的构图语法

1. 用一句话说清动势，例如“向右掠飞，胸腔前引，骨盆稍滞后，双腿朝左屈伸”。没有方向的“仙气飘飘”不能代替结构。
2. 给身体一条主长弧。肩胯略错向，手势延伸或轻轻反向制衡，避免四肢同时往不同方向发散。
3. 先安排 2—3 条主要披帛路径，再按画幅补少量细带。每条说明起点、跨越身体的前后关系、外部回环和收尾；回环长度大于局部碎褶的尺度。
4. 较宽布面表现身体运动后的拖曳，较细飘带扩大路径；不把披帛画成硬管、触手、翅膀或围住全身的铁环。
5. 卷云在下部、侧缘或运动尾部响应主弧；脸、手和乐器附近留出净空。只选一种主装饰语言，避免莲花、佛像、藻井、沙丘、金尘同时堆满。

| 动势 | 身体骨架 | 披帛与留白 | 注意 |
|---|---|---|---|
| 纵向旋升 | 上身略转，一腿折回、一腿向下伸展 | 带向上延伸，顶部安静空间 | 不是站在地面上的抬腿舞者 |
| 横向掠飞 | 胸腔前引、头朝运动方向、髋腿滞后 | 长带拖向身后，运动前方留白 | 身体在小图中仍能辨识 |
| 回身顾盼 | 身体前行、头轻回望，肩胯方向不同 | 一条外侧回环回应头部转向 | 颈部转角自然 |
| 俯冲伸手 | 对角线身体，上方大布面，下方前伸手 | 前手附近净空，带向上后方拖曳 | 写实大裙摆只在摄影等相容模式采用 |
| 持奏乐舞 | 琵琶斜放身前，手位分别对应琴颈与弦面 | 带绕外部，不横切主要手位 | 乐器结构清楚，别误写反弹 |
| 双人交会 | 一主一辅或两条互补弧线 | 披帛可呼应，但各自起止清楚 | 不让不同人物共用一条手臂或身体 |

## 线描、装饰与表面

- 人物外轮廓与主衣褶稍明确，五官和首饰较细；用线和小面积层染表现转折。默认不使用摄影式鼻影、高光皮肤或厚重立体渲染。
- 冠饰、璎珞、臂钏可精致，但分别只保留一个主要节奏；首饰服从人物，不能构成与脸同等亮度的大金属装甲。
- 壁面纹理分为底层细颗粒、局部色层不均、少量边缘露底。默认人物五官与手指保持可读，不将裂纹均匀铺满皮肤。
- “古朴”通过色层与线条表现，不自动添加脏污、废墟、阴森照明。“华丽”通过配色和描线表现，不自动增加强光粒子。
- 严格平面分支使用绘画内部的层次；洞窟斜光分支使用明确光源与一致阴影。选定一种空间逻辑。

## 系列变化

为系列建立一条共享设定，包含人物冠发、衣饰结构、色板、媒介、肌理、光照、画幅。每张都将该设定实际写入独立提示词；再改变动作与空间组织。例如：同一融合重彩人物依次纵向旋升、横向掠飞、回身顾盼。乐器只在用户选择乐舞或允许题材变化时加入。

用户只要求随机姿态时，不随机到摄影、静立莲台或深褐金线；用户要求“不同风格”时才跨模式变化。明确指定的参数不被随机覆盖。
