# 传统建筑彩画配色

使用本参考文件把传统彩绘建筑参考转译成原创仙侠巨构。保留的是颜色落位、矿物颜料表现、风化方式和材质层级，而不是源建筑、朝代复原方案、屋顶轮廓、斗拱纹样、栏杆、牌匾、文字、园林布局或水印。

## 参考图配色基因

所提供的参考图家族支持四种不同观感：

1. **岁月深檐**：褪朱、氧化蓝绿、低纯石青、尘赭、烟黑木材、粉灰沉积和窄小磨损旧金边缘。
2. **鲜明复原楼阁**：矿物朱红柱与窗、石绿和松石青斗拱、群青梁枋分区、赭金屋面、象牙白留白和清澈冷色日光。
3. **朱青长廊**：孔雀青柱、朱红椽条与窗框、群青横梁、蓝绿斗拱、浅灰石地和方向明确的投影节奏。
4. **朱红宫门**：大面积朱红柱、墙与门；窄石绿、松石青和石青梁枋带；赭色与象牙白彩画留白；细旧金轮廓；深栗红凹部和灰石台基。

不要把环境颜色自动采样成建筑漆色。蓝天属于氛围，树叶和花朵属于景观；参考图中横贯画面的栏杆、牌匾、说明牌、文字和水印属于排除项。结构合理的局部栏杆可以重新设计后使用。建筑石青通常比天空更深、更具矿物感、更哑光。

参考真实古建时先按[真实古建转译](真实古建转译.md)区分四类颜色：木构漆色和彩画、屋面瓦色、台基/墙体材料色、环境光色。本文件四条彩画路线只负责第一类及其构件绑定，不把黄/绿/蓝琉璃瓦另算成第五套油漆，也不把夜间金光或落日暖光采样成建筑固有金漆。

## 构件绑定语法

颜色必须服从建筑构造：

- **矿物朱红/辰砂红**：选定的结构柱、门扇、窗框、椽条、窄梁面，以及用户要求时的格栅状开口。
- **石绿/孔雀石绿/孔雀青/松石青**：青色长廊路线的柱列、斗拱主体、拱臂、梁底和受檐保护区。
- **石青/群青/靛蓝**：横梁、梁枋彩画面、天花分区、斗拱深凹部和冷色阴影锚点。
- **赭黄/琥珀赭/老黄釉色**：屋面、脊构、椽头和选定彩画面板。
- **象牙白/月白/粉灰**：彩画留白、面板呼吸区、灰泥、石台基和材质分隔。
- **旧金/淡金**：屋脊细节、瓦当、雕刻凸脊、轮廓和磨损凸缘；绝不能涂满整个天域。
- **深栗红/烟褐/蓝黑木色**：凹进的门、梁芯、深檐和明度锚点。

默认不要把所有颜色铺到每种构件上。面积最大的建筑平面通常保持安静，多色彩画集中在屋檐、斗拱、梁枋带、门窗开间和可识别阈境；仪式高潮或高度装饰路线可以提高覆盖率，但仍须保留构件逻辑和颜色主次。

## 配色路线1——鲜明复原·朱青赭金

适用于维护良好或刚修复的宫殿建筑，应显现矿物颜料，而不是合成亮漆。

建筑表面参考配比（非固定配额，可按构图与光照调整）：

- 32%矿物朱红用于柱、门、椽条和选定框架；
- 22%石绿、松石青和孔雀青用于斗拱或梁底；
- 13%石青、群青和靛蓝用于梁枋分区；
- 12%赭黄或琥珀色用于屋面与脊构；
- 8%深靛或烟黑木色用于凹部；
- 8%象牙白、月白或粉灰用于留白和石材；
- 5%淡旧金用于轮廓和磨损凸起强调。

风化等级：仅保留5–8%的克制证据——可见木纹、手工施彩颗粒、发丝级接缝、轻微柱脚磨损，以及受檐保护区少量积尘。颜料保持鲜明，但绝不能呈现塑料、镜面或工厂式均匀崭新。

```text
传统青绿彩画宫殿，鲜明复原·朱青赭金：矿物朱红绑定巨柱、门扇、椽条与窄框，石青石绿和孔雀青绑定斗拱、梁枋与檐底承重转换区，群青靛蓝压住梁枋分区和深檐，赭黄琥珀色用于屋面与脊饰，月白和灰白石材提供留白，淡旧金只勾瓦当、脊线和受光凸缘；手工矿物颜料颗粒、轻微木纹与5–8%自然使用痕迹，高明度、色块清楚、鲜明而不荧光。
```

## 配色路线2——岁月包浆·黯彩青绿

适用于古老但仍有人居住、结构完好的建筑。年代感必须遵循暴露与使用规律，而不是叠加随机脏污纹理。

建筑表面参考配比（非固定配额，可按构图与光照调整）：

- 25%烟褐或黑化老木；
- 20%氧化石绿、松石青和铜绿残留；
- 16%褪色矿物朱红和赭红漆面；
- 14%尘赭、老黄和土金色屋顶；
- 12%靛蓝、石青和受保护蓝黑凹部；
- 8%粉灰、露木和浅色矿物沉积；
- 5%磨损旧金或铜色脊构。

风化等级：30–40%可读包浆，同时结构保持完整。朝阳颜料粉化褪色；迎雨表面留下纵向雨痕；经触碰或凸起边缘露出较暖的木材或铜；接缝积尘；柱脚和石缝局部变深；受保护檐下保留更强的原始蓝绿和朱红。避免坍塌、腐烂、均匀开裂、棕色怀旧滤镜和废墟措辞。

```text
传统青绿彩画宫殿，岁月包浆·黯彩青绿：烟褐老木和蓝黑檐影为深值，褪朱与赭红留在柱、椽和门框，氧化石绿、铜绿和暗石青保存在斗拱凹部与檐下，尘赭和老黄压在屋面与脊饰，粉灰沉积和露木只出现在真实受风化位置，旧金仅残留于磨损凸缘；日晒褪色、纵向雨痕、柱脚磨亮、檐下积尘、石缝轻盐析，古老但仍在使用，绝非废墟。
```

## 配色路线3——朱青长廊·碧柱绛枋

适用于极长廊道和重复柱阵。颜色重复必须强化透视，而不是制造红绿棋盘格。

建筑表面参考配比（非固定配额，可按构图与光照调整）：

- 30%孔雀青、孔雀石绿或松石青结构柱；
- 22%矿物朱红椽条、窗框、门框和窄梁肋；
- 15%群青和靛蓝横梁或天花分区；
- 10%石绿和石青斗拱节点；
- 8%深木色和蓝黑檐影；
- 10%浅灰石材、象牙白面板和地面反光；
- 5%赭色与旧金椽头或凸起强调。

风化等级：12–18%生活使用痕迹。朝阳朱红轻微粉化，受保护的蓝绿保持更深，柱脚有接触磨损，石质行走轴被轻微磨亮，檐部积一层薄尘。

```text
传统青绿彩画宫殿，朱青长廊·碧柱绛枋：孔雀青与石绿巨柱形成纵深节拍，矿物朱红只用于椽条、格扇、门窗框和窄梁肋，群青横梁与靛蓝天花分区压住顶部，青绿斗拱只集中在承重节点，灰白石地稳定高彩木构，赭黄旧金仅点瓦当和梁端；近处朱青清晰、远端逐级降纯度和反差，不做红绿棋盘格。
```

## 配色路线4——朱红宫门·青绿彩画

适用于纪念碑式宫门、宫殿立面或被裁切墙体，由红色大体量主导，彩画带保持从属。

建筑表面参考配比（非固定配额，可按构图与光照调整）：

- 45%矿物朱红用于柱、墙面、门和窗框；
- 16%深栗红用于凹进的门、窗和梁下阴影；
- 14%石绿、松石青和孔雀青斗拱或梁枋带；
- 8%石青和群青彩画面板；
- 7%赭色、象牙白和低纯黄色留白；
- 7%灰白石台基和阈境；
- 3%细旧金轮廓和凸起扣件。

风化等级：选择5–8%修复复原、12–18%生活使用或30–40%岁月包浆，并明确说明。红墙和柱应形成宽阔安静的主面。彩画梁枋形成窄小水平层级，而不是覆盖整个立面。

```text
传统青绿彩画宫殿，朱红宫门·青绿彩画：大面积矿物朱红落在巨柱、宫墙、门扇与窗框，深栗红压住门窗和檐下凹部，石青石绿、孔雀青与群青只组成梁枋和斗拱窄带，米白赭黄用于彩画留白，灰白石台基稳定下部，旧金只作细轮廓线和磨亮凸缘；红色主面安静，彩画带清楚但不喧宾夺主。
```

## 整帧整合

### 琉璃瓦与台基的相容组合

以下是源型相容关系，不是固定套餐：皇家中轴宫廷可用黄琉璃瓦、朱红木构、青绿彩画与白石台基；圆形祭祀殿可用深蓝琉璃瓦、朱红环形柱网、青绿梁枋与白石圆台；水庭宫苑可用黄绿琉璃瓦、红柱、青绿彩画与灰白岸台；地方寺观或南方院落可用灰黑陶瓦、褪朱木构和群青孔雀青彩画。单幅选择一个主导组合并按实际构件落位，不把四组平均混合。

建筑表面参考配比不能替代场景整体色彩层级。天空、云、空气、水和浅色石材通常构成稳定基底，高纯度彩绘建筑保持清楚主次；夜景、风暴、内殿或彩画高潮可以改变面积关系，不需要满足固定百分比。

近景建筑更暖、纯度更高；远处彩绘建筑更冷、更亮、反差更低，但不能变灰。用暖阳照亮暴露的朱红、赭色和金色边缘；用冷天光填充檐下，使石绿、石青和靛蓝保持可读。

## 参考图与负面约束

始终排除源图精确屋顶轮廓、层数、斗拱组合、长廊布局、窗棂、宫门构图、脊兽位置、铃铛、花木位置和人物位置，除非用户明确要求。排除横贯或遮挡尺度关系的参考图栏杆，以及牌匾、说明牌、可读文字、印章、Logo、签名、水印、UI和边框；局部栏杆可以原创重构。

```text
不要彩虹式平均铺色，不要圣诞式红绿对撞，不要RGB霓虹，不要每种颜色同等纯度，不要把天空蓝误涂成建筑群青，不要把花木珊瑚色自动继承为宫殿色；不要塑料亮漆、镜面金、无差别全局色罩、所有构件统一崭新、随机均匀做旧、满墙裂纹、棕黄怀旧滤镜或废墟化；高度装饰可以存在，但不要让所有构件拥有完全相同的细节密度；栏杆保持局部从属，不要横贯开放空间或遮挡尺度链；不要文字、牌匾题字、说明牌、水印、Logo、印章、签名、截图UI或黑边；不要复制参考建筑完整构图、屋面轮廓、斗拱组合、门窗比例、长廊布局或专有纹样。
```

## 审计

- 是否明确命名所选彩画子路线？
- 是否把每种颜料绑定到明确构件，而不是全局铺开？
- 是否把天空、植被和花朵与建筑漆色分开？
- 是否把建筑参考配比当作可调起点，而不是固定面积配额？
- 是否明确风化等级及其物理落位？
- 装饰密度是否有清楚层级；高度装饰路线是否仍能读出结构？
- 旧金和高纯度强调是否保持窄小？
- 栏杆若存在，是否原创、局部且不遮挡尺度关系？文字、牌匾、水印和源图特有设计是否全部缺席？
