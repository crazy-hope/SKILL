# 图片生成标题与配文：v3 规范

日期：2026-10-31。完整执行规则及 JSON 协议见 [SKILL.md](image-to-title-best/SKILL.md)。

本版将创作目标明确为：从单张或整组图片提炼主题、感受、观点或问题，再用标题概括一个核心意思，用配文展开意义与共鸣。可用一两个视觉细节支撑表达，不能停留在景物清单，也不能脱离素材写通用鸡汤。

标题与描述都允许疑问、陈述、反问、惊叹；根据内容自然选择，不按语气凑数。主题问句不等同于邀请互动，不通过问号计数判断质量。额外邀请读者回应仍以最多一组为宜。

保留整组生成五个备选、中英对应、推荐一组、共用标签、图片读取和事实边界。五组是整组素材的五个备选总标题与配文，不是逐图命名。JSON 字段结构不变，skill_version 改为 v3。

配套工作台 v4 取消旧问号拦截，并在请求中强调主题提炼与配文展开。旧工作台 v1—v3 仍有问句限制，请使用 v4。旧 Skill v1、v2 保留；根目录 CURRENT 指向 v3，workbench/CURRENT 指向 v4。
