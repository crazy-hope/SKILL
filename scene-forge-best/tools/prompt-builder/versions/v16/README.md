# 提示词工作台 V16：围绕场景构思

日期：2026-10-30；状态：已交付，代码与模拟集成检查通过。基线：[V15](../v15/README.md)；配套[完整规范V14](../../../../versions/v14/输出/规范框架v14.md)。

先写核心场景或一个想法，点击构思获得三个简短画面方案；选中喜欢的一个，再展开为完整中英文提示词。构思数量固定三个，最终方案数量可设1—10个，默认5个。只写想法也可以开始。

首组荷塘方向包括荷上小憩、荷下庇护、荷间泛舟。方向用于发展承托、庇护或穿行的关系；人物、服饰、天气和镜头依本次要求设计，不把示例推广为全局默认。也可自行填写任何场景；原33题材与元素库在精修中保留，本轮没有为所有题材精编场景包。

精修保留原十维、地域、元素参考/必须、人物属性、关系和负面输入，还可补充环境陪衬、保持不变与允许变化。修改创作内容会清除旧构思选择，需要重新构思；只修改最终方案数量或目标模型保留选择；请求中改变输入时，过期响应不能覆盖新输入。选中构思可随草稿刷新恢复，未选择的候选仅在当前页面保留。

## 运行与数据

双击根[启动器](../../../../启动提示词工作台.command)；已有服务先停止后重启，再刷新页面。也可以从项目根手动运行：

```sh
python3 tools/prompt-builder/versions/v16/输出/server.py --port 8788 --open
```

日常使用Python和生产dist，不需要npm或CDN。开发复用V15已有node_modules，不安装新依赖。

V16使用schema5、scene-forge-backup-v5与独立scene-forge-workspace-v16，旧版创作数据不读取、迁移或覆盖。旧V15记录仍在原浏览器的原地址，通过旧版运行查看：

```sh
python3 tools/prompt-builder/versions/v15/输出/server.py --open
```

先停止占用同一端口的服务；浏览器本地存储按地址区分。独立接口配置和密钥沿用，密钥不进入创作历史、备份或下载。损坏存储保留原文并暂停自动保存。
