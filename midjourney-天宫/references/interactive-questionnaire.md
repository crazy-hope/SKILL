# 缺项问卷

先解析用户条件为六个视觉模块：`风格 / 画幅 / 构图 / 镜头 / 光线色彩 / 元素`，保留历轮已锁定内容。默认简洁入口；用户说“完整问卷／全部选项／逐项选择”时切换完整入口。简洁与完整文本问卷直接回复稳定编号或自然语言，不使用外部表单。用户要求可视化选择或图解时，提供[HTML 图鉴](visual-selection.md)，由用户复制选项回到对话，沿用本文的缺项、默认和兼容规则。

选择 `A6` 时，先按[风格预设](style.md#a6-清明云海仙宫)补齐未指定项，再判断剩余缺项，不重复询问已确定的建筑、人物和视觉取向；其他明确条件优先。只选择编号不等于请求生成，已请求生成时可据此直接执行。

## 简洁入口（默认）

1. 只补问尚未明确、会改变画面核心的主体、人物和视觉取向，每轮通常不超过三组。主体已明确时不再问建筑体系；“震撼、寂寥、留白、强对比”等已经是有效的视觉取向，不必要求用户再选风格编号。
2. 每个关键组可从[完整目录](option-catalog.md)摘选几个相关选项，沿用原编号，附“默认／随机／查看完整选项”。例如人物可显示 `F2-1 默认成年女性仙者`、`F2-2 成年男性仙者`、`F2-4 无人物`，其他选项可展开查看。人物未知时先确定是否有人及身份，不提前问发型。
3. 其余项目允许自动匹配：默认画幅 `B1 16:9`；风格与光色依已给视觉取向选择；构图按可见关系匹配，未给关系时用 `C1` 与 `C-F0`；镜头按构图和元素自动匹配；载体默认云海；只保留点名附加元素；摆放默认 `F5-1`；人物可见程度默认 `F2-V1`。简洁入口不会逐项展开镜头、辅助构图或摆放目录。
4. 自动匹配不能覆盖明确条件，不能凭“宏大”改成暗色，也不能凭画幅增加近景框架。生成摘要简短注明自动补齐的值。用户要求某一组完整选项时只展开该组，不重问其他内容。
5. 人物位置由构图与空间层次推导，不受地点示例限制；朝向自动匹配为背面或侧面，不正面朝向镜头，不另加必答轮次。女性发型固定半绾披发，确定含女性后直接绑定，不再补问。人物可见程度是可选项，默认不另加必答轮次。

## 完整入口

逐项显示缺失模块或子项在[完整目录](option-catalog.md)中的全部固定选项，已确定的不重复显示。保留编号和顺序，不兼容项仍显示并注明条件，不能标为推荐。用户回答部分选项时只补问剩余项，不擅自切回简洁入口。

- `A`：6种风格；解释气质区别。A3 不使用倒悬建筑，A6 包含明亮光色、三层空间与单人尺度参照的预设。
- `B`：7种画幅；`B1 16:9` 标记默认推荐，但任何画幅都不强制近景框架。
- `C`：41种主构图和 `C-F0` 至 `C-F12` 辅助构图；注明明确选择型模式的条件。
- `D`：29种镜头；说明站位和观看方向，不能只写焦段。`D22` 是无近景遮挡的稍高位远望，`D27`、`D28` 才是高空鸟瞰／垂直俯视。
- `E`：6种光色；`E5` 暗色史诗与 `E6` 冷青柱光只在明确语义相符时推荐，体积光仍是独立附加项。
- `F`：仅展开未确定的 `F1 主体结构`、`F2 人物`、`F3 天域载体`、`F4 可选附加`、`F5 摆放方式`；每组列全。建筑和人物可以选无，`F4` 多选并提供无附加元素。含人物时同时展示可选的 `F2-V`，说明未选按 V1；含女性时注明固定半绾披发。

## 条件子项

### F2-H 仙女发型

仙女只使用 **F2-H7 半绾披发**：上部黑发绾成小髻，其余自然披散。确定含女性后自动绑定，不显示发型问卷，不增加必答轮次。男性或无人物时跳过。

全部默认、全部随机、直接生成以及旧版界面发来的其他发型编号或发型随机，均沿用当前固定造型。多人含女性时应用于原人物，不新增人物展示发型。

### F4 新增元素子项

- 竹林 `F4-26`：自然语言“竹林／竹海／成片竹子”直接匹配；已指定中景时锁定中景，不再询问树种或改成近景框景。
- 大海 `F4-41`、大江大河 `F4-43`：自然语言“海洋／海面”与“江河／大江／大河／宽阔河流”分别匹配；用于主场景或开放载体时，将已有水域描述填入 `F3-4`，替代未指定的默认云海，不增加必答轮次。未指定的波纹、河道走向与岸线按构图匹配。
- 落日 `F4-42`：匹配“夕阳／落日／落日余晖／晚霞”。只要余晖时不补可见日轮；未指定太阳可见性时按构图匹配，保留用户曝光与主光方向，不增加必答轮次。
- 花树 `F4-30`：可直接说“粉红色／红色／乳白色／彩色花树”；未指定花色时用粉红色，不增加必答问卷。满天星 `F4-31` 单独按植物登记。
- 地面 `F4-32`／`F4-33`：分别为整齐光亮空旷平台与暗色大理石光亮平台；单一地面默认二选一，明确分区时可同选。
- 飞鸟 `F4-34`／`F4-35`：白鸽与飞鹤，可分别选、同选或不选；未选不自动加入，也不增加人物。
- 建筑构件 `F4-36` 至 `F4-40`：长屋檐、榫卯结构、顶部藻井、深檐、承重柱。自然语言“常常的屋檐／长长的屋檐”按长屋檐理解，“卯榫”按榫卯理解。顶部藻井需要可见的殿内顶棚；与用户明确机位矛盾时处理真实冲突，不随机改掉机位。

### F2-V 人物可见程度

这是独立于人数和发型的可选属性，沿用[人物可见程度](elements.md#人物可见程度)的三级定义：`F2-V1 极小剪影（默认）`、`F2-V2 轮廓可辨`、`F2-V3 人物可辨`。简洁入口在用户想调整人物可读性时展开；完整入口与人物组一起展示，不选可采用 V1。无人时跳过。

“人物极小”直接锁定 V1；“能看清发型轮廓”可匹配 V2；“人物衣饰可辨”可匹配 V3。固定半绾披发不会提高可见程度。V1、V2、V3 均服从人物默认尺度：全身高度约画面高度 2% 且严格小于 5%，仅作尺度参照；可读性要求不自动解除上限，默认极小剪影不展开不可辨发型细节。极小人物同时指定发饰时保留设计要求，只简短说明远景细节不保证可辨；只有同时硬性要求极小全身与清楚面部特写等真实冲突才询问。肩后模式按同一人物的尺度例外处理。

## 默认、随机与直接生成

“默认／推荐／你决定／随机”可用于单个模块，只解决该模块；全局口令解决所有剩余可补齐项：

- `全部默认`、`全部推荐`、`其余默认`、`其余推荐`；
- `全部随机`、`其余随机`；
- `不要问`、`无需询问`、`直接生成`、`直接给提示词`、`只要提示词`。

“随机生成10个场景”这种明确生成请求也允许直接补齐，按[主 Skill](../SKILL.md#批量策略)默认采用独立方案；同时明确“同一系列”时仍采用系列策略；只说“镜头随机”不构成全局跳过。“随机场景”不自动随机人物数量、性别或发型；未指定人物用默认一名成年女性、H7、V1。所有随机请求均保持半绾披发；普通随机仍不抽取明确选择型镜头。

所有补齐保留用户指定项。真实冲突和已选自定义编号缺少文本不因跳过口令而消失；只追问解决它们需要的信息。

## 自定义、编号与兼容

- 编号沿用完整目录：`A / B / C / C-F / D / E / F1–F5 / F2-H / F2-V`，不因只显示部分选项重新编号。固定选项含义不变；只有用户明确更新目录时才新增编号，自定义入口保持该子项末位。跨轮问卷保留当轮已经展示的编号。
- `F1-7`、`F2-6`、`F3-4`、`F4-25`、`F5-2` 都必须附对应文本；`F4-5 其他树种` 也需要具体树种。只给编号时下一轮只追问文本。自定义人物保留原文明确的数量、身份与外观，其余非冲突属性按当前入口补齐。
- 已在自然语言中说明具体位置，直接锁定 `F5-2` 和原位置文本；未指定时简洁入口可用 `F5-1`，完整入口显示两项等待选择或全局补齐。
- 无建筑 `F1-6`、无人物 `F2-4` 不要求自定义文本，也不能自动补回。`F4-0 无附加元素` 与其他 F4 选择互斥。
- 后来的明确修改覆盖较早选择；能通过重选未锁定项解决的不算冲突。只修改人物大小、发型、位置或参数时保留原场景其他内容，不重新随机整幅画。

## 状态流程与交付

| 状态 | 条件 | 输出与下一步 |
|---|---|---|
| `ASK` | 当前入口仍有必答关键项或未解决冲突 | 已锁定摘要 + 缺项纯文本选项；等待 |
| `WAIT` | 已发问，尚未收到回复 | 不生成预览或暂定提示词 |
| `ASK_REMAINING` | 回复后仍有当前入口的必答缺项 | 仅补问剩余项；等待 |
| `GENERATE` | 必答项已完成，其余按当前入口或全局口令补齐 | 简短锁定卡 + 中英文提示词 |

问卷回合不能同时生成提示词；生成回合不重问已锁定内容。先确定一次场景记录，再转写为两种语言，不能中英文分别随机。

生成时沿用[主 Skill 的压缩规则](../SKILL.md#工作流程)：`主画面及空间关系 → 必要元素（人物一次）→ 光色与关键质感`。一般3–5个短句，英文约50–100词，保留明确要求。完整内部设计不必逐段拼接成提示词；两种语言的元素、位置、尺度、发型、光色及参数必须一致，参数均放末尾。批量共享信息只在锁定卡写一次。只有用户明确指定单一语言时才省略另一种语言。
