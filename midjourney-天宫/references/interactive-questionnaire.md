# 缺项问卷

使用本 Skill 时，先把用户输入解析为六个视觉模块：`风格 / 画幅 / 构图 / 镜头 / 光线色彩 / 元素`。已明确的模块直接锁定；未明确的模块先提供选项，收到选择后才生成最终文生图提示词。

## 状态流程

| 状态 | 条件 | 本轮输出 | 下一步 |
|---|---|---|---|
| `ASK` | 至少一个模块未指定，且用户没有要求跳过询问 | 已锁定摘要 + 仅缺失模块的选项 + 回复格式 | 停止并等待用户 |
| `WAIT` | 已发出问卷，等待回复 | 不补写提示词 | 收到回复后重新解析 |
| `ASK_REMAINING` | 回复只填了部分缺项 | 新锁定摘要 + 仍缺失模块的选项 | 再次停止等待 |
| `GENERATE` | 六个模块都已确定，或用户启用跳过口令 | 六维锁定卡 + 一段最终 Midjourney 提示词 | 完成 |

问卷回合不能同时生成“预览提示词、暂定提示词、示例提示词”或完整六维锁定卡。生成回合不能重新询问已经锁定的内容。

## 什么算已指定

一个模块在以下任一条件成立时视为已确定：

- 用户点名具体选项或给出等价的可见关系；
- 用户对该模块说“默认、推荐、你决定”；
- 用户对该模块说“随机”，此时只从兼容选项中受控抽取；
- 该模块已在上一轮问卷中得到回答。

不要用其他模块的信息擅自补全。例如“宋代宫廷”只锁定元素中的建筑体系，不自动锁定风格、构图或光色；“宏大”只描述尺度，不等于暗色模式；“16:9”不等于低机位或中心构图。

## 跳过询问

以下表达作用于全部剩余模块，并立即进入 `GENERATE`：

- `全部默认`、`全部推荐`、`其余默认`、`其余推荐`；
- `全部随机`、`其余随机`；
- `不要问`、`无需询问`、`直接生成`、`直接给提示词`。

模块级表达只完成对应模块，例如“镜头随机”“构图用推荐”“其余元素不要”。`直接生成`与已明确的用户条件同时出现时，保留用户条件，只自动补齐剩余模块。

## 选项生成规则

1. 每个缺失模块只给 `2–4` 个与已锁定条件兼容的选项，不复制整份参考表。
2. 第一项必须标记 `（推荐）`，并根据当前场景选择，不机械地永远推荐默认。
3. 最后一项可以是 `随机`；用户需要更多选择时再展开完整列表。
4. 使用稳定编号：风格 `A`、画幅 `B`、构图 `C`、镜头 `D`、光线色彩 `E`、元素 `F`。普通选项写成 `A1`、`A2`；元素子项固定使用 `F建1`、`F人1`、`F天域1`、`F附0` 等分组编号。跨轮补问必须沿用原编号，不能把已经代表其他选项的编号重新分配。
5. 选项必须互相可区分。不要把“中心构图”和“中心 + 对称”作为两个几乎相同且没有解释的选项。
6. 不提供会违反用户已锁定条件的选项。例如已选冷青柱光时，不推荐明亮金色全局照明；已选框景构图时，优先提供门洞、深檐或柱旁镜头。

## 六个模块的问法

### A 风格

从[风格](style.md)筛选 2–4 个主模式。选项写清气质差异，例如：

```text
A 风格
A1 天界电影 CG（推荐）— 写实、庄严、结构清楚
A2 空明神域 — 更大留白、更柔空气透视
A3 东方超现实奇观 — 悬空与不可能体量更强
```

### B 画幅

从[画幅](aspect-ratio.md)筛选 2–4 个比例，并说明构图影响；不只列数字。

### C 构图

从[构图](composition.md)提供 2–4 个兼容的 `主构图 + 可选辅助构图` 组合。用户已指定主构图时，只询问确实需要用户决定的辅助构图；辅助构图可以选择“无”。

### D 镜头

从[镜头](camera.md)提供 2–4 个口令，每项说明相机所在空间与观看方向。不能只给焦段数字。

### E 光线色彩

从[光线色彩模式](light-and-color.md)筛选 2–4 个模式。“冷青柱光”和“暗色史诗”只有用户语义明确相符时才进入推荐位；体积光作为额外开关，不因云雾或水汽自动出现。

### F 元素

元素允许多选，但仍保持[元素](elements.md)预算。只询问未确定的子项：

- `建筑体系`：泛中国、汉、唐、宋、明清；
- `人物`：性别不强调、男性、女性、两人、无人；
- `天域载体`：云海、体积云、草原/浮空草台或其他兼容载体；
- `可选附加`：从自然锚点、天界结构、地形、水体、织物中筛选最多 3 个兼容选项，并始终提供“无附加元素”。

不要向用户倾倒完整元素库。已经指定“宋代云海、一名女性仙者”时，只问是否添加有限的附加元素；用户回答“其他不要”即完成元素模块。

元素编号按子项固定：建筑体系从 `F建1` 开始，人物从 `F人1` 开始，天域载体从 `F天域1` 开始，可选附加以 `F附0 无附加元素` 开始。即使前一轮已锁定某个子项，下一轮也不能借用其编号。

## 问卷输出模板

```text
已锁定
- [模块]：[用户条件]

请选择未指定模块
A 风格
A1 [推荐项]（推荐）— [一句差异]
A2 [兼容项] — [一句差异]

D 镜头
D1 [推荐口令]（推荐）— [相机空间与方向]
D2 [兼容口令] — [相机空间与方向]

回复示例：A1 D2；也可以回复“全部推荐”“其余随机”或直接写自定义要求。
```

只显示实际缺失的模块，字母不因省略模块而重新编号。若元素包含多个待选子项，回复可以写成 `F人2 + F天域1 + F附0`。

## 选择后的生成

收到选择后：

1. 合并用户初始条件、历轮选择和模块级默认/随机决定；后来的明确修改覆盖较早选择。
2. 再做一次兼容检查；可通过调整未锁定细节解决时直接调整，只有用户明确条件互相矛盾时才询问。
3. 仍有缺项时进入 `ASK_REMAINING`，不生成提示词。
4. 没有缺项时进入 `GENERATE`，输出六维锁定卡和一段可直接复制的最终 Midjourney 提示词。锁定卡与解释使用中文；代码块必须是一段完整英文视觉描述，末尾紧接 Midjourney 参数。只有用户明确说“中文提示词”时，代码块才使用中文。多轮问卷后的默认交付仍是英文，不能跟随对话语言改成中文。

生成代码块使用以下正向结构，不混入中文模块名：

```text
[English style and scene identity], [English composition relation], [English physical camera relation], [English architecture and elements], [English light and color relation] --ar [ratio] --raw --s [value] --c [value]
```

## 常见错误

| 错误 | 正确行为 |
|---|---|
| 对未指定模块直接套默认并生成 | 先给选项并等待选择 |
| 已指定模块仍反复询问 | 只显示缺失模块 |
| 一次列出全部 12 种构图、7 种镜头和完整元素库 | 每个模块筛选 2–4 个兼容选项 |
| 发问同时给出完整提示词 | 问卷回合停在等待状态 |
| 用户说“直接生成”仍强制提问 | 立即用受控默认或随机补齐 |
| 用户只回答一半就擅自补齐其余 | 只补问仍缺失模块 |
