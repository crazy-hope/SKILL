# V19 React＋Ant Design设计

日期：2026-10-30；基线V18；本次用户明确指定React与UI库，按既有授权直接实施。

## 方案

采用项目已有Ant Design 6.6.7，不新增另一套组件库与安装步骤。V18已用React但主要控件为原生HTML；这次将交互全面改为库组件，保留明确的六段创作流程。原生控件仅用于隐藏的本地文件选择，其他交互为Button/Input/AutoComplete/Select/Modal/Collapse等。五项一直显示，主体并排，窄屏上下排列；中英文结果并排或上下展示。

通过ConfigProvider提供统一颜色、字体、圆角和控件尺寸；卡片组织内容，Form.Item关联标签，TextArea自动高度适配。Modal负责焦点恢复、Esc和遮罩；输入模型允许自定义/清空，方案Select支持1—10。API Key使用Input.Password。负面和来源使用Collapse；Alert反馈状态，Empty显示无历史状态。

业务从App提取到useWorkbench.js，保留原有请求/保存/修订号逻辑。显示组件：BriefEditor.jsx、Results.jsx、SettingsModal.jsx、RecordsModal.jsx；App只组合布局与通知，theme.js集中主题，io.js负责本地下载。所有用户/模型内容作为文本显示。

## 数据

V19直接读写scene-forge-workspace-v18（schema6、backup-v6），不是迁移。V18/V19共享同源数据，恢复或新建影响这份共享草稿；旧v5及更早依然不读取。五项精确默认、subject/negative空值、单次请求、usage使用说明、失效保护及密钥独立保持。规范V16与服务器业务不变，API路径不变。

## 验证

沿用V18数据/服务/界面回归，调整原生select和details测试为库组件实际交互；增加模型自定义清空、选10对、弹窗Esc/焦点、服务商切换配置恢复。浏览器检查生产构建、草稿刷新、AI撤销/过期、复制下载、备份恢复、历史查看、桌面/390px手机与控制台错误。真实模型和出图不在本次前端重构验证范围。

组件API依据本地已安装6.6.7类型/源码，并对照2026-10-30查阅的[Modal](https://ant.design/components/modal/)与[Input](https://ant.design/components/input/)官方文档；不因官网当前版本变化升级依赖。
