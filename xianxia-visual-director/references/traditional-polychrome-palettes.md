# 传统建筑彩画配色

本文件在[仙侠共享总则](xianxia-master-rules.md)和所选普通视觉路线之下使用。它从传统矿物颜料的构件落位、材质行为与风化中创造原创仙侠建筑，不授权复制参考建筑、朝代样式、屋顶剪影、斗拱组合、栏杆、牌匾、文字、园林布局或水印。

## 参考图转译

四条独立配色路线：

- **鲜明复原·朱青赭金**：矿物朱红柱门，石绿与松石青斗拱，群青梁枋，赭金屋面，象牙白留白和清冷日光。
- **岁月包浆·黯彩青绿**：褪朱、氧化青绿、低纯石青、尘赭、烟褐老木、粉灰沉积和磨损旧金。
- **朱青长廊·碧柱绛枋**：孔雀青柱、朱红椽与门窗框、群青横梁、青绿斗拱、浅灰石地和强方向影。
- **朱红宫门·青绿彩画**：大面积朱红柱墙门、窄青绿石青梁枋带、赭色象牙白画板、深栗红凹部、灰石台基和细旧金线。

除非用户明确要求编辑，参考图均为非编辑的建筑/材质和配色参考。蓝天、植物和珊瑚花属于环境，不能自动迁移到建筑；栏杆、牌匾、说明牌、文字和水印只作排除。

## 构件绑定颜料语法

- `矿物朱红 / 朱砂红`：指定柱、门扇、窗框、椽、窄梁面和结构框。
- `石绿 / 孔雀青 / 松石青`：青绿长廊柱、斗拱主体、托臂、梁底和受檐保护区。
- `石青 / 群青 / 靛蓝`：横梁、梁枋画板、天花分区、斗拱凹部和冷色深值。
- `赭黄 / 琥珀赭 / 老黄釉`：屋面、脊、椽端和部分画板。
- `月白 / 米白 / 粉灰`：彩画留白、灰墙、石基和高纯色之间的分隔。
- `旧金 / 淡金`：瓦当、脊饰、细线、雕刻凸缘和磨损高点。
- `深栗红 / 烟褐 / 蓝黑老木`：凹入门扇、梁芯、深檐和阴影锚点。

颜色服从构造，不得把每种颜色铺到每个构件。最大两至四个平面保持安静，多色彩画集中在檐、斗拱、梁枋、门窗开间和人物可读阈境。

## 路线1——鲜明复原·朱青赭金

建筑表面预算：32%朱红；22%石绿、松石青和孔雀青；13%石青、群青和靛蓝；12%赭黄或琥珀屋面；8%深靛或烟褐凹部；8%象牙白、月白或粉灰；5%淡旧金。

风化5–8%：可见木纹、手工矿物颗粒、细接缝、轻微柱脚磨耗和受保护檐尘。色彩鲜明且维护良好，但不塑料、不镜面、不统一工厂新漆。

```text
建筑设色体系：传统青绿彩画宫殿；子路线：鲜明复原·朱青赭金。矿物朱红绑定巨柱、门扇、椽条与窄框，石青石绿和孔雀青绑定斗拱、梁枋与檐底承重转换区，群青靛蓝压住梁枋分区和深檐，赭黄琥珀色用于屋面与脊饰，月白灰石负责留白，淡旧金只勾瓦当、脊线和受光凸缘；手工矿物颜料颗粒、轻微木纹与5–8%自然使用痕迹，高明度、色块清楚、鲜明而不荧光。
```

## 路线2——岁月包浆·黯彩青绿

建筑表面预算：25%烟褐老木；20%氧化石绿、松石青和铜绿；16%褪朱与赭红；14%尘赭与老黄；12%靛蓝、石青与蓝黑凹部；8%粉灰、露木与浅沉积；5%磨损旧金或青铜。

风化30–40%，但建筑仍有人使用且结构完整。日晒面粉化褪色，迎雨面有纵向水痕，触摸与凸缘露暖木或铜，接缝积尘，柱脚和石缝局部变深，受保护檐下保留更强原色。禁止坍塌、腐烂、均匀裂纹、随机污垢和棕黄怀旧滤镜。

```text
建筑设色体系：传统青绿彩画宫殿；子路线：岁月包浆·黯彩青绿。烟褐老木和蓝黑檐影为深值，褪朱赭红留在柱、椽和门框，氧化石绿、铜绿和暗石青保存在斗拱凹部与檐下，尘赭老黄压在屋面与脊饰，粉灰沉积和露木只出现在真实受风化位置，旧金仅残留于磨损凸缘；日晒褪色、纵向雨痕、柱脚磨亮、檐下积尘和石缝轻盐析，古老但仍在使用，绝非废墟。
```

## 路线3——朱青长廊·碧柱绛枋

建筑表面预算：30%孔雀青、石绿或松石青柱；22%朱红椽、门窗框和窄梁肋；15%群青与靛蓝横梁或天花；10%石绿石青斗拱；8%深木与蓝黑檐影；10%浅灰石、象牙白与地面反光；5%赭色旧金。

风化12–18%：向阳朱红略粉化，受保护青绿更深，柱脚有接触磨耗，主要步行轴石地轻微磨光，檐下积薄尘。重复颜色必须强化透视，不能形成红绿棋盘格。

```text
建筑设色体系：传统青绿彩画宫殿；子路线：朱青长廊·碧柱绛枋。孔雀青与石绿巨柱形成纵深节拍，矿物朱红只用于椽条、格扇、门窗框和窄梁肋，群青横梁与靛蓝天花分区压住顶部，青绿斗拱只集中在承重节点，灰白石地稳定高彩木构，赭黄旧金仅点瓦当和梁端；近处朱青清晰、远端逐级降纯度和反差，不做红绿棋盘格。
```

## 路线4——朱红宫门·青绿彩画

建筑表面预算：45%矿物朱红柱墙门窗；16%深栗红凹部；14%石绿、松石青与孔雀青梁带；8%石青群青画板；7%赭色象牙白留白；7%灰白石基；3%细旧金。

明确选择5–8%复原、12–18%日常使用或30–40%古旧。朱红墙柱保持宽阔安静，彩画梁枋形成窄层级而非覆盖立面。

```text
建筑设色体系：传统青绿彩画宫殿；子路线：朱红宫门·青绿彩画。大面积矿物朱红落在巨柱、宫墙、门扇与窗框，深栗红压住门窗和檐下凹部，石青石绿、孔雀青与群青只组成梁枋和斗拱窄带，米白赭黄用于彩画留白，灰白石台基稳定下部，旧金只作细轮廓线和磨亮凸缘；红色主面安静，彩画带清楚但不喧宾夺主。
```

## 全画面整合与路线兼容

以上预算只用于彩绘建筑表面。天空、云、空气、水、石和未彩绘巨面通常保留全画面的55–70%；高纯彩画常占15–25%，其余由阴影、距离、磨耗和空气透视降低。近景更暖、更锐、更饱满，远景更冷、更亮、更低反差但不灰塌；暖侧光或逆光擦过朱红、赭色和金边，冷天光保持檐下青绿色可读。

- `华彩通透仙侠`优先鲜明复原或朱青长廊，色彩明亮优雅。
- `东方苍穹巨构`可用任一子路线，但巨面安静、彩绘局部。
- `神域聚居地`按城市层级分配子路线，统领城区拥有最强色彩。
- 除非明确要求，不得引入`仙界大境原典`；组合时保留原典暖柔光和克制运动。

## 排除与审计

```text
不要彩虹式平均铺色，不要圣诞式红绿对撞，不要RGB霓虹，不要每种颜色同等纯度，不要把天空蓝误涂成建筑群青，不要把花木珊瑚色自动继承为宫殿色；不要塑料亮漆、镜面金、全局橙金滤镜、统一崭新、随机均匀做旧、满墙裂纹、棕黄怀旧或废墟化；不要满铺彩画、每根梁同样繁复、彩绘吞没巨大安静平面；不要任何栏杆、文字、牌匾题字、说明牌、水印、Logo、印章、签名、截图UI或黑边；不要复制参考建筑完整构图、屋面轮廓、斗拱组合、门窗比例、长廊布局、园林花木位置或专有纹样。
```

审计：是否命名子路线且与视觉路线兼容；每种颜料是否绑定具体构件；天空、植物与花是否和建筑颜料分开；建筑表面与全画面预算是否分开；风化是否明确、有因果且符合维护/使用/古旧状态；巨面是否安静、彩画是否局部；旧金和最高纯色是否狭窄；栏杆、牌匾、文字、水印和源图专有几何是否缺席。
