# 必须包含：全题材元素仅保留名称

- 日期：2026-10-19；基线：当前 V10；事前记录；状态：已完成并交付。
- 用户要求：所有“必须包含”元素不要附带描述，避免限定动物所在场景与额外画面元素；截图示例为引风青鸾、守门麒麟、衔芝白鹿及其括号描述。
- 范围：所有 31 题材及通用 03 选项。去掉括号说明、场景动作与位置修饰，保留区分对象所需的名称，如中国龙、九尾灵狐。简短活动或构图要求保留名称，不包含完整画面句子；02 场景和 04 视觉偏好仍可描述关系。
- 本轮明确要求优先于此前在候选条目内补充关系的设计。名称用于选择，关系在本次实际生成时按用户场景和自由度设计，不影响规范要求最终画面关系清晰。

## 需求与计划

| 编号 | 要求 | 实现与检查 |
|---|---|---|
| R-01 | 03 全库只提供简洁名称 | 全量审查条目，精简括号及场景修饰，合并同名候选；检查所有题材及通用项无说明句 |
| R-02 | 实际选中值不再带描述 | 新选项直接写入简名；旧名可检索新名，原有内置长条目在当前草稿或复用输入中精简并去重 |
| R-03 | 保留自定义和历史事实 | 只对完整匹配内置旧值的条目迁移，不用通用正则裁剪用户文本；历史输入和结果保持原样，恢复到新表单时转换副本 |
| R-04 | 小维护并验证 | 追加维护记录、同步说明与索引；回归、模拟请求、语法、归档与链接检查，规范不升级 |

计划：记录 → 新增名称/迁移回归并确认失败 → 维护名称映射及候选、草稿复用 → 更新受本轮规则影响的旧测试 → 验证 → 记录交付。

## 实际结果

计划全部完成，应用仍为 V10。成果：[候选库及旧名映射](../输出/catalog.mjs)、[草稿兼容处理](../输出/core.mjs)、[预设使用入口](../输出/app.js)、[名称回归](../tests/element_names.test.mjs)。

- R-01：检查全部 31 题材及通用选项，167 个旧条目映射为简名；去掉括号说明及场景修饰，同名合并后共 1,248 个题材元素条目。东方天界生物由 25 项合并为 21 项，多个“中国龙”变体合并为一个名称。微观幻想对象用“幻想”名称前缀保留创作属性，避免将幻想装置误说成现实技术。
- R-02：候选库在构建搜索索引前转为简名，实际选中和发送值均为名称，旧描述只保留作检索别名；无隐藏描述拼回生成请求。草稿加载、备份中的当前草稿，以及预设/历史输入复用，都使用完整旧值映射与去重。
- R-03：`normalizeBrief`、历史快照及保存的预设内容仍保留原文；`reusableBrief` 仅处理新表单副本。未匹配的自定义文本不裁剪；不通过粗略删除括号来改写任意用户输入。
- R-04：现有历史兼容测试调整为验证旧条目可映射到新名称，继续检查非名称设置不变；没有删除相关兼容检查。AGENTS 与 README 记录新规则，旧维护记录不改。
