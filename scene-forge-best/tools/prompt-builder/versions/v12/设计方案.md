# 自动动作与空间设计

保留十面板。02每个已选元素的展开设置在角色、相对尺度、占比、数量之外增加动作、位置、层次、关系、关系对象；全部缺省自动。直接选择即可，文字自定义仍可使用。关系对象下拉只提供其他已选元素；目标删除后相关关系回到自动，避免误指新对象。一个元素可锁定一组对外关系，其他关系由模型补齐。

生成时先确定主要对象，再组织适合对象的动作、环境承托和前中远景、相互位置、附属服饰、视觉流向，最后落实到每个方案的中英文。自动设计不等于增加未选对象。人物仍须明确启用；选配时带手动关系的对象与关系目标一起保留。自动细节缺失不追问，明确硬冲突才澄清。concept简述自动设计结果，不能把它称为用户指定或已验证画面。

数据使用schemaVersion=3；每个elementSettings条目字段为name/role/scale/frame/count/action/position/depth/relation/target。target空字符串表示自动对象；动作、位置和关系均可自定义。前后端严格检查关联及长度。备份scene-forge-backup-v3，创作存储scene-forge-workspace-v12；不读取旧存储或转换旧备份。密钥仍独立存储，不进入创作备份。

新模块brief.mjs与brief.py统一处理当前结构，form.mjs渲染控件；core.mjs只处理当前结构与结果，catalog仍供候选检索，server.py删除旧生成分支。V11保持归档，根启动器交付时切换V12。
