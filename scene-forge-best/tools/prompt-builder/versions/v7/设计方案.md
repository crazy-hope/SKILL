# 工作台 V7 设计

沿用九项字段名和存储结构。02 标识为核心画面，03 标识为必需细节；展开后分别解释“主要描绘什么”和“补充或强调不能遗漏的对象/特征”，人物可作为主体或配角，重复强调不等于新增一个。

catalog 内维护旧场景到新版明确描述的映射；新候选只展示新版，不重复列旧名。搜索索引包含旧名。旧草稿/历史原文不变；显示新候选时识别旧名已选，用户取消时移除对应旧值，其他选项不受影响。静态建筑和自然画面以状态/空间关系表达，不为了句式强加人物。

工作台系统消息补充输入解释：02 主画面、03 硬约束、04 表现方式；先对齐跨字段对象，明确数量和新增关系优先，同名不一律合并。数量冲突或指代歧义影响画面时澄清，不能静默丢项。模型原始输入仍是九项原值，不额外提交内容库。

本轮属于工作台界面与输入解释的落实，规范正文不变。测试覆盖场景改写、旧名搜索/选择与历史兼容、请求规则注入、旧功能和响应式界面。
