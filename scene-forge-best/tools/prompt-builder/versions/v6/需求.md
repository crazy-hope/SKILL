# 工作台 V6 需求

- 日期：2026-10-16；事前记录；基线：[工作台 V5](../v5/README.md)。规范继续使用 V6。
- 用户批准：补齐赛博朋克题材辨识度高的元素，按场景排列辅助元素，视觉偏好联动配色与照明；特别补充全息影像、全息鱼灯。只维护工作台，不修改规范。

| 编号 | 要求 | 验收 |
|---|---|---|
| R-01 | 补充霓虹招牌、广告牌、全息影像与全息鱼灯等 | 元素可搜索和勾选，区分投影与实体灯具 |
| R-02 | 优先呈现核心视觉元素，按车站、人物、夜市、维修等场景推荐 | 推荐只排序，不自动勾选；旧选项保留 |
| R-03 | 选择赛博朋克后增加配色组合与照明候选 | 支持霓虹街景、工业、企业、娱乐、清晨等方向，非赛博朋克不混入 |
| R-04 | 题材/场景变化实时联动，保留已有选择 | 切换、刷新、备份及请求不丢选项，不把整个库发送给模型 |
| R-05 | 只新增工作台版本，保留规范与历史 | 旧版 SHA-256 不变，九项、双语、模型适配、密钥与下载回归通过 |

假设：全息鱼灯作为幻想投影装置选项，标明投影形态；另提供实体发光鱼形灯具。候选是原创画面设计建议，不声称已实现的物理全息技术或题材必备规则。多选仍允许组合，用户自行选择，不强制统一成蓝紫霓虹。其他题材库本轮不扩充。
