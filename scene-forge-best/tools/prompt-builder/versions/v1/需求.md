# 提示词工作台 V1 需求

- 日期：2026-10-16；状态：功能检查完成并交付；事前记录并随本轮补充修订。
- 依据：[规范 V4 需求](../../../../versions/v4/需求.md)，实现绑定完整 V4 正文。

用户要求八项选择页面；补充要求页面调用大模型根据规范生成提示词，服务商选择 OpenAI 和 DeepSeek；每个方案提供中文与英文各一份。

| 编号 | 要求与验收 |
|---|---|
| R-01 | 保持八字段顺序，多选、自定义；画幅、目标图像模型、方案数量单选 |
| R-02 | 题材联动推荐元素；示例不作为默认选择；切换题材保留已选自定义内容 |
| R-03 | 配置 OpenAI / DeepSeek、模型及 API Key；本地服务转发，每次请求读取完整规范 |
| R-04 | N 个方案输出 N 对中英文；独立复制、下载；保留失败提示，拒绝缺语言或数量错误响应 |
| R-05 | 保存草稿、预设、生成历史（包含规范摘要校验值）；密钥只在当前页面内存，刷新后重新填写 |
| R-06 | 可双击启动的本地入口；无需第三方依赖；文档、源代码、测试和验收按版本归档 |

修订：初稿仅复制八项需求；用户明确要求大模型生成，因此改为本地网页加 Python 服务。未提供真实密钥，测试使用模拟响应，实际服务商调用待用户配置。

## 本轮布局追加要求

用户明确要求：首页为八个条件卡片；右上角大模型配置；底部中央悬浮生成按钮；生成后弹窗显示与数量对应的提示词面板，支持一键复制。

| 编号 | 要求与验收 |
|---|---|
| R-07 | 八个字段各一张卡片；桌面网格，手机纵排；首页不再放右侧预览与结果区 |
| R-08 | 大模型配置按钮位于右上；生成按钮底部居中悬浮，不遮挡最后一张卡片 |
| R-09 | 点击生成打开结果弹窗；N 个方案呈现 N 个面板，每面板中英各一份，支持分别/整条/全部复制 |
