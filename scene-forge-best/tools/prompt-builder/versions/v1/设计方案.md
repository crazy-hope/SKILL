# 提示词工作台 V1 设计方案

- 状态：实施完成；已依据用户补充更新，初始纯静态复制方案被本轮接口方案取代。
- 使用 [规范 V4](../../../../versions/v4/输出/规范框架v4.md)。

主页八个独立条件卡片以网格排列，右上角配置大模型，底部中央悬浮生成按钮。点击生成即打开结果弹窗，加载完成后显示与方案数量一致的面板，每个面板包含中英文两段及独立、成对复制按钮；弹窗提供复制全部和下载。预设工具条保留，历史、需求预览、备份移至记录弹窗。冷灰底、紫色强调、清晰留白；移动端纵向排列。每项支持提示说明，主题、场景、元素、视觉偏好与自由度采用可展开复选项及自定义；画幅、图像模型和数量单选。视觉偏好按媒介、时间、配色分组，组内也保留多选，允许混合媒介；关键冲突由模型提出澄清。

八项输入原样传给模型；自动补充普通设计选择，关键冲突返回待澄清项，不静默丢掉必须项。题材推荐只改变候选元素，不修改已选项。内置东方天界、赛博朋克、自然写实、古代生活、蒸汽幻想、太空科幻及自定义题材。用户保留自己的选择，不强加默认镜头。

大模型接口和目标图像模型分别配置。服务商官方地址固定（OpenAI、DeepSeek），避免误发密钥；模型 ID 可填写或从可访问列表选择。用兼容 Chat Completions 的文本模型生成 JSON 格式方案，后端验证双语字段、数量、结束状态。未核实图像模型参数不编造；模型配置单独说明，不靠网页假装保证图像服从性。

Python 3 标准库提供本机服务，绑定 127.0.0.1，前端无第三方库/CDN。仅公开列举的静态文件、规范和指定 API。校验 Host、Origin 和进程随机令牌；不记录请求体或密钥，拒绝上游重定向，不自动重试计费请求。API Key 只在页面和单次转发内存，不写本地存储。服务商、模型、草稿、预设、历史持久化在当前浏览器同源存储，支持 JSON 备份和恢复；刷新后要重填 Key。

每次生成读取 V4 原文，记录版本和 SHA-256。历史显示请求快照，后续修改表单不会修改已保存的方案。规范版本更新需要明确更新应用绑定，避免历史来源漂移。错误响应分为凭据、配额、网络、结构不完整和待澄清，保留输入，不制造成功结果。

交付版本目录包含 输出/ 源码、README、tests、需求、计划、变更、验收。根目录稳定启动器指向本应用 V1。未来功能修改新建应用 V2；规范独立版本化。本轮不部署外网。

桌面优先 4×2、一屏呈现；下拉菜单使用浮层，已选标签区域内部滚动。平板两列、手机一列，保留底部按钮安全间距。低高度窗口允许滚动，不隐藏输入内容。
