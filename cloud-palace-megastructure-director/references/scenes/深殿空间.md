# 深殿空间

## 场景说明

以一座巨殿的内部空腔为主角。压迫感来自高处重量、宽阔净跨和纵深，而不是矮梁压头或门洞挤窄。

## 空间细类

- 深殿向外：从殿内多进大开间看远端门窗和云域。
- 外部向内：站在前场或门槛外，看层层梁柱和深处暗部。
- 高敞多层：各层独立保留地坪至梁底的净高，通过层廊和楼梯连接。
- 近窗停驻：靠窗叙事，以窗框厚度和外界尺度继续传递；不冒充深殿远景。

## 物件调用

核心为[宫殿](../objects/宫殿.md)，按可见结构调用[柱与柱础](../objects/柱与柱础.md)、[梁架与斗拱](../objects/梁架与斗拱.md)；出现门窗时读[门窗与巨型开口](../objects/门窗与巨型开口.md)。云域、远宫、树木仅在实际开口外出现时加载。不把普通圆窗识别成天环。

## 尺度与连接

使用层细节→柱础→高柱与多进主梁→殿体空腔/远端开口→所见终景。可用柱影与地缝追踪地坪，雾只局部淡化远端，不吞掉空间。近柱裁切与中景完整柱梁关系相互证明；每层有自己的可读净高。

## 可选观看关系

中轴向远门、偏轴横跨大殿、侧向看柱列、从上层回廊俯看中央空场。人物可侧面横过主轴或背向观看，不固定人后45度。纯内殿不强求露台式开放云海比例。

## 组合与检查

可以与宫廷前场、长廊或水庭相接，连接处必须有真实门槛、地坪或标高过渡。检查宽、深、高、空旷四项；勿只缩人、加粗近柱或加雾。不展示的室内维度不强迫出现。

可选片段：『地坪贯穿近景柱础、中段多进大开间和远窗，高处主梁留出巨大的垂直空腔，陈设退到边带，窗洞厚度连接远处云海。』

## 命名镜头示例

以下保留旧4A/4B用于明确匹配的近窗或深殿需求，不是一般场景的数值配额；窗宽参考不是人物大小要求。用户排除松树、远宫等内容时去掉相应依赖，改用当前物件继续尺度链。

#### 4A. 近窗巨幅框景

- 适用：需要读清窗边人物的交流、驻足或共同远望，同时仍由巨窗、墙生古松和遥远主宫维持宏伟尺度。
- 空间关系：相机位于巨窗正面法线附近，靠近殿内窗边承载面；巨窗约占画面宽度80–84%，左右宫墙各只露窄边，少量地坪与低窗台证明人物真实落地。窗外以一棵扎根外墙的巨松连接近景与云海，再由单座横向展开的遥远主宫结束尺度链。
- 机位与尺度：画幅、焦距和人物距离按[共用相机状态](../scale-and-space-rules.md#相机状态画幅焦距与拍摄距离)，按人物与窗台、巨松及远宫的关系安排落位。“近窗”首先描述人物与窗的关系，不自动改成相机贴近人物；用户明确要求近距叙事或长焦正视时再改对应字段，不设人物画高阈值。
- 连续尺度链：`成年仙女 → 地坪与窗台 → 巨型木窗和墙生古松 → 单座横向主宫 → 分层云海终景`。远宫即使远离镜头，仍应以连续水平檐带、宽阔正立面和从属大气层级读作巨宫，而不是窄高塔楼。
- 编辑不变量：用户只要求校正人物且环境比例正确时，保持主体建筑、画幅与光线；同时恢复人物脚底接触和投影。若尺度链或透视本身错误，应修正关联空间，不能靠只缩人物冒充正确尺度。
- 避免失败：不要让人物变成半身或第一视觉主体；不要出现两侧大面积宫墙、任一主要窗框无故消失、远宫缩成小塔、附墙巨松脱离承重墙面，或用均匀灰雾切断尺度链。

#### 4B. 深殿远窗揭示

- 适用：用户要求更强巨构压迫感、人物只作尺度标记，或需要同时读出深殿地坪、巨柱、深檐斗拱与远窗外主宫。
- 空间关系：相机位于巨殿深处，辽阔地坪横向延伸至两侧柱列之外，中央是广场般的大净跨；近景柱础、中段多进巨型开间、远端有厚度的巨窗构成长纵深。高处梁底与各层地坪之间保留巨大垂直空腔，柱顶承托连续屋盖，家具与隔断退至边带。巨窗外接云海与横向远宫，近柱不能把中殿夹成窄门厅。人物距离与焦距分别按共用相机状态，相机到远窗的距离另行设计，不用“深殿”另设人物画高。
- 机位与尺度：沿用共用相机状态，通过近处主承重体、多进大开间和窗外层次强化深度；人物大小服从所在承载面、既定投影和尺度链。用户明确选其他焦距或人物距离时只调整对应字段；不因“强压迫感”孤立缩人。
- 连续尺度链：`真实体型的成年仙女 → 辽阔地坪与巨柱柱础 → 深殿柱身和有厚度的巨窗 → 墙生古松与横向主宫 → 多层云海终景`。巨柱直径、柱高、地坪跨度和窗口尺寸至少提供三项相互连接的可见尺度证据。
- 避免失败：不要只把4A的人物缩小来冒充深殿远景。深殿的纵深来自相机到远窗之间可读的多进大开间；开口随真实距离后退，但自身仍保持巨大的宽度与高度，不以必须缩窄开口作为成功标准。不要让人物几步便到窗前、粗柱挤窄中殿、低梁压头或低矮楼层密叠；远宫不缩成宝塔，近殿暗部保留结构。

### 子型选择

- 用户强调人物交流、服装动作可读或指定参考人物尺度 → 优先`4A. 近窗巨幅框景`。
- 用户强调宫殿压迫感、深殿空间、巨柱地坪或强尺度断层 → 优先`4B. 深殿远窗揭示`。
- 用户只要求普通门洞或开放开间，没有上述人物与机距条件 → 使用本路线通用规则，不强行套用4A或4B。
