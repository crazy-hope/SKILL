# 提示词工作台 V7

日期：2026-10-16。基线：[工作台 V6](../v6/README.md)。已交付；继续使用原 [规范 V6](../../../../versions/v6/输出/规范框架v6.md)。

## 02 与 03 怎么选

| 输入 | 用途 | 示例 |
|---|---|---|
| 02 想画什么 · 核心画面 | 选择主要描绘的画面、主体行为或场景关系 | 街头机械师正在维修摩托 |
| 03 必须包含 · 必需细节 | 补充或强调不可遗漏的对象、身份、特征 | 机械义臂、维修工具、旁边等候的顾客 |

02 已确定的人物不必在 03 重选。03 仍允许人物身份及配角；例如“义体维修师”可用于强调主体身份，不等于自动增加另一人。若确实要增加人物，请写“另一名维修师在旁协助”等明确关系。生成请求要求模型对齐跨字段对象与数量，关键指代歧义或冲突先澄清；此语义效果尚未经过真实模型测试。

## 本次更新与兼容

- 整理 62 个含混场景名称，保留 30 个题材、305 个场景入口。静态环境使用状态或空间关系，不强制添加人物和动作。
- 1,127 个题材元素条目与既有视觉候选保持不变。两个下拉增加分工说明；桌面和手机均能看到卡片角色提示。
- 旧名称可以搜索到对应新选项。已有草稿、预设、历史原文不自动重写；对应选项会显示为已选，主动取消可移除旧值，再次勾选采用新描述。
- 九项输入、双语输出、负面默认值及明确清空、目标模型适配、密钥独立本地保存、历史、复制与下载继续保留。候选未经选择不会成为要求。

## 启动
