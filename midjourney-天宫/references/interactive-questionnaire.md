# 缺项问卷

使用本 Skill 时，先把用户输入解析为六个视觉模块：`风格 / 画幅 / 构图 / 镜头 / 光线色彩 / 元素`。已明确的模块直接锁定；未明确的模块先提供选项，收到选择后才生成最终文生图提示词。

## 状态流程

| 状态 | 条件 | 本轮输出 | 下一步 |
|---|---|---|---|
| `ASK` | 至少一个模块未指定，且用户没有要求跳过询问 | 已锁定摘要 + 仅缺失模块的选项 + 回复格式 | 停止并等待用户 |
| `WAIT` | 已发出问卷，等待回复 | 不补写提示词 | 收到回复后重新解析 |
| `ASK_REMAINING` | 回复只填了部分缺项 | 新锁定摘要 + 仍缺失模块的选项 | 再次停止等待 |
| `GENERATE` | 六个模块都已确定，或用户启用跳过口令 | 六维锁定卡 + 中文提示词 + English Prompt | 完成 |

问卷回合不能同时生成“预览提示词、暂定提示词、示例提示词”或完整六维锁定卡。生成回合不能重新询问已经锁定的内容。

## 什么算已指定

一个模块在以下任一条件成立时视为已确定：

- 用户点名具体选项或给出等价的可见关系；
- 用户对该模块说“默认、推荐、你决定”；
- 用户对该模块说“随机”，此时只从兼容选项中受控抽取；
- 该模块已在上一轮问卷中得到回答。

不要用其他模块的信息擅自补全。例如“宋代宫廷”只锁定元素中的建筑体系，不自动锁定风格、构图或光色；“宏大”只描述尺度，不等于暗色模式；“16:9”不等于低机位或中心构图。

## 跳过询问

以下表达作用于全部剩余模块，并立即进入 `GENERATE`：

- `全部默认`、`全部推荐`、`其余默认`、`其余推荐`；
- `全部随机`、`其余随机`；
- `不要问`、`无需询问`、`直接生成`、`直接给提示词`。

模块级表达只完成对应模块，例如“镜头随机”“构图用推荐”“其余元素不要”。`直接生成`与已明确的用户条件同时出现时，保留用户条件，只自动补齐剩余模块。

## 选项生成规则

1. 每个缺失模块必须显示[完整问卷选项](option-catalog.md)中的全部固定选项，不能只截取推荐项或兼容项。已锁定的模块不重复显示。
2. 保持固定编号和固定顺序；根据当前场景标记一个推荐项，但不能因推荐变化而重新编号。
3. 每个单选模块同时提供“随机”操作；`F4` 为多选，并提供“无附加元素”。
4. 使用稳定编号：风格 `A`、画幅 `B`、主构图 `C`、辅助构图 `C-F`、镜头 `D`、光线色彩 `E`、元素 `F`。普通选项写成 `A1`、`A2`；主构图固定使用 `C1` 至 `C41`，其中旧有 `C1` 至 `C12` 的含义不得改变；辅助构图固定使用 `C-F0` 至 `C-F12`；元素子项固定使用 `F1-*` 至 `F5-*`。非自定义固定选项的编号含义不得改变。每个子项的自定义入口永久占最后一个编号；新增固定项插在自定义入口之前，自定义入口随之顺延到新的末号。当前自定义项为 `F1-7 自定义主体结构`、`F2-6 自定义人物`、`F3-4 自定义天域载体`、`F4-25 自定义附加元素` 和 `F5-2 自定义摆放`。跨轮补问必须沿用当轮已显示的编号；只有用户明确要求更新技能目录时，才可按上述末位规则顺延自定义入口。
5. 选项必须互相可区分。不要把“中心构图”和“中心 + 对称”作为两个几乎相同且没有解释的选项。
6. 与已锁定条件不兼容的选项仍显示，但要标注适用条件或冲突原因，且不能标为推荐。用户选中后按兼容检查处理。

## 六个模块的问法

### A 风格

显示[风格](style.md)中的全部 `5` 个主模式，并写清气质差异。

### B 画幅

显示[画幅](aspect-ratio.md)中的全部 `7` 个比例，并说明构图影响；不只列数字。`B1 16:9` 固定标记为“默认推荐”，除非用户明确选择其他画幅，否则“默认/推荐”均解析为 `B1`。

### C 构图

显示[构图](composition.md)中的全部 `41` 个去重主构图。辅助构图完整显示 `C-F0` 至 `C-F12`；不兼容组合保留显示并标注冲突。`C24`、`C25`、`C35`、`C37`、`C39` 等明确选择型模式必须标出适用条件，不能进入默认推荐位。

### D 镜头

显示[镜头](camera.md)中的全部 `29` 个口令，每项说明相机所在空间与观看方向。不能只给焦段数字。`D22` 必须明确标注“无近景遮挡、有人物时视点仅比人物略高、无人物时仅比中景主体参考面略高、不是高空航拍”；`D27`、`D28` 必须明确标注只在用户选择鸟瞰或上帝视角时使用。

### E 光线色彩

显示[光线色彩模式](light-and-color.md)中的全部 `6` 个模式。“冷青柱光”和“暗色史诗”始终可见，但只有用户语义明确相符时才进入推荐位；体积光作为 `F4` 附加元素，不因云雾或水汽自动出现。

### F 元素

元素允许多选，但仍保持[元素](elements.md)预算。只显示未确定的子项，但每个子项内部完整显示固定选项：

- `F1 主体结构`：泛中国、汉、唐、宋、明清、无建筑、自定义主体结构；建筑不是必选项。
- `F2 人物`：性别不强调、男性、女性、两三人、无人、自定义人物；人物不是必选项。
- `F3 天域载体`：云海、体积云、草原/浮空草台、自定义天域载体；
- `F4 可选附加`：完整显示自然锚点、天界结构、地形、水体、织物、体积光、月亮、神像、墙面（白墙、石墙、红墙、云墙、水墙）和自定义附加元素，并始终提供“无附加元素”。
- `F5 摆放方式`：位置未指定时固定提供 `F5-1 随机摆放（推荐/默认）` 和 `F5-2 自定义摆放`。

已经指定“宋代云海、一名女性仙者”时，只显示仍未确定的 `F4`、`F5` 等子项；不重复显示已经锁定的 `F1` 至 `F3`。

元素编号按子项固定：主体结构使用 `F1-*`，从 `F1-1` 开始；人物使用 `F2-*`，从 `F2-1` 开始；天域载体使用 `F3-*`，从 `F3-1` 开始；可选附加使用 `F4-*`，并以 `F4-0 无附加元素` 开始；摆放方式固定为 `F5-1 随机摆放` 与 `F5-2 自定义摆放`。每个元素子项的自定义入口永久保留在最后一位；新增固定项时，自定义入口顺延而不是固定在旧编号。当前 `F4` 的墙面固定项使用 `F4-20` 至 `F4-24`，自定义附加元素为末位 `F4-25`。即使前一轮已锁定某个子项，下一轮也不能借用其编号。

用户只选择 `F1-7`、`F2-6`、`F3-4` 或 `F4-25` 却没有对应文本时，该子项仍未完成；统一规则是只有编号没有文本时继续追问，下一轮只追问缺失的自定义文本。`F1-6` 与自然语言“没有建筑”直接锁定无建筑，`F2-4` 与自然语言“无人物”直接锁定无人物，不要求补充文本，也不得为满足旧有默认自动补入建筑或人物。

用户已经在初始要求或后续回复中写出具体元素位置时，直接锁定 `F5-2` 及其原始摆放文本，不再询问 `F5`。用户只回复 `F5-2` 却没有摆放文本时，`F5` 仍未完成；下一轮只要求输入自定义摆放文本，不重复询问其他已锁定子项。用户回复 `F5-1`、对摆放方式说“默认/推荐/随机”，或用“全部推荐、其余推荐、全部随机、其余随机、直接生成”等全局口令补齐时，锁定 `F5-1`，按[元素](elements.md)的九宫格参考进行兼容随机。

## 纯文本问卷

问卷回合必须按[完整问卷选项](option-catalog.md)列出当前缺失模块内的全部选项。不要调用可视化、按钮选择器或外部表单；用户直接在对话中手动输入编号。

## 文本模板

```text
已锁定
- [模块]：[用户条件]

请选择未指定模块
A 风格
A1…A5 [完整固定选项]

D 镜头
D1…D29 [完整固定选项]

回复示例：A1 B1 C1 C-F0 D2；也可以回复“全部推荐”“其余随机”或直接写自定义要求。
```

只显示实际缺失的模块，字母不因省略模块而重新编号。若元素包含多个待选子项，回复可以写成 `F1-1 + F2-2 + F3-1 + F4-20 + F5-1`，其中 `F4-20` 表示白墙。

自定义项必须附带文本，例如 `F1-7：一面延伸出画框的远古巨墙`、`F4-25：青铜浮雕墙`；选择自定义摆放时写成 `F5-2：主宫殿右中，仙女中间偏左并站在远景桥廊上，古松左下`。

## 选择后的生成

收到选择后：

1. 合并用户初始条件、历轮选择和模块级默认/随机决定；后来的明确修改覆盖较早选择。
2. 再做一次兼容检查；可通过调整未锁定细节解决时直接调整，只有用户明确条件互相矛盾时才询问。
3. 仍有缺项时进入 `ASK_REMAINING`，不生成提示词。
4. 没有缺项时进入 `GENERATE`，输出六维锁定卡、中文提示词和 English Prompt。元素项同时记录摆放模式和最终位置；随机摆放必须先完成一次兼容位置选择，再把同一结果分别转写为中英文，不能分别随机。两份代码块都在末尾紧接完全相同的 Midjourney 参数。只有用户明确说“只要中文”或“只要英文”时才省略另一种语言。

中英文代码块都使用以下正向结构；英文版不混入中文模块名：

```text
[English style and scene identity], [English composition relation], [English physical camera relation], [English architecture and elements], [English light and color relation] --ar [ratio] --raw --s [value] --c [value]
```

两份提示词必须逐项对应：风格身份、主体位置、开放区、相机站位、已选人物的承载面、元素位置、光向、色彩和参数均一致。选择无人物时，不得为套用模板而补写人物或人物承载面。

## 常见错误

| 错误 | 正确行为 |
|---|---|
| 对未指定模块直接套默认并生成 | 先给选项并等待选择 |
| 已指定模块仍反复询问 | 只显示缺失模块 |
| 只列推荐项或截取部分选项 | 缺失模块内部完整显示固定选项 |
| 使用按钮、可视化或外部选择器 | 直接输出完整纯文本选项，让用户手动输入编号 |
| 发问同时给出完整提示词 | 问卷回合停在等待状态 |
| 用户说“直接生成”仍强制提问 | 立即用受控默认或随机补齐 |
| 用户只回答一半就擅自补齐其余 | 只补问仍缺失模块 |
| 未指定位置时不询问 `F5` | 提供随机摆放和自定义摆放两个选项 |
| 用户只选 `F5-2` 就直接生成 | 继续追问具体摆放文本 |
| 随机摆放完全无视构图 | 只从构图、镜头和物理承载兼容的位置中随机 |
| 用户只选自定义元素编号却不写内容 | 只追问该自定义文本，收到后再生成 |
| 用户选无建筑或无人物后仍自动补入 | 尊重可选状态，改用已选主体与其他可见尺度关系完成画面 |
