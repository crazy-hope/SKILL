# 场景总览

## 场景不是物件清单

场景描述承载面、主构、边界、连通路径、高差和终景之间的关系。一个场景可换物件，一个物件可进入多个场景；相机角度是另一个维度。

以下是可扩展的空间家族，不是封闭随机池。用户的明确空间关系优先；没有完全匹配的条目时，可从相近家族组合连续空间，不必为了命中条目改变用户需求或当场新增文件。

## 如何使用

1. 先按本次要求选择一个主空间家族；若需要复合空间，再选能说明实际连接的从属家族。
2. 完整阅读选中的场景文件，选择空间细类，明确核心物件与可选物件。可选列表不是加载清单，更不是必须全部出现在图中。
3. 从[物件总览](../objects/物件总览.md)读取实际物件的构造专题；需要调整桥腹只进入桥文件，不重写全局尺度。
4. 按[构图与调用](../composition-routes.md)选择观看关系和多图差异，再按共用尺度、光照和审计执行。
5. 用户排除项先过滤：无人不补仙女，无松不进入以松为核心的方案，无宫廷的水庭或桥境照样完整。不得以文件里的“核心”反向覆盖用户。

## 空间卡

内部记录以下关系即可，不要求机械填写长表或复制进最终提示词：

- 场景家族与实际变体；
- 主构是什么、承载面在哪里；
- 近中远如何连通，哪些地方有真实高差；
- 尺度链从什么熟悉参照起步；
- 建筑可见面、相机位置与人物身体朝向；
- 主次、光线和本次排除项。

命名示例T1–T5、4A/4B保留在相关文件中，只供明确匹配时复用；其数量、方向和焦段条件不成为整个场景家族的默认值。随机不同场景不必依次遍历编号，也不能仅因编号不同就认定画面不同。
