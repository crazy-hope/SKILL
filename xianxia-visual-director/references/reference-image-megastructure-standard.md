# 参考图巨构标准

本标准只在[仙侠共享总则](xianxia-master-rules.md)和[东方苍穹巨构](eastern-sky-megastructure-style.md)之下使用。它强化参考图驱动的`东方苍穹巨构`，绝不能替代五层空间、40–60%内容承载空气、可量化尺度、无栏杆和仙衣语法。

## 参考图角色与权属边界

每张图分配一个或多个角色：

- `编辑目标`：只有用户明确要求修改该图时使用。
- `构图参考`：裁切压力、地平线、负形、空间路径和尺度层。
- `建筑/材质参考`：承重路径、檐深、斗拱密度、石、漆、青铜和鎏金响应。
- `氛围/光线参考`：云层高度、雾的位置、光线方向与色温分离。
- `排除参考`：手机界面、黑边、底部指示条、播放控件、文字、印章、标志、水印、栏杆或生成瑕疵。

默认所有来源都是非编辑参考。说明迁移什么、重新设计什么；绝不复制源图完整圆环、精确松树剪影、宫殿排布、人物位置、日落位置、角色或专有装饰。

## 提取的视觉语法

- 巨型屋顶、柱、天环、天障、平台或宫基有意不完整并继续出画。
- 深檐与密集斗拱只在梁柱传力处证明重量；巨墙和玉石大面安静。
- 前景更暖、更锐、更有材质；远云、远宫和天空更冷、更亮、更低反差。
- 结构开口显露有人居住的第四层和终端第五层，不能只是平面天空纹理。
- 远方成年仙女约占画高1–3%，优先背面或侧后方，只作为尺度证据。默认静止或稳定慢走，绝不快走、奔跑或冲刺。
- 一棵古松或一道瀑布可以平衡建筑；结构已足够时省略。
- 所有门槛、露台、桥、长廊、平台和云崖边缘默认无栏杆。

## 结构事件路由

每图只选一个：

1. `半幅巨柱`：一根裁切承重柱占三分之一至一半，并明显支撑屋顶、天障或宫殿体量。
2. `结构性天环`：厚重分段天环嵌入宫基、柱或屋架，部分裁切或遮挡，绝非漂浮科幻圆环或普通月门。
3. `悬空镂空天障`：厚重不对称穿孔屏障有可见支撑或悬挂点，并以主开口通向深层天域。
4. `悬空宫基`：被裁切宫基或深檐底部压住上部，斗拱、肋和梁在透明冷阴影中仍可读。
5. `无尽建筑长廊`：巨大檐、柱和庭院序列沿一个稳定消失系统延伸到不可见终点。

每个事件都要有承重路径、厚度、裁切、人物承载阈境，以及至少一个承载第四与第五层的开口或虚空。

## 宫殿配色路由

每图只选一种：

- `纯白`：近中性白玉、象牙白、珍珠灰，金属强调0–4%。
- `朱红`：矿物朱红漆、深红棕木，以云白和冷蓝灰阴影稳定。
- `古金`：低纯老金、包浆青铜、暗青石、月白；亮金只在磨损凸缘。
- `红金`：深朱红结构加古金斗拱或窄屋沿；云、天空和石材不得橙金罩染。
- `白金`：月白玉配克制珍珠金结构缝、天障边和受光边。
- `传统青绿彩画`：绑定构件的朱红、石青、石绿、群青、赭色、象牙白、深木和窄旧金；阅读[传统建筑彩画配色](traditional-polychrome-palettes.md)，选择一条子路线并锁定风化程度。

配色是材质分布，不是全图滤镜。默认近暖远冷，云亮部近中性，阴影保持透明青灰、板岩蓝、蓝绿或紫灰。传统彩画还要区分建筑颜料与蓝天、绿树和珊瑚花，并分别说明建筑表面与全画面的色彩预算；不得硬塞进朱红、红金或古金路线。

## 细节密度、氛围与运动

- 精细斗拱集中在大檐下、梁柱转换、天环接点、天障内缘或柱础。
- 斗拱模块随纵深缩小；最大两至四个平面保持缩略图可读。
- 薄雾只在宫基、瀑布、门洞边和云层局部，禁止统一灰幕。
- 使用一个有动机的侧光或逆光；悬空宫基可在底缘下保留一道窄暖日光。
- 最多一个自然锚点和一个主要运动方向，松枝、瀑布、云流、发丝与布料不得争夺建筑。
- 视频镜头固定或缓慢；镜头推进只改变构图与视差，不能加速或时间重映射人物、云、水、瀑布、布料、发丝、粒子或建筑。
- 冲击力和紧凑节奏属于构图与揭示，不能覆盖速度规则。

## 可复制提示词模块

```text
半幅巨柱：画面左侧一根被上下边框同时截断的巨型承重柱占据约半张画面，柱体直径约八个成年人高度，深雕只集中于柱基和斗拱过渡，柱—梁—檐承重路径清晰；右侧开放云域保留四重远景。

结构性天环：一道厚重分段的天环斜贯白金主殿，环体下段埋入悬空宫基，上段被屋檐与画框遮挡，内侧显露云桥、从属宫阙和终端高天；不是完整居中的月洞门，不是独立漂浮的科幻圆环。

悬空镂空天障：一面巨型玉石屏障横贯中景，由云气、山势和水脉形成三组不对称负形开口，屏障有厚度、支撑和克制内缘浮雕，最大开口约四十个成年人高度并通向极远天域。

悬空宫基：红金主殿底部压住上半画面，层叠斗拱和梁架如倒悬山脉，宫基继续伸出左右画框，低位太阳从底缘下方掠过，近处暖金受光边与远处冷蓝云海分离。

无尽建筑长廊：白金深檐与巨柱沿一个偏侧消失点延伸数百个身体宽度，近柱与檐底被画框裁切，数十组斗拱规律缩小，远处主殿仍不可完整看见，人物只有画面高度约1–2%。
```

## 多图差异矩阵

第二张起，每图改变结构事件，并至少再改变：

- 焦距、距离、俯仰、地平线或裁切；
- 宫殿配色；
- 黎明、上午、日落、月光或云隙光；
- 背面、侧后方、静立、慢走或仰望动作；
- 可选松、瀑布、崖或云河；
- 单点、对角、框景、压缩、纵向或蛇形几何。

不要在系列中重复同一居中天环、三仙女排列、松树剪影、机位或白玉红金组合。每份提示词仍要写出五层空间、40–60%空气、四项尺度证据和无栏杆。

## 参考图审计

- 来源角色和非编辑状态是否明确？
- 迁移属性是否抽象为几何、承重、材质、氛围和光线？
- 是否一个事件主导、被裁切且有结构支撑？
- 斗拱与浮雕是否局部，巨面是否安静？
- 是否一种宫殿配色清楚分布且没有全局罩染？
- 传统彩画是否写明子路线、构件绑定、两级预算和因果风化？
- 是否近暖远冷，薄雾局部？
- 微小背面仙女是否从属于五层空间？
- 人物是否静止或慢动，镜头是否缓慢且不改变世界速度？
- 截图界面、栏杆、文字、印章、标志和水印是否排除？
- 系列中的事件、镜头和配色是否真正改变？
