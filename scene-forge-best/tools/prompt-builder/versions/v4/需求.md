# 工作台 V4 需求

- 日期：2026-10-16；基线：工作台 V3，规范仍为 V5。
- 用户要求：“那你按照上面的题材和元素进行添加吧”。此前明确：具体题材元素只能在工作台维护，不进入规范文档。
- R-01：按已讨论的六组扩充至 30 个题材，每题材 10–15 个场景、30–50 个分类元素，覆盖人物、生物、建筑、交通设施、载具、服饰、器物、信息、基础设施、自然、活动、痕迹。
- R-02：题材按组展示，场景和元素联动；支持搜索与分类筛选，结合画面内容优先推荐相关类别。
- R-03：不自动勾选推荐项，不删除切换题材前的选择；兼容旧题材名称、自定义、预设、历史和负面输入。
- R-04：库独立放在工作台源码中；规范所有版本保持不变，完整保留应用旧版，更新启动器和记录。
- 本轮按此前“先完成内置库扩充、分类搜索和场景联动”的顺序实施；AI 推荐、个人收藏不是本轮交付项。没有自动接口请求、真实模型调用或实际出图。
- 内容为创作候选，不宣称历史考据或特定作品官方设定。不能用重复添加前缀凑足数量。
