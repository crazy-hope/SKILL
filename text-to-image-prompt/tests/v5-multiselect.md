# v5 单选卡片多选收集模拟

范围：只读根 SKILL.md 与 references/visual-direction.md。未调用真实提问工具，未修改项目、未生图。下面是依据当前规则手工执行的对话状态模拟与拟调用 JSON，不代表实际客户端弹窗端到端验证，也不代表 Midjourney 生图效果验证。

模拟 schema 为 `{questions:[{title,options?}]}`，options 使用字符串数组；没有添加 multi_select、id、description 等额外字段。状态中 confirmed=false 表示集合已有值但尚未完成本项。

## 1. 无设置首题与异步 accepted

初始状态：所有八项为空；stage=settings；current=表现方式。

拟调用：
```json
{"questions":[{"title":"画面想用哪种表现方式？可直接输入多项，以＋或逗号分隔；点击单项后可以继续添加。","options":["电影画面（镜头叙事、光影与场面调度）","纪实摄影（观察式、现场感）","插画","油画","动画／卡通","微缩模型","自由选择"]}]}
```

模拟返回：`{"status":"accepted"}`。

状态保持：表现方式=[]，confirmed=false；current=表现方式；pending=true。不把电影画面作为默认值，不再发下一题，不重复发卡片。模拟本轮结束，等待用户回答。电影与纪实是独立选项。通过。

## 2. 点击电影后追加油画再完成

用户点击：电影画面。

状态：表现方式=[电影画面]，confirmed=false；current=表现方式。

拟调用：
```json
{"questions":[{"title":"当前已选：电影画面。还想添加哪种表现方式？也可输入更多方向；选完请完成本项。","options":["完成本项选择","纪实摄影","插画","油画","动画／卡通","微缩模型"]}]}
```

模拟 accepted：状态不变。用户点击油画后：表现方式=[电影画面,油画]，confirmed=false。

拟调用：
```json
{"questions":[{"title":"当前已选：电影画面＋油画。还想添加哪种表现方式？也可输入更多方向；选完请完成本项。","options":["完成本项选择","纪实摄影","插画","动画／卡通","微缩模型"]}]}
```

模拟用户再次自由输入“油画”：去重，集合仍为 [电影画面,油画]；没有覆盖电影。用户随后选择“完成本项选择”：confirmed=true，current=具体视觉风格。

下一拟调用：
```json
{"questions":[{"title":"电影画面＋油画想采用哪些具体视觉风格？可输入多项，以＋或逗号分隔。柔和光学让电影部分高光柔和；低反差细腻保留柔和明暗层次；细腻平滑或厚涂决定油画部分的笔触。","options":["柔和光学","低反差细腻","细腻平滑笔触","厚涂有触感","自由选择"]}]}
```

通过。融合需解释电影镜头表达与油画笔触／背景的分工；不能默默把人物卡通化。若具体分工显著改变结果，按规则另发一个澄清问题。

## 3. 具体风格一次自由输入组合

输入：柔和光学＋低反差细腻。

状态：具体视觉风格=[柔和光学,低反差细腻]，confirmed=true；表现方式仍为 [电影画面,油画]；current=题材。自由组合完整接收，不只取首项，不要求再改成单项。

拟调用：
```json
{"questions":[{"title":"想创作哪些题材？可以选一个，也可以融合多个；可直接输入，例如东方仙侠＋古典神话。","options":["东方仙侠","古典神话","科幻","奇幻冒险","生活","历史","自由选择"]}]}
```

通过。成品需同时有柔和高光与克制反差／细腻层次，不能让“柔和”成为全部模糊。

## 4. 题材组合与每个候选保留

输入：东方仙侠＋古典神话。

状态：题材=[东方仙侠,古典神话]，confirmed=true；文化背景=东方（来源为本轮用户输入“东方仙侠”）；current=内容现实性。题材没有自动授权现实性。

拟调用：
```json
{"questions":[{"title":"人物和事物必须属于现实世界，还是允许奇幻设定？","options":["现实世界：可存在的环境与可发生的事件","写实奇幻：允许超现实设定，材质与接触可信","自由选择：可提出两类并标明"]}]}
```

模拟 accepted：停在内容现实性，不生成场景。

为单独检验候选，补充明确测试输入：用户主动回答“写实奇幻，16:9，版本沿用界面，Personalize 关闭”。八项齐全才形成如下五个短构思；这些是模拟测试数据，不是假装前面的 accepted 已有答案。统一融合策略为电影镜头调度、可信人物材质与油画背景笔触，柔和高光、低反差层次，东方服饰器物，写实奇幻；无指定制作年代。

1. 天河断桥：东方修行者在天河石桥断口用剑诀牵引桥链，神话灵龟以龟甲托住断桥，修行者俯身将铁环扣入龟甲上的旧桥桩。仙侠行动与灵龟世界设定共同完成修桥；电影近中景突出手部接触，油画笔触组织河雾，柔和高光与低反差保留湿石层次。
2. 神木扶枝：东方修行者站在神木树根旁，以符索收紧垂落枝条，神话三足鸟咬住索头协助转向，枝条正在避开石阶上的药篮。仙侠符索与神话生灵共同处理枝条；电影斜侧视角展示受力，背景叶群有油画笔触，柔和光线与细腻低反差表现树皮。
3. 海门封隙：东方修行者跪在海神祠石门前，把剑身插入裂隙作支撑，神话龙神伸爪稳住石门上缘，二者正在阻止门后的水涌出。仙侠人物行动与龙神共同阻挡危机；电影低视点强调接触，油画海雾背景与柔和高光、低反差石面融合。
4. 月宫接灯：东方修行者立于月宫回廊，将坠落的灯架压住栏杆，神话玉兔在另一端用前爪拨开缠住灯链的桂枝。仙侠角色与月宫玉兔参与同一事件；电影侧面中景保持动作可读，油画桂树背景有细腻笔触，灯光过渡柔和且暗部反差克制。
5. 河图护卷：东方修行者在河岸石台压住展开的河图，神话龙马低头以鬃毛挡住溅来的水，两者保护图卷上正显露的纹路。仙侠寻图行动与龙马神话设定共同呈现发现；电影肩侧观察突出压卷与挡水，油画背景水流配柔和高光和低反差纸面层次。

拟场景选择：
```json
{"questions":[{"title":"想继续哪一个场景？可输入编号或修改意见。","options":["1 天河断桥","2 神木扶枝","3 海门封隙","4 月宫接灯","5 河图护卷","换一批"]}]}
```

状态：stage=scene_selection；selected_scene=null。模拟 accepted 后保持等待。五项均使两类题材共同参与事件，未拆成“纯仙侠场景”和“纯神话场景”。通过（文本模拟）。

## 5. 只要电影

独立初始用户输入：“仅电影”。

状态：表现方式=[电影画面]，confirmed=true；不是 [电影画面,纪实摄影]。下一题是具体视觉风格：
```json
{"questions":[{"title":"电影画面想采用哪种具体视觉风格？可输入多项，以＋或逗号分隔。柔和光学强调柔和高光；清晰通透强调清楚层次；浓郁明暗强调深浅对比；低反差细腻强调克制反差。","options":["柔和光学","清晰通透","浓郁明暗","低反差细腻","自由选择"]}]}
```

输出词汇约束：可用 cinematic composition；不得默加 documentary、street photography、抓拍或纪实。用户没确认题材、现实性前仍逐项问。通过。

## 6. 怀旧胶片不推导年代

前置表现方式已确认电影。用户输入具体风格：“怀旧胶片”。

状态：具体风格=[怀旧胶片]，confirmed=true；制作年代=null；故事时代=null。下一拟调用为第 3 项题材 JSON（与案例 3 完全相同），不追加一个强制年代问题，也不凭空选 1970／1980／1990 年代。

允许的画面实现：细颗粒、柔和高光滚降、略克制的饱和度，按场景分配颜色。禁止自动写“1980年代电影”“上世纪七十年代街景”。通过。

独立输入：“仅电影，具体风格用1980年代电影质感，故事仍是东方仙侠和古典神话融合”。

拟调用：

旧记录 A：表现方式=电影画面（明确用户原话）；具体风格=柔和光学；文化=东方；现实性=写实奇幻；画幅=16:9；版本=沿用界面；Personalize=关闭。用户说：“沿用上次全部设置”。

## 发现与限制

- 当前文本明确覆盖八项测试要求，未发现阻断性规则缺失。
- 自由输入组合被视为完成本项；单击选项则需要显式“完成本项选择”。这是文本规定的有意差异，实际客户端尚未测试。
- 单选后的追加卡片若工具选项数量受限，需要按工具能力分层；本模拟仅按题定的无限定 options 数组，不验证实际限制。
- 混合媒介分工可能显著改变结果，当前规则允许必要单题澄清。候选示例给的是一种一致策略，并不证明模型在所有实际对话中都会执行正确。
- 验证结论仅为规则驱动的文本／工具计划模拟；没有声称真实弹窗、真实异步用户回传或图像效果通过。
