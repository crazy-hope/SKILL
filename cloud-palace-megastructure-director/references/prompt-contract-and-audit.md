# 提示词契约与审计

## 提示词装配

全局默认与条件优先级以主文件为准，尺度与镜头以尺度参考为准。下列字段是内部核对清单，不要求逐项复制进最终提示词。最终按“画幅与机位 → 主构和支撑 → 人物与连续尺度链 → 材质光照 → 适用排除项”组织，只描述本图实际内容。人物段写承载位置、相邻尺度关系与叙事主次，默认不写画高百分比、像素框或等价份额限制。无参考图不虚构参考角色，静态图不加入视频速度契约。

内部参数索引用于防遗漏；最终只组装适用内容：

`画幅与机位 → 主构、支撑与连通 → 人物或替代参照、承载关系和尺度链 → 材质、装饰与光照 → 适用排除项`

第一句话必须写明支持的画幅比例、机位和主导几何关系。

每张最终提示词只描述当前选定的主导路线、可选从属事件、实际结构和尺度链，不罗列其他候选场景。未选中的特殊结构名称不得出现在正向提示词或负面约束中。

## 正向提示词契约

按适用条件核对以下内容；同一关系只需清楚表达一次：

- 一个支持的画幅比例；用户未指定、要求随机或直接生图时明确写`16:9`，只有用户明确指定其他比例时才覆盖；
- 写明机位家族、相机相对主构方位、机位高度、观看距离、俯仰角和焦距；
- 按尺度参考的“机位的可见证据与系列去重”，补充建筑可见面、人物身体朝向、视线与主轴关系；避免仅用“正面/侧拍”等名称代替可见空间关系；
- 写明一个与当前路线兼容的场景拓扑，并把它落实为相机、人物承载面、主构和开放天域之间可见的物理关系；不能只写拓扑代号；
- 按尺度参考记录人物身体前向与相机相对人物的水平角`θ`：人物正前方为0°，默认尽量避开315°经0°至45°的正面扇区（含边界），以侧面、背影为主；写出一个目标角度及一致的自然描述。它与建筑机位分别记录、联合核对，不为随机去重插入正面，也不固定侧后45°；明确用户朝向或机位优先；
- 明确使用人物还是替代尺度参照；启用人物且未指定性别时，正向提示词明确写“成年中国仙侠仙女”或“成年女仙”，不得只写含混的“人物”“仙者”或“旅人”；只有明确男性指令或男性人物编辑目标才写男性；无人场景不强行添加仙女；
- 启用人物时写其所在承载面、近旁人尺度使用细节及通向主构的连续关系，人物大小随场景和透视形成；默认不选档、不抽取百分比、不规定像素高度。用户明确指定数值时按尺度参考作为当次附加目标；无人场景写实际替代参照；
- 默认焦段35–50mm；人物完整位于可读近中景承载面，距离服从空间与相邻参照，不为凑比例把人物推远，也不附加未经校验的米数。天环或明确远景等条件按尺度参考处理，改变机位后联动核对尺度链；
- 柱径、柱础、主巨柱与开口按尺度参考分级选取；实际尺寸不与投影宽度混用，不给每一层柱体套同一高度和直径；
- 人物和建筑共享可信三维空间、相机投影、光照与大气系统；允许不同标高和方向，恢复真实接触、投影与遮挡；
- 写出`人物或替代尺度参照 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`中的实际连续尺度链，至少显示三级，标准巨构优先四到五级；
- 一条主导构图路线，以及需要时一个低权重、物理兼容的从属事件；
- 结构事件可为“无”；若已选择事件，交代真实支撑关系，不因提供参考图而强制增加事件；
- 主导结构在何处被裁切或延伸出画框；
- 单一连续巨构保持“整体轮廓 → 云域 → 人物或替代参照”的主次；保留巨跨、桥腹和错层，重复构件汇入同一承重系统；大面安静，装饰集中于结构转换带；
- 宽大、气派的宫廷或平淡叠层的纠偏，主构段按[宫廷气势规则](architecture-and-materials.md#宫廷气势横向体量主次重量与净跨)写清四个可见关系：`横向展开及进深 → 主殿与从属体量的高低进退 → 檐底、宫基厚度与传力路径 → 主柱净跨及其尺度参照`。未展示的构件标为不适用；单体场景不为了填字段强加侧殿；
- 用户指定楼层数时，保留实际使用层数；宽大宫廷说明楼层如何进入横向体量、退台与主从檐带。楼层数不默认等于屋檐数，要求各层可数时提供可辨的层廊或立面段；数量与气势分别核对，不用同形薄层机械叠加换取计数清楚，也不以造型为由忽略明确层数。用户明确要求细高塔体、同形等距叠层或轻盈薄檐时保留其要求，不强制横向展开、退台或加厚；
- 选择结构性天环时，明确改为远景或超远景完整入画：圆周四边留白、不得被画框截断，并写出支撑跨度、人物与多层远景尺度证据；
- 选择悬空镂空天障时，依据屏障宽高比只锁定圆形或方形一种家族；一个主开口占主导，任何从属开口必须同形、规整且明显更小；方形边线与建筑水平轴、垂直轴平行，不得旋转成菱形；
- 至少三层连续空间；标准外部巨构优先四到五层；
- 外部开放场景可参考40–60%内容承载空气；内部、垂直和极简构图写明自己的连通逻辑；
- 外部开放路线说明直接连通，内部框景说明开口厚度、围合与纵深，桥下路线说明下构和云隙；
- 展示主殿、深殿、多层宫廷或有顶巨廊时，主构段明确写出四个关系：横向净跨及两侧延伸、近中远大开间的纵深路径、各层地坪至梁底的高净空、中央空场与边带陈设；按建筑参考组装，不把这些维度省略为一个“宏大”。未展示的内部维度不强加给纯外景或局部窗景；
- 至少三个相互连接的尺度证据；
- 一个明确视觉主导关系，以及数量由画幅和层级决定的从属体量与自然元素；
- 中性基底、中等纯度材质色、高纯强调色和阴影色；
- 请求宫殿配色时，指定一个主导家族，并可选择一个相容的从属家族；
- 选择传统矿物彩画时，指定一条命名子路线、分别给出建筑表面和整帧预算、颜料到构件的落位，以及有物理位置的风化等级；
- 深斗拱或浮雕只集中在结构带或人物可识别区域；
- 一个主光方向；
- 光照使用建筑与材质参考的统一默认池；用户指定其他时段或天气时才采用扩展。所有路线保持柔和、不过曝和结构可读；
- 单一连续巨构模式沿用全局光照规则，不另行覆盖；
- 用户明确指定中午或下午时，写明建筑遮光、云层漫射和高光控制，不把它们加入随机默认池；
- 人物默认是尺度参照，动作服务于空间；允许仪式队列、攀登、迎风站立或克制动态，不以无动机奔跑和运动模糊制造冲击；
- 对视频，采用固定或缓慢镜头，推移/环绕只影响构图和视差，绝不影响世界空间运动速度；
- 栏杆若存在，保持局部、从属且不封死开放空间或遮挡尺度链；始终排除截图污染。
- 建筑与金属洁净、完整且有人维护；允许轻微褪色或磨亮，不允许锈斑、锈水、腐蚀和废墟感。

## 默认负面约束

```text
避免缺少主次的小建筑、塔楼、屋顶或浮岛平均堆积；复合城市与多体量场景必须保留一个清楚主导轴线、结构关系或空间事件。使用人物时，避免后贴、拼贴、悬浮脚、错位投影、不同焦距拼接，以及人物与建筑透视、光照、锐度或大气层级不一致；无人场景必须提供其他连续尺度参照。允许受控鸟瞰、超广角和浅景深，但避免平均铺开的游戏地图感、鱼眼式结构弯曲、混乱消失点，以及只靠畸变或虚化伪造巨构。避免刺眼白热眩光、太阳白洞、过曝天空与云层、大片高光剪切和吞没材质纹理的死黑阴影。人物动作可以变化，但避免无动机的奔跑、冲刺、突然前倾或运动模糊抢走主构；镜头运动不能无故改变人物、云雾、水流、布料、粒子或建筑的世界空间速度。栏杆可以存在，但避免连续横贯主要开放空间、遮挡尺度链或均匀覆盖所有边缘。不要手机外框、黑边、灵动岛形状、播放控件、音量条、字幕、倒计时、文字、标志、印章、签名或水印；不要复制参考图完整构图、角色、坐骑或专有设计；避免均匀灰雾、脏灰调色、无层次死黑、无差别全局色罩、塑料木材或塑料玉石；不要锈迹斑斑、橙红锈斑、绿锈团块、锈水流痕、腐蚀穿孔、金属剥落、坍塌或废墟感。
```

## 条件负面约束

只在当前路线被选中时，把对应一段追加到全局负面约束；未选中时不得出现该段或相关结构名称。

- `结构性天环`：不要近景或贴脸大环、圆周越出画框、半环、四分之一弧、无法闭合的弧段、科幻传送门、发光光圈或没有承重路径的装饰环。
- `悬空镂空天障`：不要随意不规则缺口、撕裂轮廓、山洞状破洞、碎裂孔、自由曲线负形、菱形、扁菱形、旋转四十五度方形或圆形与方形混用。
- `默认仙女人物`：启用人物且用户未指定性别时，追加“不要男性人物、男仙、男修、男性剪影、男性面部特征或男性服饰轮廓”。用户明确指定男性，或男性人物图像是明确编辑目标时，不得追加本项。

默认负面约束是按需选取的清单；仅保留当前场景适用的质量要求与用户明确排除项。静态图不追加镜头速度条款，无人场景不追加人物身份条款。
用户明确禁止的每个元素都必须作为独立、字面明确的排除项写入场景专属负面约束。不要依赖暗示：如果用户说“不要迎客松”，还要排除松树、松枝和松针；其他被点名的禁止元素也要按同样方式展开。

## 图片集归档契约

每次独立生图请求建立一个图片集目录。目录名由一次性锁定的本地时间戳和本次图片的语义名称组成：

`YYYY-MM-DD HH:mm:ss语义名称图片集`

例如：`2026-10-20 20:30:30云宫巨松观景台图片集`。

- 用户指定保存位置时，以指定位置作为根目录；否则以当前工作区或项目图片资源目录作为根目录。
- 在请求开始时只取一次时间戳；同一批多图和这些图片的针对性修订复用同一目录。新主题、新批次或另一次独立生图请求重新取时间并创建目录。
- 语义名称优先采用用户给出的主题或项目名，否则从主体、场景和主构关系中提炼简洁中文名；无法判断时使用`云宫巨构`。移除`/`、反斜杠、换行和控制字符，不生成嵌套路径。
- 图片按顺序命名为`01-语义名称.扩展名`、`02-语义名称.扩展名`。针对性修订继续递增序号，不覆盖原图。
- 文件夹重名时追加`-02`、`-03`；文件重名时在扩展名前追加`-02`、`-03`。先检查目标，再执行创建或复制。
- 内置生图工具先在默认目录生成时，把成功输出复制到图片集目录并保留原始文件；只有用户明确要求时才移动或删除原始输出。
- 最终交付路径以图片集目录内的副本为准；报告图片集目录和每张归档图片的完整路径。

## 直接生图规程

用户明确要求生成图像时：

1. 用户未指定画幅时，先锁定`16:9`；只有明确画幅指令才覆盖。
2. 锁定保存根目录、一次性本地时间戳和语义名称，按图片集归档契约自动创建独立文件夹；同批后续图片与针对性修订复用该文件夹。
3. 把提供的图像标记为有明确角色的参考图，不自动视为编辑目标。
4. 只使用能够覆盖几何、材质、氛围和尺度的最小代表性参考图子集。
5. 按统一尺度参考锁定身份、朝向、承载关系和镜头。默认成年仙女、侧面或背影优先、35–50mm；先组织空间与相邻尺度证据，再安排人物落位，不预设画高数值。正面按叙事条件低频使用，特殊机位按条件处理。无人场景不添加人物。
6. 明确说明排除截图UI和水印；栏杆可用，但必须保持局部、从属且不遮挡尺度关系。
7. 用户要求随机或不同场景时，先从10条主导路线抽取，再从兼容表选择场景拓扑、机位家族和尺度参照；多图优先不放回。连续叙事或同场景镜头组允许重复路线、拓扑和机位。先记录主导路线、可选从属事件、拓扑、物理关系、机位、尺度参照、人物身份与身体朝向（如有）和结构事件。
8. 每条提示词只描述当前选定的主导路线、可选从属事件、拓扑和机位，不得把候选路线库写进提示词。
9. 只追加当前路线适用的条件负面约束；没有选中天环或天障时，不得在正向或负面提示中提到它们。
10. 分别检查实际机位、人物身体朝向、人物与相邻构件的比例及巨构空间：先根据立面、地坪、遮挡及人体可见面核对观看关系，再检查熟悉使用细节、连续尺度链、跨度、净高、厚度和高差。多图并排比较实际空间骨架，允许人物画高随场景变化；不设通用人物百分比合格线。
11. 纠偏必须指出具体空间或叙事问题，用户未指定人物数值时，不因画高数值触发缩小编辑，也不把“先生图、再缩人”作为默认两阶段流程。用户明确要求按指定数值修图时，联合校验数值与空间关系；人物与同深度参照确有比例矛盾时，可针对性修复人物和关联接触、阴影；建筑跨度、净高、纵深或尺度链不足时修正关联结构，不锁死空间只缩人。人物朝向或建筑机位有误时联动处理姿态、承载面透视及遮挡。修订后重新核查空间与主次，避免自动重做整批或无限重试；仍有偏差时如实报告。用户只反馈问题或要求更新 skill、未要求生成时，不再生图。
12. 图像生成成功后，按两位序号把原始输出复制到已锁定的图片集文件夹；复制前检查重名并追加序号，保留生成工具目录中的原始文件。
13. 验证归档图片存在、文件类型正确且可读取；文件完整性通过不代表视觉尺度通过。报告实际可见的空间证据与偏差，不默认列人物百分比达标表；用户要求量化时按尺度参考明确测量口径与不确定性。最终报告图片集与归档路径。

## 诊断表

| 症状 | 根本原因 | 源头修正 |
|---|---|---|
| 未指定画幅却生成竖图或方图 | 提示词只写“宽画面”，没有锁定具体比例 | 把`16:9`写在提示词首句和参数锁定中；只有明确画幅指令才覆盖 |
| 默认人物生成男性 | 人物身份只写“人物”“仙者”或剪影 | 正向明确成年中国仙侠仙女或成年女仙，并追加默认仙女人物的男性排除项 |
| 图片散落在工作区或只留在生成工具目录 | 没有在请求开始时锁定图片集目录 | 从请求语义提炼名称并锁定一次本地时间戳，自动创建`YYYY-MM-DD HH:mm:ss语义名称图片集`，再把成功输出复制归档 |
| 同批图片分散到多个时间目录或覆盖旧图 | 每张图重新取时间，或复制前没有检查目标 | 同一批及其针对性修订复用一次时间戳和同一目录；图片用两位序号命名，目录和文件碰撞时追加递增序号 |
| 建筑显得小而杂乱 | 过多独立体量共享相同反差和细节 | 保留一个主导轴线、片区或结构关系；用尺寸、反差和大气层级组织其他体量，不必机械删除复合场景 |
| 观看者感觉被墙围困 | 当前承诺是外部开放场景，但中景墙挡住地平线 | 若路线需要开放感，让墙体退让并恢复外部连通；若是内殿揭示，则强化门洞、柱阵和光线形成的有意框景 |
| 宫殿很大但没有神性 | 没有已知尺度对比或终端远景 | 加入真实体型的成年人、可量化柱/开口、跨云层宫基和极远锚点 |
| 巨殿像小门厅，柱粗但空间局促 | 只放大近柱或门洞，遗漏横向净跨、殿内纵深与梁底净高 | 同步扩展主柱净跨、中央地坪、近中远大开间和地坪至高梁底的距离；将家具退至边带，保留可读承重，不只缩小人物 |
| 多层宫廷总高度很高但层层低矮 | 把总楼高或屋顶厚度误当成每层净高 | 各层分别以本层地坪至梁底核查，扩展上层净空与跨度，不通过堆叠薄层增加高度 |
| 宫廷像普通楼阁逐层复制，越补层越像窄塔 | 让层数决定整体轮廓，缺少横向体量和进深组织 | 先恢复连续基座、横向主殿、前后进退与退台，再在该骨架中落实指定楼层；分别复核层数和气势，明确塔体要求时不改成宽扁宫城 |
| 主殿、侧殿和每层屋顶都同等显眼 | 体量同形同尺度，主次只靠装饰或亮度区分 | 选定主导殿体，以高度、净跨、进退和遮挡组织从属体量；极简单体以主屋盖、基座和开间建立主次，不强行增加建筑 |
| 屋檐和宫基轻薄，宫殿像摆在漂浮板上 | 只画轮廓、瓦面和底板，未展示厚度与荷载传递 | 补清深檐底部、梁架斗拱、主柱与厚宫基侧壁或承重肋的连续关系；楼船接入甲板、船壳与龙骨，同时保留净高和阴影细节 |
| 柱子很粗却仍像窄门厅或普通走廊 | 把柱径、柱列长度当成柱间净跨 | 以同深度通行门和次级开间建立参照，扩大主柱内缘净跨与中央空场，用相应主梁、深桁架或托臂承托屋盖，不靠删支撑或缩人 |
| 正面人物频繁出现或抢走建筑主体 | 将五种朝向等概率轮换，把多样性理解为必须凑齐朝向 | 默认优先侧面、背面和侧后三分之四；正面仅作低频叙事选项，允许朝向重复，改用拓扑与机位提供变化；明确用户朝向优先 |
| 人物抢走主体，建筑失去压迫感 | 叙事权重、观看距离或相邻结构层级不当，不一定是画高过大 | 先查同深度使用细节、柱础、主柱净跨净高和纵深；按真实问题调整空间或观看关系。空间成立且建筑主导时，不因人物占比较大而缩人 |
| 人物很小但不能证明建筑巨大 | 人物与建筑不在同一连续空间，或尺度链断裂 | 把人物真实放在承载面上并显示至少三级连续尺度链；无人场景改用门洞、灯火、飞舟、树木或瀑布起链 |
| 人物周边的木柱或石柱仍像普通尺度 | 次级柱和主巨柱混用同一比例 | 按尺度参考区分人体使用层、次级柱、主巨柱及其承载体；用同深度参照比较实际尺寸，展示柱—梁/拱—宫基层级，不把普通高柱的尺寸作为主柱默认 |
| 人物像后贴或拼贴 | 人物与承载面或投影不一致 | 保留合理高差与方向变化，统一相机透视、光照、脚底接触与遮挡 |
| 系列人物与空间比例不一致 | 把画高统一当成真实尺度统一，或忽略各自深度与参照 | 保持人物真实体型及同空间透视规律，允许不同场景和镜头下投影大小变化；不强行锁定一个百分比 |
| 场景像鸟瞰游戏地图 | 高机位平均展示所有片区，缺少主导轴线和尺度断层 | 保留受控鸟瞰，但选定一个主导结构、桥系或云峡，利用遮挡、立面、明暗和尺度链建立层级 |
| 画面变灰变平 | 用均匀雾气表现纵深 | 雾气局部化；用明度、纯度和反差阶梯分离空间层 |
| 建筑显得嘈杂 | 所有巨大表面具有同等装饰密度 | 恢复安静巨面；把细节限制在一到两个可识别区域 |
| 出现参考截图杂质 | 把UI和水印误当成风格 | 重新标记参考角色；明确排除所有界面、文字和水印元素 |
| 天环或天障像科幻装饰 | 缺少承重路径、厚度或与宫殿的整合 | 把它嵌入柱、宫基或屋顶桁架并揭示更深的有人活动空间层；天环保持完整远景圆周，天障可裁切外墙但保留完整几何主开口 |
| 天环只剩四分之一弧，无法看出圆环 | 把通用裁切规则错误套到天环，或镜头距离过近 | 改用远景或超远景，把完整圆周和四周呼吸空间收入画面；用支撑跨度、人物与相邻参照、宫阙与云层证明尺度 |
| 完整天环仍显得像近景装饰圈 | 只靠画面占比制造巨大感，缺少环境尺度链 | 拉远镜头；同时显示至少两处巨型支撑、数百身体宽的跨度、环内宫阙、跨云层关系与终端远景 |
| 天障缺口像随机破洞或难看的斜向开口 | 使用了自由曲线、不规则负形或旋转方形，没有正确几何选型 | 按屏障宽高比锁定圆形或正向方形一种家族；所有从属开口同形且规整，方形不得旋转，并保持厚度与承重可见 |
| 宫殿像锈蚀废墟 | 把古老、包浆或旧金误译为腐蚀破败 | 恢复洁净完整、长期维护的表面；只保留轻微褪色、磨亮和受控材质变化，排除锈斑、锈水、点蚀与剥落 |
| 红金宫殿像主题乐园 | 暖色等量覆盖云、石材和阴影 | 恢复中性云/石材、冷色通透阴影和窄小陈金结构强调 |
| 细节丰富的宫殿仍显得小 | 装饰密度均匀且缺少人物尺度 | 把深斗拱集中在承重带；加入安静巨面和可量化成年人物对比 |
| “无边无际”变成无数小宫殿 | 把建筑数量误当成连续体量 | 只保留一块连续屋顶、墙体、柱廊、平台或宫基系统，让其延伸出画框；重复构件汇入同一承重关系，缩略图先读一个轮廓 |
| 十个变体看起来像同一张图 | 只替换了名词 | 改变构图路线，并至少再改变结构事件、镜头、裁切、配色、光线、锚点和人物动作中的两项 |
| 场景总是外部露台、宫墙一侧和开放云海 | 只抽主导结构，没有抽取人物承载面与主构的空间拓扑 | 从兼容表重新抽取场景拓扑，明确正面前场、对岸遥望、桥下仰望、深殿向外、屋顶台原等物理关系；只换配色不算新场景 |
| 镜头总在人物侧后方约45° | 把人物朝向误当成相机机位，或把侧后方当作安全默认 | 先按主构选择机位家族，再独立锁定人物身体朝向；随机变体主动轮换，连续叙事按镜头功能决定是否重复 |
| 提示词机位不同，成图仍都从人物右后方或背后望向天宫 | 只验收机位标签，忽略人物、视线与建筑主轴的实际关系 | 并排检查立面、地坪、人体可见面和遮挡；按尺度参考改变观看关系，不能只镜像、换色或把右后方换成左后方 |
| 缩小人物后便交付，但空间仍不成立 | 把人物变小当成巨构通过，忽略主次和连续尺度链 | 分别核查机位、身体朝向、相邻参照、承重与空间跨度；修改根因，不把孤立缩人当成完成 |
| 彩画宫殿显得霓虹或幼稚 | 朱红、绿、蓝和金拥有相同面积与纯度 | 把颜料绑定到构件；恢复石材/云的中性面；收窄赭色和金色；降低远景纯度 |
| 岁月宫殿显得破败或肮脏 | 风化被处理成随机脏污罩层 | 按暴露和使用规律落位褪色、雨痕、积尘和磨损；保持结构有人居住且完整 |
| 冲击力变得躁动、像游戏 | 动作、运动模糊和镜头速度同时争夺注意力 | 保留有动机的仪式行进、攀登或快速动作，但让主构仍由尺度、光线和视差主导 |
| 推镜导致云、布料或人物加速 | 镜头与世界运动被耦合或时间重映射 | 保持每种世界空间速度不变；慢镜头只影响构图和视差 |
| 中午或下午光线刺眼 | 高角度直射光、过硬阴影和白热反射同时出现 | 保留时段特征，用建筑遮光、薄云、大气和动态范围控制高光，恢复材质纹理 |
| 日出或落日变成橙色滤镜 | 暖色覆盖天空、云、石材和阴影 | 暖色只落在受光边缘与局部结构，恢复冷色天空填充和通透阴影 |
| 云宫被过曝白光吞没 | 太阳盘、云层和浅色石材高光没有上限 | 压低太阳和云层高光，保留白玉、云和檐边的明度层级与表面细节 |

## 最终审计

逐项检查适用项，不适用项明确跳过。文本审计检查提示词，视觉审计只在实际生图后执行；归档项只用于本次实际生成的图片。发现问题先修正根因，不无限重复生图。

- 缩略图尺寸下，是否由一个单体或复合东方巨构关系主导？
- 单一连续巨构是否先读整体轮廓，再读云域，最后读人物或替代参照？是否保留承重、厚度与高差层级？
- 用户未指定画幅时，是否已在参数和提示词首句锁定`16:9`；明确指定其他比例时是否正确覆盖？
- 主体占比、完整度和裁切是否服务于当前事件？若为结构性天环，是否完整收入画面并保留呼吸空间？
- 是否至少连续显示三层空间，标准外部巨构是否优先达到四到五层？
- 外部开放场景是否把40–60%内容承载空气作为参考，而内部、垂直或极简场景是否具有自己的连通逻辑？
- 除裁切和密度外，是否还能看见至少三个相互连接的尺度证据？
- 是否明确人物或替代参照，并说明承载位置、相邻尺度关系及叙事权重？是否没有默认抽取百分比、档位或像素目标？用户明确要求数值时是否仅对本次生效？
- 启用人物且未指定性别时，是否明确使用成年仙女并追加男性排除项？只有明确男性指令或男性人物编辑目标时，是否才切换为男性且不追加该排除项？
- 用户要求随机或不同场景时，是否选择主导路线与兼容拓扑并避免无意识重复？连续叙事时，重复路线和机位是否承担清楚镜头功能？
- 结构事件是否与路线匹配或明确为`无`，且提示词只描述当前选定的主导与从属事件？
- 使用人物时，景别是否服务于尺度或叙事，人物是否真实落在明确承载面上？
- 人物与建筑是否采用统一三维空间和相机投影，保持合理高差、接触、遮挡、投影及光照？
- 是否从人物或替代尺度参照起连续显示至少三级尺度链，并让相邻层级具有直接可读的大小或距离关系？
- 是否有一个明确视觉主导关系，其他建筑、自然元素和从属事件是否通过尺寸、反差、位置或大气层级保持从属？
- 对宽大、气派宫廷，是否能从实际轮廓读出横向体量与前后进深，且主次由殿体高低、进退、跨度或遮挡建立，而非只有同形屋顶等距叠层？明确要求的细高塔体或同形叠层是否仍被尊重？
- 要求厚重气派时，可见的屋檐与宫基是否有厚度、底部层级和连续传力路径，柱间净跨是否有同深度尺度参照及相应梁架支撑？这些关系是否保留了本层净高与中央空场，而非靠粗柱、薄板或死黑阴影代替？未展示的构件不适用；明确要求轻盈薄檐或狭小空间时不按厚重、大跨标准纠偏。
- 指定楼层是否按实际使用层独立核对，没有把同层重檐或左右侧殿拼数？补层后是否再次验证横向轮廓、主次、重量和净跨；是否没有因计数成功就宣称气势也已通过？
- 巨大表面和装饰密度是否服从当前风格；若高度装饰，是否仍有清楚结构与主次？
- 由参考图驱动时，是否明确说明参考角色、可迁移特征和被拒绝的源图特有元素？
- 所选天环、天障、巨柱或宫基下构是否具有可见厚度和可信承重路径？
- 若为结构性天环，是否为远景或超远景、完整闭合且没有被画框截断，并通过人物、支撑跨度、从属宫阙、云层和终端远景显示宏伟尺度？
- 若为悬空镂空天障，是否根据宽高比只选圆形或正向方形一种家族，所有从属开口是否同形且规整，并且没有菱形、旋转方形或随意不规则缺口？
- 天环或天障的专属负面约束是否只在对应路线被选中时出现？未选中时是否完全没有相关诱导词？
- 建筑和金属是否洁净、完整、有人维护，并且没有锈斑、锈水、腐蚀剥落或废墟感？
- 是否锁定明确的光照与天气路线，并明确主光方向、阴影软硬、高光上限与环境填充？
- 无论时段与天气，是否没有白热眩光、过曝天空、大片高光剪切或纹理丢失？
- 是否由一个主导配色家族和可选相容从属家族建立清楚身份，没有无差别全局色罩？
- 选择传统矿物彩画时，是否明确子路线、构件绑定、两类面积预算和因果风化？
- 是否已经锁定机位家族和相机相对主构方位，机位服从空间关系而不是默认落在人物侧后方约45°？
- 实际成图的建筑可见面、地坪透视、遮挡和人物身体朝向是否支持上述机位与观看关系？是否区分了身体朝向和头部转向，而非用提示词标签代替验图？
- 多图要求不同视角时，是否并排确认没有无意识重复“近景侧边人物＋从背后顺其视线望天宫”？只镜像、缩人、换色不算纠正；明确要求的固定机位、全背影与连续叙事是否仍被尊重？
- 默认镜头是否为35–50mm，人物落位、实际距离与承载面透视是否相容？特殊焦段是否满足条件，且没有仅为让人物变小而把其推到远处？
- 构件是否分成人体使用层、次级构件、主承重层？实际尺寸与投影宽度是否区分，是否有可读的厚度、跨度和高差？
- 是否分别记录建筑机位、人物身体前向及相机相对人物的位置角θ？是否以人物正前方为0°核对，默认尽量避开315°经0°至45°（含边界，360°等于0°），而非误用建筑轴线、镜头朝向或俯仰角？人物转身后是否重算？正面扇区的低频使用是否有用户指定或叙事依据，连续叙事是否允许重复角度？
- 展示巨殿内部时，横向净跨、近中远纵深、各层梁底净高和中央空场是否分别有可见依据？是否避开粗柱夹窄门厅、几步到远窗、低梁压头与低矮层密叠？不要仅用门高、总楼高或人物占比替代这四项；未展示的室内维度标为不适用。
- 若使用鸟瞰、超广角或浅景深，是否仍有清楚尺度链且没有用畸变或虚化伪造巨构？
- 人物动作是否服务于尺度与叙事，没有无动机奔跑或运动模糊抢走主构？
- 如果镜头运动，是否保持固定或缓慢，没有快速推进、变速或镜头诱发的世界运动加速？
- 云层是否在揭示结构，而不是吞没结构？
- 栏杆若存在，是否局部、从属，并且没有横贯开放空间、遮挡尺度链或覆盖所有边缘？
- 手机UI、黑边、字幕、Logo、印章和水印是否全部缺席？
- 用户指定的每个禁止元素及其近似变体是否都被明确排除并且缺席？
- 是否已在用户指定根目录或当前工作区图片资源目录下创建独立图片集文件夹，名称严格符合`YYYY-MM-DD HH:mm:ss语义名称图片集`？
- 同一批多图和针对性修订是否复用同一时间戳与文件夹，而新主题或新批次是否创建新目录？
- 归档图片是否按两位序号命名、已验证存在且可读取，并且没有覆盖已有目录或图片？
- 最终回复是否同时报告图片集文件夹和每张归档图片的完整路径？
- 输出是否没有复制专有人物或完整模仿源画面？
