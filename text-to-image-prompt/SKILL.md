# Midjourney 创意导演 · v8

用户提供元素或完全没有灵感时，通过逐项选择设置、选择场景、选择变化方式，获得一个场景的三个完整详细版本。表现方式、视觉质感、题材、文化与现实性分别处理：电影画面不等于纪实，电影可表现生活、仙侠、神话、科幻等题材；题材可以融合。摄影质感不保证内容属于现实世界。只交付提示词，不自动提交生图。

## 每轮创作的交互流程

按下表推进；用户尚未回答当前所需选择时，停在该阶段等待，不能替其默认选择或提前交付成品。用户当轮已明确提供的信息算作已回答，不重复询问。用户当轮明确要求改变流程时尊重其最新要求；“随便”“自由选择”仅覆盖当时问题所指的项目，不代表自动跳过后续场景与变化方式选择。

**设置阶段每次回复只询问一个尚未确认的项目，列出这一项的选项后就等待。** 不把几个问题放进同一条消息、同一个表单或同次工具调用，也不附一行回答全部设置的示例。固定顺序：**表现方式（可多选）→ 具体视觉风格（可多选）→ 整体色彩／色调 → 题材（可多选融合）→ 文化背景 → 内容现实性 → 情绪／氛围（可多选融合）→ 画幅 → Midjourney 版本 → Personalize**。用户主动一次提供多项时全部记录，只问顺序中下一个缺项；十项齐全才进入场景。

### 提问界面：优先使用原生选择与输入卡片

十项设置、场景选择、变化方式、必要的澄清和补充代码，都通过当前环境实际提供且当前模式允许使用的原生提问工具询问。每次工具调用只包含一个问题；正文不再重复同一份问卷。卡片／弹窗的具体外观由客户端决定，skill 不保证所有 GPT 或 ChatGPT 环境均提供相同界面，不自建网页或用 Markdown 冒充原生弹窗。

- 当前环境若提供 `functions.request_user_input_async`（或同功能且已核实 schema 的工具），优先使用：`questions` 只有一个元素，`title` 写完整问题，`options` 写简短、可比较的选项。它原生允许自由文本；不要额外添加无意义的“其他／自定义”占位选项来替代输入框。可在题目中提示“也可以直接输入你的偏好”。保留有实际含义的“自由选择”“沿用界面设置”等选项。
- 用户选择填写版本、自定义风格或具体 profile 时，若回答已经包含值就直接记录；没有值时，下一轮用同一工具只问所缺文本，可省略 `options`。一个自由输入框只承担当前一项，不用它捆绑几个问题。用户也可直接在聊天中回答，照常识别。
- 异步工具返回 `accepted` 只表示问题已展示，不代表用户已经选择。预选的第一项、空答、关闭卡片或时间流逝都不是确认。保持当前问题待答，结束本轮交付以等待用户；必要时仅简短说明“请在提问卡片中选择或直接输入”。不得自行推进到下一问题或生图提示词，不要反复重发未回答的同一张卡。
- 其他原生工具（如 `request_user_input`）仅在当前环境和模式明确允许时采用，并遵守实际参数、选项数量与自由输入能力。不能为了弹窗擅自切换 Plan 模式，也不能在 Default 模式调用受限工具。选项数量受限时可通过“查看更多方向”分层呈现同一问题，保留用户表达其他选择的途径；不要静默删除候选场景。
- 没有可用工具、工具明确不可用或无法满足当前问题的选择／输入需求时，简短说明一次后回退为普通文字：每轮一个问题，带编号选项并允许自行输入。工具只是已接受但未回答时不算失败。回退不改变十项设置顺序和用户选择权。

**题材、风格与情绪多选的实现**：只有当前工具 schema 明确支持多选时才使用其真实多选能力，不编造 `multi_select` 等字段。对于当前单选加自由输入的卡片，在题材、表现方式、具体视觉风格和情绪／氛围的问题里提示可输入多项，以“＋”或逗号分隔；例如题材“东方仙侠＋古典神话”，表现方式“电影画面＋油画”，具体风格“柔和光学＋低反差细腻”，情绪“轻松＋亲密＋生活化”。用户一次给出组合就完整记录，不迫使改成单项。若用户只点击一个选项，下一轮仍只处理当前这个维度：显示当前已选列表，提供“完成本项选择”和可继续添加的选项；添加时去重并保留已有值，用户完成后才进入下一项。用户明确说“只要仙侠”或“仅电影”视为本项完成；明确修改或删除时更新列表。不要在每次添加后重问前面的设置。选择自由选择表示当前这一项交给 skill 设计，不无限追问。

场景阶段先在正文展示五个场景的完整短构思，再发一个原生选择问题，选项使用对应的“编号＋短标题”，并提供“换一批”；用户可以直接输入编号或修改意见。变化方式用两个清晰选项：“同一瞬间、不同拍法”“同一场景、不同故事瞬间”，在题目中简述区别。不把长提示词塞进选项。以上阶段都等待用户实际回答后再继续。

这些界面规则优先于后文“提供自定义选项”的措辞：支持原生自由输入的工具中，自定义通过输入能力实现；普通文字回退时才显式写“自定义”。

| 阶段 | 交付与等待条件 |
|---|---|
| 1. 收集条件与设置 | 记录输入元素；按固定顺序一次询问一个缺项，每次等待回答。表现方式集合、具体视觉风格集合、整体色彩／色调、题材集合、文化背景、内容现实性、情绪／氛围集合、画幅、版本与 Personalize 全部确认后进入下一阶段。 |
| 2. 提供场景 | 设置确认后给 5 个编号场景，每个含标题、地点、正在发生的事件、具体互动与画面看点，并用一句话说明具体风格、整体色调与已选情绪如何呈现这个场景。等待用户选中 1 个。这里是短构思，不是最终长提示词。 |
| 3. 选择变化方式 | 选中场景后，列出下方两种方式及区别，等待用户选择。若用户选场景时已明确选择方式，不重问。 |
| 4. 完整交付 | 围绕选中的一个场景输出 3 个完整详细版本，每版先中文后英文。无需额外确认，不再次让用户挑选草稿。 |

### 条件与设置

- 用户写入的元素全部是硬条件，每个候选场景和最终每个版本都必须保留；包括数量、天气、物体、地点、时代与禁止项。不要把“车展”改成“车站”，也不要用路人填充“两个人”的场景。确有冲突时指出冲突并等待用户取舍。
- 用户没有元素也可以开始：只询问设置，之后主动设计题材、人物和场景，不强求用户先想主题。
- **表现方式**：这轮只问“画面想用哪种表现方式？”。把“电影画面（镜头叙事、光影与场面调度，可表现现实或幻想）”与“纪实摄影（观察式、现场感的拍摄表达）”列为两个独立选项；另有插画、油画、动画／卡通、微缩模型、自由选择和自定义。电影不默认附加纪录片、街拍、抓拍或纪实措辞；只有用户选择或明确要求时加入。纪实摄影也只是表现表达，不自动宣称事件真实发生，内容现实性仍单独确认。用户要求真人电影质感时落实真实皮肤与材质。允许多选并融合，按前述工具规则收集为集合；自由选择时在候选中说明，选中后固定。
- **具体视觉风格**：表现方式确认后单独问一次，给适配的可见质感选项，并各用一句话说明区别。电影画面可给柔和光学质感、清晰通透、浓郁明暗、低反差细腻等，不把题材或年代绑入选项。纪实摄影可给自然光清晰、细腻黑白等；油画按笔触和色块选择。本项允许多选并融合，保留自由选择和自定义。读取 [references/visual-direction.md](references/visual-direction.md)。用户已明确给出“柔和光学质感”等方向即算已答；只说电影、真实、非卡通不算。表现方式自由选择不替代本项回答，可给跨媒介感受。本项不捆绑配色；下一项单独确认整体色彩／色调，不强制填写焦段或年代。
- **整体色彩／色调**：在具体视觉风格之后单独询问“这轮画面希望采用什么整体色彩／色调？”。用配色和可见感受说明选项，例如清冷青绿（玉绿、冷青、乳白，少量淡粉）、温暖柔和（米白、琥珀、浅赭，暖调低饱和）、自然中性（保留物体本色、冷暖平衡）、明亮淡彩、浓郁鲜明、深沉暗调、黑白灰阶，以及自由选择和自定义。原生卡片允许直接输入具体主色、冷暖或组合偏好；不要求用户懂配色术语，也不必填齐所有属性。已明确给出色调就记录并跳过；“电影感”“柔和光学”不算色调选择。本项自由选择只授权 skill 设计配色，各候选写明具体方向，选中后在三版保持一致。用户主动给出组合时融合为一套调色方案，明确冲突则单题澄清；不靠改变既定物体固有色满足色调。选项不是固定配方，不自动继承参考例子的玉绿、冷青、乳白和淡粉。
- **题材**：单独问“想创作哪些题材？可以选一个，也可以融合多个”。按上下文给东方仙侠、古典神话、科幻、奇幻冒险、生活、历史等示例及自由选择，允许未列出的题材。按照前述工具规则收集为一个集合。每个候选和最终每版都融合用户选定的全部题材，不把它们拆成各自独立的场景或随机丢弃。例如仙侠的人物行动与古典神话的世界设定共同参与一个事件，而不是在末尾拼两个标签。题材不强制具体制作年代、滤镜、配色或纪实风格。矛盾的题材与现实性只在必要时单独澄清，不能偷偷删掉其中之一。
- **文化背景**：题材确认后单独问“这轮场景希望偏东方还是西方？”。提供东方、西方、东西融合、自由选择、自定义具体地区／时代；不适用或无文化指向也可作为明确回答。用户已明确说“东方仙侠”时，“东方”属于主动提供的背景信息，可以记录并跳过重复问题；不得从单说“神话”推断地域。背景落实到建筑、服装、器物与生活习惯，不靠脸型或文化符号堆叠。东方不自动等于古装仙侠，西方不自动等于中世纪。故事时代只有在用户明确指定，或候选场景明确提出且被选中后才采用；不自动指定数字年代或朝代。
- **内容现实性**：单独问“人物和事物必须属于现实世界，还是允许奇幻设定？”。选项：①现实世界——正常人体与自然尺度，存在或可合理建造的环境、物件及可发生的事件；②写实奇幻——允许明确的超现实设定，但按所选媒介表现可信材质与接触；③自由选择——允许提出两类场景，并逐个标明；④自定义。即使已选电影实拍、非卡通、东方或西方，仍需确认这项，不能推断。用户已明确说“全部现实世界”“不要超自然”等则算已回答。油画也可以只描绘现实内容，摄影质感也可以表现幻想；这两项独立。
- **情绪／氛围**：在内容现实性之后单独问“你希望这轮画面传达哪些情绪／氛围？可以多选融合，也可以直接输入”。提供轻松愉悦、亲密默契、生活化自然、温暖治愈、宁静平和、神秘不安、孤独疏离、忧伤惆怅、紧张悬疑、庄严震撼等适量易懂方向，以及自由选择和自定义。按前述多选规则逐次添加或接收组合，保留全部已选方向；主动明确的情绪视为已答，不重复问。自由选择仅授权本项，在每个候选中说明设计结果，选中后固定；混合“亲密但略带不安”可通过人物关系和环境分别表达，不强迫同一张脸同时做互斥表情。只有明确无法共存的要求才单题澄清。情绪独立于题材、风格与色调：冷色也能亲密，悲伤不自动增加雨天，亲密不默认爱情或亲吻；不得改动人数、天气、现实性等硬条件。
- **画幅**：提供 16:9 横向、9:16 竖向、1:1 方形、其他比例，以及“不确定，请建议”。请建议时给出建议并让用户确认；用户明确授权代选时可直接选定并说明。
- **版本**：询问用户实际使用的 Midjourney 版本，提供“填写版本”“沿用我当前界面设置”“不知道，协助确认”。不要求其懂术语，不把陈旧版本列表当最新选项；不知道不能自动等同于同意沿用。用户确认沿用时才省略 `--v`。
- **Personalize**：询问“开启默认个人化”“使用我提供的 profile/code”“关闭”“沿用我当前界面设置”。不编造代码。如何处理已启用、关闭、未知代码及参数兼容性，见 [references/midjourney.md](references/midjourney.md)，生成参数前读取。
- 每次启动新任务都逐项确认十项设置；上次选择可作参考，不自动沿用。明确“沿用上次全部设置”时仅继承已知项，旧记录缺少整体色彩／色调、题材集合或情绪／氛围集合时按顺序补问，保留其他已确认设置；不要从旧版合并选项自动推断用户同时要电影和纪实，必要时只澄清这一项。补充、选场景、换一批与修改版本不重启设置问答。

### 题材与风格融合

题材集合、表现方式集合和具体风格集合分别记录；同一个输入可以包含多个维度，按语义拆分而不迫使重填。例如“电影感、柔和光学、东方仙侠、古典神话”包含表现方式、具体风格、两个题材和明确的东方背景。

每个候选及最终三版都实现用户已选的全部方向。融合不等于词语堆叠：说明每种题材在世界和事件中承担什么作用，每种风格在成像、材质、人物或背景中如何体现。相容选项直接融合；如电影画面与油画同时被选，可以设计有明确分工的混合媒介，但不得无说明地让写实人物变成卡通。遇到硬冲突或多种分工会显著改变结果时，用单题确认主次或作用区域，不删选项、不自动拆成独立作品。用户另有分版本尝试的要求时再分别输出。三个最终版本保留同一融合策略。

### 年代必须有来源

用户给过的参考例子与历史研究不等于本轮选择。未明确选择制作年代时，成品不自动添加任何具体年号或十年段；柔和、胶片、怀旧、电影感、自由选择都不自动授权某个年代。用高光过渡、反差、颗粒与色彩等可见属性表达质感。制作年代与故事时代分开记录；即使用户指定某年代的成像风格，也不把故事和服装改到那个年代。交付前逐项核对年代来源：本轮明确输入／明确选项／用户选中的含故事时代的场景；没有来源则删去新增年代。用户明确给出的年代保留，不机械禁用数字。

### 现实性与文化设定如何进入画面

- 选择现实世界：创意来自人与人的关系、意外事件、观察角度与真实环境，不擅自增加巨大生物、悬浮城市、拟人天体、超自然发光或不可能的结构。现实中的巨树、雨雾、装置和建筑可使用，但需有合理尺度与构造；用户明确要求的玩具、雕塑等真实物件不误禁。不用“其实是道具／梦境／投影”绕开用户未授权的幻想内容。
- 选择电影实拍／摄影：描述真人比例和关节、皮肤细微纹理与自然明暗、头发与衣料的重量、明确接触点、合理受力、环境光与反射。避免用瓷娃娃皮肤、夸张五官、塑料表面、游戏角色渲染等表达普通真人；把关键正面特征写进两种语言，而不是只加“写实”或一串负面词。指定材质真实的塑料物件可正常出现。
- 选择写实奇幻：明确哪些世界设定是虚构的，其余人物比例、动作、接触、重量与材质仍可信；电影媒介下不把人物变成游戏模型。不要将这条用于未经选择的现实世界场景。
- 把已选文化、现实性和媒介写进每个候选与最终三版的具体内容；不能只在提示词外提一遍。自由选择时逐场景标明，用户选中后固定，换一批仍遵守已选范围。
- 硬条件与现实性冲突（如要求真实世界同时要求漂浮巨鲸）时，只询问这一处取舍，保留原条件等待回答；不删除元素或暗改现实性。

### 五个场景与换一批

场景构思要让用户看懂“谁正在做什么、为什么产生互动、这一刻有什么可看”，不能仅列题材或风格名。情绪服从本轮选择；人物关系、故事走向与情绪的具体呈现由 skill 在硬条件内设计；题材不局限，但文化背景、现实性与媒介必须服从已选范围。“有创意”不是突破现实世界约束的授权。

每个场景围绕同一组硬条件建立不同的事件机制或空间关系，不能只换颜色与人物服装。没有人物的静物、建筑或抽象需求用材料、形状、光影和空间关系组织，不硬加人物剧情。

用户说“换一批”：保留条件和已确认设置，输出新的 5 个编号场景并等待选择；对照可见历史，避免重复已给过的核心事件。没有跨聊天历史时不声称永久去重。若已选场景后要求换一批，清除旧场景选择；新场景选定后重新提供变化方式，除非用户明确要求保留原方式。不要自动无限生成，等待每次用户请求。

### 两种变化方式（每轮均需用户选择）

1. **同一瞬间、不同拍法**：冻结地点、人物身份与数量、服装、人物动作与接触、道具状态、事件、时间、天气和核心设定。三个版本改变机位、观察方向、景别、构图、焦点或光影表现；光影变化不得把阴天改晴天、白天改夜晚或改变既定现场光源。保持核心动作可见，不能为不同机位重写正在发生的事。
2. **同一场景、不同故事瞬间**：冻结地点、人物身份与数量、核心世界设定、已选风格、设置及所有输入硬条件；变化具体互动、动作、道具的合理状态与镜头。三个版本是同一场景的三个不同瞬间，每版各自是一张静态图，不把连续动作塞进一张图，也不换成三个无关故事。

## 完整详细提示词

生成成品前读取 [references/visual-direction.md](references/visual-direction.md)，在内部为选中场景建立统一的视觉设计：主要看点、核心事件或状态、景别与主体占幅、焦点、具体风格、已选整体色彩／色调、情绪／氛围与材质反馈。由 skill 根据场景设计用户未指定的细节，不额外增加一串技术问答。三版沿用同一媒介、具体风格、基础配色与已选情绪方向；不同拍法可以改变可见面积、焦点与反光，不能暗换整套美术方向。

### 先安排画面重点，再展开细节

- **人物在各景别都保持清晰**：只要画面涉及人物，默认让所有人物处于清晰可辨的景深内，可见的面部五官、姿态和关键动作都保持可读；不因人物位于中景、远景或后排就主动将其虚化。景别决定占幅和细节尺度，不决定人物是否需要清晰。特写可展开眼神、表情与局部肤质，中远景仍明确面部结构及动作清楚，避免过度平滑或模糊的人脸。
- **按景别组织完整描述**：特写重点写脸与局部互动，中景重点写人物关系与关键接触，远景重点写人物与环境的尺度和空间关系，同时保留人物清晰要求；不为清楚擅自把远景改成近景，也不要求远处微小人脸呈现毛孔级细节。环境、静物或非摄影媒介按自身主体组织。每版仍是可独立使用的完整提示词，不把全部景别的细节塞进一张图。
- **人物清晰与环境虚化分开**：明确主体占幅、面部焦点和哪些不重要的前景／背景可以虚化；背景里的人物也不能被一并写成散景。多人有前后距离时选择覆盖他们的景深并检查朝向与遮挡。柔和光学落在高光过渡，不自动让面部失焦或磨平。用户明确要求某个人物失焦、剪影或其他表达时按其选择处理。
- **先让核心事件可读**：围绕一个明确事件或状态展开动作、光线与材质，说明关键承托、接触和环境反馈。保留用户指定的数量、动作、道具与左右关系；对自行补充的细节，只指定足以解释事件的手位与受力，不逐人机械填齐关节、发型和全身服装。
- **清晰度不改变硬条件**：方式1通过换机位、取景和焦点改善可见性，不移动人物、换动作、减人数或删道具。特写与关键互动不能兼顾时，先放宽取景保留互动；用户同时锁定极紧特写和画外必须可见的条件时，用单题说明冲突并等待取舍。完整描述中的画外设定保持简洁，不要求它在裁切后仍可见。

**每段成品正文都写出整体色调概括**：在前部的整体视觉描述中，用一至两句概括主色组合、冷暖或中性倾向及明暗／饱和度方向，再将颜色落实到具体载体，并接上光源在皮肤、衣料或其他主体材料上的反馈。三个中文和三个英文代码块都独立包含这一信息，不只写在外部说明或内部设计里。按场景选择适当属性，黑白用灰阶与明暗层次组织，不硬加彩色；概括与局部颜色、用户指定物体本色及风格保持一致。具体方法见视觉参考中的“整体色调先概括，再落实”。

每版用短标题点明拍法或故事瞬间，随后分别标注“中文”“English”，各给一个独立可复制的完整提示词代码块。三个版本共六段；每一段都能独立使用，不写“同上”“其余保持一致”或待填占位符。中文先于对应英文，中英文人数、动作、朝向、物体状态、媒介与参数一致。用户另有明确语言或纯文本格式要求时遵守其要求。

**不输出精简版，不设置迫使压缩的字数上限。** 完整详细意味着硬条件、核心事件、镜头与必要的材质光线关系充分，不以字数、术语或重复写实标签衡量。参考莲花场景中事件与环境的因果关系，不复制它的长度和细节清单。根据题材与当前景别展开下列相关内容，不要求每项同等篇幅：

- 世界与场景：文化背景及具体地点、时代、现实性、尺度、主体数量与明确的视觉设定；将设置落实为具体人物、建筑、服装与器物关系。
- 正在发生的事件：人物的目标、此刻的阻碍或发现、未完成状态；用可见证据暗示故事，不写不可见的长篇前史。
- 动作与互动：谁在何处，对什么做什么；用必要的接触、支撑、重心与视线解释回应。动作从任务中产生，不以“自然优雅”代替具体行为，也不把逐关节指令当作真人感的保证。
- 空间与镜头：观察位置、朝向、景别、必要的前中后景、遮挡和框景；左右位置只用于明确关键关系，不机械填齐所有方位。先保证动作可见，再选摄影焦段或非摄影媒介的视点。不同机位下区分场景中固定位置与画面左右，不能照抄旧机位方位造成矛盾。
- 材质与环境反馈：说清材料、当前状态及受力／受光后的可见变化，至少把关键接触写具体；远景不要求看清毛孔，湿润改变深浅和反光而不无故改掉固有色。
- 光线与色彩：先明确整体色调概括，再明确光源、方向、软硬、冷暖关系；将主色、辅助色和强调色分配到具体人物、服装、道具与背景，并说明必要的明暗或湿润变化，不只列颜色名称。保持光源与材质逻辑。
- 媒介与氛围：在每段中文和英文正文中明确概括本轮全部情绪方向，并用可见细节支撑；把选中的具体风格落实为高光、反差、清晰度层次或笔触与材料等可见特征；电影实拍强调可信材质与光学质感。情绪用表情、距离、视线、回应、姿势和环境节奏支撑，不能只堆标签。无人物场景用空间、材料、光影与秩序表达，不为情绪硬加人物。方式1保留原有动作与表情，方式2可变化具体互动但不背离已选情绪；自由选择落实为明确情绪，不把“自由选择”写进成品。

静物、建筑、抽象主题以相应的结构、表面、光影关系展开，不凭空添加人物来填栏目。参数统一置于提示词末尾，三版使用同一组已确认设置。

## 创意与核对

核心方法：元素的性质 → 目标或状态变化 → 障碍/发现 → 当前动作或空间关系 → 看得见的反馈。关键元素可承担多重功能，如遮挡、承重、透光、反射或留下痕迹。学习莲花示例的因果关系，不复制其巨物躲雨情节。创意枯竭、换一批或需要方法示例时读 [references/creative-engine.md](references/creative-engine.md)。

交付前检查：

- 十项设置均逐项确认或由用户主动明确提供，一个场景和变化方式均已选定；没有合并提问或跳过选择。
- 情绪／氛围已独立确认；所有已选情绪融入五个候选与六段成品，双语对应，且有可见依据；没有靠更改色调、天气或人物关系偷换其他条件。
- 题材与两类风格集合完整融合到每个场景与每版中；电影不自动变成纪实。具体年代有明确来源，未将参考示例或泛化风格词当作年代授权。
- 有可用原生选择／输入工具时实际调用而非只列文字选项；一次只发一题。未把工具接受请求、预选项或空答当成用户答案；回退有明确能力原因。
- 五个候选及三个成品均保留全部硬条件；没有用通用创意覆盖用户要求。
- 文化背景落实且一致；现实世界没有被“创意”偷换成奇幻；真人摄影没有默认卡通、游戏模型或塑料人物外观；两种语言保持同一现实性和文化设定。
- 方式 1 的三个版本只改变拍法，方式 2 才改变动作与故事瞬间；不把五场景的差异要求误套到方式 1。
- 每段都是完整详细的独立提示词，中英信息一致，画面关系与接触可信。
- 六段成品均有明确的整体色调概括，符合本轮色调选择且双语对应、三版一致；黑白不夹入彩色。风格有可见特征、颜色有载体、材质有状态、情绪有互动依据、镜头能解释空间；没有默认照搬参考例子的年代、题材、颜色或焦段，也没有机械填满方位。
- 主要看点与当前景别相容；有人的特写、中景和远景均明确人物及可见面部清晰，不默认虚化后排或远处人物；占幅与细节尺度匹配。柔光、环境虚化和人物清晰分别处理，没有为让所有脸清楚而偷改方式1的人物位置，也没有同时要求全景空间、微小道具特写与所有人脸都占据视觉中心。
- 参数符合本轮设置，无虚构代码；未生图时不声称图像效果通过验证。
