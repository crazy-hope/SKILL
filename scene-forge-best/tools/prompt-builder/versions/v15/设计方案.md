# 开放创作设计：工作台 V15 / 规范 V11

日期：2026-10-28；状态：2026-10-29用户已确认，实施完成。基线：工作台V14、规范V10。关联：[需求](需求.md)。

## 意图与成功标准

用户可以只说想要的感觉、画面特点或模糊念头，由模型构思具体可画的主体、结构与关系。候选库帮助获得灵感；只有明确要求出现的对象才必须进入每个方案。开放创作仍须尊重题材、媒介、光色、数量、负面要求等明确条件，结果仍交付完整双语和真实采用的设计摘要。

## 方案比较与选择

| 方案 | 取舍 |
|---|---|
| 继续扩库、放宽辅助对象 | 改动较小，但仍围绕预先选好的主体，不能满足本轮目标 |
| 灵感与必须出现分开，按意图构思 | 用户已接受此方向；保留可控性，同时允许库外主体和不同方案 |
| 完全移除元素及属性选择 | 自由度高，但失去精确指定对象与造型的能力，不采用 |

采用第二种方向。下述行为最初为助手建议，用户于2026-10-29确认此具体设计。

## 输入与创作规则

保留十维顺序及独立负面输入，不增加必填长表。第10项“大致说明”承担创作意图，允许仅输入一两句话。新建和重置时该项留空，以占位提示引导表达感受；原先柔光/细节丰富句不再自动作为新任务的要求。已有内容保留在旧版本。模型、画幅、数量和负面默认保持现值。

02内的候选和自定义名称均默认是“灵感参考”。每个已选元素拥有明确的“必须出现”开关，默认关闭；打开才成为逐方案必须项。关闭后降回参考，属性仍保存。删除元素清理其属性和失效对象关系。整库不进入请求，未选候选没有约束力。

自然语言的“必须出现”“画一只白鹿”“主体是白鹿”等确定要求同样有效，不要求机械包含某个关键词；“可以参考”“例如”“也许”等仅作参考。只在真实硬冲突或影响核心意图的歧义时澄清，不为缺省细节追问。

模型可采用、转化或不采用灵感，也可从库外设计主体、建筑、生物、人物、空间和现象。明确选定的题材与风格限定创作方向，不固定题材标志物。人物不再要求先从库中启用，也不默认每图加入；人物应服务意图。明确“无人”“只画静物”“仅这些对象”等要求优先。独立衣裙、饰物不因为常见宿主关系而必然新增穿戴者。

明确“只包含这些对象”通过自然语言设置；不再保留默认禁止新增对象的allowExtra开关。移除旧“全部包含/选配”控制，以逐项必须出现替代；保留“自动设计/随机探索”，两者都允许库外创作，随机只影响未锁定部分。

## 属性、关系和冲突

出现要求与属性要求分开：参考白鹿设定白色，表示采用该白鹿时须为白色，并不要求每图出现白鹿。其参考名称可以激发其他概念，但变成不同对象时不得声称已满足原对象的锁定要求。必须出现的白鹿则每图出现，并落实其明确属性。现有人物人数、服饰与空间属性继续支持。

参考对象的明确关系若被采用，关系及目标需共同成立；可以整体不采用这组参考。必须对象的明确关系目标也必须保留。界面在把关联对象设为必须出现时，显示其依赖目标并要求用户同时勾选目标后保存，不静默标记必需；前后端均拒绝不完整的必需关系。循环关系按对象集合检查，不递归失控。target为空时模型可设计相容关系及对象，受明确禁止与必须要求约束。

必需与禁止冲突时返回具体澄清；可选参考与禁止冲突时不采用该参考，不把可选冲突升级成阻断。其他明确镜头、媒介、画幅、地域等规则继续有效，参考属性不覆盖全局硬条件。

## 生成和结果

生成顺序：理解意图与硬约束 → 构思核心概念和主体 → 有选择地吸收灵感 → 设计关系与空间 → 落实光色和镜头 → 输出完整双语 → 核对必需对象、负面与实际设计。

多方案允许不同主体与构图结构；锁定的对象继续保留，但不要求所有方案都把它当主角，除非role明确为主体。差异必须服务同一意图，不因开放创作随意偏离已选题材。concept简述核心构思与采用的参考；design继续为完整七项，只记录实际出现内容，不照抄参考池或把模型决定冒称用户指定。

清理双服务商共享指令、题材专项指引和完整规范中冲突的“全部已选必须保留”“未选人物不得添加”“只能补辅助对象”等当前行为。历史章节与示例保留并标明适用范围。云上天宫旧有1%—3%人物占比不作为新创作的强制默认；未指定主体尺度按本次画面决定。

## 数据和历史边界

本轮改变元素语义，采用schemaVersion=4、scene-forge-backup-v4及独立scene-forge-workspace-v15，避免把旧版必须项静默降级为参考。保留十维字符串、地域、elementSettings；每个元素设置必须包含presence，值为reference或required。设置表与元素名称一一对应。设计选项仅保留exploration，删除selectionMode与allowExtra。其余字符串长度、人数与方案数等限制沿用。

V15只读取新格式，不导入或迁移v3备份。旧工作台V14、旧浏览器存储和旧备份完整保留，使用V14查看旧历史；新版本使用说明明确这一点。独立接口配置和独立密钥沿用，不进入创作记录或下载。继续拒绝缺少完整design的结果并保留损坏存储保护。

草稿、预设、历史、备份和下载均保留presence及原始意图。下载输入摘要分清参考与必需，并包含属性；结果实际设计始终列最终采用对象。纯文本模板在02中允许“参考：…；必须出现：…”表达，不新增主维度。
