# 真实古建参考向仙家巨构转译

本文件用于把真实中国古建筑参考中的结构、材料与漆色转译为仙家宫苑巨构。参考图提供建筑基因，不提供最终场景模板；最终画面必须同时成立为真实古建骨架、巨构尺度和仙界空间。

无参考图时，可把本页的建筑家族作为随机云宫的古建源型库；有参考图时，只选择画面实际可见且与用户要求相容的部分。屋顶和台基的具体构造继续分别读取[屋顶与屋檐](objects/屋顶与屋檐.md)及[平台与宫基](objects/平台与宫基.md)，彩画读取[传统建筑彩画配色](traditional-polychrome-palettes.md)。

## 三层转译契约

按`真实古建骨架 → 巨构尺度变换 → 仙界空间`组织设计，三层各自解决不同问题：

| 层级 | 保留或建立的内容 | 通过信号 |
|---|---|---|
| **真实古建骨架** | 选定一个主导建筑家族，落实柱、梁、斗拱、椽檩、屋顶、墙体和台基的真实归属；漆色、瓦色、石色绑定对应构件 | 缩略图仍能读出明确的中国古建筑类型，不是欧式神殿、科幻城市或石宫涂红 |
| **巨构尺度变换** | 放大柱跨、梁高、檐深、屋顶跨度、台基厚度、空庭宽度和宫廷纵深；让连续体量延向画外，同时保留人尺度门洞、踏步和栏杆等使用节点 | 人物或替代参照与使用节点、次级构件、主殿、云域形成连续尺度链，不靠单独缩人或均匀放大所有零件 |
| **仙界空间** | 用云海、浮山、天瀑、云峡、高空薄雾、柔和晨昏光和悬置高差把巨构置入天庭世界 | 仙气来自空间、空气和光，不来自全白石材、霓虹粒子或把现实宫殿简单贴到云层上 |

最终阅读顺序应是`仙家古建巨构 → 云域与天界纵深 → 人物或替代尺度标记`。参考源型可辨，但不能压过当前场景和用户要求。

## 可选古建源型

每幅选择一个主导源型；只有结构上真实连续时才加入一个从属源型，不把整张表混成建筑拼盘。

| 源型 | 结构与空间基因 | 材料与色彩基因 |
|---|---|---|
| **北方皇家中轴宫廷** | 横向主殿、辽阔空庭、中轴台阶、重檐大屋顶、疏朗柱网与连续宫墙 | 朱红木柱和门扇、黄琉璃瓦、石青石绿梁枋、白石台基 |
| **巨型城台门楼** | 收分灰砖城台或包砖厚基座，上置多层木构门楼；中央主楼统领较低翼楼，木石转换可见 | 灰砖石大面、深朱木构、青绿斗拱、深瓦或赭黄瓦面；夜间暖金只作照明 |
| **圆形祭祀殿** | 圆形平面、环形柱网、放射梁架、攒尖屋盖、中央宝顶和多级圆台 | 深蓝或青色琉璃瓦、朱红木构、青绿彩画、白石圆台 |
| **水庭桥亭宫苑** | 临水亭廊、桥、岸台、台阶和栏杆形成连续游览动线，水面承担倒影和空间释放 | 红柱、青绿彩画、黄绿琉璃瓦、灰白石桥与岸台 |
| **地方寺观与南方院落** | 灰瓦曲面屋顶、较强起翘翼角、歇山或悬山屋盖、转折廊道和相互咬合的院落屋面 | 烟褐木梁、褪朱柱墙、灰黑陶瓦、群青与孔雀青彩画，可有受控颜料粉化但结构完整 |

这些源型是造型家族，不是文物复原或朝代鉴定。不要复制特定宫殿的层数、屋面轮廓、斗拱组合、门窗比例或院落布局。

## 屋顶、屋脊与台基选型

- 根据体量选择庑殿、歇山、攒尖、悬山、硬山或卷棚等屋顶家族；单檐与重檐另行记录，重檐不等于实际楼层。
- 正脊、垂脊、戗脊、吻兽、脊兽、宝顶、瓦当和滴水按屋顶类型与真实位置出现，作为尺度和构造证据，不平均铺满每条边。
- 北方皇家屋顶通常宽阔平稳、翼角克制；地方寺观或南方院落可以采用更明显的曲面和起翘，但仍须接入梁架与转角承重。
- 台基从灰砖城台、白石多级台基、圆形祭祀台、临水岸台和普通木构柱础中选择；台基承担上部荷载，不是漂浮装饰板。

## 漆色、瓦色、石色与光色分离

先判断颜色来源，再写入提示词：

- **木构漆色和彩画**：矿物朱红、深栗红、烟褐木色、石青、群青、石绿、孔雀青、松石青、赭黄、象牙白和窄旧金。
- **屋面材料色**：黄、绿、深蓝琉璃瓦或灰黑陶瓦。琉璃瓦保持成排瓦行、半哑光釉面和受控边缘反光；灰瓦保持矿物颗粒与低反光。
- **台基与墙体材料色**：白石、灰石、灰砖、粉灰墙体或用户指定石玉，不把浅色台基蔓延成全石宫殿。
- **环境光色**：日出、落日和夜间灯光只能改变受光面、边缘和阴影冷暖，不能被误写成建筑固有漆色。参考图中的金橙夜光或落日暖光不等于满建筑金漆。

彩画高纯色集中在斗拱、梁枋、椽头、门窗和结构转换带；大屋面、墙面、地坪和云域保留安静面积。真实古建的丰富颜色用于增强古风身份，不把巨构变成彩虹主题乐园。

## 巨构化操作

巨构化不是把参考建筑等比例放大后放到云上。至少选用三项可见操作，并保持承重相容：

1. 横向扩展连续主殿、屋盖、柱廊或城台，使其越出画框或延至大气远景。
2. 扩大主柱净跨、地坪至梁底净高和多进空间纵深，保留广阔空气与空庭。
3. 加厚深檐、主梁、城台、宫基、桥腹或悬置下构，展示真实重量和支承。
4. 保留正常可用的踏步、门洞、栏杆和次级柱作为人尺度层，再与超尺度主构比较。
5. 让宫殿跨越云层、云峡或浮山高差，并以云下下构、天瀑或终端远景继续尺度链。

推荐尺度链为`人物或人尺度使用节点 → 门洞/踏步/柱础 → 次级柱廊或殿台 → 主殿/城台/巨檐 → 云层、浮山或终端远景`，按实际画面连续显示至少三级，标准巨构优先四到五级。

## 提示词装配片段

> 以北方皇家中轴宫廷为古建骨架：朱红木柱经深梁与青绿斗拱承托黄琉璃重檐，白石多级台基和轴线台阶围出辽阔空庭；将主殿柱跨、梁底净高、屋檐跨度、台基厚度和宫廷纵深扩展到超常尺度，连续殿体跨越云层并向画外延伸，人尺度门洞与踏步仍可用；远处浮山、天瀑、云峡和分层薄雾共同组成仙界纵深，柔和晨光只染亮受光边缘，整体仍读作古风仙家宫苑巨构，而非现实景区复刻。

## 不继承与审计

- 不继承游客、现代灯具、电线、空调、说明牌、牌匾题字、字幕、Logo、水印和截图界面。
- 不复制参考图的精确地标身份、完整构图、层数、人物位置或专有纹样。
- 不把真实古建参考变成现实旅游摄影、博物馆复原图或普通比例宫殿上云。
- 不因采用皇家黄瓦、白石台基或祭祀圆殿而取消仙界巨构尺度；也不因追求巨构而抹去屋顶类型、木构承重和漆色落位。
- 审计时分别回答：古建源型是否可读、巨构化操作是否可见、仙界空间是否真实包围建筑、颜色是否按漆色/瓦色/石色/光色正确归类。任一项只能靠形容词成立时，补足可见结构关系。
