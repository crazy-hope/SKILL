# 六段直写工作台需求

日期：2026-10-30；状态：已完成并交付；事前记录。基线：规范V15、工作台V17。

用户明确纠正：需要将工作台全部重构、重新创建，取消原先选择元素让模型理解的形式。新的工作台直接提供画风题材、色彩、镜头机位、情绪、瞬间状态五段指定原文，默认显示，可自行修改；另有主体内容，手写或通过大模型描述。每个元素的位置、材质、颜色及状态写细致，主体依据五段当前设定合理生成。

| 编号 | 必须要求 | 验收条件 |
|---|---|---|
| R-01 | 全新六段界面和流程 | 不加载元素库、十维卡片、精修抽屉、荷塘方向、三构思选择或独立审校流程；五段及主体直接可编辑 |
| R-02 | 五段精确默认 | 用户五段原文逐字预填为真实输入值；修改/清空保存，刷新不恢复；恢复五段默认是显式操作，不改主体 |
| R-03 | 主体可手写或AI描述 | 主体初始为空，可按短想法或空值让AI依据五段补全；生成描述可编辑/撤销；不修改五段，细述所有实际元素位置、材质状态、颜色、动作关系 |
| R-04 | 直接完整双语 | 手写主体即可生成；不依赖选择记录；五段都是有效约束，冲突时说明，正文完整同义，复制/下载无摘要替代 |
| R-05 | 数据、接口与异常安全 | 新schema6/v6/workspace-v18，不读取或迁移旧创作数据，旧归档保留；独立接口配置/密钥沿用；损坏存储不覆盖；延迟响应在任何输入或配置变动后失效 |
| R-06 | 配套完整规范与交付 | 规范V16完整正文、V18新源码/dist/过程文件、根入口与索引同步，真实验证如实记录 |

实施选择：保留React/Vite与Python本地服务，复用已有依赖；新界面用原生语义控件与独立CSS，不继承旧组件。目标模型默认Midjourney、方案默认1对（可1—10），画幅仅由画风题材文本指定，不再有另一个9:16默认；独立负面在辅助选项中预填既有默认，可修改/清空。AI描述和最终生成分别单次文本请求，不强制额外审校收费。

“删掉当前工作台所有东西”落实为替换当前使用的实现和流程；既有版本只读归档及浏览器旧创作数据保留，避免删除用户历史。新版本不包含旧元素/场景库和旧输入协议。技术辅助的接口配置、历史/备份、复制下载重新实现，非旧创作形式。

默认原文保存于V18输出/defaults.json，与用户本轮原文核对。用户本轮要求优先于旧版“示例不作默认”和“工作台必须三构思”等条款；仅新工作台明确默认，通用规范仍适用于其他题材与媒介。
