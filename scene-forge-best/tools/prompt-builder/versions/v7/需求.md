# 工作台 V7 需求

- 日期：2026-10-16；事前记录；基线：[工作台 V6](../v6/README.md)。规范继续使用原 V6。
- 用户批准：整理 02“想画什么”和 03“必须包含”的层级，解决两处人物选项容易混淆的问题。

| 编号 | 要求 | 验收 |
|---|---|---|
| R-01 | 02 表达画面类型或核心场景，修订含混的单独人物/地点选项 | 人物描述含行为，静态环境可用关系/状态，不强迫每图有动作 |
| R-02 | 03 补充必要对象与特征，明确不需重选主体 | 页面 02/03 持续可辨，展开面板有简短解释 |
| R-03 | 跨字段重复指向同一主体不自动增加数量 | 系统请求明确对象对齐、数量和新增关系；歧义/冲突先澄清 |
| R-04 | 保留旧历史、草稿、预设，旧名可搜索到对应新场景 | 不自动重写旧值；勾选状态识别旧名，取消选择可移除旧值 |
| R-05 | 工作台单独版本化，保留规范及既有功能 | 历史哈希、九项双语与目标模型适配回归、桌面/手机检查 |

范围：全库审核含混场景，保留已有明确行为/关系描述；元素库不删除人物类别。用户自填内容保持原文。语义归并由文本模型执行，不做靠关键词猜人数的本地强制合并；不把模拟接口检查当成模型语义正确的证明。
