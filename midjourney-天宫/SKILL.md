# Midjourney 东方天界巨构导演

## 核心原则

从文字建立原创画面，并让随机变化服从同一视觉语法：

> 一个连续且尺度宏大的主视觉巨构或尺度主体 + 一个大面积空明天域 + 一套清楚的主辅构图 + 一个可选且真实落位的尺度锚点 + 一组有明确空间关系的电影镜头 + 冷环境中的少量方向性暖光。

宫廷建筑作为主视觉时，先建立一座体量远超常规建筑的主殿或同一主殿的局部。主殿自身要有横跨开阔空间的超大连续屋檐与巨壁般粗厚、实际承托它的承重柱，按[单体与构件尺度](references/elements.md#单体与构件尺度)写出主体内部的体量与距离。建筑构件库含长屋檐、榫卯结构、顶部藻井、深檐与承重柱，按[建筑构件](references/elements.md#建筑构件)匹配可见机位；顶部藻井位于真实殿内顶棚，不自动出现在纯外观远景。附属小楼是可选场景内容，可以完全没有，不作为证明尺度的必需参照；已选密集楼阁才组织为从属层。

任何画幅都不强制近景框架、遮挡、裁切或前中后三层齐全。随机场景可有前景，也可完全开阔；仅当已选构图、镜头或具体空间关系需要时才描述框景与裁切，不为证明巨构尺度自动补入近景物体。宏大尺度也可由结构重复、远近层次和已选尺度锚点体现。

所有生成画面必须满幅：场景内容延伸至画布四边，禁止上下黑边、黑色横条或电影遮幅（letterboxing）。电影感只通过构图、光色与材质表达；留白由天空、雾、水面等真实场景内容承担。具体提示词写法与画幅处理见[满幅无黑边](references/aspect-ratio.md#满幅无黑边)。

建筑与人物都不是必选元素。用户选择 `F1-6 无建筑` 时，不得为满足旧有巨构语法自动补入宫殿、楼阁、亭台、塔楼或屋顶；由已选天界结构、地形、自然奇观或自定义主体承担主视觉尺度。用户选择 `F2-4 无人物` 时，不得自动补入人物，改用结构重复、纹理尺度或其他已选锚点证明体量。

人物默认属性为“空间标尺，不是画面主体”；人物仅作为建筑与空间的尺度参照，建筑巨构和云海才是画面主体；无建筑或无云海时，由已选巨构与天域承担主体，不能改由人物承担。默认人物从头顶到脚底的全身高度严格小于画面总高度的 **5%**，只能比 5% 小，不能等于 5%；默认以约 **2%** 为目标，更小也可。位置由构图、镜头和场景空间推导，任何地点列表都只是示例，不是可选范围。保留古风身份和衣袍，朝向按构图选择背面或侧面，不采用正面朝向镜头；按[人物可见程度](references/elements.md#人物可见程度)选择极小剪影、轮廓可辨或人物可辨，默认极小剪影。仙女发型固定为 `F2-H7 半绾披发`：上部黑发绾成小髻，其余自然披散；自动使用，不再询问发型。半绾披发保留在内部造型记录；默认极小人物的最终提示词不强求发型、五官或衣饰可辨，不为展示这些细节放大人物。

人物尺度采用“明确的画面高度占比 + 可见空间距离”共同表达；两种语言的最终提示词均保留严格小于 5% 的上限，用户指定更小占比时保留该值。相机远离人物承载面，以遥远落点和已有路径纵深建立尺度；有近景地面时，镜头与人物之间保留大片空旷地面。禁止用人物特写、独立聚光、锐利衣饰或浅景深将人物变成视觉焦点。详细定义与统一句式见[人物默认尺度](references/elements.md#人物默认尺度)。默认或用户要求单人时，全画面只有一名仙者；每种语言的最终提示词只输出一次完整人物描述，由[元素中的人物统一描述规则](references/elements.md#人物统一描述与修改)汇总身份、数量、尺度、背面或侧面朝向、所在空间层和唯一承载位置。构图、镜头与摆放只提供这同一人物的属性，不各自增加人物句。用户要求“人物再小一点”时改写原人物句，不在末尾追加小人。只有用户明确要求多人时才按指定人数生成。

`C18 肩后构图` 或 `D23 肩后临边远望` 均进入同一肩后模式：仅表现原人物的近景肩背，替换远景小人描述。肩后模式不进入普通随机或默认推荐池；用户同时明确要求肩后与极小远景人物时，先解决两种尺度的冲突，不用一大一小两个人满足它们。

随机只改变当前批量策略允许变化且未被用户锁定的内容，不能随机掉以上关系。未指定项按问卷入口补齐；朝代名称只作为幻想建筑的视觉线索，不声称考据复原。

“巨构压迫感、震撼、宏大”只描述尺度关系，不自动切换为暗色、冷峻或低曝光模式。默认用于用户选择推荐、明确跳过询问或简洁入口允许自动补齐的项目；不得覆盖用户条件。

构图目录包含基础构图与用户可明确选择的高级复合构图。`C18 肩后构图`、`C24 鸟瞰`、`C25 上帝视角`、`C27 极端留白`、`C35 鱼眼式构图` 等会覆盖与其直接冲突的默认人物尺度、相机依托、留白比例或低畸变倾向，但不覆盖用户在其他模块中的明确选择；真实冲突仍进入询问。

## 交互入口

先读取[缺项问卷](references/interactive-questionnaire.md)。默认使用简洁入口：补问影响画面的关键选择，自动匹配未指定镜头；用户要求“完整问卷／全部选项／逐项选择”时切换完整入口。这两个文本入口保持纯文本；用户要求界面选择或图解时，使用[HTML 图鉴](references/visual-selection.md)，不创建对话内可视化选择器。女性人物直接采用固定的半绾披发，发型不作为问卷缺项。已指定条件不重复问，真实冲突或自定义缺少文本仍需解决。

## 六维路由

每次创建、改写或批量编写提示词，按顺序读取并应用：

1. [风格](references/style.md)：A1–A6；A3 不采用倒悬建筑，倒影须依附真实反射面；A6「清明云海仙宫」提供明亮浅色、三层空间、单人尺度参照的预设，先补齐其未指定项再处理其余维度，用户明确条件优先。
2. [画幅](references/aspect-ratio.md)
3. [构图](references/composition.md)
4. [镜头](references/camera.md)
5. [光线色彩模式](references/light-and-color.md)
6. [元素](references/elements.md)：含竹林、大海、落日、大江大河、花树四色、满天星、两种平台地面、白鸽、飞鹤和建筑构件；编号及花色选择见[完整目录](references/option-catalog.md#f4-可选附加)。

优先级始终是：`用户明确要求 > 系列锁定 > 本 Skill 默认 > 随机选择`。不同维度冲突时，保留用户条件，并重选兼容项；只有用户条件本身互相矛盾时才询问。

## 批量策略

- **系列场景**：用户要求同一系列、统一视觉或同一世界的多个镜头时采用。整批固定风格、建筑体系、色彩家族、光向与曝光，变化空间、构图与镜头。明确要求某个维度变化时，只解除该维度的锁定。
- **独立方案**：用户要求随机多个场景、不同方案或探索多种可能时采用。保留明确指定的元素类别、情绪和其他条件，允许未锁定的墙面材质、树形、配色、光线及空间组织逐张变化。例如“宫墙、古树、寂寥”不等于每张必须朱砂墙与古松；但“红墙、古松”必须整批保留。
- 只说“做一组／生成多张”而未要求随机时，默认系列场景；只说“随机生成10个场景”时默认独立方案，并在锁定摘要说明。同时出现“同一系列”与“随机”时，系列要求优先，随机只作用于未锁定维度。策略不增加一轮必答问卷。画幅、人物数量、性别策略与可见程度仍整批固定，除非用户明确要求对应项随机或变化。仙女发型始终固定为半绾披发；全部随机、批量变化及旧版界面的发型随机选择都不再改变发型。
- 独立方案不强迫更换用户已锁定的风格或光色；单张图内部始终保持一套协调色光。兼容候选不足时允许复用，不为了凑差异添加多余元素。

## 默认候选

按所选入口允许补齐未指定项时，使用以下候选：

- 风格：电影级写实东方神话环境 CG，庄严、静谧、超现实但结构可信。
- 画幅：`16:9`。
- 构图：留白构图为主，三分构图为辅；巨构位于一侧，另一侧保留空明天域。
- 镜头：相机具有与场景兼容的明确站位，中等广角、低畸变、深景深；前景是否可见、是否裁切由已选构图与镜头决定，不作为默认必填内容。
- 光色：明亮仙境；天青冷环境、朱红或深木建筑、左上方暖金清晨斜光、正常曝光。
- 元素：默认是一座超尺度、具有超大连续屋檐与巨壁般承重柱的中国宫廷主殿、平整云海和一名成年女性仙者（背面或侧面）；附属小楼不作为默认必加元素，建筑与人物也均可明确选择为无。女性人物固定采用半绾披发（F2-H7），单张、系列和随机场景均一致。墙面系统与其他奇观不自动加入。摆放方式在用户选择推荐/默认或跳过询问时使用 `F5-1`，由构图、镜头和空间层次推导兼容位置，九宫格及已有地点仅作示例。

## 工作流程

1. 按缺项问卷进入 `ASK`、`WAIT`、`ASK_REMAINING` 或 `GENERATE`。问卷回合只提问并停止，不能提前给提示词。
2. 进入 `GENERATE` 后，建立“六维锁定卡”，记录用户指定项、选择项、默认项和受控随机项。
3. 按批量策略确定整批锁定与逐张变化项。每张先确定主视觉主体、天域、构图、镜头和色光，再确定人物可见程度、发型及已选元素的位置。宫廷主建筑的场景记录必填 `主殿单体 / 主檐跨度、厚度及下方空域 / 单根柱的粗度、承托与景深关系 / 自身尺度证据 / 附属小楼：有或无`；有极小人物时，再记录 `所在空间层 / 承载面 / 与主主体及其他空间层的距离或连接关系 / 背面或侧面朝向 / 全身高度占比：默认约 2%，严格小于 5% / 作用：仅尺度参照`，落点由构图推导，不受地点示例限制。只有附属小楼已选为有时才补其大小层级；情绪落实为可见关系，如遥远距离、孤立落点或大块明暗对照，不只在末尾追加情绪词。
4. 随机构图和镜头从兼容池选择，用尽前尽量不重复；肩后、虫视、鸟瞰、上帝视角、鱼眼、不可能透视和上下颠倒等明确选择型模式不进入普通随机池。相邻画面优先改变站位、观看方向、主体方向、空域位置中的多项，独立方案还变化未锁定的材质与色光；用户固定项不为凑差异而改变。
5. 先建立语言无关的完整场景记录，再写简洁的中英文提示词。最终顺序为 `主画面及空间关系 → 必要元素（人物只描述一次）→ 光色与关键质感`。风格用短语表达；机位只保留确实改变画面的信息，不逐段串接参考模板。通常用3–5个短句，英文约50–100词；这是压缩目标，不是删除用户明确条件的硬上限。删除重复尺度词、构图标签、无关相机说明和泛泛赞美词，保留人数、人物高度上限、尺度参照作用、元素、位置和光色；默认极小人物省略不可辨的发型衣饰细节。两种语言描述同一场景。
   宫廷主建筑的开头先写超尺度单体、主檐与承重柱的具体关系，再写空间层次及已选元素。压缩时保留主檐与单根柱的自身尺度证据；极小人物句保留其所在空间层及与主体的尺度关系，不退回只有“宏大宫城、层叠楼阁、遥远平台上的小人”的概括。
6. 中英文两份提示词必须描述完全相同的构图、镜头、元素位置、光色和材质，不能各自随机。参数必须位于两份提示词末尾并保持一致。默认使用 `--ar 16:9 --raw --s 450 --c 8`；画幅替换为用户选择，单次必须给出具体数值，不能输出数值范围。用户指定参数时服从用户；不自动写死模型版本。
7. 每张中英文提示词均须在参数前保留[满幅无黑边](references/aspect-ratio.md#满幅无黑边)的短句，批量不能只在共享摘要中说明。`--no` 固定包含 `letterboxing`，其余只列当前最危险的简单对象词，例如 `neon, cyberpunk, skyscraper, text, logo, watermark`；已有负面参数时合并为一个 `--no`。先用正向关系控制画面，不用长串负面词代替构图。
8. 用户要求排查服从性或比较参数时，读取[参数对照流程](references/parameter-comparison.md)。先固定场景，每次只改一个参数；没有实际结果时不改默认、不声称改善已验证。

## 标准输出

### 问卷回合

文本入口只输出已锁定摘要与需要补问的纯文本选项；图解需求提供独立 HTML 图鉴，由用户复制选项回到对话。简洁入口不展开整套镜头目录；完整入口列出缺失模块的全部固定选项。仙女发型只注明固定半绾披发，不再提供选择或补问。出现画幅选择时标记 `B1 16:9` 为默认推荐。输出后等待，不同时生成提示词。

### 生成回合

必要选择和适用子项解决后，只输出：

1. `六维锁定卡`：用简短摘要记录风格、画幅、构图、镜头、光色、元素；批量注明策略，人物注明可见程度、高度占比上限与内部固定发型。整批重复信息只写一次。
2. `中文提示词`：一个可直接复制的代码块，使用中文视觉描述并在末尾放置参数。
3. `English Prompt`：一个可直接复制的代码块，使用英文视觉描述并在末尾放置与中文版完全相同的参数。
4. `变化说明`：仅用于随机或批量任务，说明整批锁定项和逐张变化项。

默认始终输出中英文两份；只有用户明确说“只要中文”或“只要英文”时才输出单一语言。用户要求“只要提示词”且同时表示直接生成或已经提供全部模块时，不输出锁定卡与解释，但仍输出中英文两份提示词。仅说“只要提示词”本身视为跳过询问。没有可用的 Midjourney 提交工具时，只交付提示词，不声称已经生成图片。

## 交付审计

- 每张中英文提示词是否均明确场景铺满画布四边、禁止上下黑边，并包含一致的 `--no letterboxing`（可合并其他负面词）？留白是否为真实场景内容，画幅是否直接由 `--ar` 指定？有成图时检查上下边缘，未见成图时不声称黑边已消除。
- 第一眼是否是一个连续的主视觉尺度主体，而非许多等大的独立对象？选择无建筑时，是否完全没有自动补入宫殿、楼阁、亭台、塔楼或屋顶？
- 宫廷主建筑是否有一座超尺度单体或其局部？是否同时写出主檐的跨度与厚度、单根柱的粗度及承托关系，并由柱间空域或同一构件内部的距离层次表现自身巨大？附属小楼能否完全省略，已选时是否明显从属？极小人物的承载面与巨型参照对象之间是否有清楚的距离或连接关系，批量是否按构图变化落点而非每幅都站在柱脚旁？
- 是否同时存在局部高密度结构和内容承载空气？常规构图开放域约占 `40%–60%`；明确选择 `C27 极端留白` 时为 `80%–95%`。
- 是否明确一个主构图和最多一个辅助构图，并写成可见关系而非标签堆叠？
- 单人提示词是否只有一处完整人物描述？构图中的尺度锚点、镜头中的人物和摆放中的仙者是否已经合并为同一个对象、同一个承载面和同一种远近尺度？“人物缩小”是否替换原句而非追加小人？左下等画面位置是否与远近距离分开处理？
- 是否按当前入口处理缺项：简洁入口只问关键项，完整入口列全缺失模块，未决冲突和缺少自定义文本没有被默认掩盖？
- 仙女是否固定采用 F2-H7 半绾披发，没有残留发型菜单或随机发型？内部是否保留上部小髻与下部披散造型，中英文一致，且没有为展示发型增加人物、放大人物或强求极小剪影细节可辨？
- 文本问卷是否保持纯文本、图解是否使用独立 HTML 图鉴，是否沿用稳定编号且没有重复询问已指定项？
