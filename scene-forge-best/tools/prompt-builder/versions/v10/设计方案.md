# 工作台 V10 设计

结果弹窗使用受视口约束的纵向 flex 容器。顶部保留关闭、批次信息、复制全部与下载；主体为两列：左侧标签列表独立 overflow，右侧详情独立 overflow。输入与来源放在右侧末尾。中文和英文在右侧纵向排布，取消各正文的内部滚动。

默认显示第一个方案，不触发复制。每次明确点击标签（含键盘激活）切换详情并复制完整中英一对，重复点当前标签也复制；标签文字保持不变，独立状态区提示成功或失败。切换时右侧回到顶部，左侧位置保持。提供中文、英文与整条复制按钮。移动端保留左右分区，用窄标签栏和自动换行防止横向溢出。

数量提供 1—10，前后端上限、历史清洗与 ZIP 校验同步；备份导入容量按 30 次历史每次 10 条重新估算。保留每方案字段长度及错误处理，不把失败或截断当成功。扩充上游响应及 ZIP 请求字节上限以匹配十条现有字段限制。

测试标签选择/激活，10 条请求、历史备份、ZIP及越界；浏览器用明确标注的模拟十条长内容检查实际剪贴板、左右滚动、首次不复制、手机布局、下载与旧历史。规范不改。
