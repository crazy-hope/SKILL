# 参考图巨构标准

使用本标准把参考图转译为原创云宫场景。本标准记录几何关系、结构、材质表现、光线和氛围；绝不授权复制完整源画面、专有设计、人物、文字、印章或水印。

## 参考图角色契约

编写提示词前，标注每张图的角色：

- **编辑目标**：仅在用户明确要求修改该图时使用。
- **构图参考**：提取裁切压迫感、地平线、纵深路径、负空间和尺度层级。
- **建筑/材质参考**：提取承重路径、屋檐深度、斗拱密度、石材、漆面、铜和鎏金表现。
- **氛围/光线参考**：提取云层高度、薄雾落位、冷暖分离和光线方向。
- **仅作排除参考**：记录不需要的UI、边框、栏杆、文字、印章、水印或生成瑕疵。

未要求编辑时，所有来源默认都是非编辑参考。明确说明哪些特征可以迁移，以及哪些源图特有布局、人物和纹样不得迁移。

## 可迁移视觉标准

1. **裁切体量的压迫感**：屋顶、柱、天障、平台或宫基下构约占画面50–80%，并延伸出一个或多个画框边缘。结构性天环例外：以远景完整收入圆周，用支撑跨度、人物和空间层级表现宏大。
2. **五层空间**：近景巨型框景、人物承载阈境、主导事件、从属天域、终端远景（云层、天空或更高天界）。
3. **内容承载空气**：通过开口、宫基下方虚空、云隙、庭地、水面和极远景保留约40–60%。
4. **尺度断层**：先在`0.5–2%`、`2–4%`、`4–8%`（默认）和`8–12%`四档中确认人物尺度，再在所选档内锁定具体值；柱径相当于6–10个成年人高度，开口高25–50人，跨度达数百个身体宽，并设置一个极远锚点。
5. **结构密集，体量安静**：深斗拱和木作节点出现在檐下、梁柱转换处、天障边缘或基座。宽阔墙面、玉石、屋顶和平台平面保持安静。
6. **近暖远冷**：前景结构接收暖色擦光；远处云层和建筑变得更冷、更亮、反差更低，但不能变灰。
7. **最多一个自然对形**：只有当古松、瀑布、悬崖或云河能改善平衡、方向或尺度时，才使用其中一个。
8. **远景仙者尺度尺**：成年仙女或仙者采用背面或侧后方全身角度，镜头离人物足够远，人物真实站立或行走在平台、桥面、台阶或柱础旁，与建筑共享地平面、消失点、透视缩放、光照、投影、遮挡和大气层级。动作平静、彼此保持空间间隔，绝不达到肖像尺度。默认站立、观看、轻缓转身或慢走；不得快走、奔跑或冲刺。
9. **柔和时段光**：从日出、早晨或落日中选择一条低到中低角度主光路线；用冷色天空填充维持结构可读性。中午或下午只有用户明确要求时采用，并必须经过云层或大气漫射，不能出现刺眼直射。
10. **连续尺度链**：固定使用`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`，并把“当前主导巨构”替换为本图实际选择的结构；人物一级不可省略，至少从人物起连续显示四级，并让相邻层级的比例、距离、遮挡和大气递减一致。

## 结构事件库

结构事件可以为`无`。只有用户点名，或当前构图路线本身要求时，才选择下列一个事件作为视觉命题；不得把未选事件作为从属奇观附加到画面。

### 半幅巨柱

- 一根被裁切的柱，或一对局部柱，约占画面三分之一到一半。
- 展示可信的柱础、柱身、斗拱转换，以及它所支撑的屋顶或天障。
- 优先使用远距低机位或人眼高度24–50mm；控制垂直线。
- 不要把柱做成独立装饰雕塑。

### 结构性天环

- 把天环当作融入柱、宫基、屋顶桁架或露台的建筑跨度，而不是漂浮科幻圆环或普通月洞门。
- 使用远景或超远景机位，把完整圆周连同呼吸空间收入画面；禁止近景特写、画框裁断、半环或四分之一弧。
- 暴露分段接缝、厚度、至少两处支撑点和有人活动的阈境。纤细桥线或薄云可以轻微穿越环体，但缩略图下仍必须一眼读出闭合圆形。
- 让环内开口揭示从属天域与终端远景，而不是平面背景。
- 用数百个身体宽的直径、微小人物、从属宫阙、跨云层支撑与大气透视共同证明尺度，不用贴近镜头制造虚假巨大感。

### 悬空镂空天障

- 所有开口只能属于边缘规整的圆形或方形一种家族，不使用随意不规则负形，也不在同一面天障混用形状。
- 根据天障宽高比`W:H`选型：`0.85 <= W:H <= 1.15`时可使用方形，其余比例使用圆形；方形边线与天障或建筑的水平轴、垂直轴平行，禁止旋转成菱形。
- 只设一个主开口；如需从属开口，它们必须同形、规整、显著更小并服从主开口的结构节奏。
- 赋予天障可见厚度、基座或悬挂点，以及清楚的承重路径。
- 至少保留一个通向深远云域的主要开口；不要用细密镂花填满所有虚空。

### 悬空宫基

- 让厚重宫基或深檐底部替代一部分上方天空。
- 展示层叠梁架、斗拱、结构肋、悬挂庭地或竖向支撑，同时保持底部阴影通透。
- 低位太阳可以掠过宫基边缘下方，在冷色云层前形成一道单一暖光缝。

### 无尽深檐、柱廊或长廊

- 让深檐、柱、天障或院落沿一个稳定消失系统重复。
- 构件间距和大气反差必须随距离一致变化。
- 长廊应有数百个身体宽，并延伸至视线不可达处；避免普通人类尺度的走廊比例。

## 六类宫殿材质家族

每幅场景选择一个家族。使用材质反应，而不是全局色彩罩染。

1. **纯白**：接近中性的白玉、象牙石材和珍珠灰阴影；金属强调限制在0–4%。
2. **朱红**：矿物朱漆、暗红棕木材、稳定画面的云白和冷蓝灰阴影；只保留窄小古金边缘。
3. **古金**：低纯度陈金、洁净深色铜、深青绿石材和月白建筑；亮金只落在轻微磨亮凸脊，不出现锈斑或腐蚀。
4. **红金**：深朱红结构木材配合古金斗拱或屋顶边缘；云、天空和石材保持中性，避免整幅画面变成橙色主题乐园。
5. **白金**：月白玉石和浅色石材占主导；珍珠金或古金只用于结构接缝、天障边缘和擦光高光。
6. **传统矿物彩画**：朱红结构面、石青/石绿/群青承重彩画带、赭色或老黄屋顶强调、象牙白或灰色石材稳定面，以及窄旧金。阅读[传统建筑彩画配色](traditional-polychrome-palettes.md)，并锁定一条子路线和一个风化等级。

让暖色建筑靠近镜头，让更冷的天界层位于远处。云层高光保持接近中性；阴影保持通透，可用青灰、岩蓝、蓝绿或紫灰。

## 运动与镜头相互独立

静态图提示词默认避免奔跑姿势、匆忙步态、强烈前倾和明显运动模糊，除非用户明确要求。对于动画或图生视频提示词：

- 人物默认静止，或以稳定速度缓慢自然行走；
- 禁止快走、奔跑、冲刺、突然跃进和匆忙人群运动；
- 镜头默认为固定机位、慢速恒速推移，或带轻缓起步和收束的克制慢速环绕；
- 禁止快速推镜、猛然变焦、甩镜、延时摄影、变速和加速视差；
- 世界空间运动必须与镜头相互独立：推镜只改变构图和光学视差，绝不改变人物、云、水、瀑布、布料、头发、粒子或建筑的速度；
- 云、水和布料的运动保持缓慢、宽广、符合重力，并服从建筑静止感。

`动感`、`强冲击力`、`电影感`、`能量充沛`或`节奏紧凑`等词不能覆盖上述默认规则。通过尺度揭示、遮挡、光线、构图和受控视差制造冲击力，而不是依靠速度。

## 提示词模块

把以下内容作为可扩展模块，而不是完整提示词：

```text
半幅巨柱：一根被画框截断的巨型白玉承重柱占据约半张画面，柱体直径约八个成年人高度，柱顶与深檐继续伸出画外，柱—斗拱—梁—檐的承重路径清晰，右侧开放云域揭示四重远景。

结构性天环：远景或超远景中，一道完整闭合的结构性天环连同四周呼吸空间全部收入画面，圆周不被画框截断；环体有真实厚度、分段接缝和至少两处连接宫基、柱系或屋顶桁架的承重点，直径横跨数百个身体宽，环内依次显露微小人物、云桥、从属宫阙与终端天域，以多层尺度对比呈现宏伟而不是近景放大。

悬空镂空天障：一面具有单一明确几何主开口的悬空玉石天障横贯中景；只锁定圆形或方形一种家族，所有从属开口保持同形、规整且明显更小，绝非随意破洞；如用方形，其边线与建筑水平轴、垂直轴平行，不得旋转成菱形；天障厚重而有支撑，雕刻只集中在内缘，主开口约四十个成年人高度，远景穿过开口继续延伸。

悬空宫基：被裁切的红金宫殿底部压住上半画面，层叠斗拱和梁架如倒悬山脉，低位太阳从宫基边缘下方掠过，暖金边光与冷蓝云海明确分离。

无尽深檐长廊：纵深极长的白金长廊沿单一消失点延伸至不可见主殿，数十组巨柱与深檐规律缩小；远景仙女采用已确认的人物尺度档并锁定具体占比，默认从`4–8%`随机取值，所有平台与桥面无栏杆。
```

## 系列多样性契约

多图请求中，每张图至少改变三个模块：

- 空间路线或结构事件；
- 镜头、相机距离、裁切和地平线；
- 六类宫殿材质家族之一；
- 日出、早晨或落日三条柔和光照路线之一；
- 背面、侧后方、站立、慢走或仰望的人物动作；
- 可选的单一松树、瀑布、悬崖或云河。

不要在系列中重复同一个居中天环、三人排列、松树剪影、机位高度或白玉/红金配方。每张图仍要保留五层空间、40–60%内容承载空气、微小人物和无栏杆边缘。

随机多图先从10条构图路线不放回抽取，再为每张图分别决定结构事件；只有抽中对应路线的提示词才可提及天环或天障。

## 污染与模仿排除

始终排除手机外框、黑边、底部指示条、灵动岛形状、播放控件、字幕、Logo、印章、签名和水印。排除参考图栏杆、克隆屋顶模块、扭曲柱体、不可能的支撑、重复人物和形似UI的开口。不要复制源图的精确圆环、树木剪影、宫殿布局、人物位置、日落位置或专有装饰。

## 参考图驱动审计

逐项修订，直到所有答案都是“是”：

- 是否明确标注参考图角色，并默认采用非编辑参考？
- 迁移的视觉基因是否表述为几何、结构、材质、光线或氛围，而不是复制源画面？
- 结构事件是否与当前构图路线匹配，或已明确锁定为`无`？若存在结构事件，是否具有可信承重路径？
- 深斗拱与装饰是否局部集中，同时巨大平面保持安静？
- 是否由一个宫殿材质家族主导，且没有全局色彩罩染？
- 如果选择传统矿物彩画，是否明确颜料落位、子路线、面积预算和风化等级？
- 近处暖色结构与远处冷色云层是否清楚分离？
- 五层空间、40–60%内容承载空气和四个尺度证据是否齐全？
- 是否已向用户提供`0.5–2%`、`2–4%`、`4–8%`和`8–12%`四档人物尺度，记录所选档位，并在该档内锁定一个具体值？若直接执行，是否默认从`4–8%`随机锁定？
- 若为结构性天环，完整圆周是否全部收入画面、远离镜头且缩略图下一眼可辨，并由支撑跨度、人物和多层远景证明宏伟？
- 若为悬空镂空天障，是否按宽高比只使用圆形或正向方形一种家族，所有从属开口是否同形且规整，并且没有菱形、旋转方形或随意不规则缺口？
- 金属与建筑是否洁净、完整、有人维护，没有锈斑、锈水、腐蚀和废墟感？
- 是否锁定日出、早晨或落日之一，并明确太阳高度、主光方向、阴影软硬和冷色天空填充？若为中午或下午，是否由用户明确要求且已充分漫射，没有刺眼直射？
- 镜头是否离人物足够远，人物是否以背面或侧后方全身真实落在承载面上，并与建筑共享地平面、消失点、透视缩放、光照、投影、遮挡和大气层级？
- 是否从人物起连续显示`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`中的至少四级，已把“当前主导巨构”替换为本图实际结构，并且相邻比例关系准确？
- 人物是否默认静止或慢速运动，同时没有快走、奔跑和冲刺？
- 如果镜头运动，是否保持缓慢，且与恒定的世界空间运动相互独立，没有变速或推镜诱发的加速？
- 所有边缘是否无栏杆，所有截图污染是否已排除？
- 系列中的路线、结构、镜头和配色是否真正发生变化？
