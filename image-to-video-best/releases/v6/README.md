# 图生视频提示词 Skill

先分析图片内容与元素、题材、画风和氛围，再根据动作、材质、时序和目标模型选择**简短 / 中等 / 细致**三档。支持多题材融合，默认中文、5秒；用户指定优先。

项目维护入口：[Agent.md](Agent.md) → [AGENTS.md](AGENTS.md)。所有修改记录在 [CHANGELOG.md](CHANGELOG.md)，保存与回退见 [VERSIONING.md](VERSIONING.md)。

当前完整项目快照：`releases/v6/`。规范与工作台分开发布：

| 对象 | 当前版本 | 状态 |
|---|---|---|
| 独立Skill规范 | v4 | 六段结构、场景关系与动态控制；参考资料用于学习 |
| 页面工作台 | 0.5.0 | 默认4个入口并行生成，点击详情查看与复制 |
| 工作台实际加载的规范 | v2 | 本次未切换到v4 |

规范可脱离工作台使用。发布新版规范不会自动升级工作台；完整项目快照只是归档容器，分别保留这两部分。

v4默认正文按“全局基础硬性设定、场景基底、主体动态细节、运镜规则、同期环境音效、硬性约束”六段输出，三档只调整展开深度；明确要求单行时按同一逻辑合并。环境可为动态重点，群像、承载面与附肢交互分别编排；声音未指定时不擅自添加。两张水下图和对应原文保存在一组学习参考中，不作为两个独立验证案例。

v4继承v3的只有图片时自动构思：大模型先判断可能的题材、画风和融合关系，再给符合画面的动作、环境变化、镜头与收尾。自主构思标明为建议；有明确需求时忠于需求。多个合理方向可分别提供完整候选，不要求用户先填题材标签。

## 页面工作台

已提供本地网页 **成镜**：默认4个独立任务入口，分别上传图片、填写需求，可单独或全部并行生成；点击「查看详情」复制与导出Markdown，可继续新增任务。启动命令为 `npm start --prefix web`，默认地址为 [http://127.0.0.1:3210](http://127.0.0.1:3210)。

macOS可以直接在Finder双击根目录 [启动工作台.command](启动工作台.command)，服务就绪后自动打开浏览器。保持其终端窗口运行，按Control+C或关闭窗口停止本次服务。需已安装Node.js 22.13或更新版本。

真实生成请点击页面右上角「配置模型接口」，填写兼容OpenAI的多模态服务地址、模型与密钥，保存后立即生效。详见[配置与使用](web/README.md)、[页面验证记录](web/VALIDATION.md)。应用默认只读使用v2资料快照，不改变已发布技能；尚未接入在线检索或视频生成。

v2的细致档充分展开材质外观、分层运动、动作牵引、持续状态与光影氛围，同时保留用户指定的动作、运镜方向、速度、先后顺序和收尾；不会因为进入特写就自行加速。规则和测试不等于真实视频效果保证。

## 使用

选择一个版本中的整个 `image-to-video-best` 文件夹作为技能包，保留其中的相对目录。不要同时安装多个同名版本。本项目没有自动安装、替换已有技能或调用视频生成服务。

可直接让支持本地技能的助手读取 [SKILL.md](v4/image-to-video-best/SKILL.md)，提供图片、目标模型及期望动作；不需要启动工作台。例如：

> 使用 image-to-video-best。目标 Runway Gen-4.5 官方网页，时长5秒。根据这张图片自动选择等级，给中文提示词、简短设计原因与必要设置。

> 使用细致档，目标 Seedance 2.5，7秒。图片中的人物单手施剑诀，流体持续回旋；请先确认我使用的平台，再给适配提示词。

可查看[六段结构](v4/image-to-video-best/references/prompt-structure.md)、[场景关系与动态](v4/image-to-video-best/references/scene-direction.md)、[画面分析](v4/image-to-video-best/references/visual-analysis.md)、[三档示例](v4/image-to-video-best/references/levels.md)和[参考学习资料](v4/image-to-video-best/references/learning/underwater-reference-set.md)。

## 更新与回退

1. 已发布版本保持完整快照；日常在线查证不会自动修改它。
2. 用户要求更新时，将上一版完整复制到下一个尚不存在的版本目录，例如v5。不要提前创建空版本，也不共享可变资料。
3. 在新版本中修改规则与资料，记录官方来源、核查日期、行为变化及原因。旧验证结果作为历史证据标明，重新执行新版本测试。
4. 验证技能格式、资料链接、独立复制使用、行为案例及旧版校验和；更新新版本发布说明与校验清单后，才更新这里的推荐版本。
5. 回退时选择历史技能包，并修改推荐版本索引；不覆盖历史目录。文件夹版本保存与父仓库Git可以并用，本次未操作其他项目的暂存内容或提交历史。

每版的 `SHA256SUMS` 记录该版全部文件（不含清单自身）的校验值。可在版本目录运行 `shasum -a 256 -c SHA256SUMS` 检查历史内容是否改变；这是完整性检查，不是防篡改签名。根索引不属于冻结快照。

## 验证边界

[验证记录](v4/validation/REPORT.md)区分格式/行为测试、参考学习和真实视频效果。用户反馈水下参考材料使用可灵O3效果很好；本项目未获得成片、实际提交版本和入口设置，未进行视频生成对照。模型资料会变化，使用时按技能要求核查当前官方入口。
