# 画面工作台 V19

日期：2026-10-30；基线[V18](../v18/README.md)。React＋Ant Design前端重构，继续使用完整[规范V16](../../../../versions/v16/输出/规范框架v16.md)及现有生成接口。前端重构、回归和独立审查完成并交付。

## 使用

先停止旧工作台服务，再双击根目录[启动提示词工作台.command](../../../../启动提示词工作台.command)，打开 `http://127.0.0.1:8787`。日常只运行Python和已构建页面，无需npm或CDN。

五项基调默认原文始终显示，可修改、清空或恢复。主体可手写或AI细化/撤销，直接生成完整中英；默认Midjourney、1对，支持1—10。每次AI动作一次文本请求。点击生成即打开进度弹窗，完成后在同一窗口切换方案、分别复制中英文或下载全部，并保留模型使用说明；不加入元素选择或三构思步骤。

本版将输入、选择器、按钮、卡片、提示、弹窗和折叠区改用Ant Design，统一主题。生成过程与结果、接口设置、历史与备份使用Modal，支持Esc关闭及焦点返回；TextArea随内容和宽度调整。保留桌面双栏及手机上下布局。

## 数据

与V18共用scene-forge-workspace-v18、schema6和scene-forge-backup-v6，无需导入或迁移。在相同浏览器和端口下，已有草稿、空值、历史与接口配置继续可用；恢复备份影响两版共用数据。V17/schema5及更早格式仍不读取不转换。API Key仍独立保存，不进入创作历史、备份或下载。损坏存储保护、延迟响应失效和备份恢复竞态保护保留。
