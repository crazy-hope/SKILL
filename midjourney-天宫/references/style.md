# 风格

## 根风格

所有模式共享：原创东方天界、电影级写实环境 CG、高端影视概念设计、超现实空间、真实建筑厚度、清楚大轮廓、深景深、克制材质反光。画面张力来自尺度断层和空间，不来自战斗、霓虹或特效堆叠。

## 风格模式

| 模式 | 视觉取向 | 使用条件 |
|---|---|---|
| 天界电影 CG（默认） | 写实材质、宏大电影构图、清楚结构、庄严静谧 | 用户未指定 |
| 空明神域 | 更大的天空与云域、更少装饰、更柔和的空气透视 | 用户强调空灵、禅意、寂静 |
| 东方超现实奇观 | 正向悬空、云上延伸与超常体量，结构仍连续；可用真实反射面产生倒影 | 用户强调超现实、梦境或神迹 |
| 肃穆巨构史诗 | 更重的深檐、宫基、岩壁与阴影，仍保留可读暗部 | 用户明确要求冷峻、暗色、沉重阴影或低明度 |
| 极简神域 | 一座主巨构、一个天域载体和一个尺度锚点形成大块面与清晰轮廓；以强明暗或冷暖分区建立对比，细节只集中在主体 | 用户要求干净、简约、少元素、强烈对比 |
| 清明云海仙宫（A6） | 通透明亮、浅色主材与朱红点缀；近景实体空间—中景云海—远景巨构形成深度，单名成年仙女仅作尺度参照 | 用户选择 A6，或明确给出这套明亮光色与三层空间关系 |

单张只选一个主模式；系列场景整批锁定同一模式，独立方案可在用户未锁定时选择兼容模式。不要把“电影 CG”写成廉价游戏截图、塑料 3D 模型或旅游明信片。

“巨构压迫感”是所有模式都能实现的尺度目标，不构成选择“肃穆巨构史诗”或暗色光线的充分条件。用户同时要求压迫尺度与空明天域而未指定风格时，仍使用“天界电影 CG”默认。

选择“极简神域”时，不自动抽取附加奇观或装饰物，只保留一个主视觉主体、天域载体和至多一个尺度锚点。主主体可以是建筑、非建筑巨构、地形、自然奇观或自定义元素；人物仅在用户选择时出现。用户明确选择的 `F4` 元素仍全部保留，但必须指定一个主元素，其余退到中远景或简化为低细节剪影。强对比来自两三个大面积明度或色温区块，不来自高饱和、多色灯光、密集纹样或全画面锐化。

## A3 东方超现实奇观的朝向

建筑保持正向，奇观感来自悬空、云上延伸与超常尺度，不采用倒悬建筑。若需要上下呼应，仅使用水面或光亮地面的倒影：同一建筑与其反射在可见反射面两侧对应，倒影可随水纹或材质减弱，不是另一座翻转的实体建筑。未选反射面时不为了倒影自动添加水庭。

## A6 清明云海仙宫

**视觉特征**：通透、开阔、清静，以浅色实体和丰厚云层衬托中式巨构的尺度。朱红柱列提供有节奏的色彩点缀，人物只提供尺度，不承担叙事焦点。

- **明度与材质**：浅石、玉白、浅木色构成主体色面；明亮日光与云海反光照亮檐下，云层保留厚度和高光细节。深色仅作局部材质或阴影，光亮地面有克制的反射，不以大片暗木黑瓦制造压迫感。
- **空间秩序**：近景可行走的实体承载面、中景连续体积云海、远景主建筑形成清楚的深度。平台用大面积空地建立距离，朱红木柱长廊用重复柱列和地面透视建立纵深；默认二选一，不堆叠多个近景框架。
- **中式形制**：远景由一座超尺度中式建筑主导，连续长檐、深檐、斗拱与榫卯梁架、粗厚承重柱形成可信的结构关系；具体建筑形态按用户选择。藻井只在殿内顶部实际可见时使用。
- **自然点缀**：古松或花树以疏朗枝冠和局部花色调节硬质建筑，保留通行面与云海的开放感；可完全无树。飞鸟及其他附加元素不属于必需配置。
- **尺度锚点**：默认全图仅一名成年女性仙者，以侧面或背面全身轮廓落在遥远平台或长廊上；默认约占画面高度 2%，严格小于 5%。建筑与云海为主体，人物仅为空间标尺，不展开发型、面容和衣饰细节，不添加第二个人物。

**应用方式**：A6 是带有空间、光色与人物关系的风格预设。选择后补齐尚未指定的相关项；默认浅色平台、无树、泛中国宫廷、16:9，镜头按三层空间匹配。批量可变化平台／长廊、可选古树、建筑形态、机位与人物朝向，保留上述视觉特征。用户其他明确条件与后续修改优先，不将 A6 改成全局默认，也不影响 A1–A5。提示词表达具体可见关系，不只输出“A6”标签。

## 永久造型语法

- 主体必须形成一个连续、可读且尺度宏大的主视觉系统。宫廷建筑作为主体时，以一座超尺度主殿或其局部承担主视觉，按[单体与构件尺度](elements.md#单体与构件尺度)建立横跨空庭的厚重主檐与巨壁般粗厚承重柱，附属小楼可有可无；选择 `F1-6 无建筑` 时，不得自动补入建筑，由已选天界结构、地形、自然奇观或自定义主体承担同样的连续轮廓与尺度关系。主体可完整入画，也可按已选构图延伸出画框；结构重复服务于已有大体量，不强制裁切或近景框架。
- 细节集中在一侧、顶部或结构转换处；天空、云海、云峡、水庭或深渊作为内容承载空气，常规约占画面 `40%–60%`。用户明确选择 `C27 极端留白构图` 时改为 `80%–95%`。
- 用构件重复、纹理尺度、遮挡、空气透视、可选人物和远近尺度跳跃证明体量，不用“宏伟、史诗、8K”代替可见关系。选择无人物时，不得为证明尺度自动补入人物。
- 材质以木构、瓦、石、暗铜、旧金和水汽为主。金色只作窄边、擦光或局部反射，不把整座建筑变成亮金。

## 常见偏移

| 偏移 | 修正 |
|---|---|
| 建筑密集且相连，但全是相近大小的小宫殿 | 保留密度，确立一座压倒性主殿；写出同一片超大主檐与实际承托它的巨柱，较小楼阁依附下层或侧翼，并保留开放天域 |
| 主殿号称巨大，但屋檐和柱仍像常规建筑构件 | 扩大连续主檐的跨度、挑出及厚度，将单根柱写成宽阔弧形巨壁；用檐下净空、柱间纵深及与主建筑有清楚空间关系的已选极小人物证明体量，人物落点随构图变化 |
| 每幅都塞入附属小楼，巨构必须靠小楼衬托 | 附属小楼改为可选；主殿自己的巨檐、承重柱、柱脚和空域建立尺度，不为比较添加楼群 |
| 全局高饱和、全局金色 | 冷色环境占大面积，暖色只落在受光结构 |
| 西方城堡、哥特尖塔、科幻都市 | 回到中国木构檐柱、斗拱、宫基、桥廊与瓦屋面 |
| 人物英雄海报 | 建筑巨构与云海为主体，人物仅作尺度参照；V1–V3 默认全身高度约 2% 且严格小于画面高度 5%，不为展示发型衣饰放大人物；`C18 肩后构图` 只保留一角可辨认肩背，仍不展示正脸特写 |
