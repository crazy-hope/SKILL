# 提示词工作台 V12

状态：2026-10-20 已交付；基线[V11](../v11/README.md)，2026-10-22小维护后完整规范来源为[V9](../../../../versions/v9/输出/规范框架v9.md)，历史交付时使用V8。

## 使用

双击根目录[启动提示词工作台.command](../../../../启动提示词工作台.command)。已有服务需先在原终端按Ctrl+C结束后重启；只刷新网页不会切换Python后端。

只选题材、元素和你关心的视觉条件即可生成。“大致说明”可保留默认句，也可清空；无需手写动作与空间关系。

| 面板 | 用途 |
| --- | --- |
| 01题材 | 世界与气质；下方可单选东方、西方、中国地域，默认不选；不自动指定宫殿、巨岩或人物 |
| 02元素 | 已选对象默认每方案全部包含；展开“角色、动作与空间”可指定角色、相对尺度、画面占比、数量、动作、位置、层次、关系及关系对象，未指定项自动设计 |
| 03视觉偏好 | 时间、配色、照明、氛围 |
| 04镜头 | 景别、视角、视野，默认自动设计 |
| 05风格与复杂度 | 表现风格与内容疏密独立；可直接选择精细写实、精细写实电影CG，简约仍可细节丰富 |
| 06构图 | 布局与视觉流向 |
| 07目标模型 | 默认Midjourney，清空或未知目标按通用描述；与右上文本接口独立 |
| 08画幅 | 默认9:16，可修改或自定义 |
| 09数量 | 默认5对，支持1—10对完整中英文，不表示对象数量 |
| 10大致说明 | 可选补充；预填“光线柔和漫射，空间层次分明，阴影清晰可辨，细节丰富。”，可编辑/清空 |

独立负面提示词预填原默认，可修改或清空。设计自由度保留自动/随机、全部包含/选配和是否允许额外辅助对象；这些开关不自动授权人物。

## 地域选择

在01题材下方点击“东方”“西方”或“中国”，三项单选；再次点击已选项取消，清空01会同时清空题材和地域。“东方”是较宽泛的文化视觉方向，“中国”明确为中国文化语境，“西方”不自动指定某个国家。可在大致说明补充时代、地区或作用范围。

地域与题材独立保存，不把选择改写进题材名；每方案双语落实同一地域。默认不选，未选不强加地域；不会因地域自动添加人物、地标或改写锁定媒介/配色。选择与题材或说明发生硬冲突时需澄清。

地域进入当前输入、草稿、预设、生成结果、备份和Markdown/ZIP下载；既有V12历史缺失字段时不追补。此次接入完整规范V9并记录SHA，V9中“V12尚未接入”的文字是该文档发布时的历史状态。功能已接入不代表真实模型的地域效果已验证。请停止原服务并重新启动，单独刷新页面不足以加载新后端。见[地域维护记录](维护记录/2026-10-22-题材面板地域选择.md)。

## 自动与手动

超自然现象入口：在01“自然与异境”选择“超自然现象”，02可搜索狂风暴雨、大浪、电闪雷鸣、龙卷风等36个元素，按风暴与降水、海浪与水体、雷电与天象、旋风与气流、环境与空间、幻想异常六类组织。03新增风暴灰蓝、闪电照明、云隙光、压迫感、狂暴、诡谲，可按需选择。幻想异常和其他候选只有选中才进入本次要求，不默认叠加全部现象或人物。库内另有12个场景名称，V12不单独展示场景选择面板。本次候选库更新刷新页面即可加载。见[维护记录](维护记录/2026-10-22-新增超自然现象.md)。

赛博朋克人物入口：选择01“赛博朋克”，在02元素中打开“人物与身份”。该分类默认靠前，共39个候选，包含义体改造人、仿生人、网络黑客、街头佣兵、企业高管、义体医生和底层居民等。可直接搜索名称，或在分类中筛选；选中后设置主体/辅助、数量及动作等属性，未选候选不会加入画面。详见[人物与身份维护记录](维护记录/2026-10-21-赛博朋克人物与身份.md)。

人物性别：在02中选中人物后，展开“性别、角色、动作与空间”，可分别设置自动、男性、女性、非二元、不强调性别或自定义。例如网络黑客选择女性、义体医生选择男性。“自动”允许补齐未指定项；“不强调性别”要求中性描述。自定义“一男一女”需与该元素的对象数量一致。已选人物身份与性别共同进入每条双语要求；内置非人物元素不显示性别控件，自定义元素的入口仅适用于人物。属性随当前输入、预设、历史、备份和下载保存，既有V12记录未填写性别的保持缺省。详见[性别属性维护记录](维护记录/2026-10-21-人物性别属性.md)。本次更新包含后端校验，需先停止原工作台服务，再双击启动器重新打开。

自动设计根据实际选择补齐适合对象的动作、相互位置、空间纵深、承托/悬浮、服饰归属和动势，并写入每条最终双语提示词。不会把参考画面的白鹿同行固定成所有题材的故事。真实的硬冲突会要求澄清，普通空项直接设计。

手动控制在02元素展开设置里，全部默认自动。如仙女选择动作“缓步”、关系“沿着”、关系对象“星沙云脊”；白鹿可选择“并行”，关系对象“仙女”。每个元素可锁定一组对外关系，其余关系由模型补齐。对象下拉只含已选的其他元素；删除目标会清除指向它的绑定并将关系恢复自动，其余属性保留。

## 星河巨鹿参考的点选方式（仅本例）

题材云上天宫；元素白鹿、仙女、星河、星沙云脊。白鹿选主体、巨大，仙女选辅助、常规、全身高度约占画面3%。时间日出，配色朱砂红为主/墨黑为辅/米白留白，照明柔和漫射光，氛围神秘；镜头超远景、侧面高位俯视；风格精细写实电影CG，复杂度简约；构图对角线，画幅9:16。动作和空间全部保留自动，大致说明不需追加文字。

希望固定服装时可再选竹青斗篷、交领仙袍、拖地长裙、云髻、素玉簪、披帛、丝带，以及星枝鹿角；模型组织附属关系。希望固定方向时可给星河选“左上至右下”，云脊选“下部”。选项表达创作要求，尚未实际出图验证相似程度。

## 当前数据格式

V12只支持schemaVersion=3与scene-forge-backup-v3，独立创作存储scene-forge-workspace-v12；不读取、迁移或导入旧草稿、旧预设、旧历史及旧备份，旧请求明确拒绝。旧版本和原浏览器创作记录保留，未删除。API Key继续使用独立存储功能，未放入创作备份。

动作空间属性和可选地域字段随当前预览、请求、预设、历史、备份及Markdown/ZIP下载保存。清空10只清空补充说明并恢复默认设计自由度；02的手动属性保留。重置条件恢复所有默认值。

## 结果中的工作台输入

右侧提示词上方直接展示“本次工作台输入”方框，包括十个面板、负面提示词、元素属性及设计自由度；长内容可在框内滚动。这里展示生成时保存的条件，后续修改表单不会改变已有结果。

汇总Markdown和ZIP内每个独立方案，都在提示词前保留相同输入文本框。复制提示词按钮和点击方案标题仍只复制提示词。见[维护记录](维护记录/2026-10-20-结果顶部输入方框与下载.md)。

## 下载文件命名

提示词汇总文件、单独下载ZIP及包内文件统一采用“题材名_目标模型_画幅_年月日时分秒”。例如`云上天宫_Midjourney_9x16_20261020223045.md`；ZIP内各方案末尾加`_01`、`_02`等序号。时间使用下载时的北京时间；名称取生成结果保存的条件，不受后来修改表单影响。画幅冒号改为x以兼容文件系统，特殊字符会清理。详见[维护记录](维护记录/2026-10-20-提示词下载文件命名.md)。
