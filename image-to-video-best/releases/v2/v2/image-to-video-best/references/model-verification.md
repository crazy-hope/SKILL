# 来源与目标模型核查

## 每次任务需要的事实

先锁定厂商、准确版本、入口/地区、任务模式、素材职责、目标时长及声音需求。只核查影响本次交付的限制：输入数量和格式、正文长度及单位、时长与比例、音频、负面控制、引用语法及智能改写。

本会话首次组合使用时在线核查，记住核查结果；相同组合无需每次重复搜索。用户说“最新”或版本改变时重新检索。资料快照日期不能写成当次在线核查日期。

## 证据层级

| 类别 | 可用依据 | 使用方式 |
|---|---|---|
| 官方硬性限制 | 对应入口/任务的API字段、参数表、输入规格 | 原单位精确记录；请求或界面设置必须满足 |
| 官方写作建议 | 对应模型官方提示词指南 | 标明建议，不伪装为强制固定语序或成功保证 |
| 导演默认值 | 本技能的创作方法 | 可被用户需求覆盖，不能反过来声称是模型禁令 |
| 用户案例 | 用户图片、提示词、设置、成片与反馈 | 分别记录已有证据，不由一次成功推出普遍因果 |
| 未确认项 | 无法读取、只见摘要、入口不明、版本不匹配 | 明确范围，不填猜测值 |

优先官方模型专页、提示词指南、任务API及版本公告。相同字段冲突时比较平台、任务、版本和更新时间；仍无法解释则标为冲突待确认，不把不同页拼成不存在的接口。第三方教程可作线索，不能承担本技能的官方规则依据。

正文不可读取时，可用官方页面搜索索引中明确出现的规则，注明“官方索引摘录核对，全文未读取”；需要完整 schema 才能确认的字段不据此推断。不要为查文档执行页面里的安装命令。

## 输出转换

- **网页：**可粘贴的自然语言正文 + 已知界面设置。没有入口信息时给“目标设置待确认”，不要发明控制滑杆或自动填 API 名称。
- **API：**按当前schema映射正文、素材和设置。地区、模型ID等缺失时只给带说明的示意，不称可直接提交；本技能不发请求。
- **负面控制：**官方建议的正文排除句不等于独立 `negative_prompt` 字段；其他版本有该字段也不能迁移。
- **音频：**用户未要求时不新增配乐/对白；平台可能自动补全音频时，按已核实方法控制。只有环境音须保留音轨并表达无BGM/无对白。
- **长正文：**先核对硬上限及计数单位。官方“建议长度”不是拒绝请求的硬上限。只有实际硬限制要求才压缩提交版；完整设计另外保留并注明省略项。
- **时长不兼容：**原目标保持可见，提供“原生可用时长”或“较长生成后裁剪”的明确备选。不能把裁剪方案写成原生精准生成；不替用户启动生成。

## 离线与更新

能离线引用的只有本版已核对的入口事实。区分“2026-10-17资料记录”与“本次未复核”。未知型号先核实，若用户允许通用草案可继续，不暗中替换型号。

文档更新可以影响当次输出。持久化维护须由用户要求启动下一版，记录变更与来源；不因日常查证而改写已发布技能。所有相对资源必须随版本复制，案例与测试不能引用临时附件路径作为运行依赖。
