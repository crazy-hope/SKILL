# 显示每个方案实际采用的设计

日期：2026-10-26；基线：当前工作台 V13 / 完整规范 V10；状态：已完成并交付。事前记录，按应用小维护执行。

## 需求与设计

用户要求：即使输入为自动设计或未指定，右侧也显示最终实际使用的元素，元素可以来自候选库或由模型自行设计。

- R-01：右侧顶部显示“本方案实际设计”，按当前方案列出题材、地域、元素、视觉偏好、镜头、风格与复杂度、构图。元素包括具体对象及必要数量、角色和关系；显示模型最终采用的内容，不能将输入中的自动值冒充结果。
- R-02：生成模型随双语正文返回独立 `design` 对象，七个中文键对应上述维度，值为非空中文说明；每项最多 3000 字。库外元素可用，但已锁定条件、额外对象开关及未启用人物限制继续有效。地域无约束时说明画面实际特征或不限定地域，不随机指定地区。不可应用项解释原因。
- R-03：原始输入放入折叠区保留，切换方案同步更新实际设计，复制仍只复制对应提示词；不回填或改写草稿。
- R-04：历史、备份、MD 和逐份 ZIP 保存实际设计；旧历史缺少该字段时显示“未记录”，不通过候选库匹配或当前输入补造。字段采用白名单保存。
- R-05：同步生产 dist、维护说明及索引；不改规范正文或历史版本，不安装依赖、不提交。

实现选择：让同一次生成返回结构化实际设计，可与该方案双语正文一起保存。仅重复输入无法满足需求；前端按候选名扫描正文会遗漏库外对象、误识别否定词，故不采用。模型被要求逐项核对摘要与双语正文，结构校验不能替代真实模型语义验收。
