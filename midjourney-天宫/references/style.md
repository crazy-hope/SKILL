# 风格

## 根风格

所有模式共享：原创东方天界、电影级写实环境 CG、高端影视概念设计、超现实空间、真实建筑厚度、清楚大轮廓、深景深、克制材质反光。画面张力来自尺度断层和空间，不来自战斗、霓虹或特效堆叠。

## 风格模式

| 模式 | 视觉取向 | 使用条件 |
|---|---|---|
| 天界电影 CG（默认） | 写实材质、宏大电影构图、清楚结构、庄严静谧 | 用户未指定 |
| 空明神域 | 更大的天空与云域、更少装饰、更柔和的空气透视 | 用户强调空灵、禅意、寂静 |
| 东方超现实奇观 | 悬空、倒悬、云上延伸与不可能体量更强，结构仍连续 | 用户强调超现实、梦境或神迹 |
| 肃穆巨构史诗 | 更重的深檐、宫基、岩壁与阴影，仍保留可读暗部 | 用户明确要求冷峻、暗色、沉重阴影或低明度 |
| 极简神域 | 一座主巨构、一个天域载体和一个尺度锚点形成大块面与清晰轮廓；以强明暗或冷暖分区建立对比，细节只集中在主体 | 用户要求干净、简约、少元素、强烈对比 |

单张只选一个主模式；批量任务默认整批锁定同一模式。不要把“电影 CG”写成廉价游戏截图、塑料 3D 模型或旅游明信片。

“巨构压迫感”是所有模式都能实现的尺度目标，不构成选择“肃穆巨构史诗”或暗色光线的充分条件。用户同时要求压迫尺度与空明天域而未指定风格时，仍使用“天界电影 CG”默认。

选择“极简神域”时，不自动抽取附加奇观或装饰物，只保留一个主视觉主体、天域载体和至多一个尺度锚点。主主体可以是建筑、非建筑巨构、地形、自然奇观或自定义元素；人物仅在用户选择时出现。用户明确选择的 `F4` 元素仍全部保留，但必须指定一个主元素，其余退到中远景或简化为低细节剪影。强对比来自两三个大面积明度或色温区块，不来自高饱和、多色灯光、密集纹样或全画面锐化。

## 永久造型语法

- 主体必须形成一个连续、可读且具有超画框尺度的主视觉系统。选择建筑时，它是一座可进入的连续建筑工程带；选择 `F1-6 无建筑` 时，不得自动补入建筑，由已选天界结构、地形、自然奇观或自定义主体承担同样的连续轮廓与尺度关系。除明确选择无障碍空中镜头外，主体至少一处被画框裁切或以空气透视延伸到画外。
- 细节集中在一侧、顶部或结构转换处；天空、云海、云峡、水庭或深渊作为内容承载空气，常规约占画面 `40%–60%`。用户明确选择 `C27 极端留白构图` 时改为 `80%–95%`。
- 用构件重复、纹理尺度、遮挡、空气透视、可选人物和远近尺度跳跃证明体量，不用“宏伟、史诗、8K”代替可见关系。选择无人物时，不得为证明尺度自动补入人物。
- 材质以木构、瓦、石、暗铜、旧金和水汽为主。金色只作窄边、擦光或局部反射，不把整座建筑变成亮金。

## 常见偏移

| 偏移 | 修正 |
|---|---|
| 许多独立小宫殿均匀铺满 | 合并成一个连续巨构，并释放一大片天域 |
| 完整宫殿居中展示 | 让近景构件出画，以遮挡和裁切制造超画框尺度 |
| 全局高饱和、全局金色 | 冷色环境占大面积，暖色只落在受光结构 |
| 西方城堡、哥特尖塔、科幻都市 | 回到中国木构檐柱、斗拱、宫基、桥廊与瓦屋面 |
| 人物英雄海报 | 常规构图缩到尺度标记；`C18 肩后构图` 只保留一角可辨认肩背，仍不展示正脸特写 |
