# 仙界大境原典路线

先应用[仙侠共享总则](xianxia-master-rules.md)。`仙界大境原典`是封闭、独立的创作路线：继承尺度、五层空间、内容承载空气、建筑、无栏杆、人物与衣装总则，再增加更严格的低位云海、远景锚点、运动和暖柔光线控制。它不是九图系列模式，也绝不强制`9:16`。

## 路线权限

- 只有用户明确说`仙界大境原典`、`仙界总则`、`仙界原典`或要求遵循所给原典时才选择。
- 先应用共享总则，再应用本文件；跳过普通场景、视觉风格、镜头意图、密度、配色和氛围默认值，不得暗中混入`单体仙境`、`神域聚居地`、`华彩通透仙侠`或`东方苍穹巨构`。
- 画幅参考只用于调整阅读方向；通用构图库只用于不冲突的技术执行。
- 用户新增内容只有在不破坏硬性不变量时才可扩展路线；冲突时必须点明。

## 世界承诺

阅读顺序：

`第一：不可测量的天界建筑 -> 第二：完整的远方仙界 -> 第三：微小背影仙人 -> 第四：继续通向不可见天域的道路`

气质：`空而不寂，满而不塞，巨而不乱，动而不躁，华丽而克制，通透而安静`。

## 硬性尺度

- 主柱直径约五至十个成年人高度，完整高度约四十至八十个成年人。
- 巨型开口、玉屏、门或结构孔洞约二十至五十个成年人高度。
- 主檐跨越数百个身体宽并继续出画。
- 台阶踏步与桥面符合人物使用，但整座阶、桥、廊、屋脊或平台要跨云并延伸到似乎无穷的远方。
- 每份提示词至少四项可见证据：出画巨型局部；成人与柱、门、屏或台基比较；重复构件向深处收束；人物周围十至三十个身长空地；上下分离宫殿；跨云结构；近远两组巨物；或极远巨构局部。

不得只写“宏大”或“史诗”。

## 固定五层与空气

1. 近景巨型框架：柱、檐、屏、松干、崖或门边。
2. 宽阔人物承载面：平台、阶、廊、镜面地面、浅水地面或开放边缘。
3. 一个统领天界巨构。
4. 一至三组较轻远宫、桥台或建筑碎片。
5. 终端天域：巨月、低位天光、天河、星河、低位云海或无边晴空。

保留约40–60%分层天界空气，以明暗变化和远方剪影承载内容。实体与空气交错，让天空进入门洞、柱阵、屏风、长廊与檐下。近景重、锐、暗、细，远景亮、软、低反差但不灰。

## 低位云海与局部薄雾

- 主云海低于建筑平台，其顶部低于人物脚下和平台边。
- 主要占画面底部20–35%，呈圆润、厚重、成团积云与稳定低地平线。
- 人、平台、台基、柱、廊、屏、檐和屋顶完全位于主云层之上。
- 上部天空与人物周围空气清澈透明。
- 仙雾只可薄、透明、近无色，位于宫基下、瀑布旁或少数远近层之间；不得用雾包裹全城。

## 受控天界内容

每张图恰好包含：

- 一个统领巨构；
- 一个远方天域锚点；
- 一个主要动态现象或安静生命迹象；
- 一个近景尺度参照；
- 一名或少量仙人。

只选一至两个兼容远景关系，不能列成目录：远方巨殿局部、极长天桥、沿云边后退的宫室、发光门影、透明瀑布、弧墙、天河、月前一鹤或分离浮台。

只使用一个主要运动系统：云瀑、透明水瀑、天河、浅水涟漪、受风旗纱、一只鹤、高空水渠或台下薄云流。运动缓慢、宽广、符合重力且从属于建筑静止感；移动镜头不授权加速，视差与世界速度相互独立。

## 可选模块

- **巨月**：可选而非必选。真实月海、陨坑和明暗界线，占画宽约25–50%，低位、偏心、部分裁切或被建筑分割。
- **古松**：可选且绝不自动。树干直径约一至三人高，树冠跨二十至四十个身体宽；出画树干或长枝用于框景。
- **地面**：只选一种一致类型：薄透明水膜、无边镜面平台、浅浮雕白石阶、抛光悬台、末端形成瀑布的弯曲浅水渠，或宽阔空玉面。

## 天界建筑

使用中国空间秩序但不复原朝代；重组长檐、巨柱、月洞、巨石屏、长廊、天阶、层屋、云台和悬门。建筑巨大、简洁、安静且承重清楚，大块连续材质面与少量组织线负责重量。装饰只集中一个区域，大型浅浮雕可取自云流、水脉、星轨、月晕、风痕或天弧。优先厚重浅石、珍珠灰石、屋顶或承重上部克制朱红/赭木、窄淡金脊线和局部矿物色。除非明确覆盖，地面、桥、台、阶及建筑一律无栏杆。

## 仙人与衣装

- 默认一名虚构成年人或极小群体，完整背面、30–60度斜后方、侧后方行走或越肩背面。
- 人物通常1–4%；看清全身用5–8%；只有明确要求服装主导时用12–20%，同时保留出画建筑和远方天域。
- 动作平静：慢走、远望、静立开放台边、登阶、入弧廊、双手放松或轻拢衣袖。
- 默认禁止快走、奔跑、冲刺和匆忙动作；视频使用固定或缓慢稳定镜头，绝不让镜头推进加速人物、云海、水、布料或其他世界运动。
- 身体与头部稳定，全部布料响应一个高空风向；遵循`衣有骨、纱有气、饰有止、色有主`。

## 光线、色彩与真实感

使用宽广、柔和、透明的高空漫射光。低位太阳在地平线附近或画外，只提供轻柔方向、暖黄温度和极薄轮廓光。天空作为巨型柔光源照亮石、玉、木、瓦、水、衣、松、月和云海；亮部暖而细，阴影明亮开放透明。整体可有暖色晚照感，但禁止统一橙色滤镜，保留浅石、珍珠灰、朱红/赭木、淡金、晴空和衣装强调色的材质差异。采用大型建筑摄影和实景电影布景的真实感：石材重量、暖玉半透明、木瓦构造、树皮、水面张力、连续水云流、积云体积、布料重力与半透明、真实月面和可信人体。

## 画幅适配

- 16:9和21:9横向延伸檐、廊、云边和远景锚点；4:3和3:2平衡主构、宽平台与终端远景；4:5和9:16垂直堆叠五层，并用阶、柱、瀑、月弧或高开口维持上升路径。
- 9:16绝不自动推断系列、拼贴或多图。每个请求默认一份提示词。
- 默认低机位或人眼高度；只有明确要求才用高角度或航拍，不能为展示更多建筑而自动选择。

## 提示词装配与审计

顺序：

`画幅 -> 机位高度、距离、俯仰角、焦距 -> 统领结构 -> 四项以上尺度证据 -> 五层空间 -> 40–60%空气 -> 一个远景锚点 -> 低位云海 -> 一个主要动态 -> 无栏杆建筑与地面 -> 仙人与衣装 -> 宽广暖柔光 -> 物理材质 -> 不变量与排除项`

输出前确认：

- 是否明确标注`仙界大境原典`并保持独立？
- 是否保留用户画幅，且没有九图假设？
- 是否有四项尺度证据、五层空间和40–60%分层空气？
- 主云海是否低于平台并主要位于底部20–35%？
- 远宫是否有限、更亮、更软且不呈城市密度？
- 是否恰好一个主构、一个远锚点和一个主要动态或生命迹象？
- 人物和主要动态是否缓慢稳定，镜头不改变其世界速度？
- 是否完全无栏杆，且人物比例、背面角度、衣装和风向明确？
- 光线是否宽广、暖柔、透明而非硬、灰或全局橙？
- 材质与透视是否物理可信？

任一为“否”都先修正。不得替换成普通宫殿城、屋顶海、孤亭、灰雾全景、硬金逆光、过度装饰历史宫殿或自动苍穹巨构压迫构图。
