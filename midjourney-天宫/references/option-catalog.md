# 完整问卷选项

问卷必须显示当前缺失子项的全部固定选项。编号是稳定接口，不因推荐项、构图兼容性或显示顺序改变；推荐项用视觉标记突出，不重编号。不兼容项仍显示，并标注适用条件。每个单选组额外接受“随机”；`F4` 为多选组。

## C 构图

选择一个主构图；辅助构图可选 `C辅0 无` 或以下任一兼容类型。旧有常用组合的编号保持不变。

| 编号 | 主构图及默认辅助关系 |
|---|---|
| C1 | 留白主构图 + 三分辅助（默认） |
| C2 | 框景主构图 + 三分辅助 |
| C3 | 对称主构图 + 中心辅助 |
| C4 | 对角线主构图 + 引导线辅助 |
| C5 | 中心主构图 + 对称辅助 |
| C6 | 三分主构图 + 留白辅助 |
| C7 | 三角主构图 + 留白辅助 |
| C8 | S 形主构图 + 引导线辅助 |
| C9 | 引导线主构图 + 三分辅助 |
| C10 | 偏心主构图 + 留白辅助 |
| C11 | 重复主构图 + 引导线辅助 |
| C12 | 放射主构图 + 中心辅助 |

若用户另选辅助构图，使用 `C辅1` 至 `C辅12` 对应以上十二种主构图名称；`C辅0` 表示不使用辅助构图。自定义辅助构图覆盖表中的默认辅助关系。
