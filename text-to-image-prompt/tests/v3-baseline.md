# v3 修改前证据

日期：2026-10-31。对象：已发布 v2。

用户提供的试用截图显示：风格、画幅、版本、Personalize 四项在同一条消息询问，并建议一行回复四项。v2 文本明确允许“可在一轮消息中分四项清楚列出”；其已有流程测试也将这种行为判作通过。

本轮独立基线测试：

- 输入“今天没灵感”，实际输出“先选这轮的四项设置”，随后同条消息列出风格、画幅、版本与 Personalize。
- 独立输入“电影实拍，16:9，版本沿用界面，Personalize关闭，帮我设计五个有创意的场景”，实际直接给五个场景，没有询问文化背景或现实性。
- 第二项输出包含“裁缝用夹具固定一小块坠落的月亮”和“洗衣店老板用长夹子固定一片低垂的云”。这体现了 v2 允许摄影媒介下的非现实内容；它不是实际生成图像的观察。

根因：设置询问可合并；缺少文化背景字段；风格和现实性没有独立确认，且原规则主动允许奇幻。v3 应改变选择流程及创意约束，不能仅添加“写实”关键词。

此记录不是 Midjourney 生图测试；人物塑料感等实际视觉问题仍需在生成结果中检验。
