# 工作台 V4 设计

按用户已确认的内置内容库扩充方案执行，维护现有九项输入及八卡片布局。题材、场景和元素放在独立 catalog.mjs，规范文件继续读取原 V5。

题材按六组展示，每项提供具体场景及按通用类别组织的元素。旧题材名称通过别名解析，旧候选在新库中保留，存储值和历史不强行改写。

下拉面板新增搜索框和分类选择：搜索名称、所属题材和类别；搜索与筛选不会改变选中值。场景中的人物、载具、交通或建筑等线索使相关元素类别优先展示，全部类别仍可访问，不代替用户选项。

结果与请求只含用户实际选择及自定义内容，不提交整库，不额外调用文本接口。关键验证覆盖筛选后多选、输入焦点、已选项保持、旧题材联动和规范不变。
