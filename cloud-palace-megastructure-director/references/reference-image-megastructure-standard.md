# 参考图巨构标准

使用本标准把参考图转译为原创云宫场景。本标准记录几何关系、结构、材质表现、光线和氛围；绝不授权复制完整源画面、专有设计、人物、文字、印章或水印。

## 参考图角色契约

编写提示词前，标注每张图的角色：

- **编辑目标**：仅在用户明确要求修改该图时使用。
- **构图参考**：提取裁切压迫感、地平线、纵深路径、负空间和尺度层级。
- **建筑/材质参考**：提取承重路径、屋檐深度、斗拱密度、石材、漆面、铜和鎏金表现。
- **氛围/光线参考**：提取云层高度、薄雾落位、冷暖分离和光线方向。
- **仅作排除参考**：记录不需要的UI、边框、栏杆、文字、印章、水印或生成瑕疵。

未要求编辑时，所有来源默认都是非编辑参考。明确说明哪些特征可以迁移，以及哪些源图特有布局、人物和纹样不得迁移。

## 可迁移视觉标准

1. **裁切体量的压迫感**：屋顶、柱、天障、平台或宫基下构约占画面50–80%，并延伸出一个或多个画框边缘。结构性天环例外：以远景完整收入圆周，用支撑跨度、人物和空间层级表现宏大。
2. **空间层级**：从近景巨型框景、尺度参照承载阈境、主导事件、从属天域、终端远景中至少连续显示三层；标准外部巨构优先四到五层。
3. **内容承载空气**：外部开放场景可通过开口、宫基下方虚空、云隙、庭地、水面和极远景参考保留约40–60%；内部、垂直或极简构图按视觉承诺调整。
4. **尺度断层**：按统一尺度参考组织人物与场景关系，默认35–50mm；人物大小服从承载面、相邻构件与透视，不设固定画高。至少三项证据沿同一空间传递，无人时使用明确替代参照。
5. **结构密集，体量安静**：深斗拱和木作节点出现在檐下、梁柱转换处、天障边缘或基座。宽阔墙面、玉石、屋顶和平台平面保持安静。
6. **大气分层**：近暖远冷是可选光照方案，不是透视硬规则；冷暖与明暗按主光和环境安排，远景通常降低细节与反差。
7. **自然对形有主次**：古松、瀑布、悬崖、云河、雪线、雨幕或风暴云可以单独或少量组合，只要不形成多个同等焦点。
8. **仙女尺度尺**：启用人物且未指定性别时，默认使用成年中国仙侠仙女或女仙；只有用户明确指定男性，或男性人物图像是明确编辑目标时，才使用男性。人物全身角度遵循尺度参考的朝向优先级：侧面、背影为主，正面低频，明确用户朝向优先；人物朝向与相机相对主构的方位分别锁定。默认保持`35–50mm`真实中距离与真实空间接触；结构性天环、明确极远人物要求或完整超远跨度可改用远景。任何镜头都不得后贴人物或破坏透视、光照、投影、遮挡和大气层级。仅作构图、建筑、材质或氛围参考的图像不得覆盖默认人物身份。
9. **可读光照**：默认池及用户指定扩展均采用建筑与材质参考的统一规则，不另设默认值。
10. **连续尺度链**：使用`人物或其他已知尺度参照 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`，把主导巨构替换为本图实际结构；至少连续显示三级，标准巨构优先四到五级。

## 结构事件库

结构事件可以为`无`。只有用户点名，或当前构图路线本身要求时，才选择下列一个事件作为视觉命题；不得把未选事件作为从属奇观附加到画面。

### 半幅巨柱

- 一根被裁切的柱，或一对局部柱，约占画面三分之一到一半。
- 展示可信的柱础、柱身、斗拱转换，以及它所支撑的屋顶或天障。
- 优先使用远距低机位或人眼高度24–50mm；控制垂直线。
- 不要把柱做成独立装饰雕塑。

### 结构性天环

- 把天环当作融入柱、宫基、屋顶桁架或露台的建筑跨度，而不是漂浮科幻圆环或普通月洞门。
- 使用远景或超远景机位，把完整圆周连同呼吸空间收入画面；禁止近景特写、画框裁断、半环或四分之一弧。
- 暴露分段接缝、厚度、至少两处支撑点和有人活动的阈境。纤细桥线或薄云可以轻微穿越环体，但缩略图下仍必须一眼读出闭合圆形。
- 让环内开口揭示从属天域与终端远景，而不是平面背景。
- 用数百个身体宽的直径、人物与相邻参照、从属宫阙、跨云层支撑与大气透视共同证明尺度，不用贴近镜头制造虚假巨大感。

### 悬空镂空天障

- 所有开口只能属于边缘规整的圆形或方形一种家族，不使用随意不规则负形，也不在同一面天障混用形状。
- 根据天障宽高比`W:H`选型：`0.85 <= W:H <= 1.15`时可使用方形，其余比例使用圆形；方形边线与天障或建筑的水平轴、垂直轴平行，禁止旋转成菱形。
- 只设一个主开口；如需从属开口，它们必须同形、规整、显著更小并服从主开口的结构节奏。
- 赋予天障可见厚度、基座或悬挂点，以及清楚的承重路径。
- 至少保留一个通向深远云域的主要开口；不要用细密镂花填满所有虚空。

### 悬空宫基

- 让厚重宫基或深檐底部替代一部分上方天空。
- 展示层叠梁架、斗拱、结构肋、悬挂庭地或竖向支撑，同时保持底部阴影通透。
- 低位太阳可以掠过宫基边缘下方，在冷色云层前形成一道单一暖光缝。

### 无尽深檐、柱廊或长廊

- 让深檐、柱、天障或院落沿一个稳定消失系统重复。
- 构件间距和大气反差必须随距离一致变化。
- 长廊应有数百个身体宽，并延伸至视线不可达处；避免普通人类尺度的走廊比例。

## 六类宫殿材质家族

每幅场景选择一个主导家族，也可搭配一个相容的从属家族。使用材质反应与清楚主次，而不是全局色彩罩染。

1. **纯白**：接近中性的白玉、象牙石材和珍珠灰阴影；金属强调限制在0–4%。
2. **朱红**：矿物朱漆、暗红棕木材、稳定画面的云白和冷蓝灰阴影；只保留窄小古金边缘。
3. **古金**：低纯度陈金、洁净深色铜、深青绿石材和月白建筑；亮金只落在轻微磨亮凸脊，不出现锈斑或腐蚀。
4. **红金**：深朱红结构木材配合古金斗拱或屋顶边缘；云、天空和石材保持中性，避免整幅画面变成橙色主题乐园。
5. **白金**：月白玉石和浅色石材占主导；珍珠金或古金只用于结构接缝、天障边缘和擦光高光。
6. **传统矿物彩画**：朱红结构面、石青/石绿/群青承重彩画带、赭色或老黄屋顶强调、象牙白或灰色石材稳定面，以及窄旧金。阅读[传统建筑彩画配色](traditional-polychrome-palettes.md)，并锁定一条子路线和一个风化等级。

冷暖与明暗服从实际主光和大气层级；不强制近暖远冷或远景更亮，云层高光和阴影仍须可读。

## 运动与镜头相互独立

静态图默认采用平静动作，但仪式行进、攀登、迎风站立或克制的快速动作可按叙事使用。对于动画或图生视频提示词：

- 人物默认静止或稳定行走，也可按场景进行仪式队列、攀登或短暂加速；
- 避免无动机的奔跑、冲刺、突然跃进和匆忙人群运动；
- 镜头默认为固定机位、慢速恒速推移，或带轻缓起步和收束的克制慢速环绕；
- 禁止快速推镜、猛然变焦、甩镜、延时摄影、变速和加速视差；
- 世界空间运动必须与镜头相互独立：推镜只改变构图和光学视差，绝不改变人物、云、水、瀑布、布料、头发、粒子或建筑的速度；
- 云、水和布料的运动保持缓慢、宽广、符合重力，并服从建筑静止感。

`动感`、`强冲击力`、`电影感`、`能量充沛`或`节奏紧凑`等词不能覆盖上述默认规则。通过尺度揭示、遮挡、光线、构图和受控视差制造冲击力，而不是依靠速度。

## 提示词模块

把以下内容作为可扩展模块，而不是完整提示词：

```text
半幅巨柱：一根被画框截断的巨型白玉承重柱占据约半张画面，柱体直径约八个成年人高度，柱顶与深檐继续伸出画外，柱—斗拱—梁—檐的承重路径清晰，右侧开放云域揭示四重远景。

结构性天环：远景或超远景中，一道完整闭合的结构性天环连同四周呼吸空间全部收入画面，圆周不被画框截断；环体有真实厚度、分段接缝和至少两处连接宫基、柱系或屋顶桁架的承重点，直径横跨数百个身体宽，环内依次显露人物与相邻参照、云桥、从属宫阙与终端天域，以多层尺度对比呈现宏伟而不是近景放大。

悬空镂空天障：一面具有单一明确几何主开口的悬空玉石天障横贯中景；只锁定圆形或方形一种家族，所有从属开口保持同形、规整且明显更小，绝非随意破洞；如用方形，其边线与建筑水平轴、垂直轴平行，不得旋转成菱形；天障厚重而有支撑，雕刻只集中在内缘，主开口约四十个成年人高度，远景穿过开口继续延伸。

悬空宫基：被裁切的红金宫殿底部压住上半画面，层叠斗拱和梁架如倒悬山脉，低位太阳从宫基边缘下方掠过，暖金边光与冷蓝云海明确分离。

无尽深檐长廊：纵深极长的白金长廊沿单一消失点延伸至不可见主殿，数十组巨柱与深檐规律缩小；启用仙女时使用`35–50mm`真实中距离，人物大小由近旁通行细节、柱础、主柱与深檐的连续尺度关系决定，不预设画高；栏杆可局部出现，但不横贯长廊、封死开放云域或遮挡尺度关系。
```

## 系列多样性契约

多图请求中，每张图至少改变三个模块：

- 主导路线、场景拓扑或结构事件；
- 机位家族、相机相对主构方位、距离、裁切和地平线；
- 六类宫殿材质家族之一；
- 默认从统一的五种光照中选择；月光、阴天和雨雪等扩展只在用户明确指定时使用；
- 优先侧面、背影的人物身体朝向，以及站立、慢走或仰望动作；正面按尺度参考低频使用，不为多样性凑齐朝向；
- 可选且具有主次的松树、瀑布、悬崖、云河、雪线、雨幕或风暴云。

用户要求不同场景时，避免无意识重复同一个居中天环、人物排列、松树剪影、场景拓扑、机位家族或配色配方。连续叙事允许有意重复空间与机位。每张图至少保留三层连续空间和三项尺度证据；人物、开放空气与无栏杆边缘不再是每幅硬性必选项。

随机多图且用户要求不同场景时，从10条主导路线不放回抽取，再从兼容表选择拓扑、机位与尺度参照。连续叙事可以重复路线。只有选中对应事件的提示词才可提及天环或天障。

## 污染与模仿排除

始终排除手机外框、黑边、底部指示条、灵动岛形状、播放控件、字幕、Logo、印章、签名和水印。排除参考图中横贯画面或遮挡尺度关系的栏杆，以及克隆屋顶模块、扭曲柱体、不可能的支撑、重复人物和形似UI的开口；局部栏杆可以原创重构。不要复制源图的精确圆环、树木剪影、宫殿布局、人物位置、日落位置或专有装饰。

## 参考图驱动审计

逐项检查适用项，不适用项跳过；不为通过审计增加未选择的结构。生图前做文本检查，实际生成后再做视觉检查。

- 用户未指定画幅时，是否锁定`16:9`；用户明确指定其他比例时，是否才覆盖默认值？
- 是否明确标注参考图角色，并默认采用非编辑参考？
- 迁移的视觉基因是否表述为几何、结构、材质、光线或氛围，而不是复制源画面？
- 结构事件是否与当前构图路线匹配，或已明确锁定为`无`？若存在结构事件，是否具有可信承重路径？
- 深斗拱与装饰是否局部集中，同时巨大平面保持安静？
- 是否由一个宫殿材质家族主导，且没有全局色彩罩染？
- 如果选择传统矿物彩画，是否明确颜料落位、子路线、面积预算和风化等级？
- 冷暖、明暗与近远层级是否符合所选光照，而非机械套用近暖远冷？
- 是否至少连续显示三层空间和三项尺度证据？外部开放场景是否把40–60%内容承载空气仅作为参考，而非机械配额？
- 人物大小是否由承载面、相邻参照与透视形成，而非套用默认百分比或档位？无人时是否明确替代参照？
- 启用人物且未指定性别时，是否使用成年仙女？男性是否只来自明确男性指令或男性人物编辑目标，而没有从普通参考图中误继承？
- 若为结构性天环，完整圆周是否全部收入画面、远离镜头且缩略图下一眼可辨，并由支撑跨度、人物和多层远景证明宏伟？
- 若为悬空镂空天障，是否按宽高比只使用圆形或正向方形一种家族，所有从属开口是否同形且规整，并且没有菱形、旋转方形或随意不规则缺口？
- 金属与建筑是否洁净、完整、有人维护，没有锈斑、锈水、腐蚀和废墟感？
- 是否锁定明确的光照与天气逻辑，并保留结构纹理、阴影层次和可读高光？
- 是否按统一尺度参考选择焦段、人物落位和相容距离，人物是否真实接触承载面？不同标高和方向是否服从同一相机投影系统，且机位不由人物朝向决定？
- 是否从人物或替代尺度参照起连续显示至少三级尺度链，已把“当前主导巨构”替换为本图实际结构，并且相邻比例关系准确？
- 人物动作是否服务于尺度与叙事，没有用无动机奔跑或运动模糊抢走主构？
- 如果镜头运动，是否保持缓慢，且与恒定的世界空间运动相互独立，没有变速或推镜诱发的加速？
- 栏杆若存在，是否保持局部、从属且没有封死开放空间或遮挡尺度关系？所有截图污染是否已排除？
- 系列中的路线、结构、镜头和配色是否真正发生变化？人物是否遵循侧面、背影优先，而非等概率轮换正面？
- 展示巨殿内部时，是否按建筑参考检查宽净跨、深路径、高梁底与空场，而非仅凭近柱裁切或总楼高判断宏大？
