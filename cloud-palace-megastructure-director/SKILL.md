# 云宫巨构视觉导演

本 Skill 有两个风格分支。结构可信分支围绕清楚主次、可见承重与连续尺度链组织东方仙界空间；超现实主义分支忠实保留参考图中密集叠层、极端悬浮、极小人物和多重奇观并置的视觉冲击。先选分支，再解释同一条规则。

## 风格分支

| 分支 | 何时选择 | 核心优先级 |
|---|---|---|
| 结构可信（默认） | 用户强调古建结构、承重、材质真实性、空间可信、连续尺度，或没有表现出超现实偏好 | 清楚主次与空间可信 ＞ 奇观数量 |
| [超现实主义](references/branches/超现实主义.md) | 用户明确说“超现实主义”“原图效果”“奇观优先”，或要求密集机械叠层、无支撑悬空天城、极小人物、黑金/红金/白金与冰蓝云海、多重奇观同框 | 忠实原图视觉效果 ＞ 奇观规模与氛围 ＞ 构图完整 ＞ 结构合理性 |

选择超现实主义后必须完整读取其分支文件。它覆盖共用文件中与以下内容冲突的默认：单一连续轮廓、可见承重、连续尺度链、人物投影预检、结构材质身份、自然锚点数量、模块预算和多奇观取舍。未发生冲突的共用规则继续生效，尤其是用户明确要求、参考图角色区分、版权边界、明显生成错误修正、截图污染排除、图片归档和视频文案确认流程。

只有风格意图不明且两条路线会产生实质不同结果时才询问；参考图和用户用词已明确时直接选择。不得把超现实主义中的悬浮、密集叠层、人物极小或多个奇观本身诊断为缺陷，也不得把结构可信分支偷偷应用于该模式。

## 四层分工

| 层级 | 解决的问题 | 入口 |
|---|---|---|
| 共用规则 | 人物、透视、镜头、尺度链、光照、维护与交付 | 下方条件读取表 |
| 场景库 | 物件在哪里、如何连接、内外和高差如何组织 | [场景总览](references/scenes/场景总览.md) |
| 物件库 | 桥、宫殿、松树等如何成形、细分类、承重、材质与尺度接口 | [物件总览](references/objects/物件总览.md) |
| 构图与调用 | 相机从哪里看、如何随机组合、怎样判断变体真的不同 | [构图路线](references/composition-routes.md) |

“路由”只表示按任务找到该读的文件，不是预设图像模板。先按需求选空间，再选实际物件与观看关系；不要加载整座资料库或把候选列表复制进提示词。

## 规则优先级

当前用户明确要求 → 当前选中的风格分支 → 当前实际选中物件的专属规则 → 未冲突的共用默认 → 场景变体与命名示例。专属规则只处理它负责的参数；例如完整天环影响入画方式，不自动改变人物身份。超现实主义分支的明确覆盖项优先于结构可信分支的物件承重、人物投影和尺度链默认。

- 默认画幅为16:9。结构可信分支启用人物且未指定性别时为成年中国仙侠仙女；超现实主义中的极小人物未指定身份时可用匿名古装仙者或混合群像，不为辨认性别而放大。用户要求无人、男性、女性或特定群像时遵从指定。
- 结构可信分支的默认仙女服饰采用曳地长裙、明显长拖尾与轻纱层次，并读取[服饰与裙摆规则](references/objects/人物与近身参照.md#仙女服饰与长裙摆)。超现实主义极小人物只需完整轮廓、自然落地与适度飘带，不强求远景可辨裙摆细节；用户明确服装时优先遵从。
- 结构可信分支核心规则：禁止随意预设人物占比，但允许并要求根据已锁定的相机参数推导投影；首次生图前完成空间与投影检查。超现实主义按其分支的人物、相机与尺度规则执行。
- 结构可信分支的人物大小由真实体型、姿态、空间落位和相机投影决定；每图按[空间与投影预检](references/scale-and-space-rules.md#首次生图前的空间与投影检查)计算并记录，再用连续尺度链核对空间。超现实主义允许极小人物直接制造尺度断层，不套该计算义务。
- 结构可信分支默认相机为全画幅、实际焦距20–35mm内选定具体值，有人物时相机至主要人物默认60m。传感器画幅、焦距mm、拍摄距离m分别记录；细则见[相机状态](references/scale-and-space-rules.md#相机状态画幅焦距与拍摄距离)。超现实主义只在用户明确指定精确相机时逐项锁定。
- 人物优先侧面、背影；建筑机位与人物身体朝向分别安排，尽量避开人物正前方±45°扇区，具体角度定义及用户例外见尺度规则。
- 结构可信分支在用户未指定材料时，先锁定木构主导、木石混合或石玉主导之一；普通随机云宫优先把木构主导与木石混合纳入候选。超现实主义允许先锁定整体色彩和表面身份，不强制该材料顺序。
- 结构可信分支使用真实古建参考、借鉴古建结构与漆色，或选择古建源型时，按[真实古建转译](references/真实古建转译.md)拆成`真实古建骨架 → 巨构尺度变换 → 仙界空间`。超现实主义只有在用户同时要求古建结构依据时才加载该流程。
- 共用规则只在其归属文件维护，物件和场景不得另设全局默认。普通圆窗、结构天环和镂空天障是不同物件，不按“圆形”混用规则。
- 本 Skill 不把一次诊断当成无限重画授权。仅在用户要求生图时生成；只要求解释、改 Skill 或检查时，不自动生图。
- 图片生成或修订完成后，先验图、归档并展示成图，再询问是否生成图生视频提示词及配套10字标题、20字标题和简介，等待用户明确确认后才生成。未确认时不编写、展示或保存这四部分文案，不把图片交付与文案交付捆绑；确认范围与后续流程见[图生视频提示词生成与交付](references/reference-image-megastructure-standard.md#图生视频提示词生成与交付)。这不授权自动生成视频或把文案叠加到画面。

## 按任务读取

满足条件时完整阅读对应文件；链接只提供导航，未触发的关联模块无需读取。

| 条件 | 必须读取 |
|---|---|
| 明确或推断选择超现实主义、原图效果、奇观优先、密集悬浮天宫 | [超现实主义分支](references/branches/超现实主义.md)，再按该文件的最小必要路由读取其他资料 |
| 结构可信分支下导演、生成、衍生或诊断画面 | [视觉基因](references/reference-derived-visual-dna.md)、[尺度与空间](references/scale-and-space-rules.md)、[建筑材质与光照](references/architecture-and-materials.md) |
| 结构可信分支下创建/改变场景或随机多图 | [构图与调用](references/composition-routes.md)，再读场景总览及实际选中的场景文件 |
| 设计/修改具体物件 | 物件总览及实际涉及的物件文件；单独研究桥型等构造时不必加载场景库 |
| 提供参考图、明确请求已有图片的视频提示词，或成图后确认生成配套文案 | [参考图处理与运动](references/reference-image-megastructure-standard.md) |
| 提供真实古建参考图、要求依据古建结构/漆色创作，或结构可信随机云宫需要选择古建源型 | [真实古建转译](references/真实古建转译.md)；有实际参考图时同时读取参考图处理规则 |
| 青绿、朱青、石青石绿、彩画梁枋、包浆彩绘，或随机结果需要仙古色彩变化 | [传统建筑彩画配色](references/traditional-polychrome-palettes.md) |
| 结构可信分支输出提示词或直接生图 | [提示词契约与审计](references/prompt-contract-and-audit.md) |
| 实际生图、修订图或交付本次生成资产 | [图片集归档](references/archive-and-delivery.md) |

宽大主殿、深殿、多层宫廷与宫船的体量要求在[宫殿](references/objects/宫殿.md)维护；选择这类物件时检查横向体量、主次、檐基重量、净跨与实际楼层。不要把层数正确等同于宫廷有气势。

“单一连续巨构”用于用户要求简洁、建筑不要小而密集、无边体量等情形；按[建筑与材质中的模式规则](references/architecture-and-materials.md#单一连续巨构模式)执行，不把所有随机场景改成同一种露台。

## 导演流程

1. 提取本次明确要求、排除项、参考图角色与工作类型；区分改图、借鉴、诊断和新生图，并先锁定结构可信或超现实主义分支。
2. 选择空间关系。结构可信分支写清承载面、主构位置、连通路径、高差与终景；超现实主义只需写清人物所在近景平台、主奇观方位、悬浮层级、云峡高差与终景，不强行为天城补全现实连通和锚固。
3. 结构可信分支为实际物件选择构造细类，落实可见支撑、厚度、净跨和净高；超现实主义按分支文件保留密集模块、视觉悬浮和不可能体量，只修明显生成破损。
4. 结构可信分支建立至少三级连续尺度链；超现实主义允许用极小人物与巨构直接形成断层式尺度，只要求人物落地、空间关系不出现意外拼贴或畸形。
5. 结构可信分支按尺度文件完成逐项相机锁定与空间投影预检。超现实主义只锁定画幅、镜头观感、人物远近与主体入画意图，除非用户指定精确相机或尺度，否则不以计算、默认60m或连续尺度链阻碍原图效果。
6. 结构可信分支先锁定结构材质身份，再选配色、维护与光线。超现实主义允许先锁定黑金、红金、白金与冰蓝云海等整体视觉身份，不强制木构主导、真实荷载路径或古建材料比例；仍排除非意图性的廉价塑料感、过曝和融化结构。
7. 结构可信随机多图比较空间骨架、物件形态、结构材质身份、色彩身份与观看关系，符合条件的三张及以上普通随机云宫覆盖空旷木构宫廷。超现实主义随机多图优先改变主奇观关系、悬空体量、框景方式、云峡方向和冷暖光位，不强制木构覆盖或降低建筑密度；连续叙事允许有意重复空间与材料。
8. 结构可信分支把预检结果写入第一版提示词；超现实主义按其分支提示词契约明确写出“视觉效果优先”，再写主奇观、密集层叠、极小人物、色彩与适用排除项。两者均在首次生图前完成文本审计并按归档规则建立批次目录；生成后另做视觉检查与文件验证。
9. 纠偏对应当前分支的实际根因。超现实主义不得因缺少支撑、密度高、奇观多或人物极小而返修；只处理缺少指定主体、构图失焦、明显畸形、意外断裂透视和画面污染。剩余偏差如实报告。
10. 先交付成图和图片路径，再询问是否需要图生视频提示词、10字标题、20字标题及简介，并结束本轮等待回复；不在询问的同一轮先生成文案。用户明确不要时不再询问。
11. 用户确认后，仅为确认的图片生成配套文案：按场景独立选择运镜及人物伫立或慢行状态；只有选中行走时才安排步态、方向与短位移，人物动作和5秒时长都不决定镜头必须前推。按[视频流程](references/reference-image-megastructure-standard.md#图生视频提示词生成与交付)编写连续覆盖全片的秒级时间段，再生成、核对标题与简介并逐图归档、展示。用户直接请求已有图片的视频文案时进入本步骤，不重新生图或补造相机数值；明确不要的项目跳过。

## 维护原则

新增物件时扩展其构造专题；新增场景时描述空间组织，不重复人物、光照、尺度或归档默认。已有聚合参考文件保留为导航或共用规则来源，旧路线编号只作兼容检索。修改数值、默认或专属结构要求须有当前用户依据，不能借文件重构暗中改变。
