# 提示词工作台 V14

日期：2026-10-27；状态：2026-10-27 已交付，功能与文档检查通过。基线：[V13](../v13/README.md)，继续使用[完整规范V10](../../../../versions/v10/输出/规范框架v10.md)。

## 打开方式

根目录[启动提示词工作台.command](../../../../启动提示词工作台.command)已指向本版。先停止已有服务，再双击启动器并刷新页面。沿用`http://127.0.0.1:8787`和原浏览器；日常运行仅需Python3.9或以上，生产dist已保存在本版，运行不依赖npm或CDN。

## 元素与人物

全部33题材共2478个题材元素条目，比V13新增1056项（相同名称在不同题材分别计数）。常规分类至少5项，人物与服饰至少8项；超自然保留六个专类并增加可选人物及服饰。未选择候选不进入请求，完整新增清单见[元素扩充清单](验证材料/元素扩充清单.json)。

选择人物后，点击该元素的“设置”打开右侧人物抽屉：

- 人物基本属性：性别、人物数量、年龄段、发型。
- 人物服饰：衣服款式、服装颜色、材质、配饰；当前题材候选优先，多题材合并去重，也可自定义。
- 角色、动作与空间：角色、相对尺度、画面占比、动作、画面位置、前后层次、关系及关系对象。

人数支持1—10人、多人、自动和自定义，与生成方案数量独立。同一人物元素中的多人共用设置；不同造型可分别添加人物元素或自定义“旅人甲”“旅人乙”。未指定属性保持自动；年龄、头发和服饰允许不适用，机器人不强制人类特征。没有选择人物时不自动加入人物，独立衣饰不自动添加穿戴者。

所有可编辑选择框支持点击输入框或右侧箭头展开完整候选，输入时搜索，允许直接自定义、清空和键盘选择；重新打开不被当前值过滤。右上模型配置也沿用此交互；先获取模型列表，再选择或输入自己的模型ID。

## 数据与限制

沿用schemaVersion=3、scene-forge-backup-v3、scene-forge-workspace-v12，以及独立的模型配置和密钥存储。人物设置新增可选age、hairstyle、clothing、clothingColor、clothingMaterial、accessories，每项最多80字；草稿、预设、生成历史、备份和MD/ZIP下载均保留。旧记录缺少这些字段时保持缺失，不追补已使用的设计。V13保留作历史版本，但其代码不会处理V14新增人物字段，日常编辑请使用V14。

仍只接受完整七项实际设计design的结果；无效旧记录不迁移、不删除，损坏创作存储暂停覆盖。API Key不进入备份、历史或导出。已选属性必须在双语中落实，真正的名称/性别/人数/服饰冲突由文本模型返回澄清；功能测试不证明真实模型遵循度。

## 开发与验证

沿用V13锁定的React、Ant Design、Vite与Python服务，不新增依赖。本轮仅复制既有本地依赖用于验证。

在本版输出目录执行：

```sh
npm run test:core
npm test
npm run build
```

在项目根目录执行后端测试与本机模拟服务：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools/prompt-builder/versions/v14/tests -p 'test_*.py'
PYTHONDONTWRITEBYTECODE=1 python3 tools/prompt-builder/versions/v14/tests/mock_server.py
```

模拟服务运行后，在本版输出目录执行`npm run test:e2e`，使用独立Chrome临时上下文与8793端口，不修改日常端口的用户记录。模拟内容用于验证功能，未调用真实OpenAI/DeepSeek生成，未执行实际出图。
