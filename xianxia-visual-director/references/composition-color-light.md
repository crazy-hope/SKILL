# 构图、色彩与光线库

先应用[仙侠共享总则](xianxia-master-rules.md)，再按场景选择必要内容。本库可改变几何、镜头、配色和光线，但不得削弱五层空间、40–60%内容承载空气、尺度证据、无栏杆建筑和仙人衣装语法。

## 空间骨架

- **严格单点透视**：有意放置一个居中或偏心消失点，纵向边线汇聚于此，垂直线平行，重复间距和尺寸规律缩小。
- **居中对称**：适合宫门、宫殿、仪式空间、镜湖和庄严场景；以人物、鸟、飘带或植物加入一个小不对称。
- **对角纵深**：从大型前景引向较小中景锚点，可用桥、阶、屋脊、岸线或光路。
- **蛇形流线**：用弯路、河流、云带、桥或队列逐步揭示空间。
- **框景远眺**：用门、柱、枝、檐、崖或布料边缘揭示明亮远方。
- **纵向上升**：适合4:5和9:16，从下方小主体引向高门、塔、瀑布、树或光口。

`东方苍穹巨构`要从专用参考选择主导空间事件，把框景、遮挡和建筑体量视作一个几何整体，不能再叠加多个竞争骨架。

## 镜头与机位路线

- **宽阔环境揭示，20–28mm等效焦距**：大型近景框架、深引导线和远方地标；控制垂直线，禁止鱼眼。
- **均衡电影剧照，35–50mm**：可信建筑和自然人物尺度，以尺度层级和出画延续建立宏大，不靠镜头畸变。
- **中长焦尺度压缩，70–100mm**：远距让巨殿、门、山或月压住小人物；用空气和明暗分层，不用广角汇聚。
- **低机位**：适合台阶、门、柱和塔的向上统领。
- **高位揭示**：只有明确优先鸟瞰地理、城市规划、城区分布或浮岛关系时使用；不能由云海或城市自动推断。

禁止在同一画面同时使用极端广角畸变与强中长焦压缩。

## 繁华压迫的镜头优先级

1. **远距低机位或人眼高度 + 70–100mm**：密集屋脊、分层城区及其后方或上方主巨构的默认组合。
2. **远距低机位 + 24–35mm直线广角**：接近、桥、阶、门、柱阵和底部揭示，保持足够距离以免前景失真。
3. **人眼高度阈境 + 35–50mm**：门洞、露台、崖、檐、室内与框景揭示。
4. **高位总览**：仅用于明确的`城市总览`。

远距离不等于高机位。`繁华压迫`保持低地平线、1–3%人物、下部人物承载面、中部密集从属城区和上方出画主构。通过天空、门洞、云隙、平台下虚空、街巷、庭院和城市层间空气保留40–60%内容承载空气，不能换成实心屋顶海。

## 尺度强度

### 辽阔

使用五层空间、四项尺度证据、清晰远路和充足天空、水、云、谷或庭地；人物可缺席或保持从属。

### 史诗级

强化近景巨型框架、已知成人或阈境、统领主体、从属天域和终端远景之间的尺度断裂。至少一项是成人与门、桥与宫、树与城或瀑布与浮岛的直接比较；人物通常1–4%，必要时5–8%。

### 超宏大

必须同时满足：

1. 完整五层空间。
2. 成人通常占画高1–4%。
3. 一个巨构出画或被更近框架部分遮挡。
4. 约40–60%内容承载空气。
5. 可读的极远层而不是空雾。
6. 四项以上尺度证据，近中远具有清楚的明暗、反差或纯度变化。

无法满足时应标为`史诗级`，不能只写“超宏大”。

## 焦点层级

1. 主导：空间载体或地标。
2. 支撑：人物、次级建筑、植物、瀑布或倒影。
3. 纹理：雕刻、云、鸟、花瓣、灯点和远屋。

不得让三层拥有相同反差、尺度和细节。神域聚居地以主宫区或神圣轴线统领，从属城区为第二层，屋顶、桥、阶、庭院、云路和小奇观为纹理。

## 配色配方

- **澄澈天界**：蔚蓝、玉白、朱红、暖金、深木。
- **雨洗园林**：翡翠、孔雀蓝、珊瑚、象牙白、湿炭灰。
- **明亮夜境**：群青、紫罗兰、克制洋红、琥珀金、月白；黑色保持开放彩色。
- **日照山境**：松石青、松绿、朱砂、杏色天空、浅石。
- **神圣黎明**：淡青、云白、藏红花金、矿物红、冷蓝灰阴影。

参考图驱动的苍穹巨构从六类宫殿中只选一种：

- **纯白宫殿**：白玉、象牙石、珍珠灰阴影，金属强调0–4%。
- **朱红宫殿**：矿物朱红漆、深红棕木、云白与冷蓝灰阴影。
- **古金宫殿**：低纯老金、包浆青铜、暗青石、月白；亮金只在磨损凸缘。
- **红金宫殿**：深朱红结构、古金斗拱或窄屋沿，云与石保持中性。
- **白金宫殿**：月白玉、珍珠金结构缝与冷色远天。
- **传统矿物彩画宫殿**：构件绑定的朱红、石青、石绿、群青、赭色、象牙白和窄旧金；阅读[传统建筑彩画配色](traditional-polychrome-palettes.md)，选择一条子路线并说明风化程度。

除非明确要求混合，每图只用一种宫殿家族。即使红金或传统彩画，也不得给云、天空和浅石施加全局暖色或彩虹滤镜。通常使用两个主导色族、一个高纯强调和一个中性或暗色稳定面。

## 饱和策略

- **自然鲜明**：70–80%中低纯基底，15–25%中等纯度，最多5%高纯强调。
- **选择性高饱和**：65–75%中低纯天空、云、玉与石；15–25%中纯建筑与植物；5–10%高纯朱红、珊瑚、衣装、花或鎏金边。
- **华丽高饱和**：允许15–25%高纯区域，但限制同等强度色相，并保留大块中性或暗色稳定面。

白玉、云亮部、浅石和月白接近中性；暖光只影响暴露面；冷阴影与暖亮部保持区别；远景逐级降纯度与反差但不灰塌；鎏金保持窄而亮。

## 光线配方

- **低角度暖色逆光**：暖方向光、明亮材质边缘、冷色内阴影和一个克制星芒。
- **雨后晴光**：清晰天光、湿润反射、鲜明植物、柔和破云日光和极少雾。
- **云隙照明**：一束光强调锚点，周围仍明亮而非死黑。
- **月光与灯光分离**：冷蓝紫环境光配局部琥珀光，阴影保留细节。
- **高空清晨**：洁净蓝天光、暖色擦光、体积云边和透明空气。
- **近暖远冷**：前景建筑使用暖擦光与材质色，远云、远宫和高天更冷、更亮、更低反差。
- **宫基下低日**：低位暖光从被裁切悬空宫基下掠过，底部由冷反光保持可读。

## 材质提示

玉石有细微内部散射、矿脉和抛光边；漆木有深色本体、受控高光与磨损木纹；鎏金只在窄边和凸缘；青铜有暗包浆与暖磨损脊；琉璃有彩色透射、锋利边光和可信厚度；湿石基底变暗且反射破碎；丝绸褶皱顺风，亮部柔和。

## 常见失败修正

- 画面沉闷：提高明度、色彩分离、彩色阴影和一个强调色，减少灰雾。
- 廉价霓虹：降低等强度色块，恢复象牙白、石材和暗色稳定面。
- 过饱和或过暖：缩小红金面积，恢复中性玉与云，移除全局橙金罩染。
- 物体很大但不宏伟：增加尺度断层、缩小人物、加入极远层并让巨构出画。
- 透视弱：只保留一个消失系统，说明重复缩减并移除竞争轴线。
- 单体仙境杂乱：保留一个锚点；神域聚居地杂乱：保留一个统领城区与连通拓扑，简化模块和反差层级而不删除城区连续性。
- 建筑塑料：加入表面变化、雕刻深度、边缘磨损、半透明、包浆、纹理和非均匀反射。
- 远景平：建立近、中、远、极远的反差和明度台阶。
- 光斑过量：只保留一个有光学动机的逆光光斑。
- 巨构泛化：裁切或遮挡主构，恢复东方人物阈境与尺度断裂，减少巨面等量装饰。
- 航拍地图感：降到人眼或平台高度，恢复竖向立面和底部，用远距70–100mm压缩宫层，降低地平线并放大裁切主构。
