- R-01：不增加主面板，未指定动作、位置、层次、关系时，根据题材、已选元素、角色/尺度/占比、镜头与构图直接设计，不因普通空项追问。
- R-02：02元素展开设置提供动作、位置、前后层次、关系及关系对象，默认自动；手动选择和说明是约束，自动仅补缺；关系对象只限当前已选元素。
- R-03：没有手写说明也能表达巨鹿与小仙女星河参考的主要结构；新增可直接点选的约3%占比与精细写实电影CG组合。服饰归属、适合动作、承托/距离、视觉主次自动补齐，题材不强制宫殿巨岩，不增未启用人物。
- R-04：移除旧输入、迁移和备份兼容，采用独立V12创作存储及新schema；拒绝旧请求与备份并清楚提示。旧版本和浏览器旧创作记录保留原样，不迁移或删除；独立密钥功能仍保留。
- R-05：动作空间属性完整进入预览、请求、历史、预设、备份与下载；移除元素时清理悬空关系。保留默认说明的编辑/清空语义，双语1—10方案、模型分流和密钥隔离。
- R-06：在独立应用V12目录实施并交付，验证数据、HTTP模拟与页面交互，更新入口、规则和记录；未执行真实文本生成或出图不声称画面验证。
