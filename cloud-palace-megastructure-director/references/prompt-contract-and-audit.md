# 提示词契约与审计

## 共用依据与适用范围

当前用户要求优先；人物、镜头、透视与尺度链以[尺度与空间](scale-and-space-rules.md)为唯一细则，光照、材质与维护以[建筑与材质](architecture-and-materials.md)为准。场景只负责组织，物件只负责本体；本文件负责装配与检查，不再维护第二套专属几何或数值默认。

文本审计检查计划和提示词；视觉审计只能在看到实际生成图后进行。用户只要求诊断、改 Skill 或写提示词时，不调用生图。图像归档只用于实际生成资产，按[图片集归档](archive-and-delivery.md)执行。

## 提示词装配

先把明确要求与排除项、场景空间卡、实际物件细类、尺度链和观看关系锁定，再输出一条只描述本图的连贯提示词：

`画幅与机位 → 主构、支承与空间连接 → 人物或替代参照及尺度链 → 材质、装饰与光线 → 适用排除项`

- 首句明确画幅、相机对主构的观看关系及主导几何；默认画幅16:9，镜头条件按尺度参考。不罗列候选场景或旧路线代号。
- 主构写可见厚度、净跨、净高、纵深与支承的实际关系。并非所有字段都适用，未展示的内部构件不强行补画。
- 人物启用时明确成年仙女或用户指定身份、身体朝向、真实承载面和相邻使用层参照；默认不写人物百分比、像素框、份额或档位。无人则写实际替代参照，不添加人。
- 相机对建筑的方向与相对人物的水平角分别核对，配合一致的自然语言描述；不能只用“侧拍”“背影”等标签代替立面、地坪、身体可见面的关系。
- 尺度链至少连续三级，标准巨构优先四到五级，并给出至少三个相互连接的尺度证据；不跨景深直接拿人物投影除以近柱宽度。
- 光线写时段、方向、天空填充、阴影和受控高光；配色落到真实构件，不给整图套同色滤镜。
- 排除项按本图适用内容选取，避免把全库禁词整段贴入。未选特殊结构名称不进入正向或负面提示。
- “可选 / 非必需 / 不必附带”表示按空间主线取舍：未选的普通物件可以不写，不据此添加“不增添宫殿、树木或瀑布”等类别禁令。维持主次应靠体量、连接与层级组织；用户明确要求独立单桥或排除某物件时，再按该条件限定内容。

## 物件专属检查入口

选择对应物件时，完整阅读其文件并将需要的空间关系写入主构段。检查结果只限实际画面，不为了补清单增添物件。

| 实际内容 | 检查依据 |
|---|---|
| 桥、廊桥、桥腹 | [桥](objects/桥.md)：桥型、端部归属、连续支承、宽度、纵深与下构厚度；桥境另按[跨云桥境](scenes/跨云桥境.md)检查人物承载面与整体连通 |
| 宫廷、深殿、多层宫廷 | [宫殿](objects/宫殿.md)：横向体量、主次、檐基重量、净跨；内部宽深高空旷；实际楼层与檐数分别核对 |
| 巨宽长廊 | [长廊](objects/长廊.md)：净宽、净高、纵深与同一承重系统，不只是普通窄廊拉长 |
| 结构性天环 | [天环](objects/天环.md)：完整全貌、轮廓呼吸空间、支撑与远景尺度；不套通用裁切 |
| 悬空镂空天障 | [天障](objects/天障.md)：几何选型、同形开口、厚度与支承；不影响自然孔洞和普通门窗 |
| 圆窗、月洞门、巨窗 | [门窗与巨型开口](objects/门窗与巨型开口.md)：墙厚、洞壁、窗台与内外纵深，不因圆形误用天环 |
| 宫船 | [楼船与飞舟](objects/楼船与飞舟.md)及宫殿：船壳—甲板—宫廷连接，实际层数与整体气势分别通过 |
| 其他物件 | 从[物件总览](objects/物件总览.md)读其“检查与可选片段”，只用实际内容 |

## 适用排除项

基础质量检查包括：缺少主次的小建筑堆积、悬浮薄板、无归属支承、透视断裂、均匀浓雾、过曝白洞、无层次死黑、塑料材质、锈蚀腐败和废墟感。明确用户的特殊题材要求优先，不把默认维护状态当成与用户对抗的禁令。

启用人物时检查后贴/拼贴、悬浮脚、错位投影、同深度体型失配、与建筑光照或大气层级不一致。默认仙女可追加男性排除；用户指定男性或男性编辑目标时不得追加该项，无人场景不加身份条款。

始终排除参考截图的手机外框、黑边、播放控件、字幕、Logo、印章、签名与水印。栏杆可以存在，但要从属、不封死主要云域、不遮挡尺度链。结构专属负面项只从已选物件中提取，避免未选的天环、天障等诱导词污染画面。

用户明确禁止的元素要字面排除其同义内容：如不要松树时同时避免松枝、松针等残留。不要把明确排除项重新作为场景核心加载。静态图不加入视频速度条款；视频采用[参考图与运动规则](reference-image-megastructure-standard.md)。

## 第一次生成前

1. 完成用户要求与空间卡核对，按[构图与调用](composition-routes.md)选择或组合场景，再读取实际物件；不先生成一张泛化草图等待缩人补救。
2. 先检查人体使用层—次级构件—主构的连接，再核对相机、人物朝向、支承和主次。人物投影是空间结果，不默认随机抽取数值。
3. 多图先比较主空间、承载面、连通、高差和可见建筑面；只换颜色或左右位置不算不同场景。固定机位、全背影或连续叙事遵从用户，不为去重强迫正面。
4. 单一连续巨构模式只在触发时应用；缩略图主次与特殊物件完整度分别检查，不用统一裁切吞掉完整天环。
5. 所有默认值来自共用依据；传统彩画按条件加载配色专题。参考图只取最小必要子集并标明角色。
6. 实际生图时，先按归档文件锁定本地批次时间、语义名和目录；同批复用，新请求建新目录。遵守可用生成工具的调用要求，不虚构完成或归档结果。

## 成图验证与纠偏

- 先看主轮廓与实际空间：净跨、纵深、净高、厚度、支承、云层位置和至少三级尺度链。人物较大不自动失败，人物较小不自动通过。
- 看建筑可见面、地坪、遮挡与人体可见面是否支持计划机位；正面偏好与人物相对方位按尺度参考判断，不声称由单张图精确测得角度。
- 同批不同场景并排比较真实骨架，不能因提示词写了不同名字就判定多样性通过。
- 发现问题指出根因：建筑矮窄就改跨度/净高/纵深；接触错误就修承载面与人物；只有人物和同深度参照确有矛盾时才针对性调整相关大小与阴影。默认没有“生成后统一缩人”阶段。
- 用户明确要求数值时，仅把它作为当次附加目标，区分高度/宽度/面积、目标/估计/实际测量；数值与空间可信分别核查，不保证工具精确命中像素。
- 修订限定于获得授权的当前图片和实际问题，不自动重做整批、不无限重试；复核后如实说明仍存偏差。只反馈问题或要求改 Skill 时不自动生图。
- 按归档文件复制成功输出并保留原图，验证副本存在、类型正确且能读取。文件验证和视觉验证不得混为一谈。

## 诊断表

以下保留历史症状供定位根因；物件的现行细则以所属文件为准，表内例子不建立新的默认值。

| 症状 | 根本原因 | 源头修正 |
|---|---|---|
| 未指定画幅却生成竖图或方图 | 提示词只写“宽画面”，没有锁定具体比例 | 把`16:9`写在提示词首句和参数锁定中；只有明确画幅指令才覆盖 |
| 默认人物生成男性 | 人物身份只写“人物”“仙者”或剪影 | 正向明确成年中国仙侠仙女或成年女仙，并追加默认仙女人物的男性排除项 |
| 图片散落在工作区或只留在生成工具目录 | 没有在请求开始时锁定图片集目录 | 从请求语义提炼名称并锁定一次本地时间戳，自动创建`YYYY-MM-DD HH:mm:ss语义名称图片集`，再把成功输出复制归档 |
| 同批图片分散到多个时间目录或覆盖旧图 | 每张图重新取时间，或复制前没有检查目标 | 同一批及其针对性修订复用一次时间戳和同一目录；图片用两位序号命名，目录和文件碰撞时追加递增序号 |
| 建筑显得小而杂乱 | 过多独立体量共享相同反差和细节 | 保留一个主导轴线、片区或结构关系；用尺寸、反差和大气层级组织其他体量，不必机械删除复合场景 |
| 桥外人物站在短小石台，桥境像独立小景 | 人物承载面缺少宽深与接桥路径，桥被侧向完整收短，与天庭体系脱节 | 按[跨云桥境](scenes/跨云桥境.md)补清长阔侧台→接桥节点→宽厚远伸桥体→宫基/巨门/横向巨殿；用近旁高支承、上方重量与深云峡建立压迫感，不只缩人或补云 |
| 观看者感觉被墙围困 | 当前承诺是外部开放场景，但中景墙挡住地平线 | 若路线需要开放感，让墙体退让并恢复外部连通；若是内殿揭示，则强化门洞、柱阵和光线形成的有意框景 |
| 宫殿很大但没有神性 | 没有已知尺度对比或终端远景 | 加入真实体型的成年人、可量化柱/开口、跨云层宫基和极远锚点 |
| 巨殿像小门厅，柱粗但空间局促 | 只放大近柱或门洞，遗漏横向净跨、殿内纵深与梁底净高 | 同步扩展主柱净跨、中央地坪、近中远大开间和地坪至高梁底的距离；将家具退至边带，保留可读承重，不只缩小人物 |
| 多层宫廷总高度很高但层层低矮 | 把总楼高或屋顶厚度误当成每层净高 | 各层分别以本层地坪至梁底核查，扩展上层净空与跨度，不通过堆叠薄层增加高度 |
| 宫廷像普通楼阁逐层复制，越补层越像窄塔 | 让层数决定整体轮廓，缺少横向体量和进深组织 | 先恢复连续基座、横向主殿、前后进退与退台，再在该骨架中落实指定楼层；分别复核层数和气势，明确塔体要求时不改成宽扁宫城 |
| 主殿、侧殿和每层屋顶都同等显眼 | 体量同形同尺度，主次只靠装饰或亮度区分 | 选定主导殿体，以高度、净跨、进退和遮挡组织从属体量；极简单体以主屋盖、基座和开间建立主次，不强行增加建筑 |
| 屋檐和宫基轻薄，宫殿像摆在漂浮板上 | 只画轮廓、瓦面和底板，未展示厚度与荷载传递 | 补清深檐底部、梁架斗拱、主柱与厚宫基侧壁或承重肋的连续关系；楼船接入甲板、船壳与龙骨，同时保留净高和阴影细节 |
| 柱子很粗却仍像窄门厅或普通走廊 | 把柱径、柱列长度当成柱间净跨 | 以同深度通行门和次级开间建立参照，扩大主柱内缘净跨与中央空场，用相应主梁、深桁架或托臂承托屋盖，不靠删支撑或缩人 |
| 正面人物频繁出现或抢走建筑主体 | 将五种朝向等概率轮换，把多样性理解为必须凑齐朝向 | 默认优先侧面、背面和侧后三分之四；正面仅作低频叙事选项，允许朝向重复，改用拓扑与机位提供变化；明确用户朝向优先 |
| 人物抢走主体，建筑失去压迫感 | 叙事权重、观看距离或相邻结构层级不当，不一定是画高过大 | 先查同深度使用细节、柱础、主柱净跨净高和纵深；按真实问题调整空间或观看关系。空间成立且建筑主导时，不因人物占比较大而缩人 |
| 人物很小但不能证明建筑巨大 | 人物与建筑不在同一连续空间，或尺度链断裂 | 把人物真实放在承载面上并显示至少三级连续尺度链；无人场景改用门洞、灯火、飞舟、树木或瀑布起链 |
| 人物周边的木柱或石柱仍像普通尺度 | 次级柱和主巨柱混用同一比例 | 按尺度参考区分人体使用层、次级柱、主巨柱及其承载体；用同深度参照比较实际尺寸，展示柱—梁/拱—宫基层级，不把普通高柱的尺寸作为主柱默认 |
| 人物像后贴或拼贴 | 人物与承载面或投影不一致 | 保留合理高差与方向变化，统一相机透视、光照、脚底接触与遮挡 |
| 系列人物与空间比例不一致 | 把画高统一当成真实尺度统一，或忽略各自深度与参照 | 保持人物真实体型及同空间透视规律，允许不同场景和镜头下投影大小变化；不强行锁定一个百分比 |
| 场景像鸟瞰游戏地图 | 高机位平均展示所有片区，缺少主导轴线和尺度断层 | 保留受控鸟瞰，但选定一个主导结构、桥系或云峡，利用遮挡、立面、明暗和尺度链建立层级 |
| 画面变灰变平 | 用均匀雾气表现纵深 | 雾气局部化；用明度、纯度和反差阶梯分离空间层 |
| 建筑显得嘈杂 | 所有巨大表面具有同等装饰密度 | 恢复安静巨面；把细节限制在一到两个可识别区域 |
| 出现参考截图杂质 | 把UI和水印误当成风格 | 重新标记参考角色；明确排除所有界面、文字和水印元素 |
| 天环或天障像科幻装饰 | 缺少承重路径、厚度或与宫殿的整合 | 把它嵌入柱、宫基或屋顶桁架并揭示更深的有人活动空间层；天环保持完整远景圆周，天障可裁切外墙但保留完整几何主开口 |
| 天环只剩四分之一弧，无法看出圆环 | 把通用裁切规则错误套到天环，或镜头距离过近 | 改用远景或超远景，把完整圆周和四周呼吸空间收入画面；用支撑跨度、人物与相邻参照、宫阙与云层证明尺度 |
| 完整天环仍显得像近景装饰圈 | 只靠画面占比制造巨大感，缺少环境尺度链 | 拉远镜头；同时显示至少两处巨型支撑、数百身体宽的跨度、环内宫阙、跨云层关系与终端远景 |
| 天障缺口像随机破洞或难看的斜向开口 | 使用了自由曲线、不规则负形或旋转方形，没有正确几何选型 | 按屏障宽高比锁定圆形或正向方形一种家族；所有从属开口同形且规整，方形不得旋转，并保持厚度与承重可见 |
| 宫殿像锈蚀废墟 | 把古老、包浆或旧金误译为腐蚀破败 | 恢复洁净完整、长期维护的表面；只保留轻微褪色、磨亮和受控材质变化，排除锈斑、锈水、点蚀与剥落 |
| 红金宫殿像主题乐园 | 暖色等量覆盖云、石材和阴影 | 恢复中性云/石材、冷色通透阴影和窄小陈金结构强调 |
| 细节丰富的宫殿仍显得小 | 装饰密度均匀且缺少人物尺度 | 把深斗拱集中在承重带；加入安静巨面及连续的使用层—次级构件—主构尺度对比 |
| “无边无际”变成无数小宫殿 | 把建筑数量误当成连续体量 | 只保留一块连续屋顶、墙体、柱廊、平台或宫基系统，让其延伸出画框；重复构件汇入同一承重关系，缩略图先读一个轮廓 |
| 十个变体看起来像同一张图 | 只替换了名词 | 改变场景空间或连通关系，并改变至少一项实际观看关系/物件形态；配色和动作可作为补充 |
| 场景总是外部露台、宫墙一侧和开放云海 | 只抽主导结构，没有抽取人物承载面与主构的空间拓扑 | 从场景库重新选择或组合实际空间，明确正面前场、对岸遥望、桥下仰望、深殿向外、屋顶台原等物理关系；只换配色不算新场景 |
| 镜头总在人物侧后方约45° | 把人物朝向误当成相机机位，或把侧后方当作安全默认 | 先按主构选择机位家族，再独立锁定人物身体朝向；随机变体主动轮换，连续叙事按镜头功能决定是否重复 |
| 提示词机位不同，成图仍都从人物右后方或背后望向天宫 | 只验收机位标签，忽略人物、视线与建筑主轴的实际关系 | 并排检查立面、地坪、人体可见面和遮挡；按尺度参考改变观看关系，不能只镜像、换色或把右后方换成左后方 |
| 缩小人物后便交付，但空间仍不成立 | 把人物变小当成巨构通过，忽略主次和连续尺度链 | 分别核查机位、身体朝向、相邻参照、承重与空间跨度；修改根因，不把孤立缩人当成完成 |
| 彩画宫殿显得霓虹或幼稚 | 朱红、绿、蓝和金拥有相同面积与纯度 | 把颜料绑定到构件；恢复石材/云的中性面；收窄赭色和金色；降低远景纯度 |
| 岁月宫殿显得破败或肮脏 | 风化被处理成随机脏污罩层 | 按暴露和使用规律落位褪色、雨痕、积尘和磨损；保持结构有人居住且完整 |
| 冲击力变得躁动、像游戏 | 动作、运动模糊和镜头速度同时争夺注意力 | 保留有动机的仪式行进、攀登或快速动作，但让主构仍由尺度、光线和视差主导 |
| 推镜导致云、布料或人物加速 | 镜头与世界运动被耦合或时间重映射 | 保持每种世界空间速度不变；慢镜头只影响构图和视差 |
| 中午或下午光线刺眼 | 高角度直射光、过硬阴影和白热反射同时出现 | 保留时段特征，用建筑遮光、薄云、大气和动态范围控制高光，恢复材质纹理 |
| 日出或落日变成橙色滤镜 | 暖色覆盖天空、云、石材和阴影 | 暖色只落在受光边缘与局部结构，恢复冷色天空填充和通透阴影 |
| 云宫被过曝白光吞没 | 太阳盘、云层和浅色石材高光没有上限 | 压低太阳和云层高光，保留白玉、云和檐边的明度层级与表面细节 |

## 最终审计

只核对适用项，不用未出现的物件凑清单。

- 当前明确内容、排除项、画幅、人物身份和参考角色是否正确？
- 场景、物件、机位是否分开记录，且最终提示词仅包含实际选中的内容？
- 主次、可见承重和至少三级连续尺度链是否成立？是否同时保留人尺度使用层与巨构层级？
- 桥境是否按所选空间检查宽度、厚度、纵深及承载端？桥外人物的侧台是否真实接桥，宏大天庭桥境是否体现整体建筑连接？
- 人物大小是否由空间自然形成，没有无依据的固定百分比或自动缩人？
- 人物朝向与相机方位是否分开核对，脚底接触、投影、遮挡和光照是否一致？
- 实际宫殿/长廊是否宽、深、高敞；指定楼层数、物件专属形状与完整度是否各自满足？
- 大面、装饰、维护、配色和柔和光照是否符合共用规则？
- 随机不同场景是否在可见空间上真正不同，连续叙事不变量是否保留？
- 是否排除截图污染，并且没有用模板添加用户不要的物件？
- 是否把“可选”误写为类别禁令，或为了保持单一主次擅自排除了有用的连接建筑与尺度参照？
- 实际生成后是否独立验图，并在完成复制与文件验证后报告真实归档路径？

## 标准交付

提示词任务按需要提供参数锁定、空间方案、完整提示词和适用负面约束；只有用户需要才另给衍生方向。直接生图交付图片集文件夹、逐张归档完整路径和所用提示词组，说明实际发现的偏差；不默认展示人物百分比达标表。
