# 提示词结构与示例

这些只是[仙侠共享总则](xianxia-master-rules.md)之下的结构模板，不是固定内容。每个示例都继承可量化巨物尺度、五层空间、40–60%内容承载空气、东方巨构、无栏杆边缘、背影仙人与衣装语法。保留用户参数，不要复制无关元素。

```text
主色：翡翠绿、孔雀蓝、珊瑚色
光线：雨后上午的暖色侧逆光

输出模式：标准
```

## 紧凑完整示例——9:16

```text
9:16 沉浸式竖屏画幅，空间尺度强度为超宏大，低机位 24mm 等效广角建立镜头，自下而上的纵向单点透视。宏大的无栏杆青玉天阶从画面底部近景向高处急剧收缩，通往云层上方的朱红悬空山门；山门上部继续延伸到画面之外，所有纵向边线汇聚到同一高位消失点，建筑垂直线保持挺直，台阶与柱列的间距、尺寸随纵深规律递减。两名身穿月白与孔雀蓝仙衣的成年旅人位于下方三分之一处，全部背影，人物高度约为画面的 3%，平静登阶；两条受风长幅与三层不等长后摆遵循同一向左风向，只作为尺度参照。

画面形成固定五层空间：近景半截巨柱框景；承载旅人的无栏杆青玉天阶；延伸出画面的主山门；更轻、更小的远方飞阁与浮岛；终端云海和高空天际。门柱直径约为八个成人身高，山门开口约为三十个成人身高，主屋檐跨越数百个身体宽度并继续出画，人物周围保留约十五个身长的开放阶面，构成四项以上可测量尺度证据。山门由青玉、朱红漆木与极细鎏金边构成，大体块简洁安静，斗拱、梁枋和莲云纹只集中于人可读的门洞内缘。瀑布从远处浮岛底部垂落，形成继续向上的视觉节奏；天空、门洞、桥下、云隙与远景共同保留约45%的有内容呼吸空间。

饱和策略为选择性高饱和：约七成天空、云海、青玉和月白石材保持中低纯度，朱红集中在山门结构，少量暖金只勾勒受光边缘；整体高明度、色彩分离清楚、饱满但不荧光。白玉与云层亮部保持接近中性，不被整体染成橙金色。清晨暖金阳光从右上方斜射，照亮山门和台阶边缘，内部阴影保持透明冷蓝灰，仅在山门右侧逆光边缘出现一处克制星芒。

大朵白色积云具有清晰体积，前景略微柔化，中景山门和人物清晰，远景随大气透视逐层变淡但仍保留颜色。仙侠电影剧照、纪念碑式尺度、精致东方布景设计、物理可信光线、细腻材质细节。保持五层竖向视觉路径、40–60%有内容空气、人物小尺度、背影视角、结构化仙衣、统一风向与全场景无栏杆；不要横向全景压缩、不要灰雾遮色、不要廉价霓虹、不要塑料玉石、不要多重消失点、不要文字、标志或水印。
```

## 衍生版本规则

每个衍生方向至少改变以下两项：
