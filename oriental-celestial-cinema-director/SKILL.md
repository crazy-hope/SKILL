# 东方天界电影巨构导演

## 核心原则

从文字建立原创画面，不依赖源图：

> 局部高密度的连续东方古建巨构 + 大面积开放天域 + 延伸出画框的超尺度结构 + 极小尺度标记 + 冷底暖光。

随机只改变观看关系和场景组合，不能随机掉这套视觉语法。

## 纯文本边界

- 不把原始图片、截图、缩略图或其他视觉资产放入 skill。
- 不在提示词中写来源图片、图片编号、文件名或文件路径。
- 不复刻特定作品的精确布局、人物、纹样、文字、标志或水印。
- 只使用本 skill 及其三个文字参考文件；不继承其他导演 skill 的规则或资料。
- 实际生成的图片保存到用户指定位置；未指定时保存到当前可写工作区，绝不保存进 skill 目录。

## 必读路由

1. 每次导演、写提示词或生图前，完整读取[视觉语法](references/visual-grammar.md)。
2. 用户说“随机”“来一张”“多张”“批量生成”或未锁定构图时，完整读取[随机场景矩阵](references/random-scene-matrix.md)。
3. 输出最终提示词或调用生图工具前，完整读取[提示词契约](references/prompt-contract.md)。

## 工作流程

1. 提取用户固定条件：主体、人物或坐骑、自然锚点、数量、画幅、亮度、排除项。用户指定的内容不可被随机替换。
2. 锁定视觉不变量：连续巨构、局部密度、大面积天域、画外延伸、尺度标记、冷暖分离、云雾纵深和电影 CG 质感。
3. 从随机矩阵选择一个主构图原型，再选择兼容的机位、巨构形态、天域、叙事、自然锚点、光线和色彩家族。
4. 先写场景蓝图，再按提示词契约装配正向提示词；负面边界只负责阻止常见偏移。
5. 用户只要提示词时，交付蓝图和最终提示词。用户要图片时，使用可用的位图生成工具从零生成；画幅未指定时采用宽银幕 16:9。
6. 生成后进行缩略图审计。若主轮廓、空间或色彩语法失效，只针对失效项修订，不把所有细节一起重写。

## 批量差异

批量生成时，每张必须使用不同的主构图原型，并至少改变机位、巨构方向、开放天域三项中的两项。不能只换人物、服装、颜色或装饰。所有图片仍共享同一视觉不变量。

## 完成审计

- 第一眼是否先读到一个连续巨构关系，而不是许多大小相近的小亭阁？
- 建筑复杂度是否集中在局部，同时保留足够大的天空、云海、深渊或水庭？
- 是否至少有一个屋檐、柱阵、墙体或宫基自然延伸出画框？
- 人物、坐骑、栏杆或树木是否作为极小尺度标记并真实落位？
- 是否为低饱和冷环境中的局部暖光，而不是鲜蓝、翠绿、亮金或全局橙色？
- 云是否呈平整云海、横向雾带或水汽层，而不是遍布棉花云？
- 是否静谧、庄严、超现实但稳定，无恐怖化、霓虹化、UI、字幕、Logo或水印？

任一核心项失败时不交付为合格结果。
