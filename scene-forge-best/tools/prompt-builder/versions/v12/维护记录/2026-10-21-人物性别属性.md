# 人物性别属性

日期：2026-10-21；基线：V12（含赛博朋克人物扩充）；规范V8不变。事前记录，按当前应用小维护执行。

用户原话：“虽然加了很多人物，但是没有性别”。

## 需求、方案与验收条件

- R-01：02已选人物的展开属性新增独立性别，提供自动、男性、女性、非二元、不强调性别及自定义。身份名称保持简洁，各人物分别设置；内置非人物元素不显示该控件，自定义元素提供可选入口并标明仅适用于人物。
- R-02：可选字段`gender`随对应元素进入请求、输入展示、预设、历史、备份及下载。仅扩展当前schemaVersion=3；缺少字段的既有V12记录不补造性别，schema1/2与旧备份仍拒绝。
- R-03：明确性别作为锁定要求，与对象数量和身份分别处理，中英文一致。自动仅补缺，不由职业强制性别；不强调性别时不突出性别特征；明确冲突应澄清。性别不授权添加人物或把非人物变成人物。
- R-04：新增前后端回归，检查页面选择、刷新与输入展示；核对规范、旧版和既有维护记录未变。
