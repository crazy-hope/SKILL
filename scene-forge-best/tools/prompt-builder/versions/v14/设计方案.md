# 工作台 V14 设计方案

日期：2026-10-27；用户已确认方案。

在V13的React/Ant Design/Python结构上扩展，不重构页面导航。保留选择元素→点击设置→右侧抽屉；人物基本属性、服饰、空间关系分组。共用属性作用于同名人物组，分别添加不同名称可独立设置。

比较：完整重做人物编辑器会引入逐人列表和额外操作；本轮采用已确认的按元素独立设置，所有题材复用同一控件。内容库均衡补齐，不仅扩充奇幻主题。

schemaVersion=3，elementSettings新增可选age、hairstyle、clothing、clothingColor、clothingMaterial、accessories字符串，每项1—80字；gender/count沿用。缺少新字段保留缺失；界面清空代表自动。未选人物不增加人物，非人物保持普通属性。自定义元素沿用现有可设置人物属性能力，但仅显式选择属性才进入输入。

Choice区分“已保存值”和“本次输入搜索”；打开先呈现所有候选，只有输入才按搜索过滤。下拉箭头有可访问名称，保留自由输入。服饰推荐来自当前题材并去重，通用候选补充；多题材合并，不覆盖已选值。

同组人数、性别和服饰锁定进入两种服务请求；名称、数量、说明出现硬冲突则澄清，不自行覆盖。机器人属性允许不适用。既有存储键、备份格式、结果完整design约束继续保留。
