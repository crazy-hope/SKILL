# 从元素到画面

这些是可迁移的设计方法，不是需要逐个填满的模板，也不是统计证实的爆款公式。

## 用户不会选风格时

先按 SKILL.md 一次只问一项：表现方式（可多选）、具体视觉风格（可多选）、整体色彩／色调、题材（可多选）、文化背景、内容现实性、情绪／氛围（可多选）、画幅、版本、Personalize。只在对应项被明确交给 skill 时才自行决定该项；“风格自由选择”不表示可以跳过具体视觉风格、东方／西方背景或现实性。十项确认后再给五个候选场景。按 [visual-direction.md](visual-direction.md) 把具体视觉风格落实到画面，用户选中场景后，媒介、具体风格与文化设定在最终三版间保持一致。

零输入时，在十项设置确认后主动设计五个场景，可涉及人物生活、静物设计、动物行为或建筑光影；非现实空间与尺度异常只在现实性选项允许时使用。统一遵守已选具体风格与文化背景；避免每次都是雨夜、孤独少女、巨大植物、漂浮衣裙。先让用户选一个，再进入变化方式选择，不直接交付成品。

## 按性质发明事件

| 输入元素的性质 | 可发展的机制 | 必须出现的视觉证据 |
|---|---|---|
| 轻、可被风吹动 | 拦截、压住、收拢、展开 | 受力方向、绷紧边缘、压物 |
| 吸水、遇热变化 | 变重、贴合、融化、起雾 | 水线、湿痕、凝结、下垂 |
| 透明、反光、半透明 | 透射、映照、折射、遮光 | 明确光源、影子或反射位置 |
| 尺度反差 | 临时住所、工具、道路、地形 | 已知尺寸物作为参照、接触关系；现实世界限合理真实尺度，超自然放大需明确允许 |
| 表面可留痕 | 修补、清理、测量、搬动 | 划痕、擦拭边界、压痕、足迹 |
| 空间有阈限 | 穿过、递交、探看、等待 | 门缝、边缘、内外分界 |

选一项机制，再考虑元素之间如何相互影响。例如“冰+红布”不必总写美人站雪中，也可以写冰面下的红布成为修补渔网的定位标记；必须确保事件符合文化背景、现实性及输入条件。现实题材的惊喜可以来自协作、偶然发现与新视点，无需超自然设定。

## 动作与镜头共同设计

动作配方：目标 + 受力部位 + 接触物 + 重心/支撑 + 此刻的未完成状态。

“优雅地站着”信息少；“蹲在低凳旁，一手压住待补纸面，一手刷浆糊，袖口束起，纸角因受潮微卷”能自然产生姿态。无需每次写齐解剖细节；镜头看不到的部位不占提示词预算。

| 想让观众感受到 | 可选择的视点 | 需要检查 |
|---|---|---|
| 参与与亲近 | 肩旁、桌缘、门内看出去 | 前景不遮掉关键动作 |
| 尺度和依靠关系 | 地面附近、物体边缘、人物旁 | 不是只写“宏伟” |
| 动作分工 | 斜侧中景、适度俯视 | 人物位置可区分 |
| 平面秩序 | 正俯视、正面平视 | 不同时要求强纵深特写 |
| 材料变化 | 接触点近景 | 关键物仍可识别 |

## 控制复杂度

围绕主体、关键关系、单一视点与一致光色组织完整细节。复杂互动要理顺人物位置、接触和遮挡，不通过删去硬条件、压缩文字或额外提供精简版来解决。最终三版都应完整详细；已知实际出图失败时先解释具体失效关系，再按用户选定的变化方式修订。

## 示例：不同于莲花躲雨的场景

输入：古装成年女子、巨大银杏、霜、红纸鸢。

画面：巨树裂隙成为修鸢工作台，女子用一枚落叶挡住树缝里的风，使刚粘合的纸角保持平整。镜头在树缝外侧，树皮形成侧向边框，红纸上的湿浆与树皮霜粒构成质感差异。事件是修补与挡风，不是追逐、躲雨或搭救。

生成五个候选或“换一批”时，应改变事件机制或空间关系；不要只替换手部动作。候选被选中以后，则严格遵守变化方式：同一瞬间只能改变拍法，同一场景不同瞬间才改变互动。
