# 参考图巨构标准

本文件负责参考图角色、可迁移关系、视频运动、秒级时间轴及逐图配套的视频提示词、标题和简介。物件构造已拆入物件库，随机场景由场景库与构图导航负责；未提供参考图且无需配套视频文案的纯静态任务，不因出现柱、桥或多图而加载本文件。

## 参考图角色契约

编写提示词前，标注每张图的角色：

- **编辑目标**：仅在用户明确要求修改该图时使用。
- **构图参考**：提取裁切压迫感、地平线、纵深路径、负空间和尺度层级。
- **建筑/材质参考**：提取承重路径、屋檐深度、斗拱密度、石材、漆面、铜和鎏金表现。
- **氛围/光线参考**：提取云层高度、薄雾落位、冷暖分离和光线方向。
- **仅作排除参考**：记录不需要的UI、边框、栏杆、文字、印章、水印或生成瑕疵。
- **视频首帧**：用于图生视频提示词的实际成图或用户指定图片；保持画面已有主体、身份、构图、建筑连接和光照，只设计与该图一致的连续运动，不重组为新场景。

未要求编辑或指定视频首帧时，所有来源默认都是非编辑参考。对于借鉴生图，明确说明哪些特征可以迁移，以及哪些源图特有布局、人物和纹样不得迁移；视频首帧不走借鉴重组流程。

## 提取关系，不照搬物件表

本节用于借鉴参考图生图：先记录主轮廓、承重、尺度链、纵深、材质和光线，再按当前用户需求重新组织场景。近景粗柱、深檐、远宫和巨松可以拆开使用；原图含男性、群像或天环不代表本图必须继承。视频首帧按后文视频流程保留已有内容，不执行场景重组。

使用[视觉基因](reference-derived-visual-dna.md)提取视觉主次；人物身份、朝向和镜头只服从[尺度与空间规则](scale-and-space-rules.md)，材质光照只服从[建筑与材质](architecture-and-materials.md)。不要在本文件建立第二套百分比、镜头或随机规则。

## 运动与镜头相互独立

静态图默认采用平静动作，但仪式行进、攀登、迎风站立或克制的快速动作可按叙事使用。

以下为动画或图生视频的默认规则，不改变静态图的姿态选择；用户明确指定某项动作或运镜时按该项覆盖，不连带改变其他运动。只为实际画面中存在的元素写运动，不把整张表复制进每段提示词。

| 实际可见元素 | 视频默认运动 |
|---|---|
| 低处云海 | 缓慢翻涌，形成宽广、连续的起伏与层次变化；不写成静止贴图、急速奔流或延时掠过 |
| 高空云彩 | 沿一个根据画面选定的方向缓慢移动，保留云层形态和高低层次；与低处云海分别描述 |
| 瀑布 | 水流受重力牵引，从画面已有落差处持续直泻而下，保持自然下落速度与连续水势；不因整体氛围缓慢而写成悬浮慢流、倒流或冻结 |
| 河流、水面 | 沿已有水道和坡势自然流动，平静水面仅有轻缓涟漪；不得把瀑布的垂直下落规则套给所有水体 |
| 飞鸟、飞鹤、龙等飞行生物 | 按画面中的头部、身体朝向及空域，选定并写明一个具体方向，平稳、持续飞行；鸟鹤自然振翅或滑翔，龙顺飞行路径舒展身躯，不突然转向、瞬移、无目的盘旋或原地悬停。雕刻、浮雕、纹样不作为活体启动 |
| 人物 | 按首帧姿态、场景关系与叙事选择伫立不动或缓慢行走，不默认必须走动。伫立保持原位和朝向，慢行才沿自身朝向在可通行承载面上短距离前进；具体依据见[按场景选择人物动作](#按场景选择人物动作) |
| 衣物、长拖尾、头发 | 随人物动作与同一环境风向轻缓摆动，保留重力、垂坠和地面接触，不随镜头突然鼓动或高速甩动 |
| 建筑、山体与承载结构 | 保持结构稳定和世界空间位置不变；镜头产生的遮挡与视差不等于建筑漂移、伸缩或变形 |

### 按场景选择人物动作

人物动作与镜头运动分别选择。依据首帧姿态、观看关系、叙事意图和真实承载面决定本图人物状态；没有“只要有人就必须行走”的默认，也不因桥面、可通行路径、5秒时长或时间轴分段而强制迈步。用户明确要求静止、行走或其他动作时优先遵从。

- **伫立不动**：适合静观云海、凝望巨构、守望或以人物作为尺度参照的场景。保持首帧身体朝向、脚下位置与稳定站姿，不迈步、不滑移、不主动转身；可有轻微自然呼吸，衣物和头发随环境微风轻缓摆动。即使前方有路，也可以全程伫立。人物保持原位不等于冻结整幅画面，云、水、飞行生物及按场景选定的镜头仍可自然运动。
- **缓慢行走**：适合已有行进姿态，或叙事需要沿桥面、长廊、台阶等真实通路缓行的场景。只有选中此状态时，才使用[步态与5秒约束](#已选择行走时的步态与5秒约束)；不能仅因为“可以走”就自动选行走。
- **已有坐卧或其他明确姿态**：保留与场景相符的原姿态或按用户要求安排，不为套用站立或行走模板而强行起身。

伫立时不附加步数、步频、行进距离或“镜头略慢于人物”的比较。选中行走后，前进方向依据身体和脚步可行方向，不只依据目光；背影可顺朝向远离镜头，侧身可顺朝向侧向前行，不套统一左右方向。前方若是断崖、墙体或没有可通行路径，缩短行程至承载范围内或选择伫立，不为满足慢行而补路、穿墙或走入虚空。

### 按场景选择运镜

先判断主体布局、空间开合、遮挡层次、希望揭示的建筑关系与画面支持的镜头路径，再选择最适合该图的一种运镜。人物朝向和步行路径只约束人物，不决定相机必须跟随或向前推进；有行走人物、桥面、长廊或5秒时长，都不自动触发前推。用户明确指定运镜时优先遵从；未指定时按下列场景依据选择，成稿只写选定方案及方向、范围，不保留候选列表，也不为追求多样性强行换镜头。

- **固定机位**：适合主体关系已完整、动态主要来自云水或运动空间难以判断的画面；相机位置、朝向与焦距保持不变。
- **慢速恒速位移**：方向由场景决定，不限于向前。需要沿清楚通路揭示纵深时可小幅前推；横向展开的宫墙、柱列或桥体可缓慢横移；需要展开整体关系且后退空间可信时可缓慢后拉。写明一个具体方向及小幅范围，以自然视差呈现空间，不以变焦代替位移，不穿越实体或强行暴露未知区域。
- **克制的慢速环绕**：仅在主体侧向空间清楚时采用；写明围绕对象及一个方向，保持小角度、慢速恒速，不穿过实体、不大幅绕到未知背面。

**同向前推的条件规则**：只有已根据场景选中人物行走与镜头前推，且两者沿同一路径向前运动时，才使用“镜头非常缓慢、稳定地推进，推进速度略慢于人物行走速度”。比较共同前进方向上的世界空间位移速度，不比较画面像素位移；先确定人物自然步态，再选定略慢且恒定的镜头速度，各自保持稳定，不通过加快人物、动态追赶或时间变速维持关系。此条只约束已选中的前推方案，不参与决定人物是否行走或镜头是否前推；人物伫立，以及固定、横移、后拉、环绕或不同方向运动均不套用。

禁止快速推镜、猛然变焦、甩镜、延时摄影、变速、速度坡变和人为加速视差。世界空间运动与镜头相互独立：相机推移或环绕只改变构图、遮挡和自然透视视差，不改变人物、飞行生物、云、水、瀑布、衣物、头发或粒子的运动节奏，也不让静止建筑动起来。保持连续正常时间，不用慢放把瀑布等所有元素统一减速；屏幕投影位移可以随透视自然变化，不等于物体在世界中加速。

`动感`、`强冲击力`、`电影感`、`能量充沛`或`节奏紧凑`等泛化风格词不能覆盖上述默认规则。通过尺度揭示、遮挡、光线、构图和受控视差制造冲击力，而不是依靠速度。

### 已选择行走时的步态与5秒约束

本节只用于已根据场景或用户要求选择行走的人物，不用于伫立、坐卧或无人画面。人物沿自身身体朝向，以正常成年人自然散步的从容节奏缓慢前行：小步幅、低而稳定的步频，每一步完整、清晰、自然，脚步稳定落地，身体重心随步伐轻微自然起伏；不转身迎向镜头、不倒退滑行、不为追赶镜头加速。缓慢感由真实步态与短位移实现，不靠慢放、定格或机械停顿，不为了看清脚步改变原图服装或强行露脚。

- **有人物步行时**：适用负面约束包含禁止快速行走、奔跑、快步、小跑、大步跨越，禁止快速摆臂、快速腿部动作、身体前倾冲刺及人物突然加速；禁止时间加速、快动作和延时摄影效果。无人或人物不步行时不机械附加这组步态条款。
- **总时长为5秒且有人物步行时**：写明“人物在整个5秒镜头中只沿自身朝向前进很短的距离”。不自动加入“恰好两步”或固定米数；只有用户明确给出步数或距离时才加入。总时长按[秒级时间轴编排](#秒级时间轴编排)确定；5秒草案不等于用户已指定或视频工具已锁定该时长，其他时长按本次要求调整。

当“5秒、人物步行”同时成立时，把以下人物动作模块适配人物身份与画面中的可通行方向。该模块不含运镜指令；另按[场景运镜选择](#按场景选择运镜)编写镜头段，再与该图实际存在的云海、瀑布等运动段组合，不把人物动作模块单独冒充整幅场景的完整提示词：

> 人物沿自身身体朝向，以正常成年人自然散步的从容节奏缓慢向前行走，步伐从容克制，小步幅、低步频；每一步完整、清晰、自然，脚步稳定落地，身体重心随着步伐轻微自然起伏。人物在整个5秒镜头中只向前移动很短的距离，不为追赶镜头而加速，动作舒缓、真实、沉稳，营造庄严、宏伟、宁静的氛围。人物步态保持稳定，场景内各元素的运动节奏独立于镜头。禁止快速行走、奔跑、快步、小跑、大步跨越，禁止快速摆臂、快速腿部动作、身体前倾冲刺，禁止人物突然加速，禁止时间加速、快动作和延时摄影效果；不使用慢放或定格制造缓慢感。

## 图生视频提示词生成与交付

- **实际生图或修订图后，尚未确认**：先完成验图、归档并向用户展示图片和路径，再询问：“需要为这张图片生成图生视频提示词，并附上10字标题、20字标题和简介吗？”多图可在整批交付后统一询问，并让用户选全部或指定图片。问完结束本轮等待明确回复；未回复不算同意，不提前编写、展示、保存文案或创建占位文本文件。生图请求本身及以往配套习惯不代替本次成图后的确认。
- **用户确认生成**：仅针对确认的成图进入下方逐图流程，依次生成带秒级时间段的中文图生视频提示词、10字标题、20字标题和一段简介；明确不要的项目省略。以实际成图为准，不用原生图提示词推断最终出现了什么。仅确认部分图片时不扩展到整批，后续新图或修订图重新走成图后确认流程。
- **用户拒绝、暂不需要或尚未确认**：保留已交付图片，不生成上述文案；明确拒绝后不反复询问。用户只要求改图或评价图片时，不能当成文案生成的确认。
- **用户直接请求已有图片的图生视频提示词**：该明确请求即为针对已有图片的确认，无需重复询问。先查看指定图片，按视频首帧处理，依次交付上述四部分，用户明确不要的项目省略；不重新生图、不重算或虚构首帧相机参数。
- **只要求静态提示词、诊断或改 Skill**：不自动生图、不自动创建图片集，也不附加无关的视频提示词。没有可查看图片但用户要求视频提示词时，说明依据的是场景描述而非视觉观察；若必须依赖缺失图片才能判断，先请用户补图。

仅在上述确认条件成立后，针对确认的图片逐图执行：

1. 从实际画面确认主体、人物身体朝向与承载路径、云海和高空云的区别、瀑布落差，以及是否存在活体飞行生物。已有图像观察记录可复用；不补画面没有的元素。
2. 按上方运动表选取本图适用规则，先按[人物动作选择](#按场景选择人物动作)决定伫立、慢行或保留原姿态。只为选中行走的人物和实际飞行生物落实行进方向，伫立者写清原位与朝向保持；为云层选择与画面风向相容的移动方向，不宣称从静态图测得真实风速。
3. 独立按[场景运镜选择](#按场景选择运镜)确定一种镜头方式，写明固定机位或具体移动方向与范围；人物动作段不反向决定运镜，镜头移动也不触发人物走动。按[秒级时间轴编排](#秒级时间轴编排)确定总时长与分段；只有已选行走时才加入[步态与5秒约束](#已选择行走时的步态与5秒约束)，仅在人物行走与镜头同向前推同时成立时补充相对速度规则。默认一个连续镜头，不强制添加帧率、视频平台参数或分镜切换。
4. 视频提示词内部依次写：`总时长及依据 → 首帧保持关系与全程约束 → 各秒级时间段的镜头状态和主体环境运动 → 适用负面约束`。每段使用完整、可直接复制的中文描述；全程约束可以集中写一次，不交付占位符、条件菜单或整库物件清单。
5. 视频提示词完成后，按[标题与简介](#标题与简介)依次生成10字标题、20字标题和一段简介。每张图单独标注图片编号/名称，四部分文案与该图一一对应，多图不共用场景无关的套话；标题简介与视频生成指令、所用静态生图提示词分开。
6. 交付前核对时间段完整覆盖总时长、段间动作连续、标题字数准确、简介与画面一致。实际生成资产的完整配套文案按[图片集归档](archive-and-delivery.md)保存；只交付文字不等于调用视频生成工具或发布文案。

### 秒级时间轴编排

- **总时长**：优先采用本轮明确时长，其次沿用上下文已确定的时长，例如前文已指定的5秒。若本轮与上下文均未提供总时长，为交付可用时间轴，暂按5秒草案编排，并在提示词前明确“暂按5秒编排，可调整”；不得说成用户已指定，也不据此设置或调用视频工具。
- **分段方式**：按场景动作和空间显露的节奏选择一个或多个区间，例如`0–1s、1–3s、3–5s`；全程保持同一状态时可只写`0–5s`。无需机械逐秒分成五段，也不为了段数制造额外动作。用户指定其他总时长时重排区间，不照搬5秒模板。
- **覆盖要求**：首段从0s开始，末段到总时长结束，相邻区间首尾相接、无空档或重复覆盖，每段终点大于起点。覆盖整段时间，而不只是列出“第1秒、第3秒”等孤立时间点。
- **每段内容**：写清该时段的镜头状态（固定或选定运动的方向、慢速与小幅范围）、实际主体动作、实际环境运动，以及相对上一段的延续或渐变。变化可以是自然视差、遮挡或空间层次逐渐显露；固定机位可明确“机位不变，人物和云水延续原有节奏”，不必强造镜头位移。
- **连续性**：分段是同一镜头的时间说明，不等于切镜。沿用已选运镜和人物状态，段落边界不自动换方向、变焦、加速、减速、停顿或重置动作；伫立可贯穿全片，不为“每段有变化”强制转为行走。选中行走时，短位移、步数等约束累计作用于全片，不在每段重新计算。云、水、布料与生物运动连续且独立于镜头，末段自然延续到结束，不默认冻结或变速收尾。

### 标题与简介

确认生成配套文案后，在视频提示词后独立依次输出以下三项；图片刚生成、等待确认或只要求静态提示词时不自动添加，用户明确省略某项时遵从。

- **10字标题**：标题正文恰好10个汉字，突出本图最鲜明的空间或氛围。
- **20字标题**：标题正文恰好20个汉字，在短标题主题上补充画面中的主体、动作或空间关系，不机械重复凑字。
- **简介**：一段简短、连贯的中文，介绍本图主体、场景、预期运动与氛围；不设未经要求的固定字数，不罗列镜头参数，不凭空补人物、飞行生物、建筑或故事背景，也不把拟生成的画面说成已生成的视频。

标题默认只使用汉字，不加标点、空格、数字、字母或表情；“10字标题”“20字标题”等字段标签不计入正文。交付前实际逐字计数或用字符计数工具核对，分别达到10字和20字，不凭视觉估计。标题和简介是独立配套文案，不加入视频生成提示词，不作为字幕、水印或画面文字；仍保持画面无文字污染。

### 场景适配示例

假设图片已展示，用户已确认生成配套文案并指定5秒。画面实际包含：停在宽阔石桥侧、背面朝右后方静观云海的仙女，桥下云海、右侧瀑布与高空薄云；前方桥面可通行，但叙事重点是静观而非行进。空间关系已经完整呈现，选择人物伫立、固定机位，保留云水与衣物的自然运动。可交付：

**图生视频提示词**

> 总时长5秒，单一连续镜头。保持首帧石桥、仙女、云层与瀑布的布局、身份、材质和光照，建筑结构稳定，人物与自然元素的运动独立于镜头，保持正常连续时间。
>
> 0–5s：相机采用固定机位，位置、朝向与焦距始终不变。仙女全程伫立在桥侧，保持背面朝右后方、静观云海的姿态，脚下位置与身体朝向不变，不迈步、不滑移，仅有轻微自然呼吸。长裙拖尾保持垂坠与地面接触，轻纱和发丝随微风轻缓摆动。桥下云海持续缓慢翻涌，高空薄云从左向右缓慢移动，右侧瀑布受重力牵引持续直泻而下；各元素延续原有节奏至画面结束，营造庄严、宏伟、宁静的氛围。
>
> 全程禁止人物自行迈步、滑移或无故转身；禁止快速推镜、镜头漂移、变焦、甩镜、时间加速、快动作、延时、变速、整幅画面冻结、建筑变形、画面闪烁或新增元素。

**10字标题**

云海之上仙子静立观澜

**20字标题**

云上仙子伫立长桥飞瀑直落云海天地恢宏静谧

**简介**

仙子伫立于云上长桥，静观桥下云海缓缓翻涌，远处薄云轻移，侧方飞瀑直落云间。固定镜头保留完整的空间层次，让安静的人物与自然流动的云水共同呈现宁静庄严的意境。

示例只展示组织方式，不把人物伫立、固定机位、石桥、仙女、瀑布或左右方向设为所有场景的默认；相同元素在不同叙事、构图与空间关系下可以选择慢行或其他合适运镜。没有对应元素时删除整段动作，飞行生物仅在实际存在时加入其定向飞行。标题和简介必须跟随本图实际选定的人物状态，不把伫立写成缓步前行。

## 提示词模块

静态生图只写本图实际选中的结构、空间、尺度链、材质光线及适用排除项；组装与审计见[提示词契约](prompt-contract-and-audit.md)。图生视频使用上方逐图流程，沿用首帧场景，不套静态生图的相机数值装配或投影重算要求；静态生图提示词本身不追加视频速度条款。

## 系列多样性契约

按[构图与调用](composition-routes.md)组合场景、物件和可见观看关系。参考图身份不决定每张复用相同露台、松树或右后背影视角；连续叙事则保留用户明确的不变量。

## 污染与模仿排除

始终排除手机外框、黑边、底部指示条、灵动岛形状、播放控件、字幕、Logo、印章、签名和水印。借鉴生图时，排除参考图中横贯画面或遮挡尺度关系的栏杆，以及克隆屋顶模块、扭曲柱体、不可能的支撑、重复人物和形似UI的开口；局部栏杆可以原创重构。借鉴生图不要复制源图的精确圆环、树木剪影、宫殿布局、人物位置、日落位置或专有装饰；图生视频则保留首帧主体与空间关系，不因本节的借鉴限制改造原图。

## 参考图驱动审计

- 是否明确每张参考的角色，未要求编辑时没有把来源误当修改目标？
- 是否只迁移结构与视觉关系，没有机械复制人物、文字、完整布局或生成错误？
- 是否把普通圆窗、天环、天障等按结构身份分别读取，而非按相似外形误选？
- 人物、材质、尺度和光照是否仍遵从当前用户及共用规则？
- 最终只检查本图实际内容，未为了通过参考图清单补进无关结构？
- 文本设计与真实成图分别验证；主次、连接与空间不足按实际根因处理。
