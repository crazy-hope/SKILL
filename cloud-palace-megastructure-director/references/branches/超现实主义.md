# 超现实主义分支

## 核心承诺

本分支追求参考图中的电影预告片式东方天宫奇观，不把视觉上不可能的悬浮、机械叠层、极小人物、多奇观同框或黑金红金的高反差当作待修正问题。

优先级固定为：

> 忠实原图视觉效果 ＞ 奇观规模与氛围 ＞ 构图完整 ＞ 结构合理性

“忠实”指保留可迁移的视觉语言，不复制某张参考图的完整布局、可识别人物、专有设计、文字、Logo或水印。

## 选择与退出

出现以下任一明确意图时选择本分支：

- 用户说“超现实主义”“原图效果”“照参考图的震撼感”“奇观优先”或“不要改得太合理”。
- 用户要求极密集宫阙、机械般重复屋檐、无明确支撑的悬空天城、极小人物或强烈尺度断层。
- 用户希望巨环、龙柱、瀑布、松树、浮山、群像等多种奇观同时出现。
- 用户要求黑金、朱红、白金与冰蓝云海构成电影预告片式高反差。

用户转而强调真实古建比例、明确荷载路径、材料真实性、桥腹承重或连续尺度链时，切回结构可信分支。只说“修正明显错误”不退出本分支。

## 与结构可信分支的区别

| 项目 | 结构可信分支 | 超现实主义分支 |
|---|---|---|
| 规模来源 | 连续巨构轮廓、跨度、净高、厚度和纵深 | 大量小宫殿、密集屋檐、机械重复与不可能体量共同堆出规模 |
| 悬浮关系 | 展示桥腹、宫基、柱梁、承台和锚固 | 可缺少明确支撑；视觉悬浮和违反重力本身就是奇观 |
| 人物尺度 | 人物连接台阶、栏杆、门洞或柱础，再传递到主构 | 人物可以极小，直接与巨构形成神性尺度断层 |
| 材质逻辑 | 先锁定木构、木石混合或石玉身份 | 先锁定黑金、红金、白金、冰蓝云海等整体视觉身份，不强制木构主导 |
| 奇观预算 | 控制自然锚点和特殊结构数量 | 巨环、瀑布、龙柱、松树、浮山、群像可同时出现 |
| 审计重点 | 主次、承重、连续尺度链和可信材质 | 震撼感、密度、悬浮规模、尺度断层、色彩与预告片氛围 |

## 必须保留的视觉 DNA

1. **极端悬空巨构**：天城、宫基、桥与平台可以横跨云海、倒悬天空或漂浮于深渊，不必解释全部荷载路径。
2. **超高建筑密度**：允许宫阙、塔楼、屋檐、柱阵、桥廊和下构模块成百上千地机械式重复并延伸入雾。
3. **多重奇观并置**：完整天环、盘龙柱、天瀑、巨松、浮山、云峡和人物群像可以在同一画面共同建立神域。
4. **极小人物**：人物是尺度断层和叙事标点，不需要可辨面部或服饰纹样；保持完整人体、自然落地、合理遮挡和一致光照即可。
5. **强烈色彩身份**：优先墨黑/深青屋顶、深朱红结构、旧金雕刻、白金或玉色巨面、冰蓝与亮白云海；用暖金日出或落日制造冷暖分离。
6. **预告片截图感**：16:9宽银幕、深景深、体积雾、瀑布水汽、镜面地坪、暗色檐柱框景、巨大明暗反差和精细概念设计质感。
7. **不可能但完整**：工程逻辑可以退让，指定主体的图形完整度不能退让；例如要求完整天环时必须读成闭合圆环，要求巨桥时不能意外断成薄片。

## 构图配方

每张先选一个主奇观关系，再让其他奇观共同放大它，而不是按数量预算删除：

- `完整巨环 + 对称天宫 + 盘龙巨柱 + 多层瀑布 + 巨松 + 极小人物平台`
- `悬空宫城下构 + 机械叠层 + 红金巨柱 + 瀑布云峡 + 巨松平台 + 极小群像`
- `巨壁/龙纹浮雕 + 大面积空明云域 + 单个极小人物`
- `宫殿瀑布 + 巨门框景 + 云海浮山 + 远方密集宫阙`

构图仍需有一个最先读到的主轴、轮廓或体量关系，但不要求其他奇观安静到消失。对称、压顶式悬空下构、暗檐框景、对岸遥望和高位远眺都可使用；避免平均铺开的地图式鸟瞰，除非用户明确要全域地图感。

## 人物、相机与尺度

- 默认16:9。相机可使用24–28mm广角电影观感，也可按参考图选择长焦压缩；除非用户指定，不必写传感器、默认60m或针孔投影计算。
- 用“极小、完整、远离镜头、自然落地、背影或侧影”表达人物。人物可以只占极少画高，不因缺少三级连续尺度链而放大；未指定身份时可使用匿名古装仙者或混合群像，不为辨认性别、脸部或裙摆细节而放大。
- 人物附近可以有平台、桥边、栏杆、柱础或松根帮助落地，但这些不是证明主构尺度的强制中介。
- 只修复人物畸形、重复肢体、悬浮脚、错误遮挡、光照不一致和明显后贴感。

## 结构、材质与奇观

- 允许视觉上缺乏支撑的浮台、桥、环体和天城；可以用雾、瀑布、云层遮住连接处。
- 允许宫殿模块像机械城市一样高密度复制；重复应形成方向、层级和消失关系，避免随机融化成噪声。
- 不强制桥腹、宫基、承台、锚点或木构荷载路径全部可见。只有意外断裂、薄片化、透视错接或主体不可读才修正。
- 色彩和表面观感可以先于严格材料分类。允许黑金、红金、白金接近幻想科幻边界；仍避免无意的廉价塑料、统一橙色滤镜、白热过曝和无层次死黑。
- 多个奇观可以同时高强度存在；通过中央轴线、框景、明暗或体量差建立观看顺序，不靠机械删减。

## 参考图角色索引

当用户使用本 Skill 所依据的同一组17张参考图编号时，可按以下角色选择最小必要子集：

- 构图与尺度：1、4、10、12、17。
- 天环与框景：4、6、13。
- 宫基下构与垂直高差：2、8、10。
- 巨壁与极简空间：11、14、17。
- 松树和云域关系：6、12、15、16。
- 反面诊断仅限明确错误：7 的薄桥、9 的地图化、2/8 中失去方向和主次的随机融化；不要把机械堆叠本身判错。

编号只在同组参考图身份明确时使用。每次提示词仍须说明各参考图是构图、尺度、色彩或氛围参考，不复刻具体布局。

## 提示词契约

按以下正向结构装配，不插入结构可信分支的承重与投影清单：

1. `Use case: stylized-concept`，单张16:9东方仙侠电影预告片场景。
2. 标明每张输入图的角色：仅作风格/构图/尺度参考，不是编辑目标，不复制布局、人物、文字、Logo或水印。
3. 明写最高优先级：忠实原图奇观效果；保留密集宫阙、机械重复、不可能悬浮、多重奇观与极小人物；不简化、不强制工程现实。
4. 写清本图主奇观、次级奇观、人物落位和观看关系。
5. 写黑/朱红/旧金/白金与冰蓝云海的色彩身份、冷暖分离、体积雾、瀑布水汽和镜面反射。
6. 只排除明显生成错误与画面污染：畸形人物、重复肢体、融化建筑、意外断桥、失控透视、文字、Logo、水印、字幕、手机UI和截图黑边。

不要加入“可见荷载路径”“至少三级连续尺度链”“木构主导”“自然锚点限量”“安静巨面优先”“减少独立宫殿”等与本分支冲突的语句，除非用户当次明确指定。

## 视觉审计

先问四个问题：

1. 第一眼是否达到参考图的压倒性奇观，而不是普通古建或干净概念图？
2. 宫阙是否足够密集、悬浮体量是否足够不可能、人物是否足够渺小？
3. 多重奇观、冷暖高反差、云海纵深和预告片氛围是否同时成立？
4. 指定主体是否完整，人物、栏杆和透视是否没有明显生成错误，画面是否无UI、文字与水印？

以下不是失败：缺少明确承重、机械式叠层、人物像小点、同时出现多个奇观、材质接近幻想科幻。只有这些特征破坏主体可读性、变成随机融化噪声，或违背用户明确要求时才纠偏。

## 常见误判

| 误判 | 正确处理 |
|---|---|
| “宫殿太多，应该简化” | 保留密度；只用轴线、光线和大气整理观看顺序 |
| “天城没有支撑，应该补柱梁” | 保留悬浮；只在主体变成意外薄片或断裂时修复 |
| “人物太小，尺度链断了” | 保留极小人物；只检查落地、遮挡、光照和畸形 |
| “巨环、瀑布、龙柱和松树不能同时出现” | 可以同时出现；用主奇观关系组织，而不是删到只剩一个 |
| “红金黑金不够真实，应改成木石” | 保留视觉身份；只修廉价塑料感、过曝和无层次反光 |
| “机械堆叠本身是错误” | 机械堆叠是本分支的规模语言；只有随机融化、方向混乱才是错误 |
