# 云上天宫：明确巨构与渺小人物的尺度

- 日期：2026-10-19；基线：当前工作台 V10；事前记录；状态：指引修订完成并交付，真实生成效果待验证。
- 用户要求：现在的云上天宫按 V10 的方向生成，强调“巨构震撼、人物渺小”；反馈当前生成未达到这一方向。
- 用户样本：英文结果描述巨型岩柱承托一座单殿，宫殿位于画面上方三分之一区域，仙女用 `a few tiny female immortals` 和衣裙轮廓、小色块表达；没有给出人物占画面高度或建筑相对人体尺度。
- 排查结论：现有服务端已经传递渺小人物与巨构指引，样本也包含这些用词，不能称为要求完全漏传；样本不足以验证真实图片。当前方向对建筑自身的巨构尺度、人物画面占比及二者对照表达不够具体，这是本轮修订目标，不宣称已证明模型失败的唯一根因。
- 范围：工作台题材指引与页面方向提示，规范仍为 V6，应用仍为 V10；保留建筑、山石、云海空间要求及新增神兽灵宠候选。

## 需求与处理计划

| 编号 | 要求 | 修改与验收 |
|---|---|---|
| R-01 | 建筑本身体现巨构震撼 | 单座宫殿也应具有超常体量，通过承重柱、门洞、檐口与人体的尺度关系表达，避免只放大山石；检查指引进入双服务请求 |
| R-02 | 默认人物渺小且可检查 | 未指定人物尺度时，单个人物全身高度以画面高度 1%—3% 为设计目标，由模型选择本方案具体数值；明确区分位置与占比，保留无人和明确尺度覆盖；检查完整输入传递、双语正文落实要求 |

执行顺序：保存修改前文件校验 → 记录需求与计划 → 修改云上天宫指引和页面摘要 → 现有 Node/Python 回归及双服务模拟请求 → 文档与历史保护检查 → 更新索引并交付。

## 实际变化与验证

计划全部完成。成果：[生成指引](../输出/server.py)、[页面方向摘要](../输出/catalog.mjs)。
