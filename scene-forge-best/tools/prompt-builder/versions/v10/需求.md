# 工作台 V10 需求

- 日期：2026-10-16；事前记录；基线：[V9](../v9/README.md)。
- 用户要求：结果弹窗左侧为所有题目标签，点击右侧显示中英文提示词，点击标签默认复制；左右独立滚动。后续补充最多生成 10 个方案。
- 复制默认解释：点击标题复制当前方案完整中英文一对，保留分别复制入口；首次自动显示不改写剪贴板。

| 编号 | 要求 | 验收 |
|---|---|---|
| R-01 | 左侧标题标签、右侧方案详情 | 默认首个，点击切换，仅一个详情可见 |
| R-02 | 点击标签即复制该方案双语 | 剪贴板内容一致；重复点击可复制；失败提示，不伪报成功 |
| R-03 | 左右独立滚动、响应式 | 一侧滚动不影响另一侧；右侧正文无嵌套滚动；手机仍可操作 |
| R-04 | 1 至 10 个方案端到端支持 | 数量输入、请求、历史/备份、汇总和单独下载支持 10；超出上限拒绝 |
| R-05 | 保留输入、适配、历史与版本 | 原功能回归、旧档哈希不变；规范 V6 不变 |

本轮替换结果手风琴交互，旧历史使用新浏览布局但不改写数据。真实模型及出图不属于界面验收；不会因输出多而自动重试计费请求。
