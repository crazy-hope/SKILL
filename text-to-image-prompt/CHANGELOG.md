# 版本记录

## 版本管理规则

- 根目录保存当前使用版本；`releases/vN.zip` 保存完整、可独立恢复的技能快照。
- v1 为首次创建并安装的初稿，按原文件保存，未追改历史内容。
- 交互流程、输出结构或创作行为发生大改时递增整数版本：v1、v2、v3。
- 小修沿用当前主版本，在此按日期追加修订说明；已有发布包不覆盖。需要归档小修时使用 `v2-fix1.zip` 等文件名。
- 大改前保存旧版；完成验证后保存新版、更新 `SKILL.md` 的版本标记，并同步已安装版本。发布包只包含技能与依赖参考文件，不嵌套历史包。
- 恢复旧版时，从相应压缩包取出 `text-to-image-prompt` 目录；核对并备份当前改动后再替换，避免同时安装同名历史技能。

用户明确要求本次仍修改 v3，不升级 v4。原始 `v3.zip` 保留，修订发布包使用 `v3-fix1.zip`。

- 在大类风格后新增一次单独的“具体视觉风格”选择，选项随媒介调整，支持自由选择和自定义。

- 选中场景后建立统一的视觉设计：将风格落实到成像、色彩载体、材质状态、情绪互动及镜头空间关系，三个版本保持同一方向。

验证：[原始 v3 基线](tests/v3-fix1-baseline.md) 已有局部光线、镜头与材质设计，但没有独立具体视觉风格选择；[六种入口测试](tests/v3-fix1-flow.md) 检查新增问题、油画选项、自由选择与旧设置补问；[完整输出测试](tests/v3-fix1-output.md) 检查旧书摊三种拍法的中英细节与视觉一致性。均为文本与对话验证，未进行 Midjourney 出图对照，不证明细节越多越好或某种词序必然更有效。

### 初始 v3

根据试用反馈修改：

- 每条设置问题单独一轮，依次确认风格、文化背景、现实性、画幅、版本、Personalize；已回答项不重问。
- 风格之后新增东方／西方／融合／自由选择／自定义的文化背景选择，落实到地域、时代、服装、建筑与道具，不用单一脸型或装饰符号代替文化环境。
- 将表现媒介与内容现实性分开：电影实拍不再自动代表可以生成奇幻事物。现实世界、写实奇幻、自由选择、自定义均需明确选择。
- 写实人物与环境强调自然人体、皮肤、衣料、实际尺度、接触、重量和光源；现实世界选项排除自动添加的超自然、巨物化、悬浮与塑料人物等设定。
- 六项设置随场景选择、换一批及最终三版一起保留；其余 v2 交付流程保留。

验证：[修改前基线](tests/v3-baseline.md) 重现合并四项提问、未确认文化与现实性便提供幻想场景的问题。[v3 对话测试](tests/v3-dialogue.md) 覆盖连续逐问、换批、主动多项回答、自由选择的范围和条件冲突；[现实性与文化测试](tests/v3-realism.md) 覆盖法国现实题材三个中英详细拍法版本及当代中国写实奇幻五场景。文本与流程检查通过，未进行 Midjourney 实际生图，不保证图像执行结果。

## v2 — 2026-10-31

按用户确认的需求修改：

- 每轮创作先确认风格、画幅、模型版本和 Personalize；当轮已回答项不重问。
- 默认提出 5 个场景，等待用户选中 1 个；支持保留条件换一批。
- 选中场景后，询问“同一瞬间、不同拍法”或“同一场景、不同故事瞬间”。
- 输出选定场景的 3 个完整详细版本，每版先中文再英文，不给精简版。
- 用户输入元素都是硬约束；零输入也可创作；题材、情绪和奇幻尺度保持开放。
- 删除初稿中直接生成、自动跳过设置、不同题材混作最终三版、默认短篇幅等冲突规则。

验证：格式与引用检查通过；修改前基线会直接输出成品并自行决定画幅。修改后完成 [分步流程模拟](tests/v2-flow.md) 与 [两种变化方式模拟](tests/v2-variants.md)：正确等待选择、保留换批条件，并生成两条独立路径各三个中英详细版本。检查范围是文本与交互，不包含真实 Midjourney 生图，也不构成所有可能输入均通过的保证。
