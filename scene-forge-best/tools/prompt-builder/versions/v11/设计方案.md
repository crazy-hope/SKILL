# 十面板设计

用户先选题材与元素，再按需要指定观看方式和风格；所有未锁定细节由模型合理设计，大致说明可选。十主面板外保留负面提示词、文本接口配置和现有结果/历史/下载。

## 数据与兼容

新输入 schemaVersion=2。十个面板及负面字段保存字符串；elementSettings保存按元素名称关联的role/scale/frame/count；designOptions保存exploration（自动设计/随机探索）、selectionMode（全部包含/选配）、allowExtra（布尔）。legacy保存旧场景候选、原视觉偏好和自由度，仅复用旧记录时显示可编辑的兼容输入，不推断原来没有的属性。
新历史保存新结构；旧历史快照保留旧字段与原始值，不添加MJ或9:16等本次新默认。复用时明确迁移；旧场景候选保留候选语义，旧必须项转为新元素。删除元素清理属性；未知属性和密钥丢弃。前后端校验数量、字段、枚举、长度和关联对象。

## 文件分工

core.mjs保留结果/备份/候选兼容能力；brief-v2.mjs专门管理新输入、迁移和序列化；form-v2.mjs渲染十面板，app.js继续负责接口和结果。server.py保留旧请求兼容路径，新请求调用brief_v2.py的验证和独立指令，避免旧02候选语义污染新元素。目录白名单增加前端模块。

## 控制语义

角色与尺度独立；巨大是相对对象尺度，渺小占比是画面投影大小。时间、配色、照明、氛围独立；镜头分景别、角度、视野；表现风格和复杂度独立；构图控制布局，画幅只控制宽高。选中项为明确要求，说明补充动作关系；相互冲突返回澄清。自动与随机仅影响未指定项。不得为尺度参照增加人物；云上天宫人物已启用且未指定占比时沿用1%—3%设计目标。

## 验证

新数据归一化、旧历史真实性、迁移与恢复、删除关联、权限与冲突输入；双文本服务请求完整性；负面清空、目标分流、10条导出回归；桌面和窄屏浏览器操作验证。所有模拟结果标明，真实模型/图片不在本轮验证范围。

新备份使用scene-forge-backup-v2格式，V11同时读取旧v1备份；旧版工作台不会误把新备份当作完整兼容数据而静默丢弃属性。清空03会同时移除旧视觉偏好；清空10会移除说明及全部旧兼容要求，并恢复默认设计自由度。
