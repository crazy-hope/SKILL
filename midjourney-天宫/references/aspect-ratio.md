# 画幅

画幅只定义画布比例与横纵空间，不决定近景、框架、遮挡或镜头。任何画幅都不得强制添加近景框架、裁切构件或凑齐前中后三层；这些关系由已选构图、镜头与随机场景决定。画幅以整数比例参数写在提示词末尾，未指定且允许默认时使用 `--ar 16:9`。

| 画幅 | 空间适配建议（不强制构图） | 适合场景 |
|---|---|---|
| `21:9` | 可利用横向空间展开主体与天域，保留主体可读体量 | 天城天际线、巨壁与云域对置、长桥和无尽柱廊 |
| `16:9`（默认） | 横纵布局均衡，兼容开阔远望或有前景的随机场景 | 通用电影 CG、随机单张和系列 |
| `3:2` | 横向空间略收紧，可减少次要元素 | 平台望宫、桥廊、悬崖侧望 |
| `4:3` | 可利用较充足的上下空间表现主体高度与天域 | 深檐、宫基、建筑开口 |
| `4:5` | 适合纵向尺度与竖向空域；主体和人物位置服从已选场景 | 巨柱、瀑布、水幕、天梯 |
| `9:16` | 可突出纵向延伸，避免不必要的上下元素堆叠 | 峭壁、悬空宫基、天梯、瀑布 |
| `1:1` | 可组织紧凑的大块面与留白，主体位置不由画幅限定 | 神域入口、圆形结构、开阔单体巨构 |

## 规则

- 批量系列默认锁定同一画幅；只有用户明确要求多画幅测试时才逐张变化。
- `--ar` 后只写整数比，例如 `--ar 239:100`，不写小数比例。
- 宽幅或竖幅适配时，按空间容量减少从属元素，保留清楚的主体与尺度关系，不用添加近景框架或裁切构件来补偿画幅变化。
- 不因“宏大”“天城”自动改成鸟瞰；画幅不决定机位。

## 满幅无黑边

- 所有画幅均要求场景内容铺满整个画布并延伸至四边，禁止上下黑边、黑色横条与电影遮幅。宽高比直接用 `--ar` 实现，不在画布内加黑条模拟宽银幕，也不擅自改变用户选择的比例。
- 每张最终提示词在参数前加入一次简短对应描述：中文用“场景铺满画布四边，无上下黑边”；英文用“full-bleed scene extending to all four edges, no top or bottom black bars”。两种语言的末尾参数统一包含 `--no letterboxing`；已有 `--no` 时合并词表。
- 保留电影级写实质感，但不使用要求黑边的正向描述，如 `letterboxed film still` 或“带上下黑边的电影截图”。负面词不单独使用 `black`、`bars` 或 `frame`，以免干扰暗色材质、柱列及真实建筑框景。
- 留白由天空、雾域、水面等场景内容承担；自然暗部与已选檐柱遮挡仍按原构图和曝光保留，禁止黑边不等于提亮画面或移除真实构件。
