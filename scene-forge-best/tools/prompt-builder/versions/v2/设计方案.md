# 工作台 V2 设计

这是已有页面的三项明确交互调整，沿用 V1 Python 服务和完整 V4 规范。

下拉面板由文档级 pointerdown 判断点击位置；只收起不包含点击目标的面板，内部复选不受影响，Escape 收起全部。

在用户点击“保存配置”后，把 OpenAI、DeepSeek 密钥保存在独立的当前浏览器 localStorage 条目；刷新时读取。模型配置与草稿沿用原条目，备份仍采用白名单结构，明确不导出密钥。保存失败保持弹窗并显示失败；新增“清除本地密钥”，删除两个服务商的持久化值及当前内存值。页面说明存储范围。

结果为一列方案行。左侧序号与概括标题可切换展开，右侧中文复制、英文复制不影响展开状态，最右为展开按钮。两个展开入口均有 aria-expanded 和 aria-controls；正文使用 hidden。默认首项展开，点击展开项可收起为全关闭，切换其他项保持最多一项打开。保留全部复制和下载，手机版标题与操作按钮自适应换行。

本轮不更换 API 协议，不改变提示词规范，不调用真实服务商。使用虚构凭据测试本地保存，结束时清除测试凭据。

下载追加：保留“下载全部 .md”；“下载全部（单独）”使用本机 Python zipfile 打包，每方案一份中英文 Markdown。用 ZIP 避免浏览器阻止连续多个下载；接口不调用大模型，不增加 API 费用，不包含密钥。
