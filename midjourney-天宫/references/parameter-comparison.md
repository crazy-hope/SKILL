# 参数对照流程

仅在用户排查提示词服从性、询问默认参数是否合适或要求参数对照时使用。现有默认保持 `--ar 16:9 --raw --s 450 --c 8`，画幅和用户指定参数优先。没有实际对照结果时，不声称降低参数已经解决重复人物或发型问题。

## 先固定基线

选择一张具有代表性的场景，先整理好唯一人物句和必要空间关系。确定基线后，整个参数对照期间固定提示词正文、画幅、Raw 状态、模型版本、参考图片及权重、个性化设置等。若可用，则沿用相同 seed；它只是比较辅助，不保证像素级一致。不要在改变参数时同时重写人物、换构图或换参考图。

使用用户现有参数作为基线；没有指定时使用当前默认。参数对照是待测试候选，不改写 Skill 全局默认。中英文是同一方案的两种可复制表达，实际对照固定使用其中一种语言，不能 A 用中文、B 用英文。

## 第一轮：只改变 Stylize

| 候选 | 默认基线示例 | 唯一变化 |
|---|---|---|
| A | `--ar 16:9 --raw --s 450 --c 8` | 基线 |
| B | `--ar 16:9 --raw --s 100 --c 8` | 只降低 s |

如果用户基线 s 已不高于100，选一个比它低的有效值作为 B，例如50；如果基线低于50，可取0；基线已经为0时跳过降低 s，不制造同值比较。实际交付给出具体数值，不输出范围。

为 A、B 提供正文完全相同的可复制提示词，只有 s 的值不同。正文来自已确定场景，不能以占位符冒充可用方案。未提供场景时先依据用户要求建立场景，缺少必要信息则按当前问卷入口处理。

提交后比较实际结果；没有 Midjourney 提交工具时交付提示词，等待用户出图反馈，不能假装已经运行。**未获得第一轮结果前，不指定胜出值，不把第二轮写成已完成测试。**

## 第二轮：只改变 Chaos

取得第一轮结果并选定更符合需求的 s 后，将它固定。保留其余全部条件，只将基线 c 与较低 c 比较；默认是 c8 对 c0。基线 c 已是0时跳过该轮。

不要把 s450/c8 与 s100/c0 当作单变量对照。若先前参数由用户指定，所有对照都从该实际基线展开。

## 如何比较与记录

- 先看人数、主体与承载位置、必要元素是否保留，再看人物是否符合 F2-V 和所选发型轮廓；V1 不以能否看清发簪或发丝作为成败标准。
- 比较留白、色对比、环境主次以及震撼和寂寥的表现。不要只挑一张最好看的图；查看同批结果，必要时重复同条件生成以观察稳定性。
- 记录“测试条件、实际观察、偏好与尚未验证项”，区分结构问题与审美取舍。参数只是一项影响因素，不承诺消除重复人物。
- 只有获得实际证据并且用户要求更新默认时，才将选定值写回 Skill；单次试验候选不自动成为全局默认。

## 官方参考

[Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize) 说明较低值更贴近提示词、较高值提供更多艺术解释空间；[Chaos / Variety](https://docs.midjourney.com/hc/en-us/articles/32099348346765-Chaos-Variety) 说明该参数影响结果变化程度。参数适用性以用户实际模型及官方说明为准，不写死版本。
