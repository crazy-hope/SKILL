# 云上天宫：按所选对象生成，人物尺度有条件启用

- 日期：2026-10-19；基线：当前工作台 V10；事前记录；状态：指引修订完成并交付，真实模型遵循待验证。
- 用户要求：“默认不能定宫殿和巨岩”；追加：“小人物，也是有条件的，如何选择了人物，那么人物要小，如果没有选中人物，那么就不应该有小人物的描述”。
- 用户截图场景：题材云上天宫、02 叙事场景、03 仙鹤，选简约构图、写实电影感、冷灰色与局部暖光等偏好，数量 3 个方案，其余由模型设计。此组合不应自动补宫殿、巨岩或仙人。
- 排查：服务端题材指引及疏密段此前将建筑与山石作为必须项，默认少量小人物，并强制用建筑和人体对照；页面方向摘要同步了该默认。此次明确要求覆盖这些旧默认。
- 范围：当前工作台 V10 的生成指引、方向摘要、相关检查与工作规则；规范 V6、旧应用与已交付维护记录保留。云海之上、宏大空间、协调配色和简约方向保留，不把历史宫殿场景删除。

## 需求与处理计划

| 编号 | 要求 | 修改与验收 |
|---|---|---|
| R-01 | 不默认指定宫殿与巨岩 | 删除必须出现建筑、山石以及建筑唯一主角的规则；保留可选宫殿场景，由实际选择确定主体；清理疏密段残留强制项 |
| R-02 | 选了人物才启用小人物 | 已选人物或所选具体场景明确包含人物时，才输出人物与衣裙、人体尺度及 1%—3% 默认占比；明确尺度仍优先。未选人物时不添加人物或人体尺度描述，不把“叙事场景”、数量或自由度当人物选择 |
| R-03 | 以所选对象建立画面主次 | 02 仅为画面类型且 03 为仙鹤等具体对象时，围绕所选对象组织画面；宏大与震撼可由主体体量、空间与纵深表达，不预先指定建筑，不自动放大神兽或固定数量 |
| R-04 | 范围隔离与历史保护 | 页面摘要与 AGENTS 同步当前规则；现有候选、其他题材、原始输入、模型适配和历史不变，运行已有回归、双服务模拟请求、SHA-256 与链接检查 |

执行顺序：保存修改前校验 → 记录本轮需求与补充 → 修订现有题材请求测试的旧默认预期并确认失败 → 更新题材指引、疏密提示、页面摘要与工作规则 → 回归及模拟请求 → 记录差异、验证限制与生效步骤。

不新增配置卡片或用户必填项，不用关键词正则对生成结果强行删人，不自动重试或调用真实模型。
