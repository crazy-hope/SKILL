# 工作台 V8 需求

- 日期：2026-10-16；事前记录；基线：[工作台 V7](../v7/README.md)。规范继续使用 V6。
- 用户报告：选择 21 项核心画面、生成 5 条时，模型要求用户选编号、逐条指定组合并补充人数，阻断生成。
- 用户明确选择：多选作为候选，由模型选配出 5 个不同方案。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| R-01 | 02 多选是候选范围，按数量生成方案 | 请求明确候选分配、类型不独立计数；多于/少于方案数均可设计 |
| R-02 | 未指定人数不是数量冲突 | 自由度允许时补齐普通设计；明确数量、另一名及硬性冲突继续尊重 |
| R-03 | 界面解释与生成一致，保留九项及原文 | 02、数量提示说明选配；无新增必填；结果说明选用候选 |
| R-04 | 保持强约束与历史兼容 | 03、明确全部必须覆盖、固定分组不可降级；旧档与规范哈希不变 |

仅调整工作台输入解释与请求约束，不修改通用规范，不扩充元素库。不自动重试付费请求，不以模拟测试证明模型实际效果。
