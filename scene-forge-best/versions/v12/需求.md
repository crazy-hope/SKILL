# V12 题材边界需求

日期：2026-10-29；状态：已完成并交付；事前记录。基线：[完整规范V11](../v11/输出/规范框架v11.md)。

用户要求：“题材应该限定一些元素不会出现，比如我使用了东方奇幻世界题材，应该出现东方的一些元素，而不是西方元素。”

| 编号 | 要求 | 验收条件 |
|---|---|---|
| R-01 | 题材限定文化与世界设定 | 库外对象、人物、建筑及属性均遵守题材边界；未填地域不解除题材文化要求 |
| R-02 | 可见表达与明确融合 | 通过实际采用对象的结构、服饰、器物等体现文化，不仅添加标签；只有明确要求才跨文化融合，按范围分配 |
| R-03 | 保留参考/必需语义 | 不相容参考可舍弃；不相容必需项需澄清；不把共享物体或媒介误作文化排除项 |
| R-04 | 完整成果及工作台同步 | 完整V12、记录、根入口；V15原版本小维护和dist，旧规范/应用/记录不改，实际测试状态准确 |

范围：规范通用边界、V15共享生成指令、题材提示和规范来源。候选库不扩充、不删除；不构建固定文化词黑名单，不改变schema4或存储，不调用真实模型、不出图、不安装或提交。

普通文化创作约束不推定人物族裔、国籍或历史事实。“东方”不一律等于中国、古代、水墨或固定建筑。工作台具体示例只用于解释文化边界，不成为默认必需元素。
