# 提示词契约

最终提示词必须首先建立目标画面，再写排除边界。负面词不能代替构图、尺度和光线设计。

## 正向提示词顺序

1. **用途与画幅**：原创东方天界电影 CG 场景，宽银幕 16:9；用户另有画幅时服从用户。
2. **镜头展开**：通过[镜头语言](camera-language.md)写明相机所在空间、机位高低、观看方向、近景裁切、透视关系与人物承载面，而不是只写“广角”。
3. **主巨构关系**：写连续的东方古建工程巨构、密集区位置、结构厚度、延伸方向和画框裁切。
4. **开放天域**：写天空、云海、云峡、雾域或水庭所占的大面积空间，以及远景如何衰减。
5. **尺度与叙事**：写人物、坐骑、树木或其他尺度标记的大小、位置、承载面和观看关系。
6. **光色与空气**：写选定色彩家族、光线路线、主光方向、色温、曝光、暗部可读、亮部不过曝、平整云海和横向雾带。批量任务在每张提示词中逐字重复同一条色光锁定句，不用近义改写。
7. **渲染身份**：电影剧照式构图、高端影视概念设计、清楚大轮廓、深景深、克制材质反光。
8. **排除边界**：只写最容易偏离当前画面的错误。

## 正向表达配方

使用确定性的画面陈述：

```text
原创东方天界电影 CG 场景，宽银幕构图。[镜头展开句]。[连续巨构]集中在[密集区域]，以[方向]延伸出画框；[开放天域]占据大面积画面，远方逐渐降低饱和度、细节和反差。[尺度标记]自然落位于[承载面]，与巨构形成强烈尺度断层。[批次统一色光锁定句]。低处为平整云海，中景横向雾带遮住部分连接，远景空气透视清楚。静谧、庄严、超现实但稳定，高端电影剧照与影视概念设计质感。
```

不要把随机矩阵整表复制进提示词；每个维度只保留最终选中的一项。

## 批量统一色光句

批量任务先写一条确定性的色光句，并原样复制进每张正向提示词。句子必须同时固定：色彩家族、天空或环境底色、建筑主色、暖色覆盖范围、主光方向、色温、曝光和雾层亮度。

用户未指定色光时必须采用的“明亮仙境”默认句：

```text
整批统一采用朱红暖白天青色彩家族与清晨晴光：清透中低饱和天青天空和浅蓝灰环境填充，中等饱和朱红、赭红木构与深青黑瓦统领连续建筑密集区，宫基、承重圆拱和云海保持有层次的暖白；方向稳定的暖金斜射日光从画面左上方照亮连续建筑立面、宫基和人物衣缘，统一为明亮正常曝光、清澈空气与中等偏高反差，暗部保留深墨层次，白色区域不过曝。
```

用户明确选择“冷青柱光”时改用以下句，并在批量任务中逐字复用：

```text
整批统一采用冷青柱光模式：低饱和冷青、铁蓝灰和雾白构成环境，深青黑木构与暗铜承重柱保持主体；画框外左上方受控清晨暖光只落在主要承重柱朝光面、浮雕凸起和局部弧面，形成柔和琥珀与旧金暗铜反光；深檐、圆形开口、云海、水庭和人物保持冷色与原有曝光，整体不提亮，不使用橙黄罩染、宽幅体积光或柱状光束。
```

## 排除边界

按实际风险选择短而具体的排除项：

- 不要完整宫殿居中陈列、旅游明信片构图或平均铺开的地图式鸟瞰。
- 不要许多大小相近的独立亭阁、全画面均匀密集或随机融化的建筑噪声。
- 不要装饰性发光金环、科幻传送门、霓虹线条或泛滥魔法粒子。
- 不要把“冷青柱光”理解成冷青色柱状体积光或舞台光束。
- 不要电光青、荧光蓝、翠绿树木、通体亮金、全局橙色滤镜或物体各自无关地鲜艳上色；“朱红暖白天青”允许清透中低饱和天青与中等饱和朱红建筑带。
- 不要棉花状云团、白热过曝、无层次死黑、恐怖阴森气氛。
- 不要人物立绘感、悬浮脚、重复肢体、坐骑畸形或人与栏杆粘连。
- 不要文字、字幕、边框、播放器界面、Logo、签名或水印。

## 完整示例

此示例只展示提示词结构，不是默认场景；新的随机结果必须重新抽取空间骨架。

```text
原创东方天界电影 CG 场景，宽银幕 16:9。相机位于一座高空宫廷的深檐转角，左上方被裁切的黑瓦巨檐与粗柱形成不对称近景框架。远方一座正面主宫被工程化为横贯天际的连续古建巨构，宽阔屋盖、柱廊和厚重宫基向左右延伸出画框；细密斗拱与窗格只集中在主宫和近景檐下。中央释放辽阔平整云海与淡蓝雾域，远方建筑逐渐失去细节和反差。下方真实石台路径上，一名背影骑乘者与完整坐骑安静停驻，画面左侧一棵深墨绿巨松向云域伸展，人物、坐骑、松树和主宫形成清楚尺度断层。整体为青黑、铁蓝灰和暖云白，低角度日出侧逆光只照亮檐口、柱边、坐骑轮廓和少量旧金细节，暗部保留结构，云层高光不过曝。低处平整云海缓慢起伏，中景横向雾带遮住部分宫基连接，远景空气透视清楚。静谧、庄严、超现实但稳定，高端电影剧照与影视概念设计质感，深景深，克制反光，清楚大轮廓。

排除：完整宫殿模型居中展示，全画面均匀密集，独立小亭阁堆叠，装饰性发光金环，鲜蓝天空，翠绿树木，通体亮金，全局橙色滤镜，棉花云，白热过曝，死黑阴影，恐怖气氛，人物悬浮或畸形，文字、字幕、边框、界面、Logo和水印。
```

## 提示词审计

交付或生图前逐项核对：

- 是否明确相机所在空间，而不是漂浮的万能广角镜头？
- 镜头是否同时包含机位高低、观看方向、近景裁切、主透视与人物承载面？
- 是否明确一个连续巨构及其延伸方向？
- 是否写出局部高密度区域和大面积开放天域的对置？
- 是否有延伸出画框的结构，而不是完整宫殿陈列？
- 是否有自然落位的极小尺度标记？
- 是否明确冷底暖光、暖色受光范围、暗部可读和亮部不过曝？
- 若启用冷青柱光，暖光是否只作用于主要承重柱的局部材质反光，并明确禁止体积光柱与整体提亮？
- 批量任务的每张提示词是否逐字复用了同一条色光锁定句，并保持同一光向、色温、曝光和天气？
- 是否使用平整云海、横向雾带和远景衰减建立纵深？
- 是否删除未被选中的候选项、来源信息和无关奇观？

任一核心项缺失时先修提示词，不调用生图。
