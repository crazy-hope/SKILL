# 神域聚居地路线

本路线用于设计仙人能在神话尺度下长期生活的地方。先应用[仙侠共享总则](xianxia-master-rules.md)；城市密度和拓扑可扩展，但不得替代尺度、五层空间、内容承载空气、建筑、无栏杆、人物和衣装规则。结果不是历史复原，也不是孤殿漂在云上。

## 路线承诺

优先顺序：

1. **神话创造**：用浮空大陆、公里级云城、垂直九天、悬空交通、天瀑、神树、星河等自洽奇观，使世界现实中不可能。
2. **东方识别**：以飞檐、斗拱、层屋、开放台地、庭院、门、塔、廊、阶、漆木、矿物色、青铜、玉石和克制鎏金表达文明。
3. **电影可信**：统一透视、有动机光线、物理材质、体积云、尺度比较和可读空间连续性。

历史建筑只提供词汇与秩序，不能限制尺度和几何。

## 共享总则继承

- 五层映射为：近景巨型阈境；宽阔居住交通面；一个统领城区或神圣轴线；连通的从属城区；极远聚落、更高天界或终端天空。
- 城区之间、下方、后方和内部保留40–60%内容承载空气，用庭院、街道、门洞、云隙、开放水面、平台下虚空与空气分层实现，不得变成连续屋顶海。
- 至少四项尺度证据，除密度和重复外，还要有成人与柱、门、平台、桥、树、崖或城市轴线比较。
- 平台、桥、阶、廊、露台、街道和云港默认无栏杆。
- 居民默认是1–4%的背面或斜后方成人，动作平静、仙衣结构清楚且风向统一；城市活动可增加微小人群，但不得变成正面肖像或无特征剪影。
- 最大城市结构巨大、安静且承重清楚，精细装饰集中在人物可读阈境。

## 城市层级

以一个统领层级替代单地标：

- 一个主宫区、神圣轴线、城市冠部、神山核心或高位帝宫作为主导体量。
- 两至四个更小或低反差从属城区。
- 大量小屋顶、塔、庭院、开放露台、桥、阶、瀑布和云港作为城市纹理。
- 城区必须以廊、桥、阶、云路、渡台等交通设施可见连通，不能是雾中散落的无关纪念物。
- 改变屋顶高度、平台标高、间距、重叠和朝向，避免盖章式复制。

需要高密度，但不能视觉等权；以层级、重复和连通逻辑减少杂乱，而不是删除城市。

## 世界拓扑

每次只选一种：

- **轴线上升**：门、庭、台和宫区逐级上升到高位天冠。
- **层叠浮空大陆**：巨型空中陆块承载瀑布式城区、崖宫、瀑布和低位云港。
- **悬空群岛网络**：有人岛屿以长桥、飞廊、云渡和仪式道连通。
- **九重天堆叠**：多层居住天域上下悬浮，越高越小、越亮或越神圣。
- **神轴环城**：城区围绕巨树、柱、山、天器、日轮或瀑布轴，不得变成西式科幻巨构。
- **云崖都市**：宫殿依附巨大竖崖，向上下和画外延续。
- **地平宫阙带**：庭塔组成连续横向天际线，横跨云海，适合16:9和21:9。

## 聚居地超宏大门槛

1. 五层完整：近景巨阈境、微小居民承载交通面、统领城区、连通从属城区、极远聚落或更高天界。
2. 成人通常1–4%，只有必须读清全身时用5–8%。
3. 建筑越出侧边、顶部、下层云或地平线，使城市大于画框。
4. 建成世界通常横跨大部分可用宽度，并在近中远都有建筑，不能把一座宫殿孤立于空云。
5. 一个主导体量、两至四个支撑体量和大量小型重复构件。
6. 以廊、桥、阶、台、云路、渡台或水渠式瀑布证明连通。
7. 云位于城区之间、下方和后方，以缝隙和受光边揭示尺度。
8. 约40–60%内容承载空气分布在庭、街、门洞、水、云隙、平台下虚空和垂直城区间。

画面只有一座宫、一扇门或一个平台时，即使写着“天宫”也要改回`单体仙境`。

## 镜头与清晰度

- `繁华压迫`优先远距低机位或人眼高度70–100mm，让密集宫层累积在微小人物之后并位于主巨构下方。
- 桥、阶、门与底部揭示可用远距低位24–35mm直线广角；阈境使用人眼高度35–50mm。
- 低角度也要足够远，以显示完整城市层级；控制垂直汇聚，禁止鱼眼。
- 默认深景深，近景阈境、人物面、主城区、从属城区和终端远景都清楚。
- 只有明确选择`城市总览`或索要鸟瞰地理、城区关系与浮岛分布时才用高位；不得由大全景、云海、浮岛或仙城推断。
- 以缩小、远处降冷和反差台阶制造空气透视，禁止统一灰雾。
- 前景观景台保持从属，常占画面8–15%，不能遮挡主城。

## 繁华压迫

- 下部放微小背影仙人与人物阈境，尺度人物穿结构化仙衣并遵循统一风向。
- 中景填入重叠屋顶、庭院、桥、廊、云路、瀑布、台地、灯点和仪仗。
- 后方或上方放一个统领宫殿、门、平台、墙或神轴，并由顶部或侧边裁切。
- 保留竖向立面、宫基、柱和底部；屋顶覆盖只能证明密度，不能证明压迫。
- 地平线保持低位，城市越过画框和云层继续延伸。

## 自洽奇观密度

加入两至四个相互兼容的不可能系统，而不是随机目录：浮空山体宫城、多层穿云瀑布、连接城区的云阶与悬廊、更高天界或远方神都、融入城市规划的巨树/钟/天器/日轮/玉柱、云港/鹤道/飞舟/光桥/仪仗、倒峰/悬园/空河/发光云渠。

禁止中式屋顶贴在欧洲城堡、现代摩天楼网格、科幻霓虹天际线、游戏地图杂乱或历史宫殿直接贴云。

## 宫殿色彩真实感

用户要求鲜艳时，采用“华彩但不过曝”：

- 朱红漆、矿物青绿、鎏金或铜屋细节、白玉、深木、彩色琉璃和明亮天空可以清楚饱满。
- 饱和度按材质分离，不能把所有建筑缩成强调色。
- 云、浅石和白玉近中性，作为明亮稳定面。
- 暖金只落受光边、屋脊、金属和少量受光平面，禁止全局橙金罩染。
- 阴影保持透明青色、蓝灰、蓝绿或紫灰；远方剪影清楚，禁止浑灰调色。

## 提示词顺序

`画幅 -> 机位高度、距离、俯仰角、焦距 -> 继承尺度证据 -> 五层空间与40–60%空气 -> 不可能居住世界前提 -> 所选拓扑 -> 统领与从属城区 -> 无栏杆连接设施 -> 东方巨构与局部装饰 -> 微小背影仙人与衣装 -> 鲜明材质配色 -> 一个主光 -> 离散体积云和高可见空气 -> 深景深电影渲染 -> 共享与路线不变量`

按城区和深度组织建筑，不要堆长串名词。

## 路线审计

- 是否呈现有人生活的世界，而非装饰性单地标？
- 五层空间、40–60%空气和四项尺度证据是否齐全？
- 近、中、远、极远是否都有建筑？
- 一个主层级是否清楚统领，同时保留从属城区？
- 城区是否可见连通？
- 尺度是否同时来自体量、数量、高度、连续性和微小居民？
- 云是否揭示而未遮住城市？
- 材质色是否鲜明且与光线调色分开？
- 移除人物后，城市是否仍巨大？
- 是否东方可识别但非历史复原？
- 所有边缘是否无栏杆？
- 有人物时，背面角度、比例、动作、仙衣和风向是否明确？
- 繁华压迫时，观者是否低于或处于人眼高度？
- 高位总览是否由用户明确要求，而非从“展示尺度”推断？
