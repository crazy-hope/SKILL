# 文生图提示词规范项目

本项目维护跨题材、跨模型的文生图提示词设计规范。主要成果是每个版本的完整规范 Markdown 文件；需求、计划、变更和验收记录用于追溯每次修改。

## 想生成提示词，从这里开始

双击[启动提示词工作台.command](启动提示词工作台.command)，使用[工作台V15](tools/prompt-builder/versions/v15/README.md)：主界面选择题材、元素等十项条件，支持元素属性及“必须出现”，直接生成完整双语。也可以只在“大致说明”写想法；默认Midjourney、9:16、5对，数量支持1—10。当前采用[完整规范V13](versions/v13/输出/规范框架v13.md)。

纯文本仍可使用[提示词输入模板.md](提示词输入模板.md)的十维与独立负面，也可直接自然语言描述。该模板与当前工作台十维顺序一致；不套用后续五项基调默认。

V1 仍完整保留，既可追溯原始规则，也可对照变化。V2 保留原有详细设计内容，只明确简洁输入入口及分工。V3 进一步明确示例设置不属于全局默认。V4 规定每个方案完整交付中英文各一份。V5 新增预填默认值的负面提示词。V6 补齐五类目标模型官方来源与适配规则。V8 重整十维输入与元素属性，保留独立负面输入。V9新增可选地域及其视觉作用范围，明确Midjourney自然语言表达与效果待验证边界。V10加强画面首句、关系转写、光色与细节归属、正文精简和双语检查。V11改为意图优先、元素参考与必需分离，允许库外主体与人物，条件属性在采用时生效。V12明确题材文化与世界边界，开放创作在题材内展开，跨文化融合需明确要求。V13补充条件负面、人物数量和细节正负表达。V14引入场景与陪衬分工、关系驱动的构思及选择后双语展开。V15按表现基准、逐元素属性和八个叙述职责重构完整展开及文本审校。V16重建五项基调＋主体入口，AI描述可选、手写可直接生成，取消当前选择流程和独立审校调用。查规范时默认阅读当前版本。

## 下一次如何修改

1. 读取工作规则和当前版本。
2. 用户要求修改规范时，默认创建下一个未占用版本目录；当前下一个编号为 `versions/v17/`（v7 已中止，不复用）。
3. 先记录本轮需求和计划，再生成对应版本的完整输出。
4. 检查后填写变更与验收记录，更新本页索引和 CHANGELOG。
5. V1、V2、V3 等已交付版本保持不变；新版本输出是完整规范，可独立阅读。

本页是当前版本的唯一索引入口。根目录不保留第二份可编辑的规范正文。
