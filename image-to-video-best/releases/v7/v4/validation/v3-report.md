# v3 验证记录

日期：2026-10-17。范围为独立Skill的图像分析与自动提示词设计，不涉及工作台升级或真实视频生成。

## 依据与方法

用户要求识别图片可能的风格、题材与融合，再由大模型自动生成符合画面的提示词；随后明确规范与工作台分开。采用完整复制的v3规则包，新增四层分析和自动构思入口，网页不变。

[修改前独立样本](theme-baseline.md)由全新代理仅读v2后完成。A混合古风与科技、B霓虹纪实街景、C毛毡狐狸/纸板森林均已有合理处理，没有观察到“全部套成梦幻流体”的基线失败。本次是明确用户新增的分析维度、融合关系和自动构思交付方式，不声称修复已经证实的分类错误。

[新版独立样本](theme-retest.md)由另一代理仅读v3及必要引用完成，未读基线；D及G实际查看包内原始图片，其他场景明确允许文字设计，E没有图片。人工阅读完整输出，未用标签匹配冒充语义评判。样本使用通用模式，不联网、不调用外部API。

## 场景观察

| 场景 | 本次观察 |
|---|---|
| A 东方幻想、科技、平涂线稿 | 分开题材、融合元素、画风与氛围；织物、机械和宫阙各自采用合理运动/刚性，保留缓慢抬手和固定镜头 |
| B 霓虹街景 | 未仅凭霓虹与反光判为赛博朋克；保留纪实观感和慢速向右横移，未加入故障或未来装置 |
| C 毛毡与纸板 | 保留纤维、软体块、裁切边和暖光，只有轻点头，未套流体或真人皮肤 |
| D 实际原图、简短档 | 根据蓝金水浪、深色长发、体积与反光描述幻想插画观感；保留原姿态和固定镜头，未擅加转身或手势 |
| E 缺图、缺模型 | 请求图片与目标模型，说明通用选项，未假装分析未见图片 |
| F 用户主动要求改画风 | 分开原毛毡/纸板依据和目标平涂二维设计；保留一次点头与固定镜头，并说明首帧转换能力待确认 |
| G 只有实际图片、要求两个方向 | 无需用户先选题材或动作；依据东方幻想、流体与体积反光提出“神态/小幅推近”和“水浪/固定构图”两套独立完整方案，均标明是自主设计，保留图片锚点且没有夸大为已适配模型 |
