# 提示词工作台 V11

状态：2026-10-20 已交付；基线[V10](../v10/README.md)，规范来源[V8](../../../../versions/v8/输出/规范框架v8.md)。

## 使用

双击根目录[启动提示词工作台.command](../../../../启动提示词工作台.command)。如果原工作台服务仍在运行，先在原终端按Ctrl+C，再重新启动；仅刷新网页不会替换Python后端。

1. 题材：选择世界与气质，不自动加入宫殿或人物。
2. 元素：选择每方案要保留的对象；展开“角色与大小”，分别设置角色、相对尺度、画面占比和对象数量。未指定为自动。
3. 视觉偏好：时间、配色、照明、氛围分别选择，也可自定义。
4. 镜头：景别、视角、视野独立；默认自动，提供大远景＋超广角快捷组合。
5. 风格与复杂度：卡通、纪实摄影、电影CG、精细写实、油画等表现方式，与简约、适中、密集分别选择。组合风格可用“自定义…”，如“精细写实＋电影 CG”。
6. 构图：布局与视线组织，默认自动，可自定义组合。
7. 目标模型：新表单默认Midjourney；清空使用通用描述，与右上角文本服务独立。
8. 画幅：默认9:16，支持原比例和自定义。
9. 数量：默认5对中英文，支持1—10；1/3/5/7/9快捷按钮，不代表画面对象数量。
10. 大致说明：新表单预填“光线柔和漫射，空间层次分明，阴影清晰可辨，细节丰富。”，可修改、补充动作与关系或明确清空；“设计自由度”控制自动/随机、全部包含/选配及是否允许额外辅助对象。已有十维草稿的原说明（包括空值）保留；重置条件会恢复默认说明及其他默认条件。

独立负面输入预填原默认，可编辑或清空。默认不额外补人物、宫殿、巨岩；允许辅助对象也不自动授权人物。明确选择与说明冲突时由模型返回澄清。语义规则是给文本模型的指引，尚不能保证实际出图逐项遵从。

## 参考词汇

云上天宫可选星河、银河、星空、星沙、星沙云脊、天际、星枝鹿角、竹青斗篷、交领仙袍、拖地长裙、云髻、素玉簪、披帛、丝带；复用原白鹿、仙女。日出、朱砂红/墨黑/米白配色、柔和漫射光、超远景和侧面高位俯视在对应面板。候选名称不绑定动作、位置或固定故事。

## 历史兼容

旧历史保留原九项。恢复到表单时，旧必须包含映射成元素，旧场景候选、视觉偏好和自由度显示在大致说明下的兼容区，可修改或清空；旧场景仍是候选。旧草稿的明确空模型/空画幅/数量不会强行替换为新默认，点击“重置条件”才使用新表单默认。

保留本机浏览器存储、独立密钥存储、双语结果、左侧标题复制英文、预设、备份、Markdown和ZIP下载。新增属性及设计方式进入保存与下载，密钥不进入这些数据。
