# 成镜 · 图生视频提示词工作台

上传一张图片，填写简短需求，由支持图片输入的多模态服务结合本项目 Skill 生成提示词。支持自动、简短、中等、细致四个选择；默认5秒。页面生成的是提示词和设置建议，不是视频。

## 启动

需要 Node.js 22.13 或更新版本。没有第三方运行依赖，无需 npm install。

在项目根目录运行：

```sh
npm start --prefix web
```

打开终端显示的本机地址，默认 [http://127.0.0.1:3210](http://127.0.0.1:3210)。未配置接口时，页面仍可上传预览和填写需求，生成按钮保持不可用。

## 配置真实多模态服务

点击页面右上角 **配置模型接口**：

1. 选择 OpenAI、DeepSeek 或自定义兼容服务，填写 **API 根地址**。
2. 填写 **API Key**。
3. 点击 **测试连接 / 获取模型**，或直接填写支持图片输入的 **多模态模型 ID**。
4. 点击 **保存配置**。立即生效，无需重启；刷新页面或重启服务后仍保留。

DeepSeek 预设地址为 `https://api.deepseek.com`，预填 `deepseek-flash`。其图片输入与 `image_url` data URL 格式依据 [DeepSeek 官方图像理解文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)（2026-10-17 核查）；图片单边最长8192像素。预设可编辑，未使用真实账号验证。

模型列表测试只请求 `/models`，不发送图片、不调用生成。列表可能包含纯文本模型；列表读取成功不代表已验证看图或JSON生成能力。部分兼容服务不提供此接口，可以手动填写模型 ID 并保存。

- API 根地址会追加 `/chat/completions`。不要填写完整端点、查询参数或嵌入用户名密码的URL。远程服务使用HTTPS；本机服务允许 `http://127.0.0.1:端口/v1` 或 localhost。
- 多模态模型负责看图和编写提示词；创作区域的 Seedance、Runway、Wan 是提示词的目标视频模型，两者职责不同。
- 服务需支持 Chat Completions 中的 `image_url` data URL、多模态输入、system消息以及中文JSON结果。仅名称上“兼容OpenAI”不能保证这些能力；本应用不强制JSON schema、工具调用或联网扩展字段。
- 已保存的 Key 不回显，留空可沿用；更换 API 地址后需要重新填写 Key。清除密钥后，生成会停用，直到再次填写并保存。
- 配置保存在 `web/.local-connection.json`，以本机账号可读写的权限（0600）写入，已加入Git忽略。它是本地明文配置，**不是加密密钥库**；不要复制到公开备份。浏览器不会把密钥放入 localStorage，也不会将密钥写入导出的创作结果。

仍可使用 `.env` 作为初始配置。界面一旦保存或清除，其持久配置优先于 `.env` 中的 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`；清除后不会自动恢复环境文件中的旧 Key。如要恢复由 `.env` 管理，停止服务、删除本机 `.local-connection.json` 后重启。

端口与运行限制仍通过 `.env` 设置，修改这些项目后重启：

```dotenv
PORT=3210
LLM_TIMEOUT_MS=120000
MAX_IMAGE_MB=10
```

`LLM_TIMEOUT_MS` 范围1000—600000毫秒。获取模型列表最多等待15秒；生成超时或截断不会自动重试产生第二笔调用。`MAX_IMAGE_MB` 范围0.01—10MiB，可下调以匹配服务商限制。支持PNG、JPEG、WebP，另设8000万像素上限；浏览器检查可解码，服务端检查大小、编码、格式签名和尺寸，不执行完整图片解码。

页面“接口已配置”表示字段齐全，实际生成能力要在使用时检验。若端口占用，修改PORT；工作台仅监听127.0.0.1，是个人本机工具。

## 使用

1. 上传一张首帧图片，确认预览。
2. 用一句话描述想发生的变化；选择目标视频模型、平台、时长和画幅。
3. 选择自动或明确等级。需要精细控制时展开“再精确一点”，填写氛围、动作、镜头、材质、手势、结尾、声音和约束。
4. 点击生成。结果分为提示词、设计与设置、资料依据；支持复制正文、复制全部和下载Markdown。
5. 修改输入后，旧结果会标记为对应上一次输入；重新生成后更新。遇到互斥要求，模型可以返回待补充问题。

目标时长、画幅是用户需求，是否原生支持由所选平台规则决定；页面不会擅自裁剪图片或把不支持的时长改成可用值。API取消会停止本机等待并尝试中断连接，但不能保证上游尚未处理或计费。

## Skill 与官方资料

首版只读使用 `../v1/image-to-video-best/`，加载 SKILL.md、分级规则、连续性规则、来源核查规范与选中模型的资料卡。版本和文件通过白名单限定，不接受用户提供的任意读取路径。

本版只有**资料快照模式**：核查日期2026-10-17，本次未在线复核。生成API没有浏览工具；应用不会让模型假装访问网页。结果中的版本、日期和来源链接由服务端添加，模型无法覆盖这些元数据。来源是提供给模型的资料清单，不表示逐条结论已经由程序核实。

新增或更新Skill时，应按项目约定创建下一完整版本；当前应用不会自动改写v1，也不会自动切换到目录名更大的版本。

接口实现参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Images and vision](https://developers.openai.com/api/docs/guides/images-vision)，2026-10-17读取。第三方模型是否支持该格式需要实测。

## 数据与边界

图片和需求在点击生成后发送到你配置的服务；在此之前仅在当前页面内存中预览。本地应用不写图片、生成历史或完整请求日志；刷新页面会清空当前工作。上游服务的数据保留规则由该服务决定。

网页提供密钥输入，提交到同源的本机后端保存；GET配置响应仅返回地址、模型和是否有密钥，不返回密钥。静态资源有固定白名单，生成、保存、清除和测试连接接口均检查Host与Origin。它是个人本机工具，尚未实现多用户认证、公开部署或持久历史。
