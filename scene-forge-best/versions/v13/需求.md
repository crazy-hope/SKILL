# V13 默认负面提示词补充需求

日期：2026-10-29；状态：已完成并交付；事前记录。基线：[完整规范V12](../v12/输出/规范框架v12.md)。

用户要求：“还有负面提示词也要进行补充：比如如果有人，不能手脚扭曲，错乱。然后标注只有一个人的时候，不能多人，画面细节要多，等一些常见的负面提示词，你整理后进行补充”。

| 编号 | 要求 | 验收条件 |
|---|---|---|
| R-01 | 整理常见负面要求并实际预填 | 水印、logo、黑边、非预期结构异常、关键细节缺失、乱码及伪影；模板与工作台新建/重置一致 |
| R-02 | 人物与数量条件适用 | 有人才应用人体约束；明确整图单人时排除额外人物；单个元素1人不自动限定全图；方案数不当人数 |
| R-03 | 细节正负分工与风格保护 | 细节丰富落实正向结构、材质与层次；负面避免糊团、缺失；不强制加物件、写实或全图密集，不误伤遮挡、透视及艺术变形 |
| R-04 | 完整交付与数据保护 | 完整V13、V15小维护、生产dist与根入口同步；自定义/清空/旧值保留；历史SHA不变；实际验证状态准确 |

范围：通用规范4.0.1、双语交付与验收，根模板/工作规则/索引，V15默认文案、共享生成指令、规范来源及相关测试。上一轮尺度对比仍为建议，本轮不新增尺度控件。不新增依赖、不出图、不提交；模型能力与参数登记保持原样。

设计假设：用户授权整理默认文案，保留可编辑性。“画面细节要多”作为本轮要补充的表达规则，不把所有未来任务固定为密集风格。既有草稿/预设/历史中已经填写的负面词不自动替换，需重置或手动更新才使用新默认。

预期成果：[完整规范V13](输出/规范框架v13.md)及需求、计划、变更、验收；[V15维护记录](../../tools/prompt-builder/versions/v15/维护记录/2026-10-29-默认负面提示词补充.md)。
