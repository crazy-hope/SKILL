## 如何创作

可以只在第10项“大致说明”写感觉、画面特点或一个模糊念头，其余留给模型。该项新建/重置默认为空；题材、元素都无需先选，十维及独立负面入口保留。

02候选或自定义元素默认是灵感参考，可以采用、转化或舍弃。元素名称旁勾选“必须出现”，该对象才成为逐方案必须项；确定的自然语言要求也有效。点击名称仍能设置人物外观、动作、关系、尺度等；参考对象的属性在采用时生效。必须对象指定的关系目标需要一起明确勾选，确认前原设置保持不变。

允许模型从库外构思主体、人物与空间；明确“无人”“只画静物”“仅这些对象”等条件继续有效。多个方案可以具有不同主体与概念，同时保留必须项；实际设计摘要仅展示最终采用内容。负面可编辑或清空，保留完整双语和1—10个方案。

01题材限定文化与世界设定，库外对象也须相容；东方奇幻世界体现东方造型，不能自行混入西方文化设定。地域留空仍受题材约束，只有明确要求才跨文化融合。冲突的参考可舍弃，必须项冲突需澄清；共享对象和表现媒介不凭名称排除。见[2026-10-29题材文化边界维护](维护记录/2026-10-29-题材文化边界.md)。原始交付记录保留当时V11来源，该次维护来源为V12。

2026-10-29默认负面补充：当前接入V13，新增通用缺陷、有人时肢体、明确全图单人时人数约束；细节丰富落实正向设计。新建/重置使用新默认，已有旧默认、自定义和清空保持原值。详见[维护记录](维护记录/2026-10-29-默认负面提示词补充.md)。

## 启动与旧记录

根[启动器](../../../../启动提示词工作台.command)指向本版。先停止旧服务，再双击根启动器并刷新页面。日常运行使用Python3.9以上和本版生产dist，不依赖npm/CDN。

V15使用schema4、scene-forge-backup-v4和独立scene-forge-workspace-v15。旧草稿、预设、历史及v3备份不迁移、不覆写，也不在V15读取。旧记录仍通过V14查看：停止当前服务后，在项目根运行：

```sh
python3 tools/prompt-builder/versions/v14/输出/server.py --open
```

保持同一浏览器和127.0.0.1:8787来源，才能访问原浏览器的旧记录。两版本不要同时占用该端口。返回新版可停止旧服务再使用根启动器。独立接口配置与密钥沿用，创作备份不含密钥。

每个元素记录presence=reference|required及完整基本属性；新格式导入和持久化严格校验，不把缺失出现语义补成参考。不完整design仍拒绝，损坏存储保留且暂停覆盖。详情见[设计](设计方案.md)。
