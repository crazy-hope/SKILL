# 提示词工作台 V17：充分展开一个画面

日期：2026-10-30；状态：已交付，文档、代码与模拟流程检查通过。基线：[V16](../v16/README.md)；配套[完整规范V15](../../../../versions/v15/输出/规范框架v15.md)。

继续用场景或想法开始，先比较3条短构思，选择后生成1—10对完整双语。新生成逻辑按表现基准、当前瞬间、动作接触、关键对象状态、材料反馈、整体光色、镜头空间、情绪落点展开。每个实际元素的位置、材质与状态、颜色都要进入正文；助手补齐普通设计，不要求用户填写长表。

首段明确本次媒介、年代/类型参考、光学质感和逐对象呈现要求，全文保持一致。幻想设定可以采用实拍级材料表现；电影、年代、雨天、人物或画幅不作为其他任务默认。十维精修、参考/必须、地域、负面清空与目标模型规则保留。

## 生成与检查

完整生成通常进行两次文本API请求：先展开，再独立审校。审校10项为表现基准、逐元素属性、约束、双语、当前画面、关系、材料、光线、镜头、情绪；要求引用双语正文真实证据。失败保留输入，提示问题，不保存成功历史、不自动循环重试。时间与用量相应增加，界面在生成前说明。

审校只评价文本，不修改正文；结果中的检查记录保存到历史、备份和下载。它仍是模型判断，不能保证图像或真实模型执行。当前仅模拟验证流程，真实模型质量和实际出图未执行。

## 运行与数据

双击根[启动器](../../../../启动提示词工作台.command)。已有服务先停止再启动，刷新页面。也可在项目根运行：

```sh
python3 tools/prompt-builder/versions/v17/输出/server.py --port 8788 --open
```

保持原地址/端口才能读取同一浏览器存储。V17沿用V16的schema5、scene-forge-backup-v5及scene-forge-workspace-v16，草稿、预设、历史不需要迁移；旧结果保留原规范、内容及未审校状态，不追补。两版共享同一数据存储，删除/恢复操作作用于这份共享数据。V15/v4及更早仍不读取，使用原版本查看。独立接口配置与密钥沿用，密钥不写入创作备份。

React/Ant Design/Vite及Python继续使用；生产dist供日常运行，不需npm/CDN。本轮复用V15已有node_modules，不安装依赖、不提交Git、不发布外部项目。
