# 提示词工作台 V2

基于 [V1](../v1/README.md)，继续使用 [规范 V4](../../../../versions/v4/输出/规范框架v4.md)。八项卡片、题材联动、双语生成、预设及历史保持兼容。

## 使用

1. 若旧工作台服务还在运行，关闭对应启动终端或按 Control+C。
2. 双击根目录 [启动提示词工作台.command](../../../../启动提示词工作台.command)，打开 `http://127.0.0.1:8787`。Python 3.9+，无第三方依赖。
3. 右上配置 OpenAI / DeepSeek，填写 Key 与支持 Chat Completions + JSON 输出的文本模型 ID，点击“保存配置”。
4. 选择八项条件。面板内可连续多选，点击面板外自动关闭，Escape 也可关闭。
5. 生成后显示方案列表：左侧概括标题，右侧复制中文、复制英文和展开按钮。默认展开第一条，展开其他条目会自动收起之前的条目。折叠状态也可直接复制。
6. “下载全部 .md”下载一份汇总文件；“下载全部（单独）”下载 ZIP，里面每个方案一份 Markdown，文件名含序号和标题，每份都含中文与英文。

继续支持复制全部、整条复制、历史恢复、预设和 JSON 备份。

## 密钥与历史

V2 按本轮用户明确要求，使用独立 localStorage 条目 `scene-forge-api-keys-v1` 保存两个服务商的密钥。刷新与关闭后重开同一浏览器地址仍可恢复。点击“清除本地密钥”清除两个服务商的本地值和当前页面内存值。

本地存储范围是当前浏览器配置文件与地址/端口，不是加密保险库；更换浏览器、端口或清理站点数据需要重新配置。密钥不写入项目文件、日志、方案历史或导出备份。存储失败会在配置弹窗说明，不能假定已保存。浏览器保存数据容量限制与 V1 相同。

原有草稿与历史继续读取 `scene-forge-workspace-v1`，不会因升级清空。应用升级不修改规范 V4，已交付应用 V1 保持原样。
