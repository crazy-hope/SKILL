# 画面工作台 V18

日期：2026-10-30。基线应用V17；配套完整[规范V16](../../../../versions/v16/输出/规范框架v16.md)。新界面、输入数据与生成流程已重新创建，文档、代码、模拟浏览器及独立审查已完成。真实文本模型与实际出图未执行。

## 使用

停止旧工作台对应终端中的服务，再双击根目录[启动提示词工作台.command](../../../../启动提示词工作台.command)。默认打开 `http://127.0.0.1:8787`。保留终端运行；停止使用时按Control+C。日常只需Python与已构建dist，不依赖npm或CDN。

1. 页面直接展示画风题材、色彩、镜头机位、情绪、瞬间状态五段指定原文；每段可编辑或清空。
2. 在“主体内容”手写画面，或点击“AI描述主体”让模型按当前五项细化。主体也可留空交给AI构思；AI只填主体，可编辑及撤销。
3. 点击“生成完整提示词”，直接得到完整中文与英文；默认1对，可选1—10对，分别复制或下载全部Markdown。

五项是实际约束。当前默认中的人物、花瓣、雨与长纱在未修改时也参与生成；换题材时修改对应段落，冲突由模型提示。恢复五项默认保留主体与辅助设置；“新建输入”重新预填整份输入，历史保留。

不再提供元素选择、十维精修、地域按钮、场景方向或三选构思，不调用独立审校。每次AI描述或最终生成各一次文本请求；没有自动重试。API失败/截断/无效结果不存成功历史，编辑期间的过期响应也不会覆盖新输入或进入历史。

## 设置与记录

右上角接口设置支持OpenAI/DeepSeek文本服务、模型ID、读取模型列表与独立密钥保存。目标图像模型在创作区单独填写，默认Midjourney；清空/未知采用通用自然语言，多个家族先澄清。接口采用现有Chat Completions JSON协议，具体账户与模型兼容性需实际使用验证。

草稿自动保存，历史保留最近30次成功生成。记录与备份支持查看历史、复用输入、导出及恢复v6备份。恢复明确替换当前草稿和本版历史；损坏存储暂停覆盖，可导出原始记录或恢复有效备份。备份不包含API Key。

创作协议schemaVersion=6、scene-forge-backup-v6、scene-forge-workspace-v18。旧V17/V16/v5与更早数据不读取、不迁移、不删除，通过旧版本查看。接口配置与密钥沿用独立存储项；在相同浏览器和地址端口下恢复。
