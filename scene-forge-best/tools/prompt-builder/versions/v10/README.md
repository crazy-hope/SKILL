# 提示词工作台 V10

日期：2026-10-16；已交付。基线：[V9](../v9/README.md)。继续使用 [规范 V6](../../../../versions/v6/输出/规范框架v6.md)。

## 结果弹窗

左侧列出所有方案标题标签，右侧显示当前方案的完整中文与英文提示词。左右各自上下滚动，互不带动；中文和英文在右侧纵向排列，正文不再另套滚动条。默认显示第一条。

点击标题会切换详情，并自动复制该方案完整英文提示词。再次点击当前标题也会复制；首次打开仅展示，不自动改写剪贴板。复制状态单独提示，右侧保留“复制中文”“复制英文”和“复制中英双语”。浏览器拒绝复制时提示手动选择文字，不伪报成功。键盘激活标题按钮也有效。

顶部继续支持复制全部、下载全部 Markdown、下载全部（单独 ZIP）。输入、规范 SHA-256 与目标模型来源位于右侧底部，可展开检查及恢复输入。

## 最多 10 个方案

数量现在可选 1 至 10，每个方案仍是完整中英一对。请求验证、历史、备份和独立下载全部支持 10 个；超过上限拒绝。上游输出被截断或少于请求数量时仍显示失败，不冒充成功、不自动重试。

备份导入上限调整至 320 MB，以容纳新的每批上限；不代表浏览器本地存储能保存如此大的内容，原有存储失败提示仍保留。无需新增依赖。

## 哪些必填，未选时如何处理

“题材”和“想画什么”至少填写一项，其余项目不要求逐项选择。接口生成另需在右上角配置文本服务商、模型 ID 和 API Key。

| 输入 | 是否必填 | 未选择或清空后的含义 |
|---|---|---|
| 01 题材 | 与 02 至少填一项 | 从具体画面理解题材，不随机勾选库里的题材 |
| 02 想画什么 | 与 01 至少填一项 | 依据题材与其他要求设计；多选默认作为候选按方案数选配 |
| 03 必须包含 | 可不选 | 无额外必须项，不等于画面没有对象；选中后每个方案都必须保留，除非明确限定某方案 |
| 04 视觉偏好 | 可不选 | 结合内容设计视觉方式；没有统一的简约默认，题材可能带自身方向 |
| 05 画幅 | 可不选 | 由模型建议合适画幅，不固定随机比例，也不代表已配置出图平台尺寸 |
| 06 目标模型 | 可不选 | 通用自然语言、待适配，不自动套用 Midjourney；独立于右上角文本模型 |
| 07 数量 | 有默认值 | 默认或重置为 1 个方案，即中英文各一份 |
| 08 创作自由度 | 可不选 | 默认“其余由你设计”；清空后普通缺省设计仍由模型补齐，不可改动明确要求 |
| 09 负面提示词 | 可修改或清空 | 初始预填“不要有水印，不要有logo，不要有变形，不要有空白黑边”；明确清空则不添加默认负面要求 |

“由模型设计”不等于程序随机抽库，也不保证多次生成完全相同；留空也不等于禁止出现。若要无人，请明确选择“无人空景”或写“无人”。模型只接收已填输入、完整规范和适用方向，不接收全部候选库。

## 想要比较空、简约的画面

1. 在 02 选择“空旷与简约场景”，或自填一个简洁的主体和环境关系。该组包含单一主体、空旷主要景物和无人空景三种组织方式。
2. 03 可留空，只勾选确实不可遗漏的对象。内置选项现只保留名称，例如“中国龙”“青鸾”，不再附加天门、飞行动作或其他场景对象。具体动作与关系可在 02 或自定义要求中明确，也可交给模型按自由度设计。
3. 在 04“构图与疏密”选择“简约构图”“大面积留白”或“背景低细节”。希望本批每个方案都简约时，在 04 设置；仅将简约场景放在 02 多候选中时，模型可能采用其他候选。

留白是画面内低细节空间，可以是云海、天空、水面、暗部等适合本题材的区域，不强制白底，不等于画布外的空白黑边。宏大主体仍可以搭配简约构图。已有必须项过多时，应先自行删减不再需要的选择；工作台不会静默删除硬要求。

内置旧描述在当前草稿载入、预设使用或历史输入恢复到新表单时，按完整条目映射为名称，同名项合并；仅去掉这些内置条目预设的描述，不删除不同对象。原预设存档、已生成历史的输入与结果保留原文。自行输入的数量、位置、动作、括号说明保持原样；旧名称仍可用于搜索新候选。
