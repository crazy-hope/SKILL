# 云宫巨构视觉导演

围绕一个具有清楚主次、可见承重与连续尺度链的东方仙界空间进行创作。主构可以是单体或复合系统；宏伟来自跨度、净高、厚度、纵深与真实尺度参照，不靠堆叠小宫殿或单独缩小人物。

## 四层分工

| 层级 | 解决的问题 | 入口 |
|---|---|---|
| 共用规则 | 人物、透视、镜头、尺度链、光照、维护与交付 | 下方条件读取表 |
| 场景库 | 物件在哪里、如何连接、内外和高差如何组织 | [场景总览](references/scenes/场景总览.md) |
| 物件库 | 桥、宫殿、松树等如何成形、细分类、承重、材质与尺度接口 | [物件总览](references/objects/物件总览.md) |
| 构图与调用 | 相机从哪里看、如何随机组合、怎样判断变体真的不同 | [构图路线](references/composition-routes.md) |

“路由”只表示按任务找到该读的文件，不是预设图像模板。先按需求选空间，再选实际物件与观看关系；不要加载整座资料库或把候选列表复制进提示词。

## 规则优先级

当前用户明确要求 → 当前实际选中物件的专属规则 → 共用默认 → 场景变体与命名示例。专属规则只处理它负责的参数；例如完整天环影响入画方式，不自动改变人物身份、相机状态或设置人物画高。

- 默认画幅为16:9。启用人物且未指定性别时为成年中国仙侠仙女；用户要求无人、男性或群像时遵从指定。
- 默认仙女服饰采用曳地长裙、明显长拖尾与轻纱飘逸层次；启用仙女时读取[服饰与裙摆规则](references/objects/人物与近身参照.md#仙女服饰与长裙摆)，用户明确指定其他服装时优先遵从。
- 核心规则：禁止随意预设人物占比，但允许并要求根据已锁定的相机参数推导投影；首次生图前完成空间与投影检查。
- 人物大小由真实体型、姿态、空间落位和相机投影决定；没有脱离这些依据的默认百分比、档位或像素目标。每图按[空间与投影预检](references/scale-and-space-rules.md#首次生图前的空间与投影检查)计算并记录本图投影，再用连续尺度链核对空间；没有“先生成、再缩人”的默认步骤。
- 默认相机状态为全画幅、实际焦距20–35mm内选定一个具体值；有人物时，相机至主要人物的距离默认60m。传感器画幅、焦距mm、拍摄距离m分别记录，不混为同一参数；无人时人物距离不适用。用户明确指定时逐项覆盖，细则与选项见[相机状态](references/scale-and-space-rules.md#相机状态画幅焦距与拍摄距离)。
- 人物优先侧面、背影；建筑机位与人物身体朝向分别安排，尽量避开人物正前方±45°扇区，具体角度定义及用户例外见尺度规则。
- 用户未指定建筑材料时，先锁定木构主导、木石混合或石玉主导之一，再组织物件；宏大不自动等于石构。普通随机云宫优先把木构主导与木石混合纳入候选，批量覆盖规则见[构图路线](references/composition-routes.md#随机与多图差异)。
- 使用真实古建参考、要求借鉴古建结构与漆色，或随机云宫需要选择古建源型时，按[真实古建转译](references/真实古建转译.md)把参考拆成`真实古建骨架 → 巨构尺度变换 → 仙界空间`；参考只提供建筑基因，不能直接复刻现实景区或把普通比例宫殿贴到云上。
- 共用规则只在其归属文件维护，物件和场景不得另设全局默认。普通圆窗、结构天环和镂空天障是不同物件，不按“圆形”混用规则。
- 本 Skill 不把一次诊断当成无限重画授权。仅在用户要求生图时生成；只要求解释、改 Skill 或检查时，不自动生图。
- 图片生成或修订完成后，先验图、归档并展示成图，再询问是否生成图生视频提示词及配套10字标题、20字标题和简介，等待用户明确确认后才生成。未确认时不编写、展示或保存这四部分文案，不把图片交付与文案交付捆绑；确认范围与后续流程见[图生视频提示词生成与交付](references/reference-image-megastructure-standard.md#图生视频提示词生成与交付)。这不授权自动生成视频或把文案叠加到画面。

宽大主殿、深殿、多层宫廷与宫船的体量要求在[宫殿](references/objects/宫殿.md)维护；选择这类物件时检查横向体量、主次、檐基重量、净跨与实际楼层。不要把层数正确等同于宫廷有气势。

“单一连续巨构”用于用户要求简洁、建筑不要小而密集、无边体量等情形；按[建筑与材质中的模式规则](references/architecture-and-materials.md#单一连续巨构模式)执行，不把所有随机场景改成同一种露台。

## 导演流程

1. 提取本次明确要求、排除项、参考图角色与工作类型；区分改图、借鉴、诊断和新生图。
2. 选择空间关系：写清承载面、主构位置、连通路径、高差与终景。现有场景可组合或扩展，不受旧十条路线限制。
3. 为实际物件选择构造细类，落实可见的支撑、厚度、净跨和净高；不把可选物件全塞进画面。
4. 以人尺度使用细节或其他已知参照起链，至少连续显示三级，标准巨构优先四到五级；相邻尺度、接触、遮挡和透视一致。
5. 分别锁定传感器画幅、实际焦距mm、相机—人物距离m与相机—主构距离，再安排对建筑的方位、高度、俯仰及人物朝向和落位。首次生图前完成空间与投影预检，记录有效成像尺寸、真实体型与姿态假设、投影结果及承载面/相邻参照核对；有冲突先调整未锁定的空间安排并重算。机位必须能由成图可见面验证，不以角度或相机数值标签自证。
6. 先锁定结构材质身份，再锁定与构件相容的配色、维护状态与光线；木构路线明确柱—梁—斗拱—深檐，石材只按所选身份承担台基、地坪或主体。触发古建参考转译时另记录古建源型、至少三项可见巨构化操作及仙界空间证据，并把漆色、瓦色、石色和环境光色分开。装饰服从结构，大面保持清楚；采用共用柔和光照池，不另造路线默认。
7. 随机多图先比较空间骨架、物件形态、结构材质身份、色彩身份与观看关系，避免整批石质化，也避免只换颜色、镜像或改人物位置。符合条件的三张及以上普通随机云宫按构图路线覆盖空旷木构宫廷；连续叙事允许有意重复空间与材料。
8. 把预检推导出的投影大小与落位约束写入第一版提示词，再做文本审计；只包含所选内容和适用排除项。预检完成后才首次生图，按归档规则建独立批次文件夹；生成后另做视觉检查与文件验证。
9. 纠偏对应实际根因，不因人物较大就缩人，不因一次偏差重做整批；剩余偏差如实报告。
10. 先交付成图和图片路径，再询问是否需要图生视频提示词、10字标题、20字标题及简介，并结束本轮等待回复；不在询问的同一轮先生成文案。用户明确不要时不再询问。
11. 用户确认后，仅为确认的图片生成配套文案：按场景独立选择运镜及人物伫立或慢行状态；只有选中行走时才安排步态、方向与短位移，人物动作和5秒时长都不决定镜头必须前推。按[视频流程](references/reference-image-megastructure-standard.md#图生视频提示词生成与交付)编写连续覆盖全片的秒级时间段，再生成、核对标题与简介并逐图归档、展示。用户直接请求已有图片的视频文案时进入本步骤，不重新生图或补造相机数值；明确不要的项目跳过。

## 维护原则

新增物件时扩展其构造专题；新增场景时描述空间组织，不重复人物、光照、尺度或归档默认。已有聚合参考文件保留为导航或共用规则来源，旧路线编号只作兼容检索。修改数值、默认或专属结构要求须有当前用户依据，不能借文件重构暗中改变。
