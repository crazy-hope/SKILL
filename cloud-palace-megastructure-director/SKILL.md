# 云宫巨构视觉导演

围绕一个庞大、连续的建筑事件，以及与之开放连通的天界外部空间，导演明亮的东方仙侠环境。尺度来自可见的比例关系、裁切、重复和距离，而不是堆叠形容词或罗列许多小建筑。

## 必读参考

满足相应条件时，必须完整阅读以下参考文件：

1. 每项任务都要阅读[参考图视觉基因](references/reference-derived-visual-dna.md)。
2. 每项任务都要阅读[尺度与空间规则](references/scale-and-space-rules.md)。
3. 只要提供了参考图、以截图为灵感，或请求提到巨柱、结构性天环、镂空天障、悬空宫基、深檐、长廊、宫殿配色或多图系列，就要阅读[参考图巨构标准](references/reference-image-megastructure-standard.md)。
4. 只要参考图或请求涉及`青绿彩画`、`朱青`、`石青石绿`、`彩绘斗拱`、`彩画梁枋`、修复复原色、包浆、风化漆面、彩色长廊或朱红宫门，就要阅读[传统建筑彩画配色](references/traditional-polychrome-palettes.md)。
5. 选择或改变建筑、松树、瀑布、浮雕、色彩或材质时，阅读[建筑与材质](references/architecture-and-materials.md)。
6. 创建、衍生、变化或诊断构图时，阅读[构图路线](references/composition-routes.md)。
7. 返回提示词或调用图像生成前，阅读[提示词契约与审计](references/prompt-contract-and-audit.md)。

## 工作模式

- **创建**：把简短想法扩展为一幅经过导演的场景。
- **衍生**：保留视觉基因，同时改变至少一个或两个主要模块。
- **诊断**：找出尺度、开放性、简洁度或氛围失败的原因，再修正源头。
- **变体**：给出空间事件真正不同的方案，而不是只替换名词。
- **直接生图**：仅在用户明确要求生成图像时调用图像生成。

## 参考图处理

把每张参考图标记为编辑目标、构图参考、建筑/材质参考或氛围参考。提取可迁移的几何关系和材质表现；不要复刻完整源画面。

截图界面绝不是视觉基因：排除手机外框、黑边、灵动岛形状、播放控件、音量浮层、字幕、Logo、印章和水印。参考图中的栏杆不能覆盖本世界默认无栏杆的规则。

## 参数锁定

开始导演前，记录明确输入：

- `画幅比例`：`16:9`、`21:9`、`4:3`、`3:2`、`4:5`或`9:16`；默认`16:9`。
- `空间尺度`：`史诗级`或`超宏大`；巨构请求默认`超宏大`。
- `主巨构占比`：通常占画面50–80%，并进行有意裁切。结构性天环例外：完整外轮廓必须收入画面并保留呼吸空间，宏大感由远景尺度对比、支撑跨度和空间层级建立，不能靠贴近镜头或把圆周裁出画框。
- `开放云域占比`：通常占35–55%，并与前景阈境直接连通。
- `空间事件`：从`composition-routes.md`的10条路线中只选择一条。用户点名场景时服从指定路线；用户要求随机、未指定场景或直接生图时，从10条路线等概率抽取并记录路线名。多图请求采用不放回抽取，同一批图不得重复路线。
- `结构事件`：允许锁定为`无`。只有用户点名某个结构，或抽中的空间路线本身要求半幅巨柱、结构性天环、悬空镂空天障、悬空宫基或无尽深檐长廊时，才加载对应结构事件；其他路线保持`无`，不得额外附加天环或天障。选择悬空镂空天障时，只能锁定圆形或方形之一；方形边线必须与建筑水平轴、垂直轴平行，不得旋转；所有可见开口必须服从同一几何家族。
- `机位`：分别锁定高度、距离、俯仰角和焦距。结构性天环必须使用远景或超远景机位，让完整圆周、支撑体系、人物与从属宫阙同时可读；禁止近景环体特写。
- `建筑模块`：一个主导的连续巨构；最多两个从属体量。
- `自然锚点`：零个或一个巨松、瀑布、悬崖或云河。
- `人物尺度档`：在组装最终提示词或直接生图前，提供四档供用户选择和确认：`0.5–2%｜极远尺度标记`、`2–4%｜强巨构尺度`、`4–8%｜标准巨构（默认）`、`8–12%｜人物叙事增强`。用户不选择、明确要求直接执行或不再确认时，采用默认档并在`4–8%`内随机锁定一个具体画面高度占比。
- `人物`：数量、选定尺度档内的具体画面高度占比、背面或侧后方角度、平静动作和一个统一风向。随机值必须落成一个明确百分比并写入参数锁定，不能只把区间原样写进提示词。
- `人物镜头距离`：人物是巨构比例尺而不是主体。镜头必须离人物足够远，使人物全身很小但轮廓可辨；人物必须真实站立或行走在建筑平台、桥面、台阶或柱础旁，与建筑共享同一地平面、消失点、透视缩放、光照方向、接触阴影、遮挡关系和大气层级；不得使用人物近景、半身像、肖像构图或后贴人物。
- `连续尺度链`：固定为`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`；其中“当前主导巨构”替换为抽中路线的屋檐、柱廊、宫基、云崖露台、巨型开口、瀑布、浮雕墙、巨柱、天环、天障或长廊之一。人物一级不可省略；每幅至少从人物起连续显示其中四级，优先显示完整五级，并让相邻层级的大小、距离、遮挡与透视递减相互一致。
- `人物运动`：默认站立、观看、轻缓转身或缓慢自然行走；快走、奔跑、冲刺和匆忙手势必须由用户明确要求。
- `镜头运动`：动画或视频默认固定机位，或带轻缓起步和收束的慢速恒速推移/环绕。镜头运动与世界运动必须分别锁定。
- `光照时段`：从`日出`、`早晨`、`落日`中锁定一种，默认`早晨`。日出与落日使用低角度侧逆光和冷色天空填充；早晨使用柔和清透的斜侧光。若用户明确要求中午或下午，只能采用云层漫射、柔化侧光和受控动态范围，禁止刺眼直射。
- `光照强度`：锁定太阳高度、主光方向、阴影软硬、高光上限和天空填充。巨大结构、人物、云层与浅色石材都必须保留纹理，不得被过曝白光吞没。
- `材质与色彩`：木材、墙体、柱、屋顶、石材、金属、中性基底、强调色和阴影色。
- `维护状态`：默认洁净、完整、长期有人维护；允许自然材质变化和轻微使用痕迹，但不允许锈斑、锈水、腐蚀孔洞、剥落金属或废墟感。
- `宫殿配色体系`：纯白、朱红、古金、红金、白金或传统矿物彩画；若选择彩画，还要锁定一条子路线和一个风化等级。
- `彩画落位`：把朱红、石青、石绿、群青、赭色、象牙白和旧金绑定到明确命名的建筑构件；绝不把颜色铺成全局彩虹。
- `参考图角色`：编辑目标、构图参考、建筑/材质参考、氛围参考或仅作排除参考；绝不省略标注。

## 导演流程

1. 锁定场景承诺和参考图角色。
2. 提取可迁移的几何关系、承重路径、细节密度、材质表现、氛围和光线。拒绝截图界面、源图文字、印章、水印和源图特有布局。
3. 先锁定一个主导空间事件。用户要求随机、未指定场景或直接生图时，从10条构图路线等概率抽取；多图采用不放回抽取。只在抽中路线或用户指令需要时加载匹配的结构事件，否则明确记录`结构事件：无`。
4. 让主导结构连续、有支撑，并按所选事件决定裁切。屋顶、巨柱、宫基和天障可延伸出画框；结构性天环必须完整收入画面，圆周不得被画框截断，最多只能被纤细支撑、云带或桥线轻微遮挡且仍能一眼辨认完整圆形。
5. 映射完整五层空间，并保留40–60%的内容承载空气。
6. 让前景在视觉和物理上直接连通外部云域；只能透过墙洞看见的景色不算开放空间。
7. 加入至少四个可量化的尺度证据，并按`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`建立连续尺度链；把“当前主导巨构”替换成抽中路线的实际结构。人物一级不可省略，至少从人物起连续显示四级。
8. 先提供四档人物尺度供选择确认；确认后，在所选区间内锁定一个具体占比。用户不选择、明确要求直接执行或不再确认时，默认从`4–8%`随机锁定一个具体值。
9. 执行模块预算：一个主构、最多两个从属体量、零个或一个自然锚点。
10. 使用人眼高度或更低的远距离机位，让人物保持微小全身尺度，并让建筑以明显比例断层压过人物。人物必须落在真实承载面上，与建筑共享地平线、消失系统、光照、投影、遮挡和大气递减；同一深度的人物大小一致，越远的人物按透视连续缩小。只有用户明确要求展示地理布局时才使用高机位。
11. 默认保持人物平静：静止、慢走和小幅有意图的动作。不要把冲击力、能量感或紧凑节奏转译成匆忙的人物运动。
12. 对运动提示词，保持镜头运动与人物、云、水、布料及建筑运动相互独立。推镜只能改变视差，不得加速、倍增、时间重映射或变速世界空间中的运动。
13. 选择传统矿物彩画时，把每种颜色绑定到结构构件，区分建筑颜料与天空或植被，并选择复原、生活使用或岁月包浆等级。
14. 把深斗拱、浮雕、彩画纹样和鎏金集中在承重带或人物可识别的细节带；让巨大表面保持安静且结构清楚。
15. 只执行当前路线的结构规则：抽中结构性天环时，通过完整远景轮廓、数百个身体宽的直径和连续尺度链证明尺度；抽中悬空镂空天障时，只使用圆形或方形中的一种几何家族，以一个主开口为主，从属开口同形且规整。未抽中这两条路线时，正向提示词、负面约束和尺度链都不得提及天环、圆环、天障、屏障、圆孔、方孔或菱形。
16. 从日出、早晨、落日中锁定一条光照路线，明确低到中低太阳高度、斜侧主光、柔和阴影、冷色天空填充与可读高光。中午或下午只有在用户明确要求时使用，并必须通过云层或大气漫射降低直射强度。
17. 制作系列或一次生成多图时，对构图路线执行不放回抽取；每张图路线不同，并至少再改变结构事件、镜头、配色、光线、裁切、自然锚点和人物动作中的两项。每条提示词只描述当前抽中的路线和结构，不罗列其他候选场景。
18. 回答或生成前运行完整审计。

## 不可妥协的结果

完成画面首先应读作一个位于云上或云中的巨型东方建筑事件，其次是开放天界，最后才是装饰细节。画面绝不能读作密集幻想城市地图、封闭院落、屋顶海或小宫殿集合。

除非用户明确要求栏杆，所有平台、露台、桥梁、台阶、廊道、崖边和建筑边缘一律无栏杆。

默认人物绝不快走、奔跑或冲刺。推镜绝不能让人物、云、水、布料、粒子或建筑移动得更快；除非用户明确覆盖相应速度，否则允许的镜头推进必须缓慢，并与世界运动在物理上相互独立。

人物首先是巨构的尺度参照。默认人物尺度档为`4–8%`并在区间内随机锁定具体值；用户可以改选`0.5–2%`、`2–4%`或`8–12%`。无论选哪档，人物都必须保持全身、远离镜头，并真实处于建筑的连续三维空间中；人物与台阶/门洞/柱础、主柱/平台/宫阙、当前抽中的主导巨构、云层与终端远景至少形成从人物起连续四级的尺度链。禁止后贴人物、拼贴人物、人物与建筑透视或光照不一致，以及只靠近景裁切伪造巨构。

传统矿物彩画是绑定构件的材质颜色，而不是全局滤镜：朱红属于选定的柱、门、椽或框；石青、石绿和群青属于梁、斗拱与檐下彩画；赭色与旧金保持窄小；石材、云和天空稳定整幅画面。

所有建筑与金属默认结构完整、表面洁净且有人维护。古老、包浆或风化只表示克制的褪色、磨亮与材质变化，绝不表示锈迹斑斑、腐蚀破损、锈水污染或废墟化。

光照默认只从日出、早晨、落日三条路线中选择，且都必须柔和、清透、方向明确。禁止中午或下午的刺眼硬光、高角度顶光、短促死黑阴影、刺眼高光、白热镜面眩光、强烈镜头耀斑、过曝天空和吞没结构细节的纯白高光。
