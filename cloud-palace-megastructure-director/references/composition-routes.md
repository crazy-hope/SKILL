# 构图路线

选择一个主导空间事件。可以增加一个物理兼容、视觉权重明显更低的从属事件；所有辅助元素都要服务于主次关系。

## 随机路线协议

- 用户点名场景或结构时，选择与其匹配的路线。
- 用户未指定场景时，从以下10条主导路线等概率抽取一条，再从兼容拓扑中抽取空间关系；天环和天障各只占一个抽签位。用户已点名桥、深殿等内容时，仅在匹配路线内变化，不因“随机”或“直接生成”忽略指定内容。
- 用户要求随机或真正不同的多张图时，主导路线采用不放回抽取，并优先轮换场景拓扑、机位家族和尺度参照。连续叙事、同场景镜头组或统一系列允许重复路线与拓扑，通过景别、方向、遮挡和事件变化建立连续性。
- 先抽路线，再决定结构事件。只有第2、7、8、9、10条路线分别需要悬空宫基、半幅巨柱、结构性天环、悬空镂空天障或无尽深檐长廊；其他路线的`结构事件`默认锁定为`无`，不得额外附加圆环或屏障。
- 最终提示词只描述已选事件；未选择天环或天障时不写其名称和专属排除项。普通建筑门窗可用设计所需的圆形或方形，不受特殊事件词汇排除影响。

## 场景拓扑库

场景拓扑描述观看者、建筑承载面和开放天域之间的物理关系。它与主导路线分开抽取；同一条路线换拓扑后，必须产生不同的空间骨架，而不只是换颜色、时间或装饰。

| 代号 | 场景拓扑 | 核心空间关系 |
|---|---|---|
| A | 正面轴线前场 | 相机隔着辽阔广场、台基或长阶正对巨构，人物侧向穿过或背向镜头观看主构；身体朝向独立选择 |
| B | 横向巨壁基座 | 相机沿巨墙根部平视，墙体、柱础或浮雕横贯数百个身体宽 |
| C | 云峡对岸遥望 | 相机位于另一座承载面，隔着云峡完整看见对岸巨构及其支撑关系 |
| D | 跨云桥面 | 人物与相机位于跨度明确的桥面或桥头，巨构在桥轴尽端或侧向压境 |
| E | 桥下或宫基下仰望 | 相机位于下层平台、桥腹或宫基下方，向上读取结构厚度与承重路径 |
| F | 深殿向外 | 相机在深檐或大殿内部，穿过柱阵看向直接连通的开放天域 |
| G | 外部向深殿 | 相机从开放云域一侧朝深殿、巨门或柱阵内部观看，外部空气仍占大面积 |
| H | 屋顶台原 | 相机与人物位于巨型屋顶平台或高层天台，以人眼高度观察远处连续宫阙 |
| I | 垂直阶崖 | 巨型台阶、岩壁或宫墙沿竖向跨越两层以上云域，人物处于清楚承载面 |
| J | 云河水庭 | 一条克制的云河或镜面水庭沿主轴连接人物、宫阙与开放远景 |
| K | 柱海前场 | 相机面对由少量超巨柱和辽阔空场构成的前场，柱列汇入单一主构 |
| L | 云层断面边缘 | 相机位于云层上下分界附近，巨构明确穿过不同高度的大气层 |

拓扑选中后要写成可见关系，例如“相机隔云峡正视对岸宫基，人物位于本侧桥头”；不得只在参数中写代号而不落实到画面。

路线中的机位与数值是条件示例，不覆盖统一尺度参考。普通有人场景仍从35–50mm起步，人物大小由空间关系与连续尺度链决定；镜头与人物朝向独立，朝向默认以侧面、背影为主，不为路线去重凑齐正面。用户只说“宏大、深殿”不等于要求远距或更小人物。

选中展示殿堂内部的F、G或其他主殿/有顶巨廊关系时，应用[巨殿空间：宽、深、高、空旷](architecture-and-materials.md#巨殿空间宽深高空旷)，同时组织净跨、纵深、梁底净高与空场。A、K若只展示外部前场，不为了这项规则强加室内；4A局部窗景保留其近窗承诺。

## 1. 无尽曲檐柱廊

庞大屋檐和柱阵弯曲横贯画面，消失在云光之中。

- 适用：简洁连续建筑、开放云海、单点或曲线透视。
- 机位：启用人物且用户未指定镜头时，使用人眼高度、真实中距离35–50mm；只有用户明确要求长焦压缩或超远跨度时才改用70–100mm。
- 主裁切：屋顶占据上方和一侧；柱列重复至遥远消失点。
- 自然锚点：可在一侧放置一棵松树。
- 避免失败：不要在同一屋顶下堆放数十座独立亭阁。

## 2. 云海之上的宫殿下构

被裁切的宫殿底部或悬空宫基取代上方天空，下方保留云海与克制的从属天域。

- 适用：建筑重量、可见悬空关系和垂直尺度断层。
- 机位：远距低机位35–85mm。
- 主裁切：宫殿下构延伸出顶部和两侧画框。
- 辅助运动：可以只用一条穿过云层的瀑布。
- 避免失败：不要形成科幻飞船轮廓，也不要让下构变成压死的纯黑。

## 3. 外部云崖阈境

观看者站在一座宫殿转角旁的开放外部露台上；墙体或屋脊沿悬崖退向开放天域。

- 适用：把充满画框的宫殿与直接开放的外部景观结合。
- 机位：人眼高度35–60mm。
- 主裁切：宫殿占据一侧；开放云域占据另一侧。
- 自然锚点：一棵指向外部的巨松。
- 避免失败：不要让中景墙水平横贯并封死地平线。

## 4. 天界巨型开口

巨型门洞或开放开间揭示遥远天界；结构性天环另按第8条路线处理。

- 适用：庄严揭示和清楚的焦点层级。
- 机位：人眼高度35–70mm。
- 主裁切：开口结构被部分裁切；遥远锚点的细节保持从属。
- 避免失败：不要形成圆形手机UI、缺少可信支撑的装饰环，或与外部没有物理连通的封闭院落。

### 经验证的巨窗框景子型

以下两种子型属于同一条主导路线，不增加随机路线权重。它们共享“殿内承载面 → 有厚度且受力可信的单一巨窗 → 开放云域 → 遥远主宫”的物理关系，但承担不同的叙事功能。方窗或圆窗只在用户点名或建筑几何明确要求时选择；每幅锁定一种窗形，不把普通窗洞写成结构性天环或悬空镂空天障。

#### 4A. 近窗巨幅框景

- 适用：需要读清窗边人物的交流、驻足或共同远望，同时仍由巨窗、墙生古松和遥远主宫维持宏伟尺度。
- 空间关系：相机位于巨窗正面法线附近，靠近殿内窗边承载面；巨窗约占画面宽度80–84%，左右宫墙各只露窄边，少量地坪与低窗台证明人物真实落地。窗外以一棵扎根外墙的巨松连接近景与云海，再由单座横向展开的遥远主宫结束尺度链。
- 机位与尺度：默认35–50mm，按人物与窗台、巨松及远宫的关系安排落位，允许近窗叙事使人物更清楚，但不设画高阈值；用户明确要求长焦正视时可用70–120mm。
- 连续尺度链：`成年仙女 → 地坪与窗台 → 巨型木窗和墙生古松 → 单座横向主宫 → 分层云海终景`。远宫即使远离镜头，仍应以连续水平檐带、宽阔正立面和从属大气层级读作巨宫，而不是窄高塔楼。
- 编辑不变量：用户只要求校正人物且环境比例正确时，保持主体建筑、画幅与光线；同时恢复人物脚底接触和投影。若尺度链或透视本身错误，应修正关联空间，不能靠只缩人物冒充正确尺度。
- 避免失败：不要让人物变成半身或第一视觉主体；不要出现两侧大面积宫墙、任一主要窗框无故消失、远宫缩成小塔、附墙巨松脱离承重墙面，或用均匀灰雾切断尺度链。

#### 4B. 深殿远窗揭示

- 适用：用户要求更强巨构压迫感、人物只作尺度标记，或需要同时读出深殿地坪、巨柱、深檐斗拱与远窗外主宫。
- 空间关系：相机位于巨殿深处，辽阔地坪横向延伸至两侧柱列之外，中央是广场般的大净跨；近景柱础、中段多进巨型开间、远端有厚度的巨窗构成长纵深。高处梁底与各层地坪之间保留巨大垂直空腔，柱顶承托连续屋盖，家具与隔断退至边带。巨窗外接云海与横向远宫，近柱不能把中殿夹成窄门厅。相机到人物的距离由深殿空间、承载面和焦段共同决定，不固定米数或画高。
- 机位与尺度：默认35–50mm，通过近处主承重体、多进大开间和窗外层次强化深度；人物大小服从所在承载面和尺度链。用户明确选远距压缩或极远人物时采用对应远景；不因“强压迫感”孤立缩人。
- 连续尺度链：`真实体型的成年仙女 → 辽阔地坪与巨柱柱础 → 深殿柱身和有厚度的巨窗 → 墙生古松与横向主宫 → 多层云海终景`。巨柱直径、柱高、地坪跨度和窗口尺寸至少提供三项相互连接的可见尺度证据。
- 避免失败：不要只把4A的人物缩小来冒充深殿远景。深殿的纵深来自相机到远窗之间可读的多进大开间；开口随真实距离后退，但自身仍保持巨大的宽度与高度，不以必须缩窄开口作为成功标准。不要让人物几步便到窗前、粗柱挤窄中殿、低梁压头或低矮楼层密叠；远宫不缩成宝塔，近殿暗部保留结构。

### 子型选择

- 用户强调人物交流、服装动作可读或指定参考人物尺度 → 优先`4A. 近窗巨幅框景`。
- 用户强调宫殿压迫感、深殿空间、巨柱地坪或强尺度断层 → 优先`4B. 深殿远窗揭示`。
- 用户只要求普通门洞或开放开间，没有上述人物与机距条件 → 使用本路线通用规则，不强行套用4A或4B。

## 5. 瀑布破界

一条巨大瀑布或天河切过连续宫殿体量、云隙虚空与下层天域。

- 适用：垂直运动和跨云层尺度证据。
- 机位：人眼高度或低机位35–70mm。
- 主裁切：宫殿和瀑布延伸出画框，或贯穿数层云。
- 避免失败：不要使用多条同等瀑布、过曝白洞或破碎塔城。

## 6. 浮雕巨墙与无尽天光

巨型龙纹、云纹或山纹浮雕占据一侧；一个真实体型的成年人穿过辽阔开放表面，走向远方天光。

- 适用：极致简洁、神圣空旷和极端尺度断层。
- 机位：人眼高度50–100mm。
- 主裁切：浮雕墙从上方和侧面延伸出画框；开放空间承载远景。
- 避免失败：不要做成小型装饰壁画、空白无信息地面或全局金色雾霾。

## 7. 半幅巨柱

一根被裁切的巨柱占据约三分之一到半幅画面，并支撑延伸出画框的屋顶、天障或宫殿体量。

- 适用：压倒性的近距离、强侧边框景，以及立即可见的成年人—巨柱比例。
- 机位：远距低机位或人眼高度24–50mm，并控制垂直线。
- 主裁切：柱身和受支撑体量至少从两个画框边缘退出。
- 避免失败：不要做成独立图腾、柔软雕塑柱或无支撑装饰。

## 8. 结构性天环

厚重天环嵌入宫基、柱系或屋顶桁架，并揭示更深层的天界。

- 适用：在不复制居中月洞门的情况下完成庄严揭示。
- 机位：远景或超远景、人眼高度或略低机位，优先70–135mm；拍摄距离必须容纳完整环体、支撑体系、人物与相邻参照和多层天域。
- 主构图：完整圆周全部收入画面，四周保留呼吸空间；环体可偏离中心并与柱系、宫基、桁架或云桥连接。只允许纤细结构或薄云轻微穿越轮廓，不能遮断圆形识别。
- 尺度证据：天环直径跨越数百个身体宽，至少连接两组巨型支撑或跨越两层云域；环内同时可见从属宫阙、人物与相邻参照或桥线以及终端远景。
- 避免失败：不要近景或贴脸环体，不要让圆周越出画框，不要只显示半环或四分之一弧，不要把宏大感等同于镜头贴近；不要科幻传送门、发光光圈或没有承重路径的装饰环。

## 9. 悬空镂空天障

具有单一、明确几何主开口的巨大穿孔天障分割画面，同时保持到云域的物理与视觉通路。

- 适用：纪念碑式负形、框取纵深，以及白金、朱红或古金材质研究。
- 机位：人眼高度35–70mm，略微偏离对称轴。
- 开口选型：先估算天障宽高比`W:H`。`0.85 <= W:H <= 1.15`时可选方形；其余比例使用圆形。每幅只锁定一种几何家族；方形边线与建筑水平轴、垂直轴平行，不得旋转成菱形。
- 开口层级：只设一个主开口；如必须增加从属开口，它们必须与主开口同形、边缘规整、面积显著更小并汇入同一结构节奏，绝不混用形状。
- 主裁切：可见天障厚度与支撑；一个边缘规整、尺度巨大的圆形或方形主开口揭示从属天域和终端远景。
- 避免失败：不要随意不规则缺口、撕裂轮廓、山洞状破洞、碎裂孔、自由曲线负形；不要菱形、扁菱形、旋转四十五度的方形，也不要圆形与方形混用；不要扁平镂花墙纸、大小相同的均匀孔洞或形似UI的开口。

## 10. 无尽深檐长廊

巨型屋檐、柱列和院落系统沿一个稳定消失方向延伸，通往不可见的宫殿。

- 适用：用户要求的超长廊道、重复深斗拱和缓慢移动的人物；人物与长廊构件共享同一相机投影与连续尺度链，大小由其所在开间、相邻构件和观看距离自然形成。
- 机位：默认人眼高度、真实中距离35–50mm；用户明确要求远景压缩或超远跨度时才使用70–100mm。
- 主裁切：近柱和屋檐不完整；目的地仍有一部分不可见。
- 廊内空间：横向通行面宽如前庭，主柱以疏朗大跨承托高处梁架；沿纵深有连续大开间，中央地坪保持空旷，不用狭长低矮的普通走廊比例。
- 避免失败：不要把主廊做成普通人尺度走廊或装饰处处同亮；允许合理转向的次级轴线，避免互相矛盾的透视。

| T5. 屋顶台原俯瞰宫廊网络 | 路线3＋H，路线1为低权重从属事件 | 前景巨宫屋顶承载人物，一条主轴统领下方浮山、宫廷与连廊 |

### T1. 巨松横枝远宫

- 适用：用户要求仙女坐在巨松上、以自然承载面代替建筑露台，并侧望云海彼端的宏伟宫廷。
- 空间关系：一棵被画框裁切的古松从一侧进入，树干直径约5–7个成年人高度；成年仙女以完整全身、严格侧面真实坐在承重粗枝上。两至三座浮山位于中远景，一座距离更远的主宫仍在视觉体量上明显大于全部浮山。
- 机位与尺度：默认40–50mm、人眼高度或轻微低机位；人物大小由承重松枝、树干截面与所在空间层决定，不指定画高。通过树皮细节、粗枝截面和脚腿接触证明人物不是后贴在远景上。
- 连续尺度链：`成年仙女 → 承重松枝与巨松树干 → 两至三座浮山 → 更远但更大的云上主宫 → 云海地平线`。
- 避免失败：不要让主宫小于浮山，不要生成大量同等浮岛或微缩亭阁群，不要让人物悬浮、正面对镜头或坐在不可能承重的细枝上。

### T2. 盘龙柱茶廊单瀑

- 适用：用户要求带生活痕迹的超长宫廷长廊，同时从廊内看见巨松、分层云海与瀑布天宫。
- 空间关系：数百个身体宽的深檐长廊沿一个稳定消失系统延伸；两侧盘龙柱必须具有柱础、柱身、斗拱和屋檐的连续承重关系。高处梁底与地坪留出巨大净空，中央通行轴保持辽阔，两至三张古代低茶几与少量烛光放在边带，成年仙女站在长廊中部。外部一棵巨松位于近中景，三至四层云雾之后是一座主天宫，且只从该宫流下一条贯穿多层云域的巨瀑。
- 机位与尺度：35–50mm、人眼高度的中轴深殿向外、克制偏轴或侧向跨廊机位；人物大小由所在开间、近旁茶几及柱础的层级决定，与柱列服从统一相机透视、地坪接触和光照。茶几与烛光只用于近景尺度，不得把空间变成宴席。
- 连续尺度链：`成年仙女与低茶几 → 巨柱柱础和地坪 → 盘龙柱列与深檐长廊 → 墙外巨松和远方天宫 → 单一跨云瀑布与云海终景`。
- 避免失败：不要普通人类尺度走廊、无承重关系的龙雕柱、四处摆满家具、连续栏杆、多条同等瀑布、过曝白水或被中景墙封死的外部天域。

### T3. 群仙多层圆屏殿

- 适用：用户要求两至三层半开放巨殿、中央纪念碑式圆形镂空屏障，以及十几至二十余位秩序清楚的仙人群体。
- 空间关系：巨殿两侧直接连通云雾与开放天域；上下各层均保留高敞净空、大净跨和通向深处的空场，上层回廊、巨柱、地坪和台阶汇入同一承重系统，不以密叠低矮楼层凑总高度。中央只设置一架具有可见厚度、地面基座和屋顶或侧向连接的圆形建筑屏障，完整主开口成为唯一焦点；不添加第二个同等开口。
- 人物与机位：默认16–22位完整成年人，分布于前场、台阶和从属层廊，动作平静且留有清楚通行轴。用户明确点名“男女群仙”时使用男女混合群体并服从指定比例；否则继续遵守全局人物身份默认值。可使用42–70mm的正面轴线、高层轻俯、低机位或严格侧向机位。
- 连续尺度链：`群仙 → 地坪、台阶与门洞 → 巨柱和两三层回廊 → 有支撑的圆形屏障与巨殿外壳 → 两侧云域终景`。
- 避免失败：不要发光传送门、无基座装饰圈、残缺圆周、不规则破洞、圆方混用、拥挤无序人群、重复面孔、克隆人物或所有人排成单一僵硬直线。

### T4. 断桥对角巨瀑

- 适用：用户要求极简的桥头人物、唯一巨瀑和强烈对角线关系，不需要宫殿城市作为第三焦点。
- 空间关系：一座厚重、受力可信的断桥从画面右下伸入开放云域，成年仙女完整站在断桥最前端，向左上方仰望唯一一条巨瀑；瀑布从上方画外落下并贯穿至少三层云带。默认保持“右下桥头 → 左上瀑布”的方向，只有用户明确要求镜像时才反转。
- 机位与尺度：35–50mm的桥基平视、桥下低机位、轻俯或严格侧向机位；人物大小由桥面、下构厚度与瀑布空间层次决定，不指定画高。断口是用户指定的单一结构事件，桥体其余部分保持洁净完整并显示梁、托臂或桥腹厚度。
- 连续尺度链：`成年仙女 → 桥面与断口 → 桥身和下构 → 跨越多层云域的唯一巨瀑 → 云海终景`。
- 避免失败：不要第二条瀑布、宫殿天际线、桥从左侧进入、瀑布居中或居右、人物离开桥头、断桥变成漂浮薄板、过曝白瀑或整幅废墟化。

### T5. 屋顶台原俯瞰宫廊网络

- 适用：用户要求人物站在巨大宫廷屋面上，俯瞰浮山、云海、多座宫廷与真实连接的复杂长廊网络。
- 空间关系：前景巨型屋瓦、屋脊和深檐组成一块连续主巨构并延伸出画框；成年仙女真实站在宽阔屋面承载区。下方浮山、宫廷和连廊按深度分层，所有长廊必须连接明确的平台、山体或宫殿入口，并由一条从前景屋脊指向下方主宫的轴线统领。
- 机位与尺度：35–70mm的受控高位远眺或克制鸟瞰，俯角约10–22°；人物保持完整全身，大小由屋面承载区、相邻构件与相机透视决定。保留可读的前景屋面坡度、檐口厚度和至少一个下方立面，不能只显示平面屋顶纹理。
- 连续尺度链：`成年仙女 → 巨瓦与屋脊 → 前景宫殿深檐 → 下方主轴长廊和从属宫廷 → 浮山、云层与终端远景`。
- 避免失败：不要等距游戏地图、平均铺满的同等宫殿、无支撑悬空长廊、微缩亭阁海、所有屋顶同等锐利，或让近景人物与下方城市使用不同焦距和光照。

## 路线选择

- 用户点名复用巨松横枝、盘龙柱茶廊、多层圆屏群仙殿、断桥对角巨瀑或屋顶俯瞰宫廊网络 → 先选择对应的`T1`至`T5`复合模板，再沿模板记录的主导路线、拓扑和从属事件组装提示词；这些模板不参与额外随机抽签。
- 用户要求无尽屋檐、墙体或柱列重复 → `无尽曲檐柱廊`。
- 用户要求宫殿压在城市或云海上方 → `云海之上的宫殿下构`。
- 用户希望建筑巨大但不失去外部视野 → `外部云崖阈境`。
- 用户要求门洞、更高天界或框景揭示 → `天界巨型开口`；强调近窗人物交流与巨幅窗景时选择`4A. 近窗巨幅框景`，强调深殿、巨柱地坪与强尺度断层时选择`4B. 深殿远窗揭示`。
- 用户强调水体、破界或多重云层 → `瀑布破界`。
- 用户希望极简巨墙、雕刻或稀疏神圣场景 → `浮雕巨墙与无尽天光`。
- 用户要求一根柱子占据半张画面 → `半幅巨柱`。
- 用户要求巨型圆环、圆形开口或天界环体 → `结构性天环`；如果简单的有支撑开口更合适，则选择第4条路线。
- 用户要求悬空穿孔屏障、天障或巨型负形墙 → `悬空镂空天障`。
- 用户要求极长建筑廊道或重复深檐 → `无尽深檐长廊`。

用户要求不同场景时，改变构图路线或场景拓扑，并至少再改变结构事件、机位家族、地平线高度、自然锚点、配色、光线、裁切、尺度参照、人物身体朝向、人物动作或主要材质中的两项。连续叙事可有意重复场景骨架，只需确保每个镜头承担不同叙事或空间揭示功能。避免无意识重复居中的天环、完全相同的人物排列或侧后方约45°模板。 画幅保持默认16:9；只有用户明确指定时才改变，不用随机比例凑多样性。

多图随机生成且用户要求不同场景时，先对10条主导路线做不放回抽取，再从兼容表选择拓扑、机位家族和尺度参照。连续单张验证记录近期结果用于避免无意识重复，但不设机械禁用次数；如果用户要同场景连续镜头，可以重复拓扑和机位。不要先写一个包含全部候选结构或拓扑的总提示词再拆分。
