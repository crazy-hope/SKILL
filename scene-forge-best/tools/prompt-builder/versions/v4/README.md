# 提示词工作台 V4

基于 [工作台 V3](../v3/README.md)，继续使用原 [规范 V5](../../../../versions/v5/输出/规范框架v5.md)。本轮只扩充工作台内容库和选择交互，规范文件未改动。

## 内容库

- 六组共 30 个题材，每题材 10 个场景，共 300 个场景。
- 每题材 36–40 个元素，按 12 类组织，共 1,090 个题材内元素条目；跨题材按文字去重后为 1,084 项。原有通用候选另行保留，不计入这些数字。
- 内置库位于 [输出/catalog.mjs](输出/catalog.mjs)，不放入规范正文或附件。条目是创作候选；涉及幻想、历史或科学的内容不等于经过考据的事实，需按具体任务核实。

| 分组 | 题材 |
|---|---|
| 东方幻想 | 东方天界幻想、山海异境、仙侠江湖、志怪传说、龙宫水府 |
| 西方幻想 | 高等魔法文明、龙与骑士、精灵森林、黑暗幻想、童话世界 |
| 科幻未来 | 赛博朋克、太空探索、星际文明、机器人社会、生态未来 |
| 机械与废土 | 蒸汽幻想、柴油机械幻想、机械城市、末日废土、灾后重建 |
| 历史与生活 | 古代市井、宫廷生活、丝路商旅、现代都市、乡村生活 |
| 自然与异境 | 山川荒野、深海世界、极地生态、外星生态、微观世界 |

## 使用

1. 旧服务运行时，先在对应终端按 Control+C。双击 [根目录启动器](../../../../启动提示词工作台.command)，仍在同一浏览器的 `http://127.0.0.1:8787` 使用。需要 Python 3.9+，无新依赖。
2. 打开“题材”，按组浏览或搜索，可多选；旧称“太空科幻”“自然写实”“古代生活”也能搜索到对应的新分类。
3. “想画什么”显示所选题材的场景；“必须包含”显示相关分类元素，并结合画面中的人物、交通、建筑、自然等线索排列类别。
4. 各下拉均支持搜索与分类筛选。搜索同时匹配候选名、类别和所属题材；搜索词与分类共同生效。无结果时可以清空搜索、切换分类或使用卡片底部的自定义输入。
5. 推荐不自动勾选。筛选和更换题材不删除已有选择；不再属于当前推荐库的已选内容，仍可用卡片上的 × 移除。
6. 右上配置文本模型，点击底部生成。仅九项实际输入与完整规范发送到接口，不发送整个内容库。中英文、结果折叠、复制、MD / ZIP 下载、密钥保存和负面默认规则继续沿用 V3。

## 兼容

沿用已有浏览器本地存储。旧题材名称保留原值，通过别名关联当前候选；历史结果不会改写。旧版全部场景及元素仍可访问。个人自定义内容、预设、负面要求和已有密钥不会因升级被清空。

本轮交付内置库、搜索和场景联动；AI 动态推荐和个人收藏仍属于后续功能。
