# 新增独立题材：云上天宫

- 日期：2026-10-18；当前工作台 V10 内容维护，不新增版本；规范 V6 不变。
- 用户要求：主场景一定在云海之上，云上有建筑、山石；场景宏大、巨构震撼、人物渺小，有尺度和空间感；画面简约，色彩协调。

## 需求与处理计划

| 编号 | 要求 | 处理与检查 |
|---|---|---|
| R-01 | 独立题材、云海之上 | 新增“云上天宫”，归入东方幻想；保留原有 30 题材，生成请求限定空间关系 |
| R-02 | 建筑、山石巨构与小人物 | 核心场景及分类描述承托/跨越关系，人物作尺度参照 |
| R-03 | 简约而宏大 | 一个主巨构、少量辅助体块、开阔云海留白；以遮挡、重复尺度、明度层次构造纵深 |
| R-04 | 配色协调 | 提供主色、辅色、小面积点缀的配色组合，服装颜色与环境颜色分开 |
| R-05 | 界面及请求可用 | 更新题材数量、分类优先、题材提示；检查检索、双服务模拟请求、原文和历史不变 |

执行顺序：记录 → 扩充题材及专属生成指引 → 检查分类、作用范围与兼容 → 记录结果。只传递用户明确要求的题材特征，不自动把整套候选全部变为必须项。

## 实际结果

已完成，直接维护 V10。

- R-01：在 `catalog.mjs` 新增独立“云上天宫”，归入东方幻想，与“东方天界幻想”并列；题材总数从 30 增为 31。原有 30 题材数据逐项比较保持原样。
- R-02：12 个核心场景、59 个题材元素；新增“云上巨构”和“空间与尺度”分类。场景涵盖孤峰天宫、双峰跨空宫阙、云顶天门、环形云宫、悬岩主殿、阶台天宫等，以关系和轮廓区分。保留仙女、多个仙女、男性仙人及长袍服装候选。
- R-03：视觉偏好共 14 项，包含简约构图、空间分层、明暗体块、留白与小面积人物色块。单独选本题材时，通用画面类型仅推荐建筑环境、叙事场景，仍可自定义输入；巨构分类优先。
- R-04：五套配色为月白/青灰/淡金、冷灰/深绿/暖金、暖白/墨青/朱红、浅青/象牙白/暗金、淡紫灰/深靛/琥珀，均明确主辅与少量强调的关系。多选不默认将所有配色混成一套。
- R-05：`server.py` 增加精确题材标签匹配的独立指引，同时选多个题材时按对应方案适用。云海之上及建筑、山石作为题材必须项，明确矛盾需澄清；其他设计按当前输入处理。完整规范与原始九项仍传入，两种文本服务共用此逻辑。`index.html` 同步显示 31 个题材。
