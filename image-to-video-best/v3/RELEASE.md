# v3 发布说明

日期：2026-10-17（Asia/Shanghai）。上一规范版本：v2；原版不修改。

## 独立规范的变化

本次发布独立的[图生视频提示词规范](image-to-video-best/SKILL.md)，新增[画面、题材与融合分析](image-to-video-best/references/visual-analysis.md)：先辨认主体、内容、环境与关键元素，再分别判断题材/世界观、表现画风、情绪氛围；支持多题材融合，用可见依据说明各元素的作用，不将梦幻、卡通、东方幻想等概念当成互斥选项。

分析结果必须落实到适合该图的材质、运动、光影与保持项；保留v2的动作、方向、速度、顺序与收尾规则。三档沿用同一画面判断与创作意图。缺乏证据时保留描述或不确定判断，不仅凭霓虹断定赛博朋克，不把参考案例动作、流体或电影滤镜套到所有图片。

只有图片、没有动作脚本时，也可由大模型根据图像自动构思，标明是设计建议；无需用户先选题材标签。默认给完整主方案，多个合理观看重点或用户要求多个方向时给少量独立候选。明确动作、镜头与速度始终优先。

## 规范与工作台分开

Skill可脱离任何工作台使用，不规定上传界面、API配置或应用JSON字段。本次没有修改web目录，网页仍为0.3.0、默认加载v2；发布v3不代表工作台已接入v3。根维护规则明确了这一区分，完整项目快照只作为归档容器。

本版完整复制v2后修改规则；原模型卡、原始案例资产及creative-fidelity规则保持不变，没有更新模型事实或核查日期，没有安装Skill、调用视频服务或操作父仓库Git。
