# 提示词契约与审计

## 提示词装配

按以下顺序组装可直接复制的提示词：

`画幅比例 -> 抽中或指定的单一路线名 -> 与路线匹配的结构事件或“无” -> 人物尺度四档选项与确认 -> 所选档内的具体人物占比 -> 机位高度、离人物距离、俯仰角和焦距 -> 人物承载面与同一空间约束 -> 从人物起至少四级连续尺度链 -> 适用时锁定镜头运动 -> 参考图角色和非编辑状态 -> 可迁移的几何/材质/光线及被拒绝的源图特有元素 -> 可信承重路径 -> 主体占比和裁切 -> 五层空间 -> 内容承载空气与外部连通 -> 四个或更多可量化尺度证据 -> 模块预算 -> 建筑与局部斗拱/装饰 -> 人物全身角度/平静动作/稳定慢速/服装/风向 -> 六类宫殿配色家族之一 -> 彩画构件落位与风化 -> 近暖远冷分离 -> 日出/早晨/落日光照路线 -> 太阳高度/主光方向/阴影软硬/高光上限/天空填充 -> 缓慢且相互独立的云/水/布料运动 -> 深景深渲染 -> 当前路线专属排除项 -> 全局排除项`

第一句话必须写明支持的画幅比例、机位和主导几何关系。

每张最终提示词只描述当前抽中或指定的路线、实际结构和尺度链，不罗列、对比或否定其他候选场景。未选中的结构名称不得出现在正向提示词或负面约束中。

## 正向提示词契约

每条完整提示词都要明确陈述：

- 一个支持的画幅比例；
- 分别写明机位高度、观看距离、俯仰角和焦距；
- 提供`0.5–2%｜极远尺度标记`、`2–4%｜强巨构尺度`、`4–8%｜标准巨构（默认）`、`8–12%｜人物叙事增强`四档人物尺度供选择确认；确认后在所选档内锁定并写明一个具体画面高度占比；用户不选择、明确要求直接执行或不再提问时，默认在`4–8%`内随机锁定具体值；
- 写明镜头离人物足够远、人物完整全身可辨并真实落在平台、桥面、台阶或柱础旁；人物与建筑共享同一地平面、消失点、透视缩放、光照、接触阴影、遮挡和大气层级；
- 写出固定尺度链`人物 → 台阶/门洞/柱础 → 主柱/平台/宫阙 → 当前主导巨构 → 云层与终端远景`，把“当前主导巨构”替换为当前路线的实际结构，至少从人物起连续显示四级，并为相邻层级指定直接可读的大小或距离关系；
- 一条选定构图路线；
- 参考图驱动时，指定一个结构事件和可信支撑关系；
- 主导结构在何处被裁切或延伸出画框；
- 选择结构性天环时，明确改为远景或超远景完整入画：圆周四边留白、不得被画框截断，并写出支撑跨度、人物与多层远景尺度证据；
- 选择悬空镂空天障时，依据屏障宽高比只锁定圆形或方形一种家族；一个主开口占主导，任何从属开口必须同形、规整且明显更小；方形边线与建筑水平轴、垂直轴平行，不得旋转成菱形；
- 完整五层空间；
- 约40–60%的内容承载空气；
- 前景如何连通开放云域；
- 至少四个可量化尺度证据；
- 一个主构、最多两个从属体量，以及零个或一个自然锚点；
- 中性基底、中等纯度材质色、高纯强调色和阴影色；
- 请求宫殿配色时，指定一个宫殿配色家族；
- 选择传统矿物彩画时，指定一条命名子路线、分别给出建筑表面和整帧预算、颜料到构件的落位，以及有物理位置的风化等级；
- 深斗拱或浮雕只集中在结构带或人物可识别区域；
- 一个主光方向；
- 从日出、早晨或落日中锁定一个光照时段，默认早晨；分别写明低到中低太阳高度、斜侧主光、柔和阴影、受控高光与冷色天空填充；
- 若用户明确要求中午或下午，必须写明云层或大气漫射、降低直射强度和保留浅色材质纹理；
- 人物是巨构尺度参照而不是视觉主体，默认静止或稳定慢速运动，绝不快走、奔跑或冲刺；
- 对视频，采用固定或缓慢镜头，推移/环绕只影响构图和视差，绝不影响世界空间运动速度；
- 所有边缘无栏杆，并排除截图污染。
- 建筑与金属洁净、完整且有人维护；允许轻微褪色或磨亮，不允许锈斑、锈水、腐蚀和废墟感。

## 条件负面约束

只在当前路线被选中时，把对应一段追加到全局负面约束；未选中时不得出现该段或相关结构名称。

- `结构性天环`：不要近景或贴脸大环、圆周越出画框、半环、四分之一弧、无法闭合的弧段、科幻传送门、发光光圈或没有承重路径的装饰环。
- `悬空镂空天障`：不要随意不规则缺口、撕裂轮廓、山洞状破洞、碎裂孔、自由曲线负形、菱形、扁菱形、旋转四十五度方形或圆形与方形混用。

添加场景专属排除项时，不得删除上述默认约束。
用户明确禁止的每个元素都必须作为独立、字面明确的排除项写入场景专属负面约束。不要依赖暗示：如果用户说“不要迎客松”，还要排除松树、松枝和松针；其他被点名的禁止元素也要按同样方式展开。

## 直接生图规程

用户明确要求生成图像时：

1. 把提供的图像标记为有明确角色的参考图，不自动视为编辑目标。
2. 只使用能够覆盖几何、材质、氛围和尺度的最小代表性参考图子集。
3. 明确说明排除截图UI、水印和栏杆。
4. 用户要求随机、未指定场景或直接生图时，从10条构图路线等概率抽取；多图采用不放回抽取。先记录每张图的路线名和匹配结构事件或`无`。
5. 每条不同场景提示词各生成一张图；每条只描述当前抽中的路线，不得把候选路线库写进提示词。
6. 只追加当前路线适用的条件负面约束；没有选中天环或天障时，不得在正向或负面提示中提到它们。
7. 检查结果的主体、裁切、开放性、尺度、污染物和不变量。
8. 每次只针对一个问题迭代修正。
9. 把最终项目资产保存到工作区，并报告路径。

## 诊断表

| 症状 | 根本原因 | 源头修正 |
|---|---|---|
| 建筑显得小而杂乱 | 过多独立体量共享相同反差和细节 | 减少为一个连续主导体量；裁切它；把远处屋顶降为一条从属屋顶带 |
| 观看者感觉被墙围困 | 中景墙挡住地平线，或只能透过门洞看云 | 移到外部阈境；让35–55%画面直接开放到云/虚空；让墙体斜向后退 |
| 宫殿很大但没有神性 | 没有已知尺度对比或终端远景 | 加入微小成年人、可量化柱/开口、跨云层宫基和极远锚点 |
| 人物太大，建筑失去压迫感 | 选择了过高尺度档，或镜头靠人物太近 | 改选`0.5–2%`或`2–4%`档并锁定具体值；拉远人物镜头，保持全身轮廓和连续尺度链 |
| 人物很小但不能证明建筑巨大 | 人物与建筑不在同一连续空间，或尺度链断裂 | 把人物真实放在平台、桥面、台阶或柱础旁，从人物起连续显示至少四级尺度链，并写明相邻层级比例 |
| 人物像后贴或拼贴 | 人物与建筑使用了不同地平线、焦距、光照、投影或大气层级 | 统一地平面、消失点、透视缩放、主光和雾化递减；恢复脚底接触、正确投影与遮挡关系 |
| 人物比例在系列中漂移失控 | 只写了范围，没有为每张图锁定数值 | 每张图先记录所选档位，再在档内随机锁定并报告一个具体百分比 |
| 场景像鸟瞰游戏地图 | 机位过高且片区覆盖均等 | 降到人眼高度；揭示竖向立面与底部；用50–100mm压缩 |
| 画面变灰变平 | 用均匀雾气表现纵深 | 雾气局部化；用明度、纯度和反差阶梯分离空间层 |
| 建筑显得嘈杂 | 所有巨大表面具有同等装饰密度 | 恢复安静巨面；把细节限制在一到两个可识别区域 |
| 出现参考截图杂质 | 把UI和水印误当成风格 | 重新标记参考角色；明确排除所有界面、文字和水印元素 |
| 天环或天障像科幻装饰 | 缺少承重路径、厚度或与宫殿的整合 | 把它嵌入柱、宫基或屋顶桁架并揭示更深的有人活动空间层；天环保持完整远景圆周，天障可裁切外墙但保留完整几何主开口 |
| 天环只剩四分之一弧，无法看出圆环 | 把通用裁切规则错误套到天环，或镜头距离过近 | 改用远景或超远景，把完整圆周和四周呼吸空间收入画面；用支撑跨度、微小人物、宫阙与云层证明尺度 |
| 完整天环仍显得像近景装饰圈 | 只靠画面占比制造巨大感，缺少环境尺度链 | 拉远镜头；同时显示至少两处巨型支撑、数百身体宽的跨度、环内宫阙、跨云层关系与终端远景 |
| 天障缺口像随机破洞或难看的斜向开口 | 使用了自由曲线、不规则负形或旋转方形，没有正确几何选型 | 按屏障宽高比锁定圆形或正向方形一种家族；所有从属开口同形且规整，方形不得旋转，并保持厚度与承重可见 |
| 宫殿像锈蚀废墟 | 把古老、包浆或旧金误译为腐蚀破败 | 恢复洁净完整、长期维护的表面；只保留轻微褪色、磨亮和受控材质变化，排除锈斑、锈水、点蚀与剥落 |
| 红金宫殿像主题乐园 | 暖色等量覆盖云、石材和阴影 | 恢复中性云/石材、冷色通透阴影和窄小陈金结构强调 |
| 细节丰富的宫殿仍显得小 | 装饰密度均匀且缺少人物尺度 | 把深斗拱集中在承重带；加入安静巨面和可量化成年人物对比 |
| 十个变体看起来像同一张图 | 只替换了名词 | 改变构图路线，并至少再改变结构事件、镜头、裁切、配色、光线、锚点和人物动作中的两项 |
| 彩画宫殿显得霓虹或幼稚 | 朱红、绿、蓝和金拥有相同面积与纯度 | 把颜料绑定到构件；恢复石材/云的中性面；收窄赭色和金色；降低远景纯度 |
| 岁月宫殿显得破败或肮脏 | 风化被处理成随机脏污罩层 | 按暴露和使用规律落位褪色、雨痕、积尘和磨损；保持结构有人居住且完整 |
| 冲击力变得躁动、像游戏 | 把动感措辞转译成了速度 | 恢复站立或稳定慢走；通过尺度揭示、光线和受控视差制造冲击力 |
| 推镜导致云、布料或人物加速 | 镜头与世界运动被耦合或时间重映射 | 保持每种世界空间速度不变；慢镜头只影响构图和视差 |
| 中午或下午光线刺眼 | 高角度直射光、过硬阴影和白热反射同时出现 | 改用日出、早晨或落日；若必须保留时段，用薄云或大气漫射主光，降低高光并恢复材质纹理 |
| 日出或落日变成橙色滤镜 | 暖色覆盖天空、云、石材和阴影 | 暖色只落在受光边缘与局部结构，恢复冷色天空填充和通透阴影 |
| 云宫被过曝白光吞没 | 太阳盘、云层和浅色石材高光没有上限 | 压低太阳和云层高光，保留白玉、云和檐边的明度层级与表面细节 |

## 最终审计

逐项修订，直到所有答案都是“是”：

- 缩略图尺寸下，是否由一个连续东方巨构主导？
- 它是否约占画面50–80%，并按事件正确裁切？若为结构性天环，是否改为完整圆周收入画面并保留呼吸空间？
- 五层空间是否都清晰可读？
- 是否有40–60%的内容承载空气，并与前景直接连通？
- 除裁切和密度外，是否还能看见至少四个尺度证据？
- 是否已经提供四档人物尺度选项、确认档位，并为当前画面锁定一个具体百分比？若用户不选择或直接执行，是否使用默认`4–8%`档随机锁定具体值？
- 随机场景是否从10条路线等概率抽取？多图是否不放回、没有重复路线，并分别记录路线名？
- 结构事件是否与路线匹配或明确为`无`，且提示词只描述当前抽中路线，没有泄漏其他候选结构名称？
- 镜头是否离人物足够远，人物是否完整全身且处于从属地位，并真实站立或行走在明确承载面上？
- 人物与建筑是否共享同一地平面、消失点、透视缩放、光照、投影、遮挡和大气层级，没有后贴或拼贴感？
- 是否从人物起连续显示固定尺度链中的至少四级，并让每个相邻层级具有准确、直接可读的大小或距离关系？
- 是否遵守模块预算？
- 巨大表面是否安静、材质是否可信、装饰是否局部集中？
- 由参考图驱动时，是否明确说明参考角色、可迁移特征和被拒绝的源图特有元素？
- 所选天环、天障、巨柱或宫基下构是否具有可见厚度和可信承重路径？
- 若为结构性天环，是否为远景或超远景、完整闭合且没有被画框截断，并通过人物、支撑跨度、从属宫阙、云层和终端远景显示宏伟尺度？
- 若为悬空镂空天障，是否根据宽高比只选圆形或正向方形一种家族，所有从属开口是否同形且规整，并且没有菱形、旋转方形或随意不规则缺口？
- 天环或天障的专属负面约束是否只在对应路线被选中时出现？未选中时是否完全没有相关诱导词？
- 建筑和金属是否洁净、完整、有人维护，并且没有锈斑、锈水、腐蚀剥落或废墟感？
- 是否锁定日出、早晨或落日之一，并明确太阳高度、主光方向、阴影软硬、高光上限与冷色天空填充？
- 是否完全没有中午或下午的刺眼直射、高角度顶光、短硬黑影、白热眩光、强镜头耀斑、过曝天空或纹理丢失？若用户明确要求中午或下午，是否已用云层或大气充分漫射？
- 是否由六类宫殿配色家族之一主导，具有近暖远冷分离，且没有全局色彩罩染？
- 选择传统矿物彩画时，是否明确子路线、构件绑定、两类面积预算和因果风化？
- 机位是否服从建筑，而不是漂浮在建筑上空？
- 人物是否静止或以稳定自然速度缓慢移动，并且没有快走、奔跑或冲刺？
- 如果镜头运动，是否保持固定或缓慢，没有快速推进、变速或镜头诱发的世界运动加速？
- 云层是否在揭示结构，而不是吞没结构？
- 除非用户明确要求，否则每个边缘是否都无栏杆？
- 手机UI、黑边、字幕、Logo、印章和水印是否全部缺席？
- 用户指定的每个禁止元素及其近似变体是否都被明确排除并且缺席？
- 输出是否没有复制专有人物或完整模仿源画面？
