## 用户补充后的回归

用户明确要求人物清晰适用于中景、远景。相应规则已改为所有景别默认人物与可见面部清晰，背景人物也不能自动进入虚化区；景别只控制占幅与细节尺度。远景不擅自放大人物，也不以清晰为由承诺微小人脸的毛孔细节。

v6-flow.md 保留修订前 B，用 B2 与 F 记录修订后的远景及前后排中景输出，分别核对占幅、所有人物清晰、环境虚化与固定位置约束。

- 官方 quick_validate.py 首次执行因本机缺少 PyYAML 而未完成；改用系统 Ruby YAML.safe_load 解析两个 YAML 文档，再用 Python 检查名称、description、版本、UI 字段、未完成占位符与本地引用，不能把替代检查记为原脚本通过。
- 检查每份三版样例含六个独立提示词块，各块参数一致；中英文内容由人工逐段比较，不能只靠块数证明语义一致。
- 压缩包逐成员比较运行文件字节，拒绝历史包、测试记录、隐藏文件和额外成员；历史 zip 哈希不变；安装三个入口解析到当前项目运行文件。
- 对比 v5 与 v6，完整交付章节之前的交互流程在去掉版本号差异后完全一致，防止误改八项、多选或等待逻辑。
