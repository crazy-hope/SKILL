# 默认视觉语言

本文件保存超现实天界仙宫的稳定视觉身份。用户明确要求可以覆盖具体镜头、时间或配色，但不因简短请求回落到普通古建、结构工程图或游戏地图。

## 视觉优先级

`东方神话奇观 → 神性尺度断层 → 电影摄影氛围 → 主体完整 → 工程合理性`

- 画面先读到一座压倒天际的主导仙宫或神域巨构。
- 人物若出现，是远离镜头的极小叙事标点，不是环境人像。
- 宫阙、平台、桥、巨环和宫基可以悬空、倒悬或跨越云海；不必解释全部承重。
- 允许密集屋檐、柱阵、宫阙与下构模块机械式重复，但重复必须形成方向、层级和消失关系，不能融化成噪声。
- 多重奇观可以同框；用中轴、轮廓、明暗与体量差建立观看顺序，不靠删减换取“合理”。

## 默认摄影

- 横版 `16:9`，全画幅 `18mm` 超广角电影镜头。
- 极低机位，镜头贴近承载面或位于主体下方，略微仰视 `5–10°`。
- 超远景、深景深、真实电影摄影质感，保留自然透视与大气递进。
- 建筑可以越出画框，远宫即使数公里外仍保持横向压迫体量。
- 默认不是高位俯拍、无人机视角、垂直鸟瞰、人物肩后近景或正面肖像。用户明确指定时再覆盖。

## 建筑与尺度

- 主体是巨大、完整、横跨天际的东方天界仙宫，而不是小亭阁、细塔或平均铺开的城市。
- 可使用四层以上高敞宫阙、重檐、密集柱阵、错层宫基、悬空平台、巨环、龙柱、长桥和天瀑制造不可能尺度。
- 极端尺度来自巨构占据巨大画幅、层层云域、超远距离仍庞大的轮廓，以及极小人物或其他尺度标点。
- 不使用针孔投影、人物百分比或工程尺度链作为默认流程。用户给出数值时把它作为视觉目标，并说明生成工具不保证精确像素。

## 东方幻想色彩与材质

- 主体色：深朱红墙面与巨柱、深栗色凹部、低反光墨青黑瓦。
- 彩画：石青、石绿、群青集中在斗拱、梁枋、檐底和门窗结构带。
- 金色：旧金只勾瓦当、屋脊、雕刻凸缘和少量受光节点；不铺满建筑。
- 云海：冰蓝、青灰、亮白分层，具有透明阴影、受光边缘和巨大体积。
- 材质可以超现实，但要有真实电影级表面响应；避免塑料朱红、镜面黑瓦、廉价金属和均匀发光。

## 默认光线与情绪

- 日出低角度侧逆光，太阳靠近云海地平线或巨构侧后方。
- 暖金光只勾亮人物、屋脊、朱红边缘、松针、栏板或瀑布水汽；冷青天空光填充云影和檐下。
- 使用长距离体积光、分层云雾、瀑布水汽与高动态范围，但保留云和建筑纹理。
- 情绪是庄严、神圣、寂静、震撼。宏大来自尺度、距离、留白、光线与静止感，不靠快速动作、霓虹粒子或满画面特效。

## 通用质量底线

排除普通古建旅游照、欧式或日式宫殿、现代城市、赛博朋克、科幻飞船、廉价游戏CG、融化建筑、克隆屋檐、失控透视、意外断裂、人物悬浮或拼贴、重复肢体、均匀灰雾、白热过曝、无层次死黑、全局橙色滤镜、文字、Logo、水印、字幕、UI和黑边。
