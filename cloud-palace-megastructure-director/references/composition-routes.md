# 构图路线

只选择一个主导空间事件。所有辅助元素都要服务于这个事件。

## 随机路线协议

- 用户点名场景或结构时，选择与其匹配的路线。
- 用户要求随机、未指定场景或直接生图时，从以下10条路线等概率抽取一条；结构性天环和悬空镂空天障各只占一个抽签位，不提高权重。
- 一次生成多张图时采用不放回抽取，同一批图的路线不得重复；每张图还要按文末多样性规则改变至少两个其他模块。
- 先抽路线，再决定结构事件。只有第2、7、8、9、10条路线分别需要悬空宫基、半幅巨柱、结构性天环、悬空镂空天障或无尽深檐长廊；其他路线的`结构事件`默认锁定为`无`，不得额外附加圆环或屏障。
- 最终正向提示词和负面约束只描述当前抽中的路线。未抽中第8或第9条时，不得出现天环、圆环、天障、屏障、圆孔、方孔或菱形等相关诱导词。

## 1. 无尽曲檐柱廊

庞大屋檐和柱阵弯曲横贯画面，消失在云光之中。

- 适用：简洁连续建筑、开放云海、单点或曲线透视。
- 机位：人眼高度，远距50–100mm；只有必须突出柱础时才用35mm。
- 主裁切：屋顶占据上方和一侧；柱列重复至遥远消失点。
- 自然锚点：可在一侧放置一棵松树。
- 避免失败：不要在同一屋顶下堆放数十座独立亭阁。

## 2. 云海之上的宫殿下构

被裁切的宫殿底部或悬空宫基取代上方天空，下方保留云海与克制的从属天域。

- 适用：建筑重量、可见悬空关系和垂直尺度断层。
- 机位：远距低机位35–85mm。
- 主裁切：宫殿下构延伸出顶部和两侧画框。
- 辅助运动：可以只用一条穿过云层的瀑布。
- 避免失败：不要形成科幻飞船轮廓，也不要让下构变成压死的纯黑。

## 3. 外部云崖阈境

观看者站在一座宫殿转角旁的开放外部露台上；墙体或屋脊沿悬崖退向开放天域。

- 适用：把充满画框的宫殿与直接开放的外部景观结合。
- 机位：人眼高度35–60mm。
- 主裁切：宫殿占据一侧；开放云域占据另一侧。
- 自然锚点：一棵指向外部的巨松。
- 避免失败：不要让中景墙水平横贯并封死地平线。

## 4. 天界巨型开口

巨型门洞、开放开间或天环揭示遥远的更高天界。

- 适用：庄严揭示和清楚的焦点层级。
- 机位：人眼高度35–70mm。
- 主裁切：开口结构被部分裁切；遥远锚点的细节保持从属。
- 避免失败：不要形成圆形手机UI、缺少可信支撑的装饰环，或与外部没有物理连通的封闭院落。

## 5. 瀑布破界

一条巨大瀑布或天河切过连续宫殿体量、云隙虚空与下层天域。

- 适用：垂直运动和跨云层尺度证据。
- 机位：人眼高度或低机位35–70mm。
- 主裁切：宫殿和瀑布延伸出画框，或贯穿数层云。
- 避免失败：不要使用多条同等瀑布、过曝白洞或破碎塔城。

## 6. 浮雕巨墙与无尽天光

巨型龙纹、云纹或山纹浮雕占据一侧；一个微小成年人穿过辽阔开放表面，走向远方天光。

- 适用：极致简洁、神圣空旷和极端尺度断层。
- 机位：人眼高度50–100mm。
- 主裁切：浮雕墙从上方和侧面延伸出画框；开放空间承载远景。
- 避免失败：不要做成小型装饰壁画、空白无信息地面或全局金色雾霾。

## 7. 半幅巨柱

一根被裁切的巨柱占据约三分之一到半幅画面，并支撑延伸出画框的屋顶、天障或宫殿体量。

- 适用：压倒性的近距离、强侧边框景，以及立即可见的成年人—巨柱比例。
- 机位：远距低机位或人眼高度24–50mm，并控制垂直线。
- 主裁切：柱身和受支撑体量至少从两个画框边缘退出。
- 避免失败：不要做成独立图腾、柔软雕塑柱或无支撑装饰。

## 8. 结构性天环

厚重天环嵌入宫基、柱系或屋顶桁架，并揭示更深层的天界。

- 适用：在不复制居中月洞门的情况下完成庄严揭示。
- 机位：远景或超远景、人眼高度或略低机位，优先70–135mm；拍摄距离必须容纳完整环体、支撑体系、微小人物和多层天域。
- 主构图：完整圆周全部收入画面，四周保留呼吸空间；环体可偏离中心并与柱系、宫基、桁架或云桥连接。只允许纤细结构或薄云轻微穿越轮廓，不能遮断圆形识别。
- 尺度证据：天环直径跨越数百个身体宽，至少连接两组巨型支撑或跨越两层云域；环内同时可见从属宫阙、微小人物或桥线以及终端远景。
- 避免失败：不要近景或贴脸环体，不要让圆周越出画框，不要只显示半环或四分之一弧，不要把宏大感等同于镜头贴近；不要科幻传送门、发光光圈或没有承重路径的装饰环。

## 9. 悬空镂空天障

具有单一、明确几何主开口的巨大穿孔天障分割画面，同时保持到云域的物理与视觉通路。

- 适用：纪念碑式负形、框取纵深，以及白金、朱红或古金材质研究。
- 机位：人眼高度35–70mm，略微偏离对称轴。
- 开口选型：先估算天障宽高比`W:H`。`0.85 <= W:H <= 1.15`时可选方形；其余比例使用圆形。每幅只锁定一种几何家族；方形边线与建筑水平轴、垂直轴平行，不得旋转成菱形。
- 开口层级：只设一个主开口；如必须增加从属开口，它们必须与主开口同形、边缘规整、面积显著更小并汇入同一结构节奏，绝不混用形状。
- 主裁切：可见天障厚度与支撑；一个边缘规整、尺度巨大的圆形或方形主开口揭示从属天域和终端远景。
- 避免失败：不要随意不规则缺口、撕裂轮廓、山洞状破洞、碎裂孔、自由曲线负形；不要菱形、扁菱形、旋转四十五度的方形，也不要圆形与方形混用；不要扁平镂花墙纸、大小相同的均匀孔洞或形似UI的开口。

## 10. 无尽深檐长廊

巨型屋檐、柱列和院落系统沿一个稳定消失方向延伸，通往不可见的宫殿。

- 适用：用户要求的超长廊道、重复深斗拱和缓慢移动的远景人物；人物采用已确认的尺度档，默认在`4–8%`内随机锁定具体值，并与长廊构件共享同一消失系统和连续尺度链。
- 机位：人眼高度35–50mm，或远距70–100mm压缩。
- 主裁切：近柱和屋檐不完整；目的地仍有一部分不可见。
- 避免失败：不要普通人类尺度走廊、装饰处处同亮或多个竞争透视轴。

## 路线选择

- 用户要求无尽屋檐、墙体或柱列重复 → `无尽曲檐柱廊`。
- 用户要求宫殿压在城市或云海上方 → `云海之上的宫殿下构`。
- 用户希望建筑巨大但不失去外部视野 → `外部云崖阈境`。
- 用户要求门洞、更高天界或框景揭示 → `天界巨型开口`。
- 用户强调水体、破界或多重云层 → `瀑布破界`。
- 用户希望极简巨墙、雕刻或稀疏神圣场景 → `浮雕巨墙与无尽天光`。
- 用户要求一根柱子占据半张画面 → `半幅巨柱`。
- 用户要求巨型圆环、圆形开口或天界环体 → `结构性天环`；如果简单的有支撑开口更合适，则选择第4条路线。
- 用户要求悬空穿孔屏障、天障或巨型负形墙 → `悬空镂空天障`。
- 用户要求极长建筑廊道或重复深檐 → `无尽深檐长廊`。

制作变体时，改变构图路线，并至少再改变结构事件、镜头、画幅比例、自然锚点、六类宫殿配色家族之一、光线、裁切、人物动作或主要材质中的两项。避免重复居中的天环或完全相同的三人排列。

多图随机生成时，先对10条路线做不放回抽取，再分别锁定各图参数；不要先写一个包含全部候选结构的总提示词再拆分。
