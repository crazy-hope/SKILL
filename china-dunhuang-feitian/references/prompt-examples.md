# 提示词组织与使用示例

## 输出形态

用户只要一条提示词时，直接给完整的一段；需要说明选择时加一行模式说明即可。要求方案比较、图片分析时才展开分类和推导。

提示词依次写清：**主体与动作 → 构图与披帛路径 → 衣饰与配色 → 绘画／摄影媒介、光照和肌理 → 简短排除项**。人物数量、时代要求、乐器、画幅和用途服从用户。

提示词本身不依赖“图 7 的身体、图 2 的风格”等外部指代。分析文档可以引用编号，最终生图文本应转写成完整视觉描述。不要把图中水印、AI 标记、旁边的分析问题复制为生成要求。

默认用中文；用户需要英文时忠实翻译关键结构。仅在明确指定平台且参数语法已确认时附平台参数，不默认猜测模型版本、`--v` 或参考权重。避免用一串“8K、杰作、大师级”代替姿态和材质。

## 默认融合重彩：可直接使用

一名成年敦煌题材飞天凌空旋升，完整全身，躯干形成舒展的 S 形，肩胯轻微错向，一腿向身后屈起、另一腿自然下伸，一手抬至脸侧、另一手向外舒展；面容宁静，长眉细目，低垂目光，黑色高髻配小型旧金冠饰。青绿与赭红披帛从肩臂、腰际延展，先绕至身体外侧形成两组宽松长弧，再向上方和侧后方拖曳，前后遮挡清楚，脸和双手周围留有净空。赭红裤裙、青绿腰布、暖白肌肤，冠颈腰间只有少量旧金细饰。暖砂赭褐底，浅色卷云集中在下部，顶部保留安静留白。工笔细描与矿物重彩观感，平面色块轻微层染，柔和漫射光，壁面细颗粒、局部褪色和边缘露底，五官与手部清晰。竖幅 2:3，原创当代敦煌风格绘画；无翅膀、无多余肢体、无霓虹和大面积金属高光，不生成额外文字、标志或水印。

## 明确要求洞窟斜光时

一名成年飞天在古壁圆拱前回旋腾起，双臂自然上扬，一腿屈起，青绿与米白披帛从肩臂向左右展开后垂落，形成可追踪的两条长回环。宁静细目、黑色发髻、少量旧金冠饰，赭黄长裙与青绿腰布。人物占据主要画面，圆拱只作局部框景，手和头部轮廓完整。暖色斜光自左上落在人物与旧墙上，暗部保留褐色和青绿，受光与阴影方向一致；细线重彩与适度立体层染结合，墙面局部剥蚀，人物皮肤不铺满裂纹。现代敦煌题材洞窟光影插画，竖幅 2:3，画面底部为脚和衣摆保留余量，不添加强烈魔法光束或额外标识。

## 明确要求真人摄影时

一名成年舞者演绎敦煌飞天，身体沿右上至左下的对角线凌空前伸，左手向运动前方舒展，肩胯与后屈腿形成连贯长弧；沉静侧脸、黑髻和精简金色发饰。深孔雀青大裙摆在身后翻卷，少量赭红内层露出，橘赭和青绿色细披帛从肩臂连接处向后上方延展，面部与前手周围保持干净。暖褐背景、局部柔暖光、真实皮肤与衣料厚度，长布面和细飘带层次明确，少量金色微尘位于人物后方。原创敦煌题材摄影主视觉，竖幅 2:3，完整肢体与可信关节，不添加未指定的产品、品牌或包装。

## 同系列提示词的交付

每条必须独立可用：共享人物设计、配色、画幅、媒介、光照与肌理要在每条中重现，不能仅写“其余同上”。先锁定系列，再按视觉配方替换动作与长带路径。用户只要求三种姿态时，可用旋升、横掠、回望；不把静立造像、强斜光、摄影分别当成三种姿态。

## 常见偏移的定向修订

| 观察到的问题 | 修改提示词中的具体关系 |
|---|---|
| 像普通古装人物站在云上 | 写明凌空重心、躯干长弧、腿的屈伸和飞行方向；移除无意加入的地面／莲台 |
| 飘带成团、像触手 | 减少主要路径，补起点和遮挡关系，扩大单个回环尺度 |
| 只有金光没有重彩 | 减少金色覆盖，恢复红青衣带与暖土背景的面积关系 |
| 像塑料 3D 人偶 | 默认模式改为细描、平涂、轻层染和漫射光；移除镜面高光词 |
| 模糊脏旧盖住五官 | 把露底限制在背景、衣饰边缘；脸手保留清晰描线 |
| 琵琶与手互相穿插 | 明确琴颈、弦面、两手各自位置，优先简化周围披帛 |
| 系列各张风格不同 | 将共享媒介、光照与色板逐条写回，保留已选动作差异 |

如果用户明确要求文字、标识或其他与默认排除项不同的元素，按其要求调整；排除项服务于本次画面，不覆盖用户选择。
