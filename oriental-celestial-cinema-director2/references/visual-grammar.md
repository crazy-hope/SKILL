# 视觉语法

本文件描述所有随机结果必须共享的视觉系统。它不是物件清单，也不要求每张图同时出现圆环、瀑布、巨树、龙柱或浮山。

## 一句话公式

> 局部高密度的连续东方古建工程带，占据画面一侧或顶部；大面积开放天域释放空间；极小人物建立尺度；冷色环境被有方向的暖光切开，同一批图片保持统一色光基准。

## 1. 古建工程巨构化

- 使用深檐、斗拱带、柱廊、宫墙、宫基、屋顶和平台等东方古建构件。
- 把构件横向延伸、弯曲、重复、叠层或悬置，形成连续结构系统；不是在云上摆放许多独立宫殿。
- 至少一个主要结构从画框顶部、左侧或右侧被有意裁切，显示厚度、方向和连续性，使其看起来延伸出画框。
- 主宫可以正面出现，但应横向压住天际线、部分被雾或近景结构遮挡，不能像完整模型一样居中陈列。
- 圆形只在它是巨大建筑开口、拱门或承载结构时使用；不把金色装饰圆环当作默认奇观。

## 2. 局部密度与开放天域

- 密度必须分区：精密斗拱、檐带、窗格、柱列和下构集中在一个连续建筑区。
- 与密集区相对的是大面积开放天域：天空、平整云海、云峡、深渊、远方薄雾或镜面水庭。
- 空白承担尺度与神性，不用飞岛、粒子、小塔或装饰填满。
- 缩略图的阅读顺序应是：一个巨构轮廓 → 一片开放天域 → 一个尺度标记。

## 3. 镜头语言（独立参考）

相机位置、机位高低、观看方向、近景裁切、透视关系、焦段倾向与人物承载面，集中写在[镜头语言](camera-language.md)。每次任务必须完整读取该文件；此处不重复镜头细则。

## 4. 尺度与叙事

- 人物不是肖像主体，而是极小尺度标记；优先背影或侧影。
- 人物必须站在桥、廊道、露台、门槛、阶面或水庭边缘等可使用空间中，不悬浮、不后贴。
- 骑乘者与坐骑构成一个清楚完整的叙事单元，轮廓不与栏杆、树根或建筑边缘纠缠。
- 人物动作克制：凝望、等待、慢行或骑乘停驻。画面张力来自尺度和空间，而非战斗或魔法特效。
- 巨树用于自然尺度时，只设一棵主树并放在侧边；树冠以深墨绿或近黑剪影参与框景，不使用鲜绿。

## 5. 云雾与距离

- 低处使用平整云海、宽阔雾层或连续云流；中景用横向雾带遮住部分连接；远景由空气透视降低饱和度、细节和反差。
- 瀑布只在有明确高差时出现，优先宽阔水幕或少量垂直水带，并与水汽相连。
- 云层亮部保留暖灰或珍珠灰层次，阴影带冷蓝灰；禁止纯白剪切和遍布画面的棉花状云团。

## 6. 色彩与光线

颜色不是分别给物体涂鲜艳固有色，而是由同一束光组织冷暖。

### 色彩家族

| 家族         | 大面积环境                 | 建筑主体                                             | 局部受光与标点                 |
| ------------ | -------------------------- | ---------------------------------------------------- | ------------------------------ |
| 朱红暖白天青 | 清透天青、浅蓝灰、暖白云海 | 中等饱和朱红与赭红木构、深青黑瓦、暖白宫基或承重圆拱 | 暖金日光、象牙白高光、极少暗铜 |
| 青黑铜金     | 青黑、铁蓝灰、雾灰         | 深木、炭黑瓦、暗铜                                   | 旧金擦光、少量朱砂             |
| 蓝灰朱砂     | 深蓝灰、冷雾白             | 暗木、灰黑瓦、低纯石材                               | 矿物朱红、暖铜边缘             |
| 雾白暗木     | 珍珠灰、暖云白、浅蓝灰     | 烟褐木、墨色屋面                                     | 琥珀斜光、窄旧金               |
| 冷青柱光     | 冷青、铁蓝灰、雾白         | 深青黑木构、暗铜承重柱                               | 仅柱面柔和琥珀、旧金暗铜反光   |

- 大面积环境保持低到中低饱和；普通色彩家族的高饱和只允许成为极小标点。使用“朱红暖白天青”时，连续建筑密集区可以由中等饱和朱红或赭红统领，但不能变成荧光红、纯橙或全画面暖色罩染。
- 暖色来自日出、落日、清晨晴光或云隙斜光。普通家族以檐口、柱边、雕刻凸起和人物衣缘的局部受光为主；“朱红暖白天青”允许暖金日光照亮一段连续朱红建筑立面，同时保留天青环境、暖白宫基和深色框景的冷暖分区。任何家族都不把整座建筑涂成亮金。
- 近景可以深，但要保留木纹、瓦行和结构层次；暗部不是无信息死黑。
- 远方开放天域可以亮，但云和天空不能白热过曝。

### 冷青柱光模式

只在用户明确点名时启用。“柱”指画面中的承重柱，不指柱状光束。环境保持低饱和冷青与铁蓝灰，原有曝光不变；暖光仅在主要承重柱的朝光面、浮雕凸起和局部弧面形成柔和琥珀、旧金、暗铜材质反光。不得产生冷青色体积光柱、宽幅舞台光、橙黄罩染或全局增亮。

### 光线路线

- 日出：冷青天空填充 + 低角度柔暖侧逆光。
- 落日：深蓝灰环境 + 局部暗红金边光，避免全局橙色罩染。
- 暮蓝：冷蓝主环境 + 少量室内灯火或残余暖光，结构仍可读。
- 云隙光：大面积冷色漫射 + 一束方向明确的暖灰光照亮主构或路径。
- 清晨晴光：清透天青天空填充 + 方向稳定的暖金斜射日光；可照亮连续建筑立面和暖白宫基，形成明亮清澈、反差明确但不过曝的气氛。

### 批量色光基准

- 用户未指定色彩和光线时，单张与批量任务都默认采用“朱红暖白天青 + 清晨晴光”，主光从画面左上方斜射，使用明亮正常曝光、清澈空气和中等偏高反差；不要随机抽成暗色方案。
- 用户只要求“随机场景”时仍保持明亮默认。只有用户明确要求随机色调、天气、时辰或每组不同氛围时，才从其他兼容组合中抽取。
- 整批重复同一色彩家族、光线路线、主光方向、色温、曝光档位、天空清澈度和雾层亮度。用户明确指定冷青柱光时整批统一采用该模式；构图变化不能隐式改成另一个时辰或天气。
- 用户明确要求“每张不同氛围”“不同天气”或“不同时间”时，才允许逐张改变色光基准。

## 7. 渲染身份

- 宽银幕电影 CG、高端影视概念设计、清楚大轮廓、深景深、体积空气、克制材质反光。
- 大面安静，精细细节集中在檐下、柱头、窗格、结构转换带和受光区域。
- 超现实来自体量、悬置、无边延伸和空间断层；保持建筑稳定完整，不使用融化、扭曲或梦魇式变形。

## 8. 不是共同视觉基因的元素

巨环、龙柱、瀑布、巨松、镜面地坪、悬浮宫城和群像都只是可选变量。任何随机结果都不应为了“像”而机械堆入这些物件。真正必须稳定的是构图、尺度、密度分区、空气和冷暖光。
