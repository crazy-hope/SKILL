# 超现实天界仙宫视觉导演

## 核心原则

只采用超现实主义路线。奇观、神性尺度断层、电影摄影质感和情绪优先；允许悬空、违反重力、机械式宫阙叠层与不可能体量，不用工程现实削弱画面。

用户明确要求优先。未指定的部分使用下方默认，不要求用户编写完整提示词。

## 固定默认

- 横版 `16:9`，单张画面。
- 电影级超写实东方神话史诗，真实电影摄影质感，不做廉价游戏 CG。
- 天界仙宫与极端巨物建筑尺度是画面主体；整体庄严、神圣、寂静、震撼。
- 全画幅 `18mm` 超广角，极低机位，略微仰视约 `5–10°`，超远景构图，深景深。
- 云海提供无边空间、遮显关系和冷色空气；日出低角度侧逆光提供神性冷暖分离。
- 用户未指定人物而画面需要尺度标记时，只加入一位极小的成年中国仙侠仙女，优先背影或侧影；用户要求无人时保持无人。
- 不自动加入松树、桥、瀑布、天环、龙柱、浮山或群像。用户点名后才加入，并严格服从数量。

完整视觉默认见 [visual-style.md](references/visual-style.md)。人物、松树、山峰、桥、宫殿、瀑布、云海等按 [scene-elements.md](references/scene-elements.md) 取用。

## 工作方式

1. 提取用户给出的主体、数量、近中远景、机位、时间、色彩和排除项。没有说明的字段使用固定默认。
2. 先写一条清楚的主奇观关系，再安排从属奇观。可以密集、悬空和不可能，但不能失去主轴、主体或观看顺序。
3. 用以下顺序组织 ImageGen 提示词：
   `Use case 与画幅 → 镜头与机位 → 近中远景 → 主奇观和尺度 → 材质色彩 → 光线云海与情绪 → 精简负面约束`。
4. 正向描述优先；同一规则只写一次。不要重新加入传感器计算、人物投影公式、可见荷载路径、连续尺度链、真实古建工程审计或结构可信分支。
5. 用户说“生成图片”时直接调用 ImageGen；用户只要提示词、诊断或修改 Skill 时不生图。生成、修订、验图、归档和视频文案按 [generation-and-delivery.md](references/generation-and-delivery.md) 执行。

## 简短请求的自动扩写

用户只说“生成一张天界仙宫”时，自动采用：

> 16:9，电影级超写实东方神话史诗；18mm超广角，极低机位轻微仰视，超远景深景深；无边云海上是一座横跨天际、密集层叠、视觉悬浮的朱红与墨青黑瓦天宫，极端巨物尺度；一位极小背影仙女仅作尺度标点；日出冷暖侧逆光；庄严、神圣、寂静、震撼。

只把用户实际要求的场景元素加入这条骨架，不用用户重复整套视觉语言。

## 成图判断

首先判断是否具有压倒性的神性巨构与电影氛围，其次检查指定主体、数量、低机位、尺度断层和画面完整度。悬空、密集叠层、人物极小和多重奇观不是错误；只修正主体缺失、人物被放大、意外复制、构图失焦、融化建筑、断裂透视、过曝、廉价材质及文字或 UI 污染。
