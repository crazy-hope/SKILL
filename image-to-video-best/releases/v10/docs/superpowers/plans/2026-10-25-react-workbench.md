# React工作台与四模型接入实施计划

> 使用 writing-plans / executing-plans；依 dispatching-parallel-agents 将资料和后端接入与前端重构拆为不重叠任务。用户已要求实施并确认四型号、任务列表＋编辑结果并排布局。项目版本快照隔离，不操作父Git分支或暂存区。

**目标：** 工作台0.6.0使用React、Vite与Ant Design，改善表单和结果交互，支持Seedance 2.0、Seedance 2.5、Kling O3、Kling 4.0。

**设计：** 左侧可选任务列表、中间首帧与创作要求、右侧结果预览；小屏转为单列编辑/结果切换。保留默认4任务与全部并行，支持新增、复制任务、单独重试和取消；输入变更使旧响应失效、保留旧结果并提示。简要需求可留空由图片自动构思，基础设置随手可见，细节要求用折叠面板。配置用抽屉；目标视频模型与看图写词服务明确区分。结果直接可读、复制与导出，无需反复开详情。

**取舍：** 多卡同时展开会重复长表单；逐步向导不利于来回调整。采用任务列表与并排编辑结果，使用成熟组件提供键盘、焦点、校验和反馈，保留本机Node后端及安全配置逻辑。

**版本：** v4只读，新增v5仅增Kling4模型卡及适配索引/必要说明，创作六段规则继承；工作台实际加载v5。完整项目releases/v7，下一快照v8。官方Kling4指南正文抓取超时，按官方搜索索引明确标注证据范围；不伪称入口/视频实测。

## 边界与接口

- 本应用生成提示词，不调用目标视频生成API；可配置OpenAI兼容看图服务保持不变。
- 当前四模型ID：seedance-2.0、seedance-2.5、kling-o3、kling-4.0。旧v1/v2显式加载保留历史兼容。
- 当前配置API返回skillVersion v5、appVersion 0.6.0、四模型和不含密钥的连接状态；输出元数据保留各模型资料日期和本次未在线复核。
- 单图可自动设计；空idea允许，原始输入不被伪造。声音/手势等details字段保持完整。
- React从同源/api加载，dist为可直接运行的静态产物，源码与lockfile一并保存；启动不依赖node_modules，开发需npm ci/build。
- Ant Design需要动态及内联样式，仅放宽style-src；script-src仍self，Host/Origin、路径边界、密钥不回传、不入localStorage不变。
