# 东方苍穹巨构

`东方苍穹巨构`是视觉处理而非场景类别。先应用[仙侠共享总则](xianxia-master-rules.md)，再加入裁切、阈境揭示与尺度断裂；不得削弱五层空间、40–60%内容承载空气、东方巨构、无栏杆和仙衣规则。它可与`单体仙境`或`神域聚居地`组合。

## 共享总则继承

- 五层映射为：近景巨型框景；承载微小背影仙人的人物面；被裁切的统领巨构事件；较轻从属天域；终端天空、月、云海、更高天界或极远聚落。
- 至少四项尺度证据。裁切本身不能证明大小，还要加入成人与柱、开口、桥、台、墙、树、崖或远方神域的比较。
- 在事件内部和周围以门洞、庭地、宫基下虚空、云隙、水、天空和距离保留40–60%内容承载空气；实心灰场不算呼吸空间。
- 门槛、平台、桥、阶、廊和建筑边缘默认无栏杆。
- 人物通常1–4%、背面或斜后方、动作平静、仙衣结构明确且风向统一。

## 核心处理

- 建立一个主导**空间事件**，而不是完整地标或物体清单，例如巨门悬压城市、长桥进入不可抵达宫殿、瀑布切开云城、天域从结构开口显现。
- 只展示巨构碎片、底部、墙、门洞、巨台、裁切屋顶、竖向宫基或远方建筑地平线，并让它越出至少一条画框边。
- 通过檐、门、崖、松、柱、开放暗台或云隙进行有意遮挡和阈境观看。
- 尺度沿五层断裂：近景巨框—人物阈境与微小成人—统领巨构—从属天域—终端远景。
- 允许不可能的悬浮、倒置重量、云上宫基和天瀑，但保持内部物理可信。

## 空间事件库

每次只选择一个：

- **苍穹压顶**：被裁切的巨门、宫殿底部或平台占据上部，下方是城市或云海。
- **阈境揭示**：阴影门洞、开放露台、崖边或柱阵打开到明亮且不可抵达的天域。
- **画中开口**：月环、门洞、拱、对檐或松崖间隙框住远方主体。
- **长桥入未知**：窄桥或云阶从微小人物附近开始，消失于云、光或巨殿底部。
- **纵向破界**：瀑布、光柱、悬基或天河切穿城市、云和虚空。
- **宫基下显城**：巨大上层结构悬在从属屋顶与庭院上方。
- **建筑切片**：以巨墙、石板、宫基、柱阵或局部屋顶暗示更大整体。
- **半幅巨柱**：一根裁切柱占约三分之一至一半，并把荷载传至屋顶、天障或悬空宫殿。
- **结构性天环**：厚重天环融入宫基、柱或屋架，部分遮挡，并通向更深居住层。
- **悬空镂空天障**：有厚度和支撑的不对称穿孔屏障形成巨大负形，同时保留外部通路。
- **无尽深檐长廊**：巨柱、斗拱与开放庭地沿单一消失系统重复，通向数百个身体宽之外不可见的宫殿。

不要自动复用月环或居中长桥。涉及新增结构事件、悬空宫基、指定宫殿配色或参考图时，应用[参考图巨构标准](reference-image-megastructure-standard.md)，且只选一个结构事件作为视觉论点。

## 尺度与框景门槛

史诗或超宏大必须具有：

1. 一个被裁切、遮挡或延伸出画的主构。
2. 成人通常占画高1–3%；只有明确要求读清全身时用5–8%，仍保持背面角度和仙衣语法。
3. 完整五层和至少四项尺度证据，其中一项是直接的不可能比较。
4. 无栏杆的人物承载阈境，用于揭示而非遮挡主事件。
5. 从属天域和可读终端远景，而不是空雾。
6. 约40–60%云、虚空、天空、水、开口、庭地或距离，用于显露悬浮和高度，又不把建筑缩成孤物。

巨构可占约三分之一至三分之二；如果更强裁切更有利，不必机械遵守百分比。

## 镜头

- 默认观者从属：远距低机位或人眼高度，平视至略仰视；禁止默认鸟瞰、航拍、高角度或俯视。
- 繁华宫城与压迫巨构并存时，优先远距低机位70–100mm，让屋顶、台地、云和主构压缩成厚重文明层。
- 桥、低位接近、柱阵、巨门和底部揭示使用24–32mm直线广角，并保持足够距离。
- 门洞、露台、室内和可信建筑碎片使用35–50mm。
- 默认深景深和受控垂直线，以空气、重叠和反差台阶分层，不靠焦外虚化。
- 只有明确要求城市地理布局时才用高位总览，不能因为云、岛或建筑多而选择。
- `繁华压迫`保持低地平线，下缘放微小人物与阈境，中部压缩密集城区，主巨构统领中上部；观者永远位于结构下方或前方。

## 高明度克制配色

- 约65–80%为浅石、云白、低纯玉、蓝灰天空、冷水等中低纯明亮基底。
- 约15–25%为板岩蓝、矿物绿、深木、克制朱红或风化青铜。
- 最强暖色通常只占3–8%，用于受光屋沿、漆色强调、衣装、旗帜或金属边；明确要求更高饱和时也要保留大面积稳定面。
- 高明度必须色彩分离清楚；低纯度不能变成浑灰、米灰雾或死调。

## 光线与氛围

- 优先黎明或傍晚的低位侧光/逆光，亮部为暖象牙、淡杏或克制金。
- 冷高空天光负责环境补光；阴影保持青灰、板岩蓝、蓝绿或紫灰的开放细节。
- 薄雾只在阈境、瀑布、宫基和云边局部散射，禁止统一雾幕。
- 亮部过渡柔和且材质边缘响应可见，禁止过曝白云和死黑宫基。
- 默认不加镜头光斑；只有强化阈境事件时允许一个很淡且有光学动机的光斑。

## 运动纪律

- 保持神圣建筑静止感。人物默认静立、观看、轻转或稳定缓慢行走，禁止快走、奔跑和冲刺。
- 视频使用固定镜头或恒定慢速推移/环绕；除非用户明确覆盖镜头速度，禁止快速推进、甩镜、变速、延时和加速视差。
- 镜头与世界运动物理独立；推镜只改变构图与光学视差，绝不能让云、水、布料、发丝、粒子、人物或建筑加速。
- 冲击力来自裁切尺度、阈境揭示、光线和遮挡，而非躁动。

## 材质方向

优先纪念碑式浅石、风化玉、崖状宫基、哑光矿物面、克制漆木、暗青铜、窄鎏金边、水和体积云。最大体量减少装饰种类，把中国细节放在阈境、屋沿、门、柱础和人物尺度区域。

深斗拱必须对应荷载，集中在大檐下、梁柱转换、宫基肋和天环接点。巨墙、玉板和平台大面保持安静。参考图驱动时只选六类宫殿之一：纯白、朱红、古金、红金、白金或传统矿物彩画；把配色视为材质分布而非全局调色。选择传统彩画时阅读[传统建筑彩画配色](traditional-polychrome-palettes.md)，彩绘斗拱、梁枋和阈境保持局部，裁切巨墙、平台和主结构保持安静。

## 提示词顺序

`画幅与机位 -> 继承的尺度证据 -> 五层空间与40–60%内容承载空气 -> 场景路由 -> 主导空间事件 -> 裁切或遮挡 -> 无栏杆人物阈境 -> 东方巨构与局部细节 -> 背影仙人与衣装 -> 高明度克制配色 -> 低位侧逆光 -> 局部空气散射 -> 深景深电影材质 -> 共享及路线不变量`

## 审计

- 是否是空间事件而非物体清单？
- 五层空间、40–60%空气和四项尺度证据是否齐全？
- 是否至少有一个结构大于画框，并由阈境、遮挡和尺度参照有意揭示？
- 人物是否足够微小，并保持背面、平静动作、仙衣和统一风向？
- 画面是否明亮而不依赖满幅高饱和，暖亮部局部、冷阴影透明？
- 雾是否塑造而未隐藏建筑？
- 是否具有东方识别度，又不是朝代复原、欧洲城堡、现代都市或科幻混凝土体？
- 镜头是否从属于巨构，高位总览是否由用户明确要求？
- 所有边缘是否无栏杆？
- 人物与镜头是否默认平静，镜头不改变世界速度？
- 参考图角色是否明确，并拒绝完整仿制？
- 天环、天障、巨柱和宫基是否有厚度、支撑和可信承重路径？
- 结构细节是否局部化，只由一种宫殿配色主导，近暖远冷且不灰塌？

避免完整宫殿居中漂在空云中、默认航拍、密集红金主题乐园色、巨面满铺雕花、克隆屋顶、浑灰调色、不透明雾、死黑前景、鱼眼、多个同等奇观或缺乏尺度证据的小亭。
