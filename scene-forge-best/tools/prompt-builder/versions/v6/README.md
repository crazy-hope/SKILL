# 提示词工作台 V6

基线：[工作台 V5](../v5/README.md)。继续使用原 [规范 V6](../../../../versions/v6/输出/规范框架v6.md)，本轮不修改规范。

## 本次更新

- 赛博朋克元素从 37 项扩为 74 项，场景从 10 个扩为 15 个。原候选全部保留，其他 29 个题材内容未改。
- 增加霓虹灯管、竖式霓虹招牌、巨型电子广告牌、悬浮全息广告牌、楼体广告屏、监控闸机、街头商业设施等。
- 新增“照明与光效”“全息影像与装置”两个题材专属类别。全息影像、全息鱼灯、全息鱼群、全息广告人物、悬浮地图等可以搜索和勾选。
- “全息鱼灯（悬浮游动的鱼形投影）”和“鱼形实体灯笼（可见灯体与吊线）”分开。前者是幻想画面建议，不声称现实中存在对应物理装置。
- 新增 15 个视觉候选：5 个配色组合、7 个照明与反射方案、3 个全息表现。覆盖霓虹商业街、工业下城区、企业控制区、地下娱乐场所和清晨城市。

## 使用

1. 旧服务仍在运行时，先在其终端按 Control+C，再双击 [根启动器](../../../../启动提示词工作台.command)。
2. 选择“赛博朋克”。“必须包含”默认优先照明、全息、信息标识与建筑；选定场景后，相关分类向前排列，其他候选仍可检索。
3. 例如选“全息鱼灯巡游”，全息影像与装置优先；选车站则轨道交通优先，夜市则广告招牌优先，维修场景则工具优先。
4. 在“必须包含”搜索“全息鱼灯”“霓虹”或“广告牌”勾选；在“视觉偏好”选择赛博朋克配色、照明及全息表现。通用媒介、时间等选项继续保留。
5. 填“清晨街区”会把清晨配色与照明移到对应组前面，仍需手动勾选。切换题材会更新推荐，但已有选择保留，需删除时点卡片上的 ×。

未勾选的候选不会加入必须项，不会把整个库发给模型；可以混合题材、自定义元素和视觉要求。选项存在并不保证实际出图效果，生成仍由规范与目标模型适配规则处理。
