# 把风格变成具体画面

本文件指导创作选择，不声称某个词或某种顺序已被实验验证能提高 Midjourney 成功率。用户的莲花总结是细节层级参考，不是通用题材或固定参数。

## 先区分几个不同维度

- 题材是拍什么：生活、仙侠、神话、科幻、历史、产品等，可以多选并融入同一场景。
- 媒介是怎么表现：摄影、油画、插画、动画、微缩。
- 具体视觉风格是怎样成像或绘制：高光怎样过渡、明暗反差、边缘与细节如何处理、笔触是否可见。
- 故事时代属于世界设定，作品制作年代属于风格参照。两者分开记录；用户未选制作年代时用具体成像特征描述，不推导出某个十年段。怀旧、柔和、胶片感均不是具体年代授权。
- 文化、现实性和情绪分别决定环境依据、可发生的事、人物关系；不能把它们捆成一个风格选项。

## 具体视觉风格的选择

每轮只问这一项，用可感知区别帮助选择，而不是展示技术名词词库。选项随已经确定的媒介调整。

电影画面与纪实摄影在表现方式里是独立选项。电影可以拍神话、仙侠、科幻或日常，纪实也不能仅凭画面风格证明事件真实。不要给只选电影的用户自动加 documentary、street photography 等词。

电影的具体质感选项可为柔和光学、清晰通透、浓郁明暗、低反差细腻；不绑定题材与年代。表现方式与具体风格都支持多选，按成像、人物材质、背景处理等明确分工，形成一致的混合风格；相互矛盾时单独澄清。不得默默只保留首项。

油画可选细腻平滑、厚涂有触感、概括大色块；插画可选清透线描、平面几何、手绘纸感；动画可比较线条、色块及体积表现。不要给油画强加相机机身、胶片颗粒或光学柔焦。不知道媒介时给跨媒介感受选项，用户明确代选后再落实。

保留自由选择、自定义，并接受具体描述。只有用户本轮明确选择某制作年代，才把那个年代作为成像参照；它不改变故事时代。参考文本、历史研究和旧会话中的具体年代不是本轮默认值。

## 整体色调先概括，再落实

整体色彩／色调是具体视觉风格之后的独立选择，按 SKILL.md 单独询问并等待。视觉风格描述如何成像或绘制，色调描述整幅画面的颜色组织；柔和光学不自动等于低饱和青绿。已明确的色调沿用，未指定的细节在该方向内设计；自由选择时为候选明确具体配色，选中后固定。

每条完整中文和英文提示词的前部都用自然语句明确整体色调，而后展开局部颜色与光材反馈：

1. **全局概括**：主色及辅助／点缀色、偏冷／偏暖／中性或冷暖对照，以及适合场景的明暗和饱和度关系。无需填满颜色数量、面积百分比或色号，不把低饱和设为默认。
2. **颜色载体**：哪些颜色占大面积，哪些落在人物、道具或环境的视觉重点；尊重物体固有色，不将整幅图统一染色。
3. **光线与材料**：光从哪里来、有什么冷暖与软硬特征，在关键材料上形成什么高光、透射或反射；符合已定场景与媒介。非人物场景不添加皮肤描写，油画等按笔触与明暗处理。

例如用户选定青绿淡彩且场景确有透光花瓣时，可以写：“整体以玉绿、冷青、乳白与少量淡粉组成清冷柔和的淡彩色调，绿色环境占主导，浅色人物与花瓣形成明亮落点；花瓣透出暖白柔光，在皮肤和湿润衣料上留下细腻高光。”学习“整体配色→局部载体→受光反馈”的关系，不复制此场景的颜色、植物或湿润状态到其他主题。

黑白选择以黑、白、灰的面积与明暗层次概括，不添暖金高光等彩色；中性配色可强调本色与冷暖平衡，不强造冷暖对比。用户指定的红车等本色不可擅改，冷调可以体现在环境和受光关系上；明确黑白成像与必须可见鲜红等冲突时，按单题澄清。三版保持相同整体调色方向，不能借机位或故事瞬间更换配色。

## 情绪／氛围：先选择，再用画面表达

在内容现实性之后按 SKILL.md 独立询问情绪／氛围，支持多选融合、自由选择和自定义。色调、电影感或题材不替代本项选择。自由选择时各候选明确设计结果，选中后固定；有明确选择时每个候选和最终三版均保留所有方向。

每段中文与英文正文既概括情绪，也写可见依据。例如“轻松、亲密、生活化”可以由放松的神态、顺手照应的动作、共同关注的小事体现；“安静而略带不安”可以由克制姿态与朝向画外的警觉视线共同体现。这些是表达方法，不是必加的事件、表情或道具。亲密可属于朋友、家人或同伴，不自动变成爱情关系。

温暖情绪不强改暖黄色调，忧伤不自动增加雨水、眼泪或死亡；神秘不自动授权超自然。无人物主题通过留白、空间距离、材质与光影组织氛围，不添加人物补齐互动。方式1不为强化情绪更改已经冻结的表情、视线和动作；方式2在既定情绪范围内变化瞬间，不能把三版变成三个不同情绪方向。真正矛盾的明确要求用单题澄清，不擅删选择。

## 一个场景先形成一致的视觉设计

以下设计在内部完成；整体色调概括与相关可见关系须明确写入每段成品，最终融入流畅、完整的提示词，不把所有项目都做成额外问题，也不强制按栏目逐项输出。

| 要设计的关系 | 应写成什么 | 避免什么 |
|---|---|---|
| 风格 → 可见特征 | 例如柔和但有层次的高光、克制的局部反差，人物眼神与手部接触仍可辨 | 只堆电影感、年代标签、写实或全局糊掉 |
| 配色 → 对象与面积 | 大面积冷灰石面，人物暗蓝衣料，少量暖白纸边作为视觉落点 | 只有蓝、灰、白的清单，或让所有物体染同色 |
| 光源 → 表面响应 | 天光从棚外进入，窗内暖光沿湿布边缘形成细亮反射 | 任意发光、相互矛盾的光源方向 |
| 材料 → 状态与反馈 | 棉袖受雨后局部变深并贴住手腕，粗纸边吸水微卷 | 所有东西统一油亮，“真实材质”反复堆叠 |
| 情绪 → 可观察关系 | 一人稳住书箱，另一人顺手腾出落脚处，两人的目光追随同一物件 | 只贴“轻松亲密”标签，肢体却无联系 |
| 镜头 → 空间与注意力 | 从棚内向外看，近处棚沿框住上缘，中景手部互动清楚，远处雨街保留辨识度 | 只有“低机位35mm”，却没有相机所处位置 |

颜色保持固有色、照明色与表面状态的区别。湿浅粉可以变成较深的粉色，乳白高光可以局部出现；不能无说明地把整条粉纱写成白纱。按材料决定吸水、反光、透光，不把湿玻璃与湿棉布写成同一种表面。

用前中后景和左右关系解释必要的结构，不要求每张图都具有六个方位槽。极简、特写与平面设计允许层次少；不为填背景新增路人或道具。广角、低机位、中远景与细微纹理的可见程度要相容。相机移动后，世界中的人物位置仍固定，但画面左右、遮挡和投影可变化，应重新检查。

基础风格、调色方向与道具固有色在最终三版间保持一致。方式1只变化拍法及合理的可见光影；方式2可改变故事瞬间与受力、湿痕等状态，但仍使用同一场景的美术体系。不得一版冷青旧片、一版暖金广告、一版霓虹游戏渲染。

## 景别决定细节的落点

先确定观众最应看清的主体或互动，再选择容纳它的取景。焦段名称只是辅助；应具体写出画面裁到哪里、人物占多大、哪些动作在画内、焦点在哪里。只要有人物，特写、中景、远景都默认保持所有人物与可见面部清晰；小占幅不等于允许失焦，背景人物也不自动算作可虚化环境。下面只调整细节分配，不降低任何景别的人物清晰要求。

| 画面目的 | 优先展开 | 其他内容的处理 |
|---|---|---|
| 人物近景／特写 | 脸部占幅、眼睛与面部结构、表情、视线、可见的手部互动、局部受光 | 背景只保留识别场景所需线索；全身服装和站位不是同等细节中心 |
| 多人互动中景 | 面部结构与表情清楚、核心动作、人物距离、视线回应、道具接触与遮挡 | 景深覆盖前后人物；微小物件不同时要求微距级细节 |
| 环境远景 | 保留小人物占幅，同时写出人物清晰、可见五官与姿态动作可辨，以及环境尺度和事件走向 | 不主动模糊远处人脸，也不承诺远处毛孔和微小针脚可辨，不擅自改成特写 |
| 静物、建筑或非摄影媒介 | 对应主体的结构、表面、空间或笔触组织 | 不强加人脸、眼部对焦、皮肤纹理或摄影锐度标准 |

无论景别，人物可见的眼睛与面部关键结构都应清楚可辨；通过对焦、覆盖所有人物距离的景深及遮挡安排表达，不靠反复加“高清、真人”。人物的实际占幅决定能展开多少细节，不以放大人物替代清晰要求。避免一边要求“所有脸清楚”，一边把后排人物写成远处虚焦。方式1已冻结的人物位置不可为共面而重排；可调整摄影机、景深或取景，必要冲突回到用户取舍。新设计场景或方式2可合理安排人物距离，但仍服从硬条件。

检查脸的朝向与视线是否真的向所选机位露出：景深不能让背向摄影机的眼睛可见。面部清楚不等于所有人都正面看镜头；侧脸可以清楚，方式1不能为露出双眼而偷转人物头部。

## 柔和光学与真实状态

柔和高光、背景散景、运动模糊、面部失焦与皮肤磨平是不同现象。让高光边缘平滑过渡，不重要且不包含人物的环境可适度柔化，同时保留所有人物的眼神、面部体积与自然明暗变化；不要求全画面锐利，也不强求每个毛孔都清楚。只有用户明确要求人物失焦等表达时才改变这一默认值。

真人感通过当前场景可见的状态组织：例如雨中湿发成束贴在额角、衣料局部吸水变深；侧光下鼻梁与面颊受光不同；承托物体时指腹压住表面。选择适合景别和事件的少量关键反馈，不把湿发、雨水、缺陷、汗珠或夸张毛孔变成通用配方，不改动既定天气。油画、插画等按其媒介处理人物，不自动套用摄影皮肤标准。

## 用一个事件串起细节

组织顺序可为“谁正在完成什么 → 关键阻碍或配合 → 摄影机能看见的动作 → 光线与材质的反馈”。这是设计方法，不是让最终提示词变成机械栏目。

例如两人正在把一只湿木箱搬过门槛：一人托底，另一人稳住箱侧，湿袖在弯肘处贴紧，窗光擦过手背与木箱水痕。这些细节共同解释搬运；无需再逐一指定每根手指和所有关节。人物特写则选择仍容纳两张脸与托箱手势的取景，将细节放在目光、承重表情和接触处，画外的鞋履与地面不再扩写。

完整详细保留独立使用所需的信息。去掉同义重复、互相争夺视觉中心的描写和无关的画外细节，不等于输出精简版；也不能借“简化”删除用户要求的人数、角色、动作或关键道具。

## 参考的边界

参考例子的画幅、制作年代、题材、配色、情绪和焦段只在本轮确实选定或指定时使用。通用方法是“确认题材与风格集合、解释融合后的可见特征，再把色彩、材料、情绪和空间协调起来”。不要以详细为由机械扩写无关细节。
