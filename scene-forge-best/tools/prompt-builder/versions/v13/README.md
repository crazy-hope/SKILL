# 提示词工作台 V13

状态：2026-10-25 已交付；功能与文档检查通过，真实模型与出图未执行。基线为[工作台V12](../v12/README.md)，本版采用React与Ant Design重构前端，接入[完整规范V10](../../../../versions/v10/输出/规范框架v10.md)。

## 打开工作台

双击项目根目录的[启动提示词工作台.command](../../../../启动提示词工作台.command)。已有工作台在运行时，先在其终端按Control+C停止，再重新启动；只刷新旧服务页面不会切换后端。

日常运行需要Python 3.9或以上版本。生产页面已构建到[输出/dist](输出/dist/index.html)，不需要运行npm或连接CDN。默认地址为`http://127.0.0.1:8787`，请保持原端口与浏览器以继续读取原有本地记录。

## 主要变化

- React组件负责页面与交互，Ant Design统一选择器、表单、抽屉、弹窗与提示；浅色紧凑布局，桌面五列两行，手机自动排为单列。
- 题材与元素在可搜索、可分类的抽屉选择，支持自定义；完成或关闭选择抽屉时提交尚未点击“添加”的自定义文字，超限时保留抽屉并提示。
- 已选元素点击后设置性别、角色、相对尺度、占比、数量、动作、位置、层次、关系与对象。自定义属性最多80字；普通输入可清空或自定义。
- 规范来源升级为V10，保留完整正文、SHA-256及目标图像模型适配信息；旧历史继续显示原来的规范版本。

## 保留的使用方式

十个主面板依次为题材、元素、视觉偏好、镜头、风格与复杂度、构图、目标模型、画幅、数量、大致说明，另有独立负面提示词。默认Midjourney、9:16、5对双语；负面和说明可明确清空，不补回默认。地域东方/西方/中国可单选、再次点击取消，清空题材同时清空地域。

元素动作与空间默认由模型设计，未选择人物不自动添加人物；允许随机、选配和辅助对象的含义不变。原32个题材及候选库原文保留，新增“东方奇幻世界”后共33个题材，未选项不会进入请求。

右上角打开“配置模型接口”（已配置时显示服务商名称），先选择OpenAI或DeepSeek，再填写对应平台的API Key，点击“测试连接 / 获取模型”并选择文本模型ID，最后“保存配置”；07目标模型仍指最终出图模型。API Key只保存在独立浏览器存储中，可清除，不进入创作备份、历史、项目源码或日志。

底部生成1—10个双语方案。结果弹窗左侧标题、右侧详情独立滚动，第一次展示不复制；点击标题切换并复制该条完整英文。保留中文、英文、双语、全部复制，以及汇总Markdown和逐方案ZIP下载。结果顶部显示每个方案最终实际采用的题材、地域、元素、视觉偏好、镜头、风格与复杂度和构图，切换方案同步变化；原始输入可在下方折叠区查看，不随当前草稿编辑变化。实际设计可含符合输入约束的库外原创元素，随历史、备份和下载保留；仅接受完整的七项实际设计，缺失或无效时按格式错误拒绝，不提供旧记录兼容或迁移。失败与澄清不保存为成功历史。

## 记录与兼容

V13与V12使用同一`scene-forge-workspace-v12`创作存储项，保持schemaVersion=3及scene-forge-backup-v3。草稿、预设及满足当前完整结果格式的最近30条历史可使用；缺少实际设计的旧历史不再兼容（整个创作存储或导入备份包含此类记录时校验失败，原存储不自动覆盖）；不读取或迁移V11及更早格式，不删除旧存储。备份最多100项，导入历史仍保留最近30条。V12及更早目录完整保留。

文本服务商及两个平台的模型ID独立保存在`scene-forge-connection-v1`，优先于创作存储中的接口配置；尚未保存独立配置时读取当前schema3创作存储的接口字段，即使历史校验失败也不重置服务商。此操作不兼容或迁移无效历史；受保护的原创作存储保持原样。API Key继续使用`scene-forge-api-keys-v1`。更换端口、浏览器或用户配置会形成不同的浏览器存储；需要时先导出备份，再在新的页面导入，密钥需单独填写。损坏存储会显示提示并暂停自动覆盖，允许下载原记录、恢复有效备份或明确重置。

## 开发与验证

实际构建环境：Node 24.20.0、npm 11.19.0。运行依赖React 19.3.1、Ant Design 6.6.7；构建Vite 8.3.5。完整版本见[package.json](输出/package.json)和[锁文件](输出/package-lock.json)。安装只影响本版`输出/node_modules`，该目录不作为交付源码。

在本版`输出`目录运行：

```sh
npm ci
npm run build
npm run test:core
npm test
```

在项目根目录运行后端测试（仅使用本机模拟服务）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools/prompt-builder/versions/v13/tests -p 'test_*.py'
```

开发时先运行本版Python服务，再在`输出`目录执行`npm run dev`，Vite监听源文件并重建dist，浏览器手动刷新查看。此流程沿用Python同源API，不关闭Host/Origin/token验证，也不需要额外开发代理。

浏览器自动化使用本机Chrome。在一个终端从项目根目录执行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tools/prompt-builder/versions/v13/tests/mock_server.py
```

再在`输出`目录运行`npm run test:e2e`。模拟服务为`http://127.0.0.1:8793`，仅用于测试；所有内容明确标注模拟，不是实际模型输出。测试浏览器使用独立临时上下文，不修改日常端口的浏览器记录。

Python只公开构建后的index/assets与既有API，不公开源文件、依赖和配置；脚本策略仍限制同源，样式策略允许Ant Design运行时样式。
