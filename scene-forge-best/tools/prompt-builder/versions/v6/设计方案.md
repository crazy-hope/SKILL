# 工作台 V6 设计

用户已批准的方向在现有选择流程中实现。保留原赛博朋克条目，增加照明与光效、全息影像与装置两类可选分类；不强迫其他题材填充这些分类。

赛博朋克默认优先照明、全息、商业信息与建筑。具体画面优先对应类别：车站优先轨道与载具，人物优先身份与服装，夜市优先招牌广告，鱼灯巡游优先全息装置，维修优先工具。仅改变排序，全部候选可检索。

在赛博朋克数据内维护五组配色、照明与全息表现候选；视觉偏好下拉合并题材候选与现有通用选项。题材及场景变化时刷新候选，原已选值仍保留。不同题材混选只合并各自候选，不自动给场景加元素或颜色。

全息鱼灯用“全息鱼灯（悬浮游动的鱼形投影）”，实体灯用“鱼形实体灯笼（可见灯体与吊线）”，避免概念含混。短语已包含关键形态，后续关系由生成流程按规范补齐。

不新增外部服务或依赖，不更改规范、模型请求协议与密钥存储。验证新候选可达性、场景排序、视觉联动、旧值兼容及桌面/手机展示。
