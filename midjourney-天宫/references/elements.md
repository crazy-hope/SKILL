# 元素

元素库用于选择，不是必须全部出现的清单。用户明确点名的元素全部保留；未指定时按预算选择，不能自动堆入天环、浮山、瀑布、天梯、体积光和飘带。

用户没有说“随机”时，只使用主 Skill 默认与用户点名元素，不从可选库抽取。用户说“随机场景”时，只在未锁定类别中选择兼容项；朝代默认仍为“泛中国天界宫廷”，除非用户明确要求朝代也随机。

## 元素预算

每张图使用：

- `0–1` 个主建筑系统；选择 `F1-6 无建筑` 时为 `0`，并禁止自动补入宫殿、楼阁、亭台、塔楼、门殿或屋顶；
- `1` 个主视觉尺度主体，可由建筑、天界结构、地形、自然奇观或自定义主体承担；
- `1` 个天域载体，默认平整云海；
- `0–1` 组人物，默认一名极小人物；选择 `F2-4 无人物` 时为 `0`；
- `0–1` 个自然锚点；
- `0–2` 个从属奇观；
- `0–1` 套墙面系统；用户明确选择多种墙面时全部保留，但指定一种为主墙面，其余作为从属边界；
- `0–1` 个织物系统。

用户指定超过预算时仍须全部保留，但要明确一个主奇观，其余退到中远景，不能等权争夺画面。

建筑和人物都是可选元素。无建筑时，由用户选定的天界结构、地形、自然奇观或自定义主体建立主轮廓；无人物时，使用墙体砌块、台阶、门洞、树木、舟、灯火、道路宽度、云层距离或其他已选可见关系证明尺度，不强行补入人物。若建筑与人物同时为空，仍需从已选元素中明确一个主视觉主体，不能把所有内容写成等权背景。

## 自定义入口

各元素子项的最后一项保留为自定义入口：`F1-7 自定义主体结构`、`F2-6 自定义人物`、`F3-4 自定义天域载体`、`F4-25 自定义附加元素`、`F5-2 自定义摆放`。这里的“最后一项”是位置规则，不是固定编号：以后新增固定项时，把固定项插在自定义入口之前，再将自定义入口顺延到新的末号。选择任一自定义项时必须同时提供对应文本；只有编号没有文本时继续追问，不擅自猜测。自定义内容服从用户原文，只在构图、镜头或物理承载出现真实矛盾时询问。

## 元素摆放方式

摆放方式属于元素模块的必选子项。用户已经说明具体位置时，锁定为自定义摆放并保留原始位置文本；用户没有说明时，通过缺项问卷提供：

- `F5-1 随机摆放（推荐/默认）`：从下表与当前构图、镜头兼容的位置中受控随机；
- `F5-2 自定义摆放`：用户必须同时提供摆放文本，例如 `F5-2：主宫殿右中，仙女中间偏左，瀑布右中，古松左下`。

仅选择 `F5-2` 而没有摆放文本时，摆放方式仍未完成，必须继续追问。只有用户选择推荐/默认、使用全局跳过口令，或明确选择 `F5-1` 时，才自动采用随机摆放。

### 摆放约束

- 优先级为：`用户明确位置 > 已锁定构图 > 镜头可见性与物理承载 > 九宫格兼容随机`。
- 九宫格表提供候选关系，不覆盖构图。中心构图可把主宫、天门或巨轮置于正中；三分、偏心、留白等构图应把主体移到相应位置。
- 随机摆放只在元素的兼容格位中选择。同一画面优先把不同元素分散到不同格位，避免所有物体堆在一个区域；一个跨格的大体量元素仍只登记其视觉重心。
- 已选择人物时，随机人物位置不固定在画面底部：约 `60%` 的兼容结果从左中、正中或右中选择，约 `40%` 从左下、中下或右下选择；构图不兼容时重选位置，不为满足概率破坏主体关系。选择无人物时跳过人物位置抽取。
- 人物位于画面中段时，必须完整站在远景桥廊、悬空平台、宫殿露台、石阶转折处或崖壁栈道上；位于下段时也必须站在道路、平台、廊道、台阶或其他承载面上，任何位置都不能悬浮。
- 极小人物背后优先安排云海、雾白天空或低细节墙面形成清楚轮廓。人物只能用来作为空间尺度标记，不得因位于中段或正中而变成叙事主体、视觉焦点或角色海报主体。
- 瀑布可由右上水源延伸至右中，但必须是一套连续水体；不能把水源和瀑布主体写成两个互不相干的奇观。
- 批量随机时，为每张登记元素位置；兼容位置用尽前尽量不重复同一主元素的位置，并继续服从整批锁定的构图与镜头规则。
- 最终提示词必须把位置转写成可见英文空间关系，例如 `at the lower center of the frame`，不能只列元素名称或九宫格标签。

| ------------ | ------------------------------------------------------------------ |

| 成年男性仙者 | 成年男性仙者，束发或冠发、古代长袍或宽袖外袍；轮廓克制，不展示面部特写 |
| 成年女性仙者 | 成年女性仙者，束发、古风高髻或层叠长衣、裙袍；轮廓端庄，不性感化、不展示面部特写 |
| 两三人成年仙者       | 两三名成年仙者，古风衣袍、束发；仅用于对话、同行或仪式关系，仍是极小尺度标记，男女随机                       |
| 无人物       | 不生成任何人物；可用已选结构尺度、树木、舟、台阶或稀疏灯火建立尺度 |
| 自定义人物   | 完整保留用户给定的数量、身份、年龄、服装和尺度要求；缺少文本时继续询问 |

### 仙女头型

仙女头型规则保留为：优雅的高云髻，部分黑色长发挽起，其余长发垂至腰间；佩戴精致白玉发簪、纤细克制的金色步摇和少量珍珠流苏；两缕柔和鬓发修饰脸型。只有在人物局部编辑、用户明确要求人物可辨或选择 `C18 肩后构图 OTS` 时，才在中文提示词和英文提示词中展开这组造型关系；其他情况下不展开发型细节，避免诱导 Midjourney 放大人物。用户选择自定义人物或明确指定其他发型、发饰时，以用户文本为准。

存在人物时，人物只能用来作为空间尺度标记，必须保留 `xian/仙者/古风背影` 等身份锚点词，不可出现现代服饰或姿态语义。除非用户明确要求其他尺度或明确选择 `C18 肩后构图 OTS`，用“远景中极其渺小、被主体巨构衬得微不足道、面部不可辨”表达尺度，不使用画面高度百分比、像素高度或数值比例。默认和单人选项必须明确全画面只有一名人物，将身份、远景尺度、站立姿态和唯一位置合并为一句，不分别描写一个近景人物和一个远景尺度标记。英文单人关系句可用 `exactly one adult Chinese xian in ancient robes, standing still on [one supporting surface], seen from behind as a barely visible tiny silhouette dwarfed by the primary structure, no facial detail, the only person in the entire scene`；女性或男性按已选身份替换，中文与英文人数、位置一致。人物必须完整站在平台、桥、廊道、台阶、浮台、草坡、崖顶或其他已选可承载表面；不悬浮、不与栏杆或布料粘连。用户明确选择两三人或自定义多人时才使用对应人数，仍不添加额外的大人物或重复身影。`C18` 仅允许把同一名成年背影人物提高为画面一角可辨认的肩背轮廓，相机与人物必须共享承载面，不另补远景分身，人物仍不得遮住主主体或变成正脸英雄海报。选择无人物时跳过全部人物模板。批量任务默认锁定人物是否存在、数量、性别策略与尺度，只有用户明确要求时才逐张变化。

无论中文或英文提示中出现人物，人物关系句需保持一致：即便为最小尺度角色，也需保留 `仙者/ancient xian/immortal back-view` 等身份锚点表达，避免被理解为现代人物。 

## 中国古代宫廷建筑

朝代只提供可见的幻想化建筑线索，单图只选一个主体系，不宣称历史复原。批量任务默认锁定同一主体系；只有用户明确要求朝代变化时才逐张更换。

| 体系                   | 可见线索                                                                         |
| ---------------------- | -------------------------------------------------------------------------------- |
| 泛中国天界宫廷（默认） | 深檐、斗拱带、柱廊、宫墙、厚重宫基、连桥与可行走平台组成连续巨构                 |
| 汉代线索               | 高台、阙门、简练厚重屋面、强轴线与大块体量                                       |
| 唐代线索               | 宽阔舒展屋面、深远出檐、雄健柱网、赭红或朱红木构、横向恢宏轴线                   |
| 宋代线索               | 精密模数化斗拱、层叠楼阁、较轻秀的檐线、灰青或深色瓦、细密结构节奏               |
| 明清线索               | 严格轴线、红墙、层级清楚的屋顶与院落系统、克制使用黄或青绿琉璃瓦；不复刻具体宫殿 |
| 无建筑                 | 不出现宫殿、楼阁、亭台、塔楼、门殿、屋顶或其他建筑；由已选非建筑元素承担主体       |
| 自定义主体结构         | 完整保留用户文本，可为自定义建筑、巨墙、天体结构、地貌或其他主视觉主体             |

不要在同一主建筑上平均混合唐代雄浑屋面、宋代精细楼阁和明清强装饰。用户要求混合时，指定一个主体系，其他朝代只作为局部从属层。

选择 `F1-6 无建筑` 时，上表中的朝代与宫廷造型语法全部停用；不得因为风格名称含“东方天界”而偷偷补入飞檐、斗拱、宫墙或远景宫群。选择 `F1-7` 时，以用户文本定义主主体及其造型边界。

## 天界结构与地形

| 元素        | 使用规则                                                             |
| ----------- | -------------------------------------------------------------------- |
| 天环        | 最多一个，作为局部出画的巨大建筑环、天体环或远景结构；不是发光传送门 |
| 天梯        | 实体宏大阶梯通向云上宫城，必须有起点或可见承载关系                   |
| 云梯        | 由云雾凝成但仍有连续踏步节奏，边缘柔化，不与普通云团混成噪声         |
| 石梯        | 厚重可行走石阶，显示磨损、宽度与人物尺度；适合崖壁和宫基             |
| 悬崖 / 峭壁 | 只设一条主崖体或巨壁，保留岩层厚度并与宫基建立连接                   |
| 浮山        | `1–3` 座为宜，主次明确、被云雾部分遮挡；不生成满天碎石               |
| 浮台        | 必须有厚度、结构下缘和可站立表面；可悬空，但不能像薄纸贴片           |

天梯、云梯、石梯默认三选一。悬崖与峭壁按同一地形系统处理，不重复计数。

## 水体

| 元素 | 使用规则                                             |
| ---- | ---------------------------------------------------- |
| 瀑布 | 有清楚水源、高差与水汽落点；优先一条主瀑或少量远瀑   |
| 水幕 | 宽阔连续水面从宫基或崖缘垂落，作为一个大轮廓面       |
| 水帘 | 较细密、可分缕的垂直水线，常位于檐缘、洞口或庭院边界 |

单张默认只选一个主水体系统。水幕、水帘和瀑布不能在没有来源与落差时悬空出现。

## 墙面

墙面是构图中清楚可见的连续边界或大体量面，不是建筑上顺带出现的一小段普通外墙。未选择墙面固定项时，不禁止宫殿体系自然拥有普通宫墙；只有明确选择 `F4-20` 至 `F4-24` 时，才把墙面登记为独立可见元素。默认只选一种墙面；用户明确选择多种时全部保留，但必须指定一种主墙面，并让其余墙面退为中远景边界或位于不同空间层。

| 选项 | 墙面 | 使用规则 |
|---|---|---|
| `F4-20` | 白墙 | 连续的暖白、灰白或冷白灰泥/石灰质墙面，保留细微旧化、灰阶和接缝；避免纯白过曝、现代极简盒体或无厚度白色贴片。 |
| `F4-21` | 石墙 | 厚重石块、石板或岩层砌筑的承重墙体，显示砌缝、层理、风化与墙体厚度；不能用普通悬崖冒充石墙。 |
| `F4-22` | 红墙 | 低饱和朱砂、赭红或暗红墙面，表面哑光并保留旧化层次；避免霓虹红、塑料亮红或全画面红色罩染。 |
| `F4-23` | 云墙 | 局部连续、具有可读厚度与高度的密云边界，边缘柔化但墙面轮廓清楚；不能变成满画面棉花云堆或发光能量墙。 |
| `F4-24` | 水墙 | 局部连续的垂直水体边界，必须写清水源、垂落方向、落点或水汽承接；不能变成无来源能量墙。 |

实体墙面（白墙、石墙、红墙）必须依附建筑、宫基、地形或可见地表，并可通过裁切延伸出画框来建立尺度。云墙与水墙可独立存在，但仍要有明确空间位置；水墙必须具备物理来源与落点。选择 `F1-6 无建筑` 时，用户明确选定的墙面可以独立承担非建筑主视觉边界，但不得因此自动补入屋檐、斗拱、门楼、宫殿或其他建筑。

`F3-2` 描述承载整个开放天域的单侧体积云墙或云峰；`F4-23` 描述场景中局部可见的连续云墙面。两者同时选择时合并为同一套云系统，由 `F3-2` 定义天域、`F4-23` 定义墙面轮廓，不生成两套互相争夺的云墙。`F4-3` 巨大水幕与 `F4-24` 水墙都属于宽阔连续水面；同时选择时合并为同一套水系统，由水幕定义垂落形态、水墙定义围合边界。`F4-13` 水帘仍表示较细密、可分缕的水线，不与水墙互换。

## 自定义附加元素

`F4-25` 接受目录之外的任何附加元素文本。它与其他 `F4` 项一样受元素预算与主次关系约束；若用户把该元素指定为主视觉主体，它可以在 `F1-6 无建筑` 时承担整幅画的巨构或尺度主体。`F4-0` 与 `F4-25` 及其他附加元素互斥。

## 织物

| 元素 | 使用规则                                                   |
| ---- | ---------------------------------------------------------- |
| 布帘 | 较厚、重量感强，依附门洞、柱间或殿内深檐；不遮主轮廓       |
| 薄纱 | 半透明、低对比，放在近中景制造层次；保留后方结构可读性     |
| 丝带 | 数量少、路径清楚、统一风向，只作视线引导；不变成魔法能量带 |

织物默认三选一，并与人物衣摆、柳枝、云流保持同一风向。

## 兼容速查

- 冷青柱光优先搭配粗柱旁斜望、深檐、宋代线索、云海或水帘。
- 天梯优先搭配轴向正望或贴地仰望；浮山优先搭配侧向压缩或高台轻俯。
- 古松适合厚重、肃穆构图；杨柳、薄纱和水帘适合空明、柔和构图。
- 白墙适合雾白、空明和留白构图；石墙适合厚重、低机位或极端尺度构图；红墙适合轴线、框景和宫廷层次；云墙、水墙适合围合、分层或引导视线，但不能被写成发光能量屏障。
- 草原与宫城同时出现时，草原是开放负空间，不能塞满亭阁、树群和浮山。
- 天环已经承担主奇观时，最多再选一个瀑布、浮山或天梯类从属奇观。
- 自定义摆放与已锁定构图或镜头发生真实矛盾时，保留两项用户条件并询问；随机摆放发生冲突时直接重选兼容位置。
