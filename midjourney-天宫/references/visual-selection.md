# HTML 图鉴入口

保留[完整 HTML 图鉴](../visual-guide.html)：169 个选项逐项配有简图，包含全部构图与镜头，可离线浏览、搜索、放大和复制选项。目录更新时同步检查覆盖。

用户要求界面选择、查看构图示意或理解 Skill 时，提供此独立 HTML 文件。不再创建或嵌入对话内可视化选择器。默认简洁文本和完整文本问卷继续保留。

- 用户在图鉴中查看并复制选项编号或名称，回到对话提供选择与场景要求；沿用[缺项问卷](interactive-questionnaire.md)的默认和兼容规则。
- 用户只要求解释选择时，解释空间、光色与人物关系，不同时生成提示词。请求生成时，按已提供条件执行，后续修改保留其他已锁定内容。
- 示意图仅帮助理解，不作为 Midjourney 图片参考。任何画幅都不强制近景框架。
- 仙女只采用半绾披发；发型示意是独立轮廓说明，不增加场景人物，也不改变人物尺度。
