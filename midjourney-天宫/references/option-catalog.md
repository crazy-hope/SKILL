# 完整问卷选项

本文件是完整选项源。完整入口显示当前缺失子项的全部固定选项；简洁入口可摘选关键组的相关项，镜头等自动匹配，详见[缺项问卷](interactive-questionnaire.md)。仙女发型固定半绾披发，不作为待选项。编号是稳定接口，不因推荐项、构图兼容性或显示顺序改变；推荐项用视觉标记突出，不重编号。不兼容项仍显示，并标注适用条件。可选的单选组额外接受“随机”；仙女固定发型不参与随机；`F4` 为多选组。

## F2 人物

### F2-V 人物可见程度

可选属性，未指定按 V1；无人时跳过。V1–V3 默认均严格小于画面高度 5%，约 2% 为目标，仅作尺度参照；建筑巨构与云海为主体，选择可见程度不自动授权放大人物。简洁入口按需展开，完整入口随人物组展示，选择发型不自动提高可见程度。

| 编号 | 选项 |
|---|---|
| F2-V1 | 极小剪影（默认）：遥远全身背面或侧面剪影，约画面高度 2% 且严格小于 5%，仅作尺度参照 |
| F2-V2 | 轮廓可辨：小型全身人物，发型与衣袍轮廓可辨 |
| F2-V3 | 人物可辨：人物衣饰可读，环境仍为主，不自动变成肖像 |
