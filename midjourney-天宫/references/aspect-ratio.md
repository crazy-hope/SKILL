# 画幅

画幅必须转化为构图行为，并以整数比例参数写在提示词末尾。未指定时使用 `--ar 16:9`。

| 画幅 | 构图行为 | 适合场景 |
|---|---|---|
| `21:9` | 巨构横向延伸，开放天域至少占一大段横向空间；避免把主体压成细线 | 天城天际线、巨壁与云域对置、长桥和无尽柱廊 |
| `16:9`（默认） | 近景框架、中景承载面、远景云域三层齐全 | 通用电影 CG、随机单张和系列 |
| `3:2` | 强化单一消失点或对角线，减少横向从属元素 | 平台望宫、桥廊、悬崖侧望 |
| `4:3` | 增加上方压顶巨构或下方云峡的垂直层次 | 深檐、宫基、建筑开口 |
| `4:5` | 主巨构沿侧边或顶部入画，人物置于下部承载面，保留竖向空域 | 巨柱、瀑布、水幕、天梯 |
| `9:16` | 用单一垂直事件贯穿画面；避免上下各塞一座完整宫殿 | 峭壁、悬空宫基、天梯、瀑布 |
| `1:1` | 只保留一个框景关系和一个主奇观，四周留出空气 | 图标式神域入口、圆门框景 |

## 规则

- 批量系列默认锁定同一画幅；只有用户明确要求多画幅测试时才逐张变化。
- `--ar` 后只写整数比，例如 `--ar 239:100`，不写小数比例。
- 极端宽幅或竖幅会放大随机失控；应减少从属元素，并加强近景裁切、主消失关系和人物落位。
- 不因“宏大”“天城”自动改成鸟瞰；画幅不决定机位。
