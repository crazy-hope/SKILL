# 画面基调

本目录是规范项目的配套基调资源，由用户于2026-10-31明确要求建立；不属于通用规范的强制规则，也不会自动成为所有任务的默认。完整规范仍为V16，历史版本不改。

## 已保存基调

- [巨构荷塘-写实柔和](巨构荷塘-写实柔和.json)：保存当前工作台五项原文。名字由用户指定，不额外改写五项内容或自动加入巨型荷叶等对象。
- 默认携带用户指定的Midjourney参数：`--profile ny6wlzu --chaos 15 --ar 16:9 --raw --hd`。

## 文件与使用

每个基调用一个UTF-8 JSON文件：`name`为下拉显示名称；`values`包含style（画风题材）、color（色彩）、camera（镜头机位）、mood（情绪）、moment（瞬间状态）五个字符串；`midjourneyParameters`为参数字符串，无参数可写空字符串。不得放入密钥或主体描述。

工作台在构建时读取本目录所有JSON，校验名称唯一与字段格式。添加或修改文件后，在`tools/prompt-builder/versions/v19/输出/`运行`npm run build`，然后刷新页面。Python服务无需重启、日常不需要npm或CDN。

在“画面基调”的下拉框中选择基调，会替换五项内容；描绘内容、负面、目标模型、数量保持。参数以“Midjourney 参数（仅目标为 Midjourney 时使用）：”独立行附在画风题材末尾，可修改参数或删除整行。保留条件行名称可确保新MJ结果自动补齐参数。手改后下拉显示自定义，重新选择可恢复该文件内容。“恢复五项默认”恢复原始五项并移除该参数行。

实际五项（含参数行）进入既有草稿、历史、备份与下载，不依赖隐藏的预设标识。旧草稿/历史不会追补参数。新MJ结果在完整双语末尾附加参数；相同参数去重，冲突拒绝保存。其他目标不自动附加；原有非MJ参数防混用检查继续有效。此处理仅用于新生成结果，不改写历史。

## 来源及边界

2026-10-31核对原Chrome页面五项值，与V19默认五项一致。参数由用户追加。[Midjourney官方参数表](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List)同日查阅：参数置于正文末尾，列出profile、chaos、ar、raw及hd；HD页面说明适用于V8.1，不据此宣称所有版本支持。本预设不自动指定版本，profile代码权限与出图效果未经验证。
