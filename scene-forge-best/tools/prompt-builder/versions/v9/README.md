# 提示词工作台 V9

日期：2026-10-16；已交付。基线：[V8](../v8/README.md)。继续使用 [规范 V6](../../../../versions/v6/输出/规范框架v6.md)。

题材、想画什么、必须包含、视觉偏好、创作自由度五个多选卡片，已选项全部显示在各自的纵向滚动区域。滚动条清晰可见，可用滚轮或键盘滚动到后面的标签，直接点击 × 删除；长标签自动换行，删除按钮保持可见。

桌面区域利用下拉框与自定义输入框之间的剩余空间；平板和手机使用有界高度，选择数量增加不会把卡片无限撑高。手机仍按原有方式纵向浏览页面。画幅、模型、数量保持单选，负面输入不变。

旧服务运行中时先在对应终端按 Control+C，再双击 [根启动器](../../../../启动提示词工作台.command)，确认页脚“工作台 V9”。草稿与历史保留，V8 的候选分配及生成规则不变。

本地 Node 32/32、Python 32/32 通过。浏览器验证五个区域滚动到底、删除/刷新、桌面一屏、手机长标签与横向溢出；未调用真实模型或出图。
