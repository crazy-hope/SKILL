# 长廊空间

## 场景说明

以连续通行与柱梁节奏组织空间。辽阔感须同时有横向净跨、头顶净空和向远处可追踪的路径，不是把普通窄廊复制得很长。

## 空间细类

- 单侧开廊：一侧连接宫墙，另一侧通向云域。
- 双侧柱廊：中央大通行轴，两侧疏朗柱列承托同一屋盖。
- 转折回廊：路径转向内庭或云崖，转角有共同支承。
- 分层长廊：上下层由阶台连接，各层保留独立净高，不能密叠薄片。

## 物件调用

核心为[长廊](../objects/长廊.md)；需要细化时读[柱与柱础](../objects/柱与柱础.md)、[屋顶与屋檐](../objects/屋顶与屋檐.md)。云域、近身家具、主宫或巨松按实际内容选择。廊桥额外读桥文件，解决下构与跨越而非只加廊顶。

## 尺度与连接

踏步/坐凳→柱础→疏朗大跨与高梁→连续长廊→所接宫体或终景。家具不能等比放大到失去人尺度；廊深必须由可见开间递减证明。转角处允许不同消失点，全部属于同一相机空间。

## 可选观看关系

沿轴向深处、横看几组大跨、从外侧看连廊立面、从下方看廊桥腹部；人物可以侧向穿过而非总站前景角落。近檐裁切不能把中央开间压成窄门洞。

## 组合与检查

可连接深殿、观景台、水庭或跨云桥。只有接入的空间真正出现时加载相应场景；不把多个场景说明整段串接。检查净跨、净高、通路与支承同时成立。

可选片段：『几组疏朗高柱承托同一深檐，宽阔地坪跨过多个正常使用开间，柱列向远端转折，外侧云域与廊下空气直接相通。』

## 命名示例

仅在明确要求或选用“盘龙柱茶廊单瀑”方案时加载以下组合；不把茶几、巨松或瀑布变成长廊默认元素。

### T2. 盘龙柱茶廊单瀑

- 适用：用户要求带生活痕迹的超长宫廷长廊，同时从廊内看见巨松、分层云海与瀑布天宫。
- 空间关系：数百个身体宽的深檐长廊沿一个稳定消失系统延伸；两侧盘龙柱必须具有柱础、柱身、斗拱和屋檐的连续承重关系。高处梁底与地坪留出巨大净空，中央通行轴保持辽阔，两至三张古代低茶几与少量烛光放在边带，成年仙女站在长廊中部。外部一棵巨松位于近中景，三至四层云雾之后是一座主天宫，且只从该宫流下一条贯穿多层云域的巨瀑。
- 机位与尺度：人眼高度的中轴深殿向外、克制偏轴或侧向跨廊机位；画幅、焦距和人物距离按[共用相机状态](../scale-and-space-rules.md#相机状态画幅焦距与拍摄距离)。人物大小由所在开间、近旁茶几、柱础层级与既定相机投影决定，与柱列服从统一地坪接触和光照。茶几与烛光只作相邻使用层参照，不得把空间变成宴席。
- 连续尺度链：`成年仙女与低茶几 → 巨柱柱础和地坪 → 盘龙柱列与深檐长廊 → 墙外巨松和远方天宫 → 单一跨云瀑布与云海终景`。
- 避免失败：不要普通人类尺度走廊、无承重关系的龙雕柱、四处摆满家具、连续栏杆、多条同等瀑布、过曝白水或被中景墙封死的外部天域。
