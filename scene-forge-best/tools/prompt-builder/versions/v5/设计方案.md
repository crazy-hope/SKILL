# 工作台 V5 设计

在现有生成流程中增加目标模型适配，不新增必填项或新服务。

规范第 11.3 节维护可读说明及 JSON 登记块，作为模型规则与来源的唯一来源。服务端每次从实际读取的完整规范中提取登记块，按目标名称识别家族；家族匹配不代表具体版本通过验证。空值/未知模型使用通用规则并标记待核实；多模型混填返回澄清，保留原值。

将本次适配规则放在系统消息末尾，明确优先于其他家族示例；用户九项原值仍在用户消息中。输出继续采用七字段双语方案；服务端另外附加受控 target 元数据。非 Midjourney 的中英文正文含专用参数则报错，不存为成功结果，不自动重试或静默删参数。

结果来源详情显示适配信息，下载和历史备份保留该信息。旧历史缺少 target 时不补写。官方来源仅作为文本显示，避免导入备份创建任意可执行链接；无请求时抓取网页。密钥存储隔离和已有布局不变。

验证：针对请求内容与错误边界的单元/HTTP 测试，备份元数据兼容测试，模拟生成及来源显示、下载检查。模型效果与语义一致性仍需真实生成和出图判断。
